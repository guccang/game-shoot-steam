# 世界特色任务入口

晴叶营地麦田前新增「晴叶回信驿」：绿屋顶木制驿牌、信封告示与侧挂邮筒。靠近点击「查看委托」或按 E，即可接取、继续或重玩关联故事。世界地图用信封标记地点。取消进入营地区域就出现的固定底部故事按钮；右侧「故事」仍可浏览全部目录，实际接取必须靠近关联地点。

当前驿牌关联已有六章主线与两条委托，解锁顺序、战斗参数、借用装备与奖励沿用原表。进入章节后世界入口隐藏，暂离或交付后重新出现；章节临时人物、线索和道具仍按原清理规则移除。

## 新增地图任务点

在 `src/config/story-posts.js` 的 `STORY_POSTS` 加一行：

```js
// 地图ID和章节ID必须来自现有注册表，坐标选择实际可达陆地。
{
 id:'valley-post', mapId:'jiuzhaigou', name:'湖畔回信驿',
 x:1485, y:1625, approach:{dx:0,dy:30}, radius:120,
 chapters:['sunleaf-01']
}
```

此例仅展示扩展方式，本轮没有在九寨沟投放新任务。建筑、世界标签、地图信封、当地目录、距离权限统一读取这张表，不需要为每个地点再写入口判断。`chapters` 填已有章节ID；新增特色故事的剧情、任务、人物和清理继续写入原章节表。配置会检查无效地图、故事、重复ID与非法坐标。

入口位置与故事场景独立：从别的地图接取既有章节，会进入该章节场景；暂离、交付和刷新恢复后返回接取时的原地图与位置。新任务希望在当地发生时，应把章节自身 `mapId` 和 `world.sites` 配置在当地。森林入口自动预留树冠空间；其他地图的具体落点仍需实机确认不在水域、山体或建筑内。
