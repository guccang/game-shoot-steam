# 森林巡游美术生成任务单

复制本任务单，为每项美术任务保存一份至 `docs/art-tasks/<任务标识>.md`；已有对应任务单时继续更新。执行依据为[游戏美术资源生成标准](art-generation-standard.md)与 [AGENTS.md](../AGENTS.md)。复制到子目录后，将这两个链接分别改为 `../art-generation-standard.md` 与 `../../AGENTS.md`，其他相对链接也按实际位置调整。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

默认按 **imagegen + 程序绘制 + SVG 实现动态效果与交互 → 实机确认 → imagegen精修 → PNG替换与复核** 推进。本任务单分阶段填写，开发阶段不要求最终PNG齐备；后续精修项明确标注“后续阶段”，不得以空白模板或生成预览代替当前阶段验收。用户明确要求本次直接生成或替换PNG时，记录该范围并验证已有动态逻辑。

## 4 动画任务补充

静态资产说明动画不适用原因。程序或SVG动画填写实际时钟、局部动作和录制路径，不虚构视频来源或序列帧；使用视频和序列帧时填写来源字段。猫身体继续使用真实连续帧，当前仅生成正面待机和移动，不增加多方向身体序列，也不以单张imagegen图片变形代替身体动作。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 【idle / move / hit / death等，逐项填写】 |
| 时钟、帧率与循环 | 【程序/SVG动画填时钟及循环方式；视频或图集另填帧率、帧数，目标与实际结果分别记录】 |
| 动作源码或源视频与连续片段 | 【程序/SVG填源码入口；视频或图集填源片路径、哈希、源时间和帧索引】 |
| 尺寸、裁切和缩放 | 【固定逻辑尺寸与锚点；有序列帧时使用整段共用裁切参数，不逐帧重置】 |
| 起停与状态衔接 | 【姿态匹配、暂停、减少动态、驾驶等】 |
| 局部真实动作 | 【脚步、尾巴、翼、履带或旋翼如何变化】 |
| 独立部件 | 【小手、枪、后坐、枪口、炮塔或控制器的连接点】 |

## 5 生成指令

记录本轮imagegen实际提示词、参考图及请求/响应位置；未使用生成图片时说明原因并记录程序或SVG实现入口。开发阶段生成参考或阶段性图片，先配合程序做出动态效果；精修阶段提供已确认实机截图与PNG风格参考，明确需要分开的运动部件。下段按阶段修改后使用。

> 本轮为【动态效果开发的参考/阶段性图片，或美术精修与PNG替换】。延续《森林巡游》的二维森林绘本风格，采用提供的实机参考。主体为【对象】，用途为【用途】，关键识别结构为【特征】。采用现有三分之四俯视比例、森林绿或材质偏色描边、柔和草木与奶油配色、有限平涂，左上受光、右下冷影。按【尺寸与锚点】制作，分为【图层与独立部件】，交付【本阶段格式；精修为透明PNG或所需PNG图集】。与【邻接对象】通过【地面过渡】衔接，保持【指定区域】开放。动态进度、数值、状态及动画时钟由程序控制，不烘焙进图片。动作要求为【适用时填写】。不要改变【已确认效果、接口和保留项】。

> 排除：写实摄影、另一套三维风格、纯黑厚描边、满屏碎纹、规则对称岸线、漂浮影子、主体比例跳变、复制帧假动画、额外方向、烘焙操枪部件、文字水印和不透明地板。
