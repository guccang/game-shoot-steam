# 手机单行 HUD 与战斗音频层次

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称 / id | 手机单行资源环境栏 / mobile-single-row-hud |
| 类别与用途 | 正式 DOM HUD 布局；同时优化战斗声音主次 |
| 目标 | 金币、木材、季节、昼夜、天气、瞄准同一行；资源只显示向下取整的 k/w/Y 数量 |
| 数量和变体 | 320、390、桌面，白昼/夜晚；沿用所有原图标 |
| 保留项 | 森林绿、奶油底、环境圆环、辅助名称、资源精确量提示；场景与所有角色动作 |
| 制作路线 | CSS 排布与资源格式化，无新增插画或位图 |
| 参考 | 用户手机截图；现有 environment-pictures.css 与 resource-icons.css |
| 场景 | 正式森林战场，保留秘境专属状态栏规则 |

## 2 造型与空间

顶部左侧资源，右侧季节→昼夜→天气→瞄准，保持图标轮廓。缩小资源间距和窄屏按钮尺寸，回收原第二行空白；波次卡恢复第一行下方。不新增地面物件、碰撞、投影或遮挡，地面衔接与邻接造型不适用；HUD 沿用固定奶油底与森林绿，不参与场景昼夜染色。

## 3 技术交付

- 屏幕 CSS 像素，顶部安全区锚定，HUD 图层。320 屏左右各 10 像素；窄屏环境按钮 36×40、图标 26×26、圆环 32×32；资源按钮 24×30。桌面保持既有大小。
- 原 SVG 图片与透明度保持，无新增图集、画布、解码或资源请求；声音继续按需缓存，召唤物限制共享发声频率及并发。
- 正式文件：`src/styles/environment-pictures.css`、`src/ui/resource-number.js`；检查入口 `inspectHudCompact`。

## 4 动画任务补充

不新增角色或图标动画，源视频、裁切、帧数不适用。保留圆环、点击响应、主角/怪物/载具与召唤物原有动作及独立武器。音效按真实来源区分，不改战斗时钟和随机数。

## 5 制作指令

沿用现有森林绘本 HUD 图标和配色，只收紧排布；不增加描述、贴图、视觉特效或世界碰撞。不以截断资源数字或隐藏天气图标换取单行。
