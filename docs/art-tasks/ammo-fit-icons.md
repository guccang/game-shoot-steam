# 弹药图标与当前装备适配
依据：[项目约定](../../AGENTS.md)、[美术标准](../art-generation-standard.md)、[手机框架](../ui-foundation.md)。

## 目标与设计
开发阶段使用现有SVG图标体系扩展四种弹药，背包／整理／购买／当前装备共用同一入口。通用子弹为两枚窄铜壳尖弹，标准炮弹为单枚长绿弹头，重型炮弹为宽体红棕弹头及双底带，潮汐弹罐为方圆水罐、水滴与顶部接口；轮廓、宽度和细节差异同时可辨，不只换颜色。
颜色沿用森林描边#315c43、铜金#d3b776、草绿#8eab78、红棕#c98670、水青#93bcb4、纸白#fff6dc；字体沿用项目本地字体。64×64 SVG视框、无底板、中心锚点，商店48px、装备提示40px，背包按既有容器缩放，无外部图片或缓存。

## 信息结构
保留猫猫／载具分类；其下只展示该分类的当前装备和所用弹药，载具显示真实主炮。对应商品前置，并用文字“当前武器适用／当前载具适用”标记，其他商品明确标为不适用，仍允许提前储备。无主炮、近战或独立供给时说明无需实物弹药。继续展示每包数量、重量、库存、用途和正式购买／制作按钮。
沿用ui-panel、ui-inset、ui-section、ui-button，无新字体或独立动效。商品采用图标加名称的单列货架；匹配信息优先，删除重复的通用负重警示段落，超载购买确认仍保留。触控至少44px，窄屏和横屏正文滚动。

## 逻辑与保留项
适配读取正式ammoKind、game.weapon()与vehicleWeapon；主炮换装后按当前主炮匹配，不按车型名猜测。背包／载具分流、价格、制作、负重确认、保存与真实弹药消耗不变。无世界锚点／碰撞／动画变更；此任务不用生成位图，沿用SVG入口，PNG精修不适用。
