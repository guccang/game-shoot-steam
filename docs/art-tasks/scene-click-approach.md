# 建筑、楼梯与床的点击行走任务单

本任务按[美术生成任务单](../art-generation-brief.md)的六节填写，执行[美术标准](../art-generation-standard.md)与[项目合同](../../AGENTS.md)。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称、标识、类别 | 场景点击行走；`scene-click-approach`；透明交互层 |
| 阶段、目标 | 动态交互开发；点击建筑本体或门前空地，走到门口后进入；点击楼梯和床，走近后执行原候停动作 |
| 数量 | 15个既有营业建筑入口；一楼床、各层楼梯。仓库打开既有室外存取页面 |
| 保留项 | 建筑修复与传奇权限、室内外坐标、碰撞、候停与防重复、原真实猫动作、独立手持武器 |
| 制作路线 | 现有图片和Canvas绘制完全复用，只添加透明DOM触点及正式运动输入，无生成图片或SVG需求 |
| 参考与确认目标 | `src/rendering/cottage.js`、既有营业房；触点覆盖可见本体，不增加悬浮名称提示 |
| 后续精修 | 本轮不变更图案，不需要PNG替换 |
| 使用场景 | 晴叶森林营业建筑、小屋室内 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 剪影、变体、主次 | 不改既有建筑、床和楼梯剪影，透明热点无新造型 |
| 地面衔接、邻接、光向 | 沿用正式世界、家具底座和昼夜绘制 |
| 活动空间 | 建筑门前扩展到门坐标左右36、前后44世界单位；移动仍检查墙、树、家具及载具障碍 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸、锚点 | 建筑取正式配置的宽高与门坐标，触点覆盖屋顶至门前；床取原底座，楼梯取原梯身与落脚点 |
| 像素尺寸、透明背景 | 无新增图像；触控区至少44×44 CSS像素，全透明 |
| 分层 | 既有世界/家具Canvas层不变，DOM命中层在固定HUD下；室内按视窗裁切 |
| 程序职责 | 每次点击替换临时移动目标，分帧寻路，输出正常移动向量；原业务负责进入、切层和睡眠保存 |
| 接口与保留 | 稳定建筑/家具ID、脚底、真实动画和武器绘制保持；意图不写入存档，换角色或楼层清理 |
| 碰撞与通行 | 室外复用正式任务路线碰撞；室内注入`cottageBlocked`逐段扫掠，目标阻塞不传送 |
| 昼夜 | 同一套触点和既有正式昼夜画面 |
| 文件与入口 | `src/config/scene-approach.js`集中目录和数值；`src/core/navigation/scene-approach.js`负责规则；`src/ui/world-workshop.js`、`src/ui/cottage-approach.js`负责触控 |
| 内存和缓存预算 | 不增加位图、图集、音频或画布；最多17个透明按钮，一个当前搜索，4096节点预算，每逻辑步最多1.5ms/256批 |
| 必需资源及失败 | 沿用既有必需图集和加载错误；无备用美术；无可达路径时停止移动 |

## 4 动画任务补充

本轮无新动画资产。实际行走继续使用`Game.update`、`updateCottage`与`updateCatMotion`；原真实视频连续帧、脚底和独立操枪保留。不复制静帧或变形。暂停不推进，手动方向取消自动行走，抵达后由原一秒候停执行动作。录像路径记录在验收表。

## 5 生成指令

未调用imagegen：本轮仅补齐交互，不新增或替换图案。程序入口见第三节；PNG精修不适用。

## 6 验收记录

| 设计目标 | 证据与结果 |
| --- | --- |
| 系列一致、剪影和落地 | 原图像、比例、层次完全复用；手机昼夜截图复核通过，无额外入口文字或可见按钮底板 |
| 通行和边界 | 专项规则测试覆盖全部入口、绕家具与堵塞目标；通过 |
| 真实动作与独立部件 | 正式触摸录像保留原猫连续走路与收步，不传送至床或楼梯，不修改小手及武器分层；`output/playwright/scene-approach/video/` |
| 点击、候停、暂停、取消、防重复 | 6项专项规则测试、7项正式导航搜索回归、17项已有床/楼梯规则通过。15建筑×本体/门前共30项真实触摸通过；拖动不入屋、手动移动取消通过 |
| 昼夜与手机 | 320×568和390×844分别通过昼夜上下楼与睡眠；844×390短横屏和900×1280既有竖版容器通过。短屏实际移动让床入镜后点击，未增加桌面布局；触点≥44px |
| 资源预算 | 新增图像/解码像素/画布均为0；只增加有界搜索及透明DOM |
| PNG接口 | 不适用，本轮无图案替换 |
