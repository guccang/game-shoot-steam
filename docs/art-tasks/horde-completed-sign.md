# 兽潮累计次数盾牌任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)，沿用美术生成任务单的范围、造型、技术、动画和验收项目。

## 1 目标与范围

- 名称 / ID：兽潮累计次数盾牌 / horde-completed-sign。
- 类别与用途：营门场景入口；北门、西门各一个，显示同一份已领取结算的累计兽潮次数。
- 目标：用户截图中的盾牌只显示累计数字，以兽群图案强调兽潮主题；点击原面板查看完整说明；不显示当前波次，不提前计入待领取的场次。
- 保留：盾形轮廓、木柱、脚底、原门旁坐标、守门入口、通行空间；既有角色和装备动作。
- 路线与参考：扩展 src/rendering/camp-defense.js 正式 Canvas 绘制；参考用户提供的门旁盾牌截图。

## 2 造型与空间

- 盾牌从小图标扩大为88×84逻辑单位兽群徽牌，保留奶油黄、森林绿描边与底部尖角；上方三只怪物形成兽群徽记，下方突出纯数字，不显示标题或单位。
- 两门共用造型，不增加不必要变体；木柱向上延长24单位以避开西门屋顶，底座和接触影保持原样。
- 仍在门柱旁，脚底位置不变；不新增碰撞，不移动营门、围栏、房屋或道路。
- 昼夜共用形体及正式光照，正文保持深绿与浅底对比。

## 3 技术交付

- 牌面 x=-44…44，y=-138…-54，原点为木柱底座；沿用世界缩放和实体深度排序。
- Canvas矢量与运行字体，无位图、不新增图层、画布或纹理缓存。
- 兽群徽记约62×30逻辑单位；次数22逻辑像素，最大绘制宽68；文本与无障碍名均读取progress.campDefense.runs。
- 点击区域同步扩为96×150；仍支持短按、键盘及原场景拖动。
- 纯装饰，无实体碰撞；角色、怪物和载具状态无变化。

## 4 动画任务补充

静态徽牌，不新增动画。角色连续帧、独立武器、履带和怪物动作保留原运行时，不涉及重新生成或裁切。

## 5 生成指令

沿用现有盾形入口、木柱、奶油黄与草木配色；用深绿底带、两只小怪与中央獠牙兽头组成兽潮徽记，下方只显示累计数字，保持底座不变。文字使用正式字体，读已结算记录，不另存一份数字或将当前波数当作次数。

## 6 验收记录

| 设计目标 | 实际结果与证据 |
| --- | --- |
| 突出兽潮且牌面只留数字 | 深绿上栏以中央獠牙兽头及两只小怪构成兽群徽记；正式 Canvas 采样确认只绘制累计数字，不绘制标题及“次” |
| 累计而非当前波次 | 0、9、10、999999均显示正确；两门读取相同已结算记录；末波与领主结束未领奖仍为9，点击领取后为10，刷新续档仍为10 |
| 点击显示详情 | 使用真实触摸点击新牌面顶部，原守门面板显示“已完成9次兽潮”和下一次、波次、评分规则；仍可正常开始守门 |
| 手机桌面昼夜 | 两门×320/390/1280宽度×昼夜共12组实机采样通过，按两门、各尺寸及昼夜抽查正式截图；正文数字及兽群徽记可辨，页面无溢出 |
| 遮挡、通行、动作 | 西门牌面抬高避开工坊屋顶，六位数字无遮挡；实际驾驶向右移动70.59世界单位并返回，木柱脚底与碰撞不变；沿用实体排序，北门木柱底部被前景围栏自然遮挡 |
| 角色怪物载具同屏 | 固定截图夹具同时保留正式猫、松果战车、独立装备、怪物及环境/UI；不生成新角色动作，动画资源专项不适用 |
| 资源预算 | 无新位图或缓存；一个小兽群矢量徽记与一次数字绘制；运行字体沿用既有资源，浏览器脚本及HTTP资源错误均为0 |
