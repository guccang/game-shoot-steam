# 地下一层仓库升井与小屋楼梯分置

依据[美术标准](../art-generation-standard.md)与[项目合同](../../AGENTS.md)。本轮为现有设施的位置与交互调整。小屋楼梯保留原点，仓库升井沿水平方向移至六格外（384 世界单位，接近手机一屏宽），形成两个独立出入口。保留正式梯口造型、栈板、描边、文字、角色与矿车动画。以格心为锚、沿用原有地形与实体层；井口使用已有梯口绘制，井牌和地图标识由程序投影。施工、材料、卸货及存档由逻辑层处理。无新增位图、视频及解码缓存。本轮不涉及 PNG 精修。

## 验收记录

正式入口为 `drawMining`、`drawMineMap` 与 `drawMineExplorationMap`。工作台 `inspectMineFreight` 读取真实站址，设计目标为 `mine-freight`。
- 390×844 页面从小屋楼梯出发，通过触控菜单在库存 0、背包 2 的情况下铺一格轨，再沿干燥通道步行至仓库升井，余下的 1 份铜原矿卸入仓库。点击「返回仓库」后从仓库再次下井，抵达同一格。按钮、标牌与小地图一致。另检查 320×568 和既有桌面竖版容器。浏览器无脚本错误。
- [小屋白天与升井夜间对照](mine-warehouse-shaft.jpg)。原始画面与[行走和触控录屏](../../output/playwright/mine-warehouse-shaft/walk.webm)保存在本地。角色走停、前景遮挡和 HUD 均按原场景实际显示。复核中移除了升井牌下多余的空白小标牌。本次涉及步行和矿车卸货，角色、武器、敌人与载具动作资源均沿用现有实现。
- 已验证楼梯与升井分别返回小屋和仓库，旧档自建洞口错开，矿车与背包在新站址卸矿，深层标记按层隔离。库存、背包和铺轨共同提交，重复施工、缺木或保存失败不扣料。未新增运行图片或缓存。布置与交互验收通过。
