# 地下矿心团王与核心解锁

依据：[美术标准](../art-generation-standard.md)、[动作合同](../../AGENTS.md)。本轮为动态效果开发：用现有Canvas与团子软体实现，不新增PNG；精修图片为后续阶段。

## 目标与参考
新增晶盾、煤火、钻头三种地下团子及矿心团王。参考现有地貌团子与金属灰地下团子，统一森林绿描边、奶油高光、有限平涂。保留猫、独立武器、矿车、真实边界、地下生态和存档；不更换引擎。

## 结构、空间与技术
晶盾：短宽青灰身体、两侧晶盾，散射晶片；煤火：矮圆煤色身体、炉口冠饰，锁点落火；钻头：窄高黄铜身体、锥形钻冠，直线冲刺。矿心团王：宽大岩灰软体、三层晶冠、左右独立矿锤、胸前发光核心，依次晶片扇射、锁点震地、环射，半血后缩短恢复。
普通团子约44×48，首领约84×92，世界脚底为原点。影子、局部软体、冠饰/矿锤、攻击预警/弹丸独立分层；不旋转或拉伸整张角色图。碰撞半径普通16、首领32。入口135单位避险范围保留；唤醒首领需远离入口的宽敞干燥洞厅且与玩家视线相通，不改地形、不阻塞升井。
运行代码位于config/mine-specials.js、core/mining/mine-core-boss.js、combat/mine-specials.js、rendering/mine-specials.js。无新增位图/派生画布；敌方弹丸上限12。共用地下灯光、游戏时钟、暂停、受击回弹和死亡淡出。缺失代码按模块加载失败，不设置美术替代路径。

## 玩法与交付
地下建设页提供唤醒入口和核心状态。每层首次击败本层团王原子结算1枚专属晶核（地下1层铜辉、2层银霜、3层熔金等，矿物主题循环但层号独立），不占普通背包。开通下一层同时消费本层晶核、金币、矿石和木材：二层1万/10/20，三层3万/20/40，之后沿用递增公式。晶核不可跨层替代，已开层往返免费；旧档已开层不锁回。普通特种团子按稳定地貌/格子自然出现，旧实体身份不变。死亡不重复奖励；存储失败可重试，读档不复活已领核心的首领。
