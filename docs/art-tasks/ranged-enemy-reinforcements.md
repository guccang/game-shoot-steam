# 森林巡游美术生成任务单

本任务执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 远程增援 / ranged-enemy-reinforcements |
| 类别和用途 | 怪物、独立武器及攻击预警 |
| 本轮目标 | 炮车、重炮手、弩手可凭轮廓辨认；更积极的远程攻击有可反应的预警 |
| 数量和变体 | 3 新种：低矮四轮装甲车、宽体树桩重炮、细长叶帽弩手 |
| 保留项 | 真实猫帧、原怪物动作、车型、物理和地图通路 |
| 制作路线 | 程序化部件绘制 |
| 参考与同类资产 | src/rendering/ranged-enemies.js、原版森林配色 |
| 使用场景 | 森林怪潮、野外移动遭遇 |

## 4 动画任务补充

静态资产标注“不适用”。猫身体当前仅生成正面待机和移动，不增加多方向身体序列。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 行走/轮转随实际路程；蓄力→发射后坐→恢复；死亡复用碎裂 |
| 帧率、帧数和循环 | 按正式 dt 连续更新，无独立帧表 |
| 源视频与连续片段 | 不适用：程序化怪物，猫帧不修改 |
| 统一裁切和缩放 | 不适用图集裁切；原生世界尺寸不整体拉伸 |
| 起停与状态衔接 | 停步保留轮相位和脚步；暂停冻结；低动态抑制摆动但保留预警 |
| 局部真实动作 | 车轮、双脚、炮管/弩弦局部独立；炮口固定接合 |
| 独立部件 | 炮管与弩的旋转中心 (0,-15)；弹丸从各型正式枪口发出；后坐仅回缩武器 |

## 5 制作约定
复用森林绿轮廓、木色与奶油黄有限平涂，不生成位图。车轮随位移转动；炮管单独回缩，弩弦单独拉动；重炮落点圈半径与真实爆炸半径一致。保留角色视频帧、地图与现有动作。

## 7 本次数值与范围

- 新种类：苇叶弩手（第2波/当地2级起）、荆棘装甲车（第4波/当地4级起）、树桩重炮手（第6波/当地6级起）。不增加原波次总数与奖励。
- 第一波保留近战；后续每3个名额抽取1次远程，早期85%、后期95%概率。飞行名额、剧情/秘境/居民脚本与领主援军保持原有入口限制。普通移动遭遇也可刷远程，种类按实际区域等级解锁。
- 原孢子：射程235→330，前摇0.85→0.65秒、恢复3.6→2秒；原弹弓：射程260→360，前摇1.05→0.8秒、恢复4.6→2.4秒。伤害系数分别0.65→0.85、0.8→1。
- 普通在场上限3→6、弹量3→6、共享发射间隔0.9→0.32秒。画外不蓄力，树干仍挡弹，近战数量占多数。
