# 武器与载具 UI 精修样品 v2

依据：[美术标准](../art-generation-standard.md)、[AGENTS](../../AGENTS.md)。本单按[任务模板](../art-generation-brief.md)六节填写。

## 1 目标与范围

- 稳定身份：`pistol`（武器0）、`pine-tank`（载具0），两枚菜单静态图标样品。
- 阶段：美术精修试样；仅交付样品、正式界面对照与生成记录，不批量替换正式资源。
- 目标：真实结构不变，校准森林绿轮廓、有限明暗和手机小尺寸辨识。
- 保留：游戏的装备映射、进度、点击、操枪、后坐、车轮与主炮动画。
- 路线：正式 Canvas 结构参考 → imagegen 精修 → 原尺寸/昼夜实机临时贴图对比。
- 参考：[武器](../art-reference/equipment-sample-v2/weapon-reference.png)、[载具](../art-reference/equipment-sample-v2/vehicle-reference.png)，来自正式绘制器；不采用上次退回的PNG为结构参考。
- 已确认基准：[回退实机](../art-reference/ui-art-rollback/4175-menu.png)。使用场景为战场菜单。
- 后续：样品评估后再决定是否扩充全部装备映射，本轮不声称最终资源替换通过。

## 2 造型与空间

- 手枪保持向右上倾斜的枪管与下方握把、原长宽比与原配色。
- 松果战车保留正式参考的轮式底盘、猫驾驶位、车身和主炮；禁止改成履带坦克。
- 主次：轮廓与结构优先，内部细节从简。邻接原任务、邻里、角色菜单图标。
- 地面衔接、活动空间、碰撞与通行：不适用，本轮仅静态菜单图案，不改变世界实体。
- 光照：左上浅色面、右下单层暗面；不增加亮金属、强高光与装饰。

## 3 技术交付

- 原接口112×112画布；样品按原按钮实际显示尺寸评估，中心锚点(56,56)，保留全部透明边距。
- 生成PNG尺寸与实际解码预算在输出后记录。样品单图目标≤2MB；正式导出倍率后续决定。
- 分层：仅静态图案；按钮、文字、数值、状态、动态圆环继续由程序负责。
- 透明背景：需要，不含底板、文字、棋盘格。昼夜使用同一图标，依托原UI底板辨识。
- 替换接口：仅评审页临时覆盖图片；正式入口和装备变化仍以原绘制器为准。
- 输出与来源放 `docs/art-reference/equipment-sample-v2/`，不进入运行资源目录。缺失显示明确加载失败，不以旧图冒充样品。

## 4 动画任务补充

静态UI试样不生成动画；不触碰真实猫动作、独立操枪、履带、旋翼、动作时钟及起停逻辑。正式替换阶段需再次验收装备映射与动态接口，本轮不生成虚构动画证据。

## 5 生成指令

使用内置 imagegen，实际提示词记录在同目录 `prompts.json`；每张使用自己的正式绘制参考，固定结构和视角，只做有限平涂精修。输出原生透明PNG。模型具体版本未由工具公开，不宣称调用了某个特定版本。

## 6 验收记录

实际结果见下表。遮挡/通行/序列帧不适用于静态评审样品。

正式绘制器：`src/ui/inventory.js#renderFieldIcons` → `src/rendering/characters.js#drawWeapon`；`src/rendering/vehicle.js#drawVehicleIcon`。

既有 `designCriterion: ui-art-rollback` 保持有效；本轮样品评审目标为 `equipment-sample-v2`，尚非正式替换案例。

生成：内置imagegen，首次与局部修订各2次，提示词见 [生成记录](../art-reference/equipment-sample-v2/generation-record.json)。两枚第二轮均因图面比例偏移退回，选第一轮。高分辨率下仍有轻微渐变，不能宣称已严格满足纯平涂；正常按钮尺寸下较不明显。

动态效果开发：沿用原正式实现，未修改。

PNG精修替换：后续阶段；本轮仅样品评审交付，不作为正式替换通过。

本轮结论：样品与实机对照已完成。结构一致性比上轮泛化生成好；相对程序版，审美提升有限，暂不扩充或自动替换。

后续修订：若继续精修，需进一步压平渐变、校准边距，并确认小尺寸效果确实优于原版再扩充其余装备。
