# 林间赛道站成绩牌

依据[任务单](../art-generation-brief.md)、[美术标准](../art-generation-standard.md)与[AGENTS.md](../../AGENTS.md)记录本轮程序绘制调整。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称、标识、用途 | 林间赛道站 / race；普通森林玩法站牌 |
| 当前阶段与目标 | 动态数据显示；直接显示完赛次数、最好名次、最快用时 |
| 动态与交互 | 正式完赛记录驱动每帧显示；未有成绩显示暂无；原参赛入口保留 |
| 数量和变体 | 一个三行牌面，日夜共用 |
| 保留项 | 双柱、下方名称牌、底座、位置、修复权限、竞赛规则、奖励及存档结构 |
| 制作路线与参考 | 现有Canvas文字，参考用户截图与足球站记分牌；无需新增图片 |
| 确认目标与后续精修 | 正常手机画面可读、按钮不挡数据；无新增PNG精修范围 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 剪影与差异 | 原双柱站牌；主牌加宽至112、加高至62，三行数据区别于足球两行 |
| 主次与邻接 | 绿色成绩文字放在奶油色主牌内，下方保留名称木牌；周边场景不移动 |
| 地面与活动空间 | 原底座、接触影和通行空间不变，不增加碰撞 |
| 光向明暗 | 沿用当前场景昼夜色调与森林绿描边 |

| 字段 | 内容 |
| --- | --- |

## 4 动画任务补充

本次仅更新数据文字，无新增角色动作、连续帧、时钟、裁切或独立运动部件；原动作系统保持不变。

## 5 生成指令

未调用imagegen。成绩必须随存档更新，由正式Canvas绘制，不能烘焙进静态图片。名次按现有best编码转换；次数超过一万显示一位小数的万单位，向下取整；时间复用raceTime。

## 6 验收记录

| 设计目标 | 实际结果与证据 |
| --- | --- |
| 数据真实与持久化 | 两次正式结算保留2次、最好第1名、最快51.2秒；失败及重复结算不累加；正式保存刷新后保持 |
| 无成绩与边界 | 零记录为0次/暂无/暂无；四种名次映射与99.9万次数通过专项测试；未修复不显示成绩 |
| 风格、遮挡与空间 | 保留双柱、名称牌、底座，三行没有越界；提示底边高于牌面，六组浏览器场景检查均无重叠；通行几何未改 |
| 手机、昼夜与既有容器 | 390×844、320×568、1280×900的昼夜六图通过；实看390白天和320夜晚，未新增桌面布局；为浏览器模拟而非物理手机 |
| 动态与交互 | 当前场景立即读取新成绩，无需打开面板；附近操作仍使用原按钮，锚点回归3项通过；未改入口动作 |
| 动作真实性 | 不适用：无新增动作，角色与独立武器绘制未改 |
| 资源与预算 | 无新增位图/画布/缓存，浏览器pageerror为0 |

证据：output/playwright/race-scoreboard/result.txt、zero.png、390-day.png、320-night.png及同目录其余昼夜截图。针对性测试：race-scoreboard、football-scoreboard、interaction-anchors共8项通过（部分复验，不重复计数）。
