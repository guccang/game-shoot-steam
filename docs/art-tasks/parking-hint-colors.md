# 停车入位提示配色

依据[美术标准](../art-generation-standard.md)及[AGENTS](../../AGENTS.md)，沿用任务单结构简化记录本轮纯配色调整。

## 目标与参考
用户截图中的“点击 · 停车入位”改为建筑提示一致的浅奶油底、深绿文字、灰绿描边，悬停使用浅鼠尾草绿。参考正式附近工坊购买/修复入口。不新增美术素材或精修图片。

## 结构与保留项
仅覆盖停车交互按钮的颜色变量；保留字体14px、8×12px内边距、至少44px触控高度、原圆角和阴影，泊位世界投影中心锚点与层级25保持。点击停车、倒车与下车动作使用原逻辑。角色真实帧、车辆比例、树木及工坊不变。

## 交付与预算
正式文件`src/styles/ui-foundation.css`，目标`parking-hint-colors`。共用`--ui-paper`、`--ui-text`、`--ui-line`、`--ui-sage`变量；无新增DOM、位图、画布、纹理或缓存。PNG精修、造型变体和新碰撞不适用，本轮为CSS配色。

## 验收计划
正式游戏里靠近工坊泊位，检查手机320/390、横屏与既有桌面竖版容器的昼夜显示、颜色与触控边界；点击后完成停车。保存截图及检查结果。

## 验收结果：通过
320×568、390×844、844×390与1280×900既有竖版容器共八组昼夜检查通过，实际底色为#fff6dc、文字#294338，按钮边界均在屏幕内且触控尺寸至少44px。真实点击完成泊位入位及下车，浏览器错误为零。人工查看[白天](../art-reference/parking-hint-colors/day.png)与[夜晚](../art-reference/parking-hint-colors/night.png)，确认中文清晰、配色与建筑提示统一。完整截图位于`output/playwright/parking-colors/`，临时验收脚本`output/parking-colors-check.cjs`。本轮仅CSS变量改动，无需新增单元测试或动作素材验收。
