# 探索节奏第一轮：巡林簿交互验收

依据：[美术任务单](../art-generation-brief.md)、[资源标准](../art-generation-standard.md)、[手机UI框架](../ui-foundation.md)。日期：2026-11-02。

## 1 目标与范围

- 名称与标识：巡林簿自选体验与自由探索，`mainline-dialog`、`mainline-choices`、`mainline-pause`。
- 阶段：动态交互开发。仅使用现有 HTML、统一 UI 类和正式绘制器；没有图片生成、SVG造型或PNG替换。
- 目标：8项必经阶段与40项自选体验分开；交付后撤下主线卡、导航和操作高亮，由玩家主动继续。自选列表默认折叠。
- 交互：触屏选择任务、恢复主线、自由探索；同版本刷新保留选择，切换保留阶段与园艺地块；失败不得部分提交。
- 参考：现有巡林簿与 `src/styles/ui-foundation.css`。保留猫猫、独立武器、怪物、载具与昼夜风格、原有任务ID及奖励规则。
- 数量：一个既有页面、两个新增交互区域；无美术变体、无后续PNG精修项。

## 2 造型与空间

复用森林绿标题和奶油色正文，无新增配色、轮廓、世界实体、投影或碰撞。自选内容折叠在正文内，主要操作仍位于原固定底栏。世界空间、通行、桥头、水界、载具碰撞及遮挡几何均不变，相关新增美术检查不适用。

## 3 技术交付

- 尺寸：沿用手机底板480px上限，320×568、360×640、390×844、430×932、844×390按原框架响应。320窄屏的三个按钮约80.7×65.2px，均超过44px。
- 锚点与分层：原对话框居中；内容滚动、底栏固定；暂停追踪后原任务HUD隐藏。无新增Canvas、SVG视框、图集、透明背景或缓存。
- 程序职责：任务阶段、保存事务、追踪和显示状态由程序控制，角色动作时钟不变。
- 正式入口：`src/ui/mainline.js#createMainline`，`src/core/story/mainline-selection.js#selectMainlineTask`，`src/core/story/mainline-manager.js#mainlineObjective`。
- 预算：新增位图0、解码内存0、画布0；自选按钮仅打开/选择时重建，不在战场逐帧创建。
- 必需素材仍沿用现有正式加载器，缺资源失败行为不变。

## 4 动画任务补充

本轮不新增动画或改动身体、武器、怪物、履带和旋翼。连续帧、姿态、起停与动作生成不适用。运行时移动验证使用真实更新；视觉取样固定时间和镜头，未将静态截图当作新动画验收。

## 5 生成说明

未使用 imagegen：本轮是任务结构与既有页面行为调整，不需要生成图案。未来精修不属于本轮范围。

## 6 验收记录

| 设计目标 | 结果与证据 |
| --- | --- |
| 与原UI一致 | 正式页面沿用统一底板与按钮，已人工查看320短屏和390自选页面截图 |
| 自选体验独立 | 实际点击足球后切回主线，列表40项；已完成项不可再领 |
| 结束后真正自由探索 | 正式交付、刷新、真实移动后无主线卡/高亮/对白；邻里结算、秘境退出针对性回归通过 |
| 手机点击和长文 | 五种尺寸昼夜共10组，底栏未越界；独立hasTouch上下文实际tap继续/暂停，320三按钮均>=44px |
| 昼夜同屏 | `output/playwright/exploration-pacing/world-day.png`、`world-night.png`，角色、载具、怪物与场景同屏；已有画风保持一致 |
| 页面可读 | 同目录 `book-320-day.png`、`book-390-night.png`、`optional.png`、`touch-320-active.png` |
| 资源预算 | 无新增图片、缓存或画布；浏览器验收无pageerror |
| 遮挡/通行/独立动作 | 无修改几何或动画资产，不扩展该范围；真实移动未被主线打断 |
| PNG替换 | 不适用，本轮不生成或替换PNG |

对应 `designCriterion`：沿用 `visual-contract.json#mobileUiPagesCriterion` 的正式手机底板与触控目标；本轮专项行为由 `tests/exploration-pacing-browser.cjs`、`tests/exploration-pacing-touch-browser.cjs` 验证。截图以人工复核为准，未以机械检查替代审美判断。

结论：本轮动态交互通过。没有物理手机安装包验收；上述触控与刘海/安全区相关能力限于浏览器移动端模拟，未宣称实体设备验证。
