# 建筑交互 UI 固定锚点任务单

由美术生成任务单复制后按本轮范围填写。依据：[游戏美术资源生成标准](../art-generation-standard.md)、[AGENTS.md](../../AGENTS.md)、[手机 UI 框架](../ui-foundation.md)。

## 1 目标与范围

2026-10-28营门修订（实施前约定，现已验收）：修复/已修复的营门提示改用通用奶油纸色与深绿文字，底边固定在正式守备标牌顶端上方；手机短屏若上方空间不足则放在牌座下方，不能覆盖标牌。保持真实营门实体、点击二次校验、修复价格和修复流程。只调整DOM样式与锚点，不生成图片、不新增碰撞或缓存。参考用户遮挡截图、`ui-foundation.css`、破损木牌最高67单位和修复后盾牌最高138单位；分别使用80/150单位顶锚点，底部回退统一留12单位。无新增人物动作、碰撞、纹理或PNG精修项。

| 字段 | 本轮约定 |
| --- | --- |
| 名称、标识 | 建筑交互 UI；`nearby-interaction`，原操作 ID 保留 |
| 类别、阶段 | 现有 UI 动态定位调整，无插画生成或 PNG 替换 |
| 目标 | 停车、消防车入库、工坊、修复、告示及室内操作固定到目标，不跟随主角 |
| 动态交互 | 镜头移动时跟随建筑投影；玩家在范围内移动不改变目标锚点；点击仍重新校验身份与距离 |
| 数量与变体 | 一个复用按钮；停车和消防倒车徽记、入室/出门徽记分别归属对应设施 |

| 场景 | 森林建筑、公共车场、消防站、小屋及工坊室内 |

## 2 造型与空间

沿用森林绿按钮、奶油文字、圆角与描边，没有新增剪影、变体、材质或地面投影。建筑按钮取前立面的固定点，告示取牌面，公共停车取所选泊位，家具取本体。床的锚点位于床面右侧四分之一处，保证 320 像素窄屏下按钮完整。进门倒计时放在屋面，与前立面的升级按钮分开；出门倒计时固定在出口。

主次关系以目标建筑为准，不再跟着猫移动。原道路、院落、家具碰撞和通行范围不变。白天和夜晚使用同一组件，场景沿用正式光照。锚点离开画面时隐藏，不移到屏幕边缘。

## 4 动画任务补充

不制作角色或载具动画，不改脚底、枪械、车轮、履带与旋翼。徽记只读取既有停车阶段及进出门进度；逻辑帧率、时长、暂停和取消规则保持。车身移动时提示留在目标建筑。正式程序入口为 `drawParkingCountdown` 与 `drawPlayerActionCountdown`。没有源视频、裁切或新图集交付。

## 5 生成指令

未使用 imagegen：仅修正既有 UI 坐标来源。实现要求为“沿用原样式、真实目标及正式投影；建筑交互固定到目标实体，不能回退到玩家周围或屏幕边缘”。

### 2026-10-28 营门遮挡与配色修订验收

- `designCriterion`沿用`building-interaction-anchor`，正式验收器`inspectBuildingInteraction`识别营门提示上下锚点与横向安全边距。

- 配色直接引用`--ui-paper`、`--ui-text`、`--ui-line`和`--ui-sage`，修复提示与已修复营门入口均沿用轻纸色。最小44px触控保留；上下切换不做穿过主体的位移动画，按下也不跳位。
- 真实点击前不扣料；足料点击后仅扣120木头并创建`defense`施工。未改修复权限、价格、倒计时或场景通行。
