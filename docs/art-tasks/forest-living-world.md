# 森林生活圈美术生成任务单

依据：从[任务模板](../art-generation-brief.md)复制字段，执行[生成标准](../art-generation-standard.md)。本记录先填写制作合同，验收结束后补充真实证据。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称 / id | 森林常驻生活圈 / forest-living-world |
| 类别和用途 | 三组生活设施、六位常驻居民、生活交互界面 |
| 目标 | 玩家在无任务时也看见备餐、维修、交接与休息，完成帮助后能回访 |
| 数量和变体 | 厨房有灶台与洗碗池；陶作台有宽台面与陶坯；哨站有高灯和雨棚；栖架有高枝与花盆；营地桌有信件和工具 |
| 保留项 | 原版猫连续帧、怪物局部动作、独立枪械、载具、森林轮廓及通路 |
| 制作路线 | 复用正式猫/怪物绘制器，程序绘制设施与独立手部劳动部件 |
| 参考 | art-reference/camp-layout/center-1280-night.png、art-reference/monster-stories/world-390-day.png |
| 场景 | 晴叶营地—旧哨站—怪物邻里，四境森林 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 低工作台、宽厨棚、高栖架及窄哨灯，设施各有用途 |
| 结构差异 | 宽度、高度、屋顶和工作表面分别识别厨房、陶台和灯站 |
| 主次关系 | 居民动作优先，摆件集中工作面，不铺满道路 |
| 地面衔接 | 小片暖土踏地、脚底接触影，与现有土路连接 |
| 活动空间 | 通路不低于现有最大地面载具通行需求；实体与树冠避让交互点 |
| 邻接组合 | 营地麦田、雾松林缘、既有南向主路及旧哨站 |
| 光向 | 左上受光、右下冷影；夜间只在灯芯增加暖光 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸 | 厨棚140×92、陶台104×46、桌90×48、栖架100×112、哨站104×100；居民沿用正式比例 |
| 像素与倍率 | Canvas随正式镜头和DPR绘制，无新增位图 |
| 锚点 | 全部以世界底座/脚底为原点，与角色按y排序 |
| 分层 | 地面道路、实体设施、居民身体与独立手部、局部灯光、DOM交互 |
| 透明 | Canvas透明局部绘制，不带背景板 |
| 碰撞 | 道路真实可通行；设施底座阻挡，前方交互与工作锚点留空 |
| 昼夜 | 共用形体，运行时材质与暖灯切换 |
| 文件 | src/rendering/living-world.js，持久证据在docs/art-reference/forest-living-world/ |
| 预算 | 无新增下载图集；最多六居民、九设施。静态设施18份320×320透明缓存，上限7.03MiB，卸载释放；身体与劳动工具不缓存 |

## 4 动画

猫复用assets/cat-front/animations.json同源连续待机/移动；不重新生成或裁切身体。怪物复用正式行走和飞行动作。工作手、木碗、锤柄按局部轨迹绘制，禁止旋转整个人物假装工作。独立动作时钟停步继续；暂停冻结，减少动态固定工作动作。原视频来源与帧索引沿用原清单，本任务不新增视频。

## 5 制作指令

森林绿轮廓、奶油黄及柔和草木色、有限平涂；生产可拆分工作设施，不改变原版角色。厨房留洗碗位置、陶台留宽工作面、夜班栖架与灯站在高度和功能上不同。保持道路开放，禁止铺满碎纹、强辉光及整图拉伸动画。
