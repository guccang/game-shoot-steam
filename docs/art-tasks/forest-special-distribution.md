# 地面特殊团子与全图等级清缴

本轮只扩展已有PNG团子的出生编成和任务选点，沿用既有身体/冠饰动态、攻击、碰撞与图集，不新增美术素材。参考[既有地貌团子验收](biome-dumplings.md)及[美术标准](../art-generation-standard.md)。

普通森林约每12个遭遇名额出现一只陆生特殊团子，同屏最多2只；特殊地貌保留原有族群。清缴第3、9、15等名额穿插地貌团子，同屏最多3只；兽潮每5个名额一只，同屏最多4只；不增加原本总量，不替换飞行、重装等保留身份，水团仍只在水中出现。守门特殊团子的弹丸与落砸按锁定目标伤害拒马，保留树干、护盾和共享弹量。

清缴任务Lv1–3继续营地安全草甸；其余按森林等级带从近郊到全图远境选取真实可达场地，使用营地中心而非接单位置计算分布。候选场地与路径检查等级安全范围；玩家追击出安全区后允许先沿可通行路径返回，进入后不再绕出。世界循环边界共用正式最短距离，旧任务坐标与暂停首领保持，下一轮重新选点。场地/导航/地图标记/存档共用相同坐标，不为任务移除山湖或树木。战斗数值继续由清缴轮数决定。

技术预算：运行图集、派生画布增量0；配额共享原有怪物/弹丸上限；选点候选512、路线搜索预算24000、至多16条失败路线，首轮保留原预算。无需imagegen，未伪造生成记录。正式入口enemy-manager.js、camp-defense.js、core/story/clearing-site.js及ui/clearing.js。designCriterion为forest-special-distribution。

验收通过（2026-11-10）：本轮新增/直接相关21项、12种子远点选址1项、既有地貌团子7项与守门成长9项通过。覆盖配额与上限、专用战斗隔离、直射/落砸伤拒马、等级路径安全、存档与续接、保存失败回滚及领奖幂等。旧夹具补齐已购用地和当前到达版本，圈外击杀采用真实可站立坐标。
