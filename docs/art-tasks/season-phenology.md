# 森林巡游美术生成任务单

复制本任务单，为每批资源填写一份。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 四季物候强化 / season-phenology |
| 类别和用途 | 树冠、林下地面小景 |
| 本轮目标 | 春季少量花簇，夏季叶层与蕨草丰茂，秋季树下落叶；冬景逐像素保留 |
| 数量和变体 | 春花、夏叶与低草、秋叶三个静态装饰组；原树数量/坐标/冠幅不变 |
| 保留项 | 独立操枪、现有动作、主树分区、路径/碰撞与活动空间 |
| 制作路线 | 现有Canvas绘制，预绘入当前季节地块和树图集 |
| 参考与同类资产 | 现有forest-winter-day/night.png、四境森林实机 |
| 使用场景 | 四境森林四季；大雪与天气沿用全地图环境 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 春季小朵粉白花、夏季成组叶片与低蕨、秋季贴地尖叶；冬雪冠保持 |
| 与其他变体的区别 | 花瓣、叶片、蕨草、地面落叶的结构与分布不同，配合季节色阶 |
| 主次关系 | 树冠维持主景，低矮花草落叶只贴近现有林缘 |
| 地面衔接 | 林缘花草与树下落叶接原草地；冬季所有绘制路径保持原样 |
| 活动空间 | 道路、桥头、门前、沙滩中央保留通行 |
| 邻接组合 | 原山湖沙林组合保持坐标 |
| 光向与明暗 | 左上暖白、右下蓝灰，夜间统一冷色 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 树128×160；地面簇半径不超过18、高不超过16逻辑单位 |
| 像素尺寸与倍率 | 树256×320；地块保持384逻辑单位及2单位扩展边 |
| 锚点与原点 | 树根64,145，所有实体原锚点不变 |
| 分层 | 花草落叶进地面缓存；芽花叶片裁入树冠原透明轮廓 |
| 透明背景 | 沿用树图集透明轮廓 |
| 碰撞与可通行性 | 纯视觉；不新增阻挡、不冻结湖面 |
| 昼夜处理 | 地面由地块夜色统一转换，树冠与原夜色图集共同转换 |
| 文件格式与位置 | src/rendering/season-ground.js与season-art.js等现有入口 |
| 内存与缓存预算 | 地块只保留当前季节；树图集季节切换释放旧缓存；1490个林缘候选点一次生成，不按季节累积 |

## 4 动画任务补充
静态物候不新增动画；原猫动作、小手操枪、树木风摆、大雪与昼夜机制保持。

## 5 生成指令
延续森林绘本有限平涂。春季粉白花少量成簇，夏季深浅绿叶层和低蕨草，秋季赭黄叶片疏密聚集；不增加树木数，不放大树冠，不占用道路、田前、建筑入口、沙滩中央与营地活动区。冬季和九寨沟保持原图元。只缓存当前季节，不预加载所有季节图集。
