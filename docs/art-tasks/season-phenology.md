# 森林巡游美术生成任务单

复制本任务单，为每批资源填写一份。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 四季物候强化 / season-phenology |
| 类别和用途 | 树冠、林下地面小景 |
| 本轮目标 | 春季少量花簇，夏季叶层与蕨草丰茂，秋季树下落叶；冬景逐像素保留 |
| 数量和变体 | 春花、夏叶与低草、秋叶三个静态装饰组；原树数量/坐标/冠幅不变 |
| 保留项 | 独立操枪、现有动作、主树分区、路径/碰撞与活动空间 |
| 制作路线 | 现有Canvas绘制，预绘入当前季节地块和树图集 |
| 参考与同类资产 | 现有forest-winter-day/night.png、四境森林实机 |
| 使用场景 | 四境森林四季；大雪与天气沿用全地图环境 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 春季小朵粉白花、夏季成组叶片与低蕨、秋季贴地尖叶；冬雪冠保持 |
| 与其他变体的区别 | 花瓣、叶片、蕨草、地面落叶的结构与分布不同，配合季节色阶 |
| 主次关系 | 树冠维持主景，低矮花草落叶只贴近现有林缘 |
| 地面衔接 | 林缘花草与树下落叶接原草地；冬季所有绘制路径保持原样 |
| 活动空间 | 道路、桥头、门前、沙滩中央保留通行 |
| 邻接组合 | 原山湖沙林组合保持坐标 |
| 光向与明暗 | 左上暖白、右下蓝灰，夜间统一冷色 |

| 字段 | 填写内容 |

## 4 动画任务补充
静态物候不新增动画；原猫动作、小手操枪、树木风摆、大雪与昼夜机制保持。

## 5 生成指令
延续森林绘本有限平涂。春季粉白花少量成簇，夏季深浅绿叶层和低蕨草，秋季赭黄叶片疏密聚集；不增加树木数，不放大树冠，不占用道路、田前、建筑入口、沙滩中央与营地活动区。冬季和九寨沟保持原图元。只缓存当前季节，不预加载所有季节图集。

## 2026-11-08 加载90%等待修复（实施目标）

本轮只优化季节地面装饰的准备范围与缓存，不修改花瓣、蕨草、落叶、原树位、颜色、坐标、锚点、分层、图元或昼夜转换。实测冷启动22.95秒，90%停留约19秒，首块地面累计构建7.97秒。原流程先对整张48,000×36,000森林生成全部树下点缀，首屏才继续铺地。本次改为按地块及绘制边缘范围查询原树位，保留原数组索引和绘制顺序，分帧生成当前区域；完整布局入口仍供工具与等价验收使用。另检查首帧营地布局版本同步，避免刚准备的缓存被首次正式绘制清空。

验收目标：冷启动对比、正式100%门禁、开始／返回重入、首屏无同步重建、四季地面像素等价、跨块边缘与取消恢复、手机昼夜实景。无新增位图和Canvas，原缓存尺寸与预算不扩大；无需imagegen或PNG替换。

### 加载修复验收结果

本轮通过。正式地块生成改为只准备当前裁切区域及75单位树位扩边，仍按原森林序号排序；每棵树的五个候选点与所有避让规则保持。取消时已完成的树点缀可复用，冬景不额外生成装饰。营地版本同步提取为`Renderer.syncCampLayout`，预热与正式帧共用，实际搬迁仍按原规则失效。

同一台机器、Edge手机触控模拟390×844、全新隔离会话对照：[修复前](../../output/loading-profile/baseline.json)总计22.95秒，90%后18.66秒；[修复后](../../output/loading-profile/after.json)总计6.04秒，90%后1.73秒。地块累计CPU耗时8.75→0.94秒，最慢一块7.97→0.42秒；导航预热仅约4毫秒。世界初始化仍需约3.8秒，未通过改变百分比或提前放行掩盖此耗时，也不承诺所有设备均为固定秒数。

独立[正式浏览器回归](../../tests/loading-local-ground-browser.cjs)结果见[报告](../../output/playwright/loading-local-ground/report.json)：首次5.93秒、90%后1.74秒；读档重载7.23秒、90%后3.11秒；返回首页再进入2.02秒。三例均观察到100%后进入，首帧分别复用6/8/8个缓存，丢失0、同步补建0；再进入保留玩家和树数组身份，页面异常0。

针对性检查16项通过：开始过场6项、分帧预热3项、营地缓存3项、季节点缀4项。新覆盖局部生成、取消续建、顺序和边缘完整性；原慢加载门禁、失败／销毁及减少动态测试保持通过。没有执行全量测试。20组四季×营地／远区／世界边界的局部绘制与完整布局参考像素逐通道完全相同。完整布局参考沿用正式图元，仅将候选集换回全森林，确保可见花草未被删减或换成备用图。
