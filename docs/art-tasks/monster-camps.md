# 怪物营地美术生成任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。本任务从标准任务单复制，制作前填写目标、规格、锚点和保留项，以下保留完整分项记录。

## 1 目标与范围

| 字段 | 本轮内容 |
| --- | --- |
| 中文名称 / 稳定标识 | 怪物营地 / monster-camps；每营地独立英文 ID |
| 类别和用途 | 常驻野外聚落、篝火摆件、简棚、怪物生活、具名人物与手机目录 |
| 当前阶段 | 动态效果开发；Canvas 实现并复用原怪物绘制器，PNG 精修属后续阶段 |
| 本轮目标 | 世界里能看见怪物三三两两生活；可安全观察、听见性格与营地传闻，进入警戒圈才开战 |
| 动态与交互 | 五只分为两只和三只；散步、轮流接话、进入攻击、退出回家、清空重聚；导航、线索、奇物和存档 |
| 数量及变体 | 森林 7 处（2/4/7/10/13/16/20 级）、湖谷 4 处（实际等级取出生点）；锅架型与晾架型 |
| 保留项 | 原猫真实连续帧、独立枪械、小手、受击与死亡、载具及世界坐标；不更换引擎 |
| 制作路线 | 现有原生 Canvas 怪物 + 程序局部火焰和简棚。已具备同类参考，不新增 imagegen 位图 |
| 参考 | [白天基准](../art-reference/landscape-six-day.png)、[夜晚基准](../art-reference/landscape-six-night.png)；`src/rendering/living-world.js`、`enemies.js` |
| 本轮确认目标 | 与角色同屏比例协调，棚和火塘不封路，闲聊与边界可辨，手机短屏目录能滚动 |
| 后续精修 | 可用 imagegen 精修棚布、锅与晾晒物为透明 PNG；保持尺寸、锚点和独立火焰。本轮不宣称完成 PNG 精修 |
| 场景 | 森林各等级带与九寨沟干地；副本、剧情、室内、消防和预览不生成营地 |

## 2 造型与空间

| 字段 | 本轮内容 |
| --- | --- |
| 主体剪影 | 低矮斜布棚、石火塘、分组怪物；无栅栏 |
| 结构区别 | 锅架型为三角支架和悬锅；晾架型为双柱横梁和两串植物；区别不只换色 |
| 主次关系 | 怪物和火塘为主体，棚与两只储物箱为次景；外围树冠留白 |
| 地面衔接 | 柔和草土椭圆与小接触影；警戒虚线和真实圆形触发区一致 |
| 活动空间 | 半径 150 的警戒圈不产生碰撞，周围 310 单位树冠留白；观察点在北侧，冷灰堆在东侧 |
| 邻接组合 | 沿现有生态林区配色；坐标选择通过真实地形检查，保留河岸和山体，不改水界 |
| 光向明暗 | 左上亮、右下冷影；夜间共用形体，石火塘有小范围暖色光，场景继续统一调色 |

## 3 技术交付

| 字段 | 本轮内容 |
| --- | --- |
| 逻辑尺寸 | 营地直径 300；布棚约 85×65；火塘约 60×68（含锅架）；沿用原怪物尺寸 |
| 像素尺寸 / 倍率 | 矢量 Canvas，无新增固定像素图；由原镜头和 DPR 缩放 |
| 锚点 | 火塘世界坐标为营地原点；棚底在原点北侧 80 单位；怪物保持脚底坐标 |
| 分层 | 地面草土和虚线 → 棚、火塘、怪物按脚底排序 → 独立火焰 → DOM 小气泡与手机面板 |
| 程序和图片职责 | 配置保存坐标/种子/台词，核心负责战斗/事务，UI 负责按钮与导航，绘制器负责局部火焰和外观；无新增图片 |
| 替换接口 | 保持营地 ID、世界坐标、150 警戒半径、人物/冷灰点和正式绘制入口；未来图片不能烘焙火焰与文字 |
| 透明规则 | 程序直接绘制，无不透明贴图地板；接触影单独绘制 |
| 碰撞与通行 | 低矮摆件均为装饰，警戒边界可走；人物不进入敌人表；保留真实水/山/树碰撞 |
| 昼夜 | 正式环境日历与 SceneTone 共用；火焰只做局部亮色，减少动态保留稳定火芯 |
| 文件位置 | `src/config/monster-camps.js`、`src/progression/monster-camps.js`、`src/core/monster-camps.js`、`src/rendering/monster-camps.js`、`src/ui/monster-camps.js` |
| 内存与缓存 | 新增位图 0 字节、离屏画布 0 个；11 个固定目录记录，每处最多5名额；仅650单位内建立生活实体，远处释放；复用既有怪物缓存 |
| 资源与失败 | 使用现有怪物/猫/字体资源与正式加载流程；没有新外部图片或隐藏替代图。保存失败保留旧账本和未结算死亡，重试时不重复发种 |

## 4 动画任务补充

| 字段 | 本轮内容 |
| --- | --- |
| 动作及时长 | 日常小范围散步；每5秒换一句闲聊；进入警戒圈使用原怪物蓄力/扑击/恢复/死亡；清空后90秒有效游玩时间且离开340单位再重聚 |
| 时钟与循环 | 日常和火焰读取 `game.time`；移动按固定逻辑 dt 推进；暂停/离线不补计冷却 |
| 动作来源 | 原 `dumpling-motion.js`、`enemies.js`、`monster-atlas.js`；新增局部火焰在 `drawMonsterCampObject`；不新增源视频，不复制静帧 |
| 尺寸/裁切 | 原怪物比例与脚底稳定；未新增序列图集，因此裁切参数不适用 |
| 起停衔接 | 进圈登记同一对象，退出撤销攻击后实际走回生活点；闲聊怪物通过 gameSource 绑定正式运行时，保留胶体步态 |
| 局部动作 | 原团子软体步伐/表情/受击；火芯高度错相变化；原载具履带/车轮/旋翼规则保留 |
| 独立部件 | 手、枪、枪口、后坐仍由原运行时绘制；棚、锅、晾架不与角色合并 |
| 连续证据 | `output/playwright/monster-camps/camp-motion.webm`，正式 Canvas 20fps 连续录制，含走位和起停；另采实际游戏的昼夜 PNG |

## 5 生成指令

本轮没有调用 imagegen：延伸已有 Canvas 摆件系列，先完成动态交互。正式实现入口是 `src/rendering/monster-camps.js`，无生成服务请求、原始位图或外部资源。后续精修提示应以本任务的实机截图为参考，保持森林绿描边、奶油与草木平涂，分开交付棚、锅/晾架，不烘焙火焰、文字、怪物与独立枪械。

## 7 玩法交付与边界

- 11处营地覆盖17种种子。清空一轮后，必得目录内已开放品种各一粒；未达到原清剿轮次门槛的品种不提前解锁。首次获得继续解锁种子小屋购买；教学找种也读取真实营地奖励。
- 清空次数不是入场次数。五个真实击败名额持久化，切图/回收不会冒充清空；刷新继续剩余名额。离开半径150停止战斗，已死名额不复活；完整清空才进入90秒休整。
- 灰耳、苔小报、慢半拍三位圈外人物提供三条异地线索，分别有昼夜和清空条件。奇物只领一次，收进正式小背包；对应营地指定种子额外一粒，仍受品种开放门槛约束。
- 自己营地的清空次数与其他营地最高次数进入日常八卦。没有联机服务器或离线世界模拟；只记录这个玩家的本地世界。
- 圈外不会主动成为本营地目标；已有其他野怪仍可能经过，观察范围内暂停随机遭遇新增，不宣称全局无敌。
