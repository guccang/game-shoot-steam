# 森林巡游美术生成任务单：道路镜像与邻里实时路径

从 art-generation-brief.md 复制，执行[游戏美术资源生成标准](../art-generation-standard.md) v1.0。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 生活道路与委托光点 / living-road-guidance |
| 类别和用途 | 程序化地面道路、任务引导 |
| 本轮目标 | 移动时不生成竖直假路；所有已接邻里委托的当前步骤都有实时路径 |
| 数量和变体 | 原有五条道路；三个委托共十五个步骤；没有新增造型变体 |
| 保留项 | 道路位置、宽度、设施、角色动作、独立武器、地形碰撞与奖励 |
| 制作路线 | 修正程序化绘制镜像；复用正式任务路径规划器和光点 |
| 参考与同类资产 | living-world.js 道路、story-guidance.js 光点、既有森林昼夜参考 |
| 使用场景 | 四境森林常驻生活圈；章节、秘境、其他地图保持既有路径 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 原双层圆头道路；稀疏奶油黄光点与目标地面圈 |
| 与其他变体的区别 | 不适用；不生产新结构，仅修正空间连续性 |
| 主次关系 | 路面低对比；光点小面积提示当前行动 |
| 地面衔接 | 原草地、路肩、设施前落脚地保持位置 |

| 邻接组合 | 沿用原建筑、树木、河岸；导航查询实际树干、山水、设施 |
| 光向与明暗 | 沿用昼夜场景转换；光点保留森林绿描边与奶油色核心 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 道路56/43双层宽；光晕半径7.5×5，光点半径3.4×2.5；28单位间距 |
| 像素尺寸与倍率 | Canvas随正式镜头和DPR缩放，无新位图 |
| 锚点与原点 | 道路整条折线使用同一世界周期平移；光点锚定目标端；居民使用实时脚底 |
| 分层 | 正式地面层，在人物、载具、树木和战斗预警下面 |
| 透明背景 | 直接绘制透明地面提示；无不透明贴图 |
| 碰撞与可通行性 | 查询正式碰撞；阻塞时不绘制穿墙直线；工作台旁目标可落在交谈半径内 |
| 昼夜处理 | 共用形体，继续使用既有场景色调；减少动态固定光点亮度 |
| 文件格式与位置 | JS源码；PNG证据在 docs/art-reference/living-road-guidance/；浏览器原始输出在 output/playwright/living-guidance/ |
| 内存与缓存预算 | 新增图集/解码内存0；每游戏最多3条委托缓存、共享树索引；最多72个邻里光点，原主线最多24点保留 |

## 4 动画任务补充

静态道路不增加动画；光点复用正式脉动。无新源视频、帧率、裁切或身体序列，相关项不适用。猫、居民、车轮、操枪及起停继续由原正式绘制器负责，未改变锚点或时钟。暂停与对话清空委托路径，恢复时重新规划。

## 5 生成指令

修复道路逐顶点镜像，改为整条折线包围盒裁剪和共同平移。邻里委托当前步骤复用正式可通行规划器、地面光点与目标圈。坚持森林绘本比例和奶油色提示，不增加纹理、装饰、假动作或新的碰撞。制作前约定已记录，实施范围保持一致。
