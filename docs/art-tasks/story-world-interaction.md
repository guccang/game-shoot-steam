## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 资源名称与稳定标识 | 故事现场点击指引 / story-world-interaction、story-interact |
| 类别和用途 | 任务交互 UI，引导点击场景人物或物品 |
| 当前阶段和本轮目标 | 动态交互开发；移除固定底部交互按钮，保留赶路导航，靠近后直接点击目标 |
| 动态交互目标 | 箭头轻点指向本体；短按开始调查或交谈，拖动仍移动；状态不满足即隐藏 |
| 数量和变体 | 单个可复用透明按钮；人物、药箱、布条路牌、中继站、工具箱共用样式与不同实体尺寸 |
| 保留项 | 原任务路点、调查计时与中断、战斗条件、对白、奖励、角色动作和镜头 |
| 制作路线 | 现有 DOM + CSS + 内联 SVG；无需生成位图或新增美术资源 |
| 参考与同类资产 | 用户提供薄荷站位截图；scene-hit.js 原生场景命中区、navigation-markers.js 奶油黄与森林绿 |
| 已确认效果目标 | 箭头指向真正操作对象，目标旁短按可执行；不再寻找底部按钮 |
| 后续精修项 | 无新增插画需求；未来若替换箭头图案，保持脚底锚点、44px 命中下限与事件接口 |
| 使用场景 | 森林故事各章节；赶路阶段不增加点击要求 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 短“点击”标签与向下箭头，不再显示长条操作底板 |
| 变体区别 | 本体人物或物件沿用原轮廓，提示统一；操作进行中显示“操作中”，试射显示“结束试射” |
| 主次关系 | 目标物件为主体，箭头为小型次级提醒 |
| 地面衔接与邻接 | 路线、地面到达圈继续使用既有绘制；就近的旧路点悬浮标记让位于本体点击箭头 |
| 活动空间 | 不调整人物、树木或建筑，不推动镜头；透明目标区允许拖动起步；头顶空间被任务栏占用时，侧向箭头指回本体 |
| 光向与明暗 | 奶油黄填色、森林绿描边和小面积接触阴影；昼夜保持可读 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸 | SVG 显示 28×26 CSS px，viewBox 32×30；点击区域按实体身高与镜头倍率计算，宽高至少 44px |
| 锚点与原点 | 当前阶段正式人物/物件脚底，读取 storyPosition；世界镜像和镜头投影复用 placeSceneHit |
| 分层 | 原实体仍由 Canvas 排序；透明命中区 z-index 4，在 HUD 下方；箭头是其局部子元素 |
| 程序与图片职责 | 程序控制目标、距离、短按、计时、状态和镜头；SVG 仅绘制箭头 |
| 替换接口 | story-interact ID、E 键、原 interactStory/打开准备面板入口保留 |
| 透明背景 | 目标区完全透明；小标签与箭头有实色，无新全屏遮罩 |
| 碰撞与通行 | 不新增碰撞；实际目标旁与旧路点均在既有交互半径内可操作，调查取消使用同一检查 |
| 昼夜处理 | 运行时同一形体与材质；不新增昼夜图集 |
| 文件位置 | src/core/story-interaction.js、src/ui/story-interaction.js、src/styles/story.css；正式入口 createStoryPanel.renderFrame |
| 内存与缓存 | 一个复用按钮、一个内联 SVG；零新增图片、图集、离屏画布或定时器 |
| 必需资源与失败行为 | 沿用现有场景素材；显式目标未出场时报告章节和阶段错误，不默默误指向陪同者 |

## 4 动画任务补充

箭头沿游戏时间轻点，约 1.26 秒一周期、上下 3 CSS px；只移动箭头，不移动命中区。暂停跟随游戏时间停住，减少动态或调查中静止。无新身体动画、视频、序列帧、裁切或独立武器变化，相关项不适用。源码为 `createStoryInteraction.renderFrame`，镜头移动每帧继续投影。

## 5 生成指令

本轮没有调用 imagegen，因仅替换既有 UI 定位与点击方式；沿用森林绿描边和奶油黄的小型 SVG 箭头，不新增插画或位图。来源为本仓库上述程序源码，无外部图片依赖。
