# 松齿电锯射程与锯刃一致性任务单

依据：[美术标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。由美术任务模板复制并按本次范围填写。

## 1 目标与范围
- 标识：chainsaw / 14；武器动态效果修正，沿用正式 Canvas 绘制，无图片生成。
- 目标：升级范围后只伸长导板和锯链，怪物必须与可见锯链接触才受伤。
- 参考：src/rendering/characters.js 原版森林绿护罩、奶油色锯齿；保留机身、握柄、小手、后坐、独立挂载及原伤害数值。
- 变体：范围1级至最高等级；区别为导板长度和沿边锯齿数量，宽度与机身固定。
- 场景：森林实战、骑乘、浮游炮挂载、工坊预览。无新增主题或素材，PNG精修不属本轮。

## 2 造型与空间
- 剪影：短机身、封闭握柄、圆头长导板；延长部分不整体拉伸。
- 主次：锯链为攻击读数，机身保留识别色；沿用有限平涂和森林绿描边。
- 地面、邻接和通行：武器不新增地面投影或实体碰撞；角色和环境布局不变。
- 光向：沿用原武器左上亮面及场景昼夜处理。

## 3 技术交付
- 原点：原持枪锚点；机身31×26，导板宽18逻辑单位，长度按射程和实际绘制倍率换算。
- 分层：原猫身体、手持武器、小手、独立挂载和命中特效；只修改锯链几何。
- 实现：共享射程/接触几何，正式绘制器按相同导板末端绘制；原稳定ID、升级接口及声音事件保留。
- 背景：透明 Canvas，未新增位图；像素尺寸随既有画布。
- 预算：不新增图集、离屏画布或缓存，锯齿数量随有限升级等级有界增长。
- 必需资源：既有猫连续帧和场景资源；缺失不得视为验收通过。

## 4 动画任务补充
- 使用原后坐 flash 驱动局部锯齿流动，暂停停止；保持同源猫动作、独立小手和骑乘锚点。
- 不生成视频、不复制静帧、不拉伸身体；连续相位及起停证据待实机检查。

## 5 生成指令
本轮无 imagegen：修改既有代码原生武器几何，使用 src/rendering/characters.js 正式入口，不生产替代位图。
