# 种田工具栏电锯入口

> 2026-10-28 后续调整：按用户最新要求移除种田工具栏的电锯按钮，以下为历史接入记录。内部锯树规则和正式绘制器保留；`tests/farm-saw-browser.cjs` 改为内部兼容检查，不再声称存在电锯 UI 入口。当前五按钮左下角布局见 [农田 UI 任务单](farm-layer-ui.md)。

依据[美术标准](../art-generation-standard.md)与[AGENTS](../../AGENTS.md)，从美术任务单建立。本轮为现有动态交互接入，关联world-farm-delivery。

## 目标与参考
用户截图中的五按钮工具栏加入电锯，便于清理树木。顺序为锄头、镰刀、水壶、电锯、战斗、退出；沿用奶油底板、森林绿描边、原角色与全部既有动作。已有正式电锯图标、手持武器14和走近锯树事务直接复用，不生成新图片。

## 结构、尺寸与分层
按钮单排六列，工具栏宽404px并遵守手机两侧8px留白，320px宽时按钮仍不小于44px；高度62px，图标32×32，内部画布88×88。底部锚点与层级6保持，种子层仍在工具栏之上。新图标复用paintFarmToolIcon('saw')；角色电锯沿用drawFarmTool与drawRiderWeapon，未调整武器比例或脚底。

## 动态行为与保留项
点电锯高亮选中并提示点击树木；点树后通过原农活队列走近、锯树及木材结算。空地点击明确提示，切换工具与退出沿用取消规则。自动迎敌与脱战后恢复原电锯继续沿用现有农活状态，建筑提示隐藏规则保持。树木碰撞、再生、道路禁种和田块对齐不变。

## 技术交付与预算
正式入口src/ui/farm.js、src/styles/farm.css；图标及场景锯树均复用src/rendering/farm-tools.js，逻辑复用src/core/farming/farm.js。只增加一个88×88图标画布，RGBA理论约31KiB，无网络资源、图集或昼夜纹理副本。沿用正式透明Canvas与现有资源失败逻辑。PNG精修/裁切与新动作视频不适用，没有新增美术素材。

## 验收计划
真实触控选择电锯、点击树木走近完成锯树、空地反馈、键盘选择和自动迎敌后恢复；320/390/横屏及桌面既有竖版容器按钮边界与昼夜截图检查。完成后记录结果与证据。
