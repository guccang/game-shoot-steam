# 片头橘猫的绿围巾

以 assets/title/background.mp4 的草绿色长围巾、橘色条纹和奶油黄口鼻为参照。仅调整栗子橘猫。片头为站姿并持枪，身体继续取 assets/cat-front 的同源待机和移动，独立提取片头围巾连续轮廓。160×160 身体帧沿用 (80,152) 脚底；布尾在身体后层、左颈固定，速度上升时展开，停止时落下。保留操枪层与地形碰撞。

## 技术交付与验收

- 栗子调整耳距、脸宽和毛色。围巾按正式片头 0.001 秒起每 1/12 秒采一帧，共 33 帧；在原片 720×1280 坐标中采布尾的上下边缘，运行时平涂、描边。布尾锚在身体后层，速度按真实位移计算，布尾抬升和下落共用游戏时间，暂停冻结。源片已有所需轮廓，本轮直接采样。
- 身体来源、源时间、裁切及姿态匹配见 assets/cat-front/animations.json 的第一个角色。正式入口为 src/rendering/cat-animation.js 的 CatSpriteAtlas.draw；工作台 hero-breed-0 走同一入口。designCriterion 见 visual-contract.json 的 titleCatScarfCriterion。
- 透明导出位于 output/title-cat-scarf/idle.png 与 move.png。每格 160×160，每行 8 格，24 帧/秒，分别为 45 帧与 24 帧。此两张图用于交付预览；游戏使用原图集与独立布尾，保留连续速度和枪手层。无额外解码图集，浏览器采样时两张身体图集及帧缓存合计 16,998,400 字节。
- 速度验证采用 390×844 触屏浏览器的真实单指拖动，抬升权重超过 .99，松手后低于 .12。录制 output/title-cat-scarf/preview.webm 展示待机、行走、停止与独立持枪。已有动作单测 7 项通过，涵盖暂停、乘车、姿态匹配、八向枪口与缺件报告。
- 正式画面见 output/title-cat-scarf/touch-run.png、field-390.png（白天）、field-320.png（短屏夜晚）、field-580.png（桌面竖版容器）。角色、电动车、小团子、地形和 HUD 同屏。布尾在驾驶者背后，未改地形、可通行性、枪械与交互热区。结构、轮廓及分层开发通过；无单独的精修图片替换阶段。

## 乘车速度补充
以本次直升机截图检查驾驶座上的栗子。沿用左颈布尾、原序列帧、驾驶坐姿和叠放顺序，目标为低速垂下、实际速度超过 60 世界单位/秒开始抬升、达到 160 时完全展开。沿用原阵风叠加、停车缓落与减少动态逻辑。

验收通过。正式入口为 updateCatMotion → CatSpriteAtlas.draw → drawTitleScarf，设计项为 titleCatScarfCriterion。通过游戏的召车入口登上直升机，以单指摇杆驾驶；390×844 白天、320×568 夜晚及 580×844 竖版容器均测得车上步态权重为 0，高速布尾抬升权重超过 0.93，松手停车后低于 0.02。地形、HUD、怪物和旋翼在同屏复核中可见。现场截图为 output/title-cat-scarf/heli-moving-{390,320,580}.png 与对应 heli-stop 截图；heli-scarf-compare.png 为实际昼间截图裁切。复用原图集与缓存，本次新增运行位图 0 字节。角色动作与矿车乘坐针对性检查共 12 项通过。
