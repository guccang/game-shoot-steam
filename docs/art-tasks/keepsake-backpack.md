# 小背包与巡林手机美术任务单

执行依据：[美术标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。

## 1 目标与范围

- 名称与稳定标识：小背包 `keepsake-backpack`；信 `elder-letter`、钥匙 `house-key`、手机 `patrol-phone`。
- 类别：随身物品 UI；本轮为程序与 SVG 动态交互开发，后续 PNG 精修另行开展。
- 目标：折叠菜单进入小背包，三件重要物品各有明确用途；手机连接现有地图、邻居作息与导航。
- 交互：选择物品、重读来信、完成首次阅读、查看小屋状态、打开地图、拨打邻居电话、前往邻居或回家；沿用弹窗暂停归属。
- 数量与结构差异：背包为带提手和翻盖的布包；信是横向封口信封；钥匙有圆环、长柄和齿；手机为竖向外壳、屏幕与听筒。
- 保留项：角色、怪物、载具、世界建筑与动作均不改；物品不出售、不消耗；首次读信仍保存正式入职进度。
- 路线与参考：沿用 `src/styles/ui-foundation.css`、`src/ui/ranger-arrival.js`、既有任务页；本轮直接扩展代码原生 SVG 图标，不生成位图。
- 精修参照与后续：先确认实际手机页面比例与交互，后续可按相同 viewBox 替换静态图案；本轮无 PNG 替换。
- 场景：森林随身面板，旧存档兼容已有交接记录。

## 2 造型与空间

- 剪影和主次：背包标题配小提手图标，三件物品横排布袋格；下方正文与操作，手机通讯录逐行排列。
- 配色：森林绿 `#315c43`、深绿 `#234333`、奶油 `#fff6dc`、草绿 `#e8edcf`、麦黄 `#edbd63`；直接复用 UI 变量。
- 字体：现有汉仪旗黑；标题 22px，正文 14px，辅助 12px。内容左对齐，物品格居中。
- 布局：固定标题 / 横排物品格 / 可滚动详情 / 固定操作栏；不新增桌面布局。
- 地面衔接、邻接和通行：不适用，纯 UI 不增加场景实体或碰撞；折叠时不增加战场常驻遮挡。
- 光向：图标有限平涂，左上亮面，不添加动态光源；面板昼夜共用纸面材质。

## 3 技术交付

- 尺寸：SVG viewBox 64×64；菜单 36px，物品图标 48px，详情 64px；触控至少 44px。
- 锚点：图标中心，DOM 随面板布局；无世界坐标锚点。
- 分层：图标轮廓 / 平涂主体 / 少量细节；数值、文案和操作保持 DOM。
- 替换接口：保留物品稳定 ID、viewBox、aria 名称与事件属性。
- 透明：SVG 图标透明背景；无位图裁切和解码副本。
- 昼夜：既有世界绘制器正常运行，UI 保持明晰对比。
- 正式源码：`src/ui/keepsake-backpack.js`、`src/ui/keepsake-icons.js`、`src/styles/keepsake-backpack.css`。
- 预算：4 个内联 SVG 模板，按打开事件渲染；无逐帧 DOM 重建、无新 Canvas、无新图片网络请求；源码目标小于 20KB。
- 必需资源：新增代码及已有字体、地图绘制器；模块缺失明确报错，不使用图像备用。

## 4 动画任务补充

本轮为静态物品图标与用户操作状态切换，无新增肢体动画、视频、帧率、循环或独立操枪部件；既有角色动作保持。暂停、恢复、电话与地图返回由正式弹窗系统处理，不设装饰性计时器。

## 5 生成指令

未调用 imagegen：本轮扩展既有代码原生 UI 图标系统，SVG 更适合保持尺寸与触控布局；上述四种剪影、配色、尺寸即程序制作要求。PNG 精修属于后续阶段。

## 6 验收记录

制作前计划：实际运行检查新档交接、旧档迁移、手机点击、首次读信保存失败、电话不远程交付、导航、地图嵌套暂停、短屏/长屏/横屏及昼夜同屏。

验收日期：2026-10-27；结论：通过。本地默认端口 4175 已被占用，本次使用隔离服务 4178。以下为 Chromium 手机触控模拟及桌面浏览器检查，未声称使用实体手机。

- 功能：重要物品专项与直接受影响的入职测试共 13 项通过；覆盖新档空背包、正常/跳过交接、保存失败回滚、旧档补齐、重复阅读、电话不推进委托、位置跟随及战斗导航限制。
- 实际交互：从正式折叠菜单点击进入；首次读信失败后重试成功；手机打开地图再返回仍保持背包暂停，关闭后恢复游戏；拨号、挂断、拜访导航均通过。夜间休息留语音，天气避雨仍沿用居民实际作息。
- 屏幕：320×568、360×640、390×844、430×932、844×390、1280×900 各检查白天/夜晚，共 12 组通过；沿用同一手机底板，无横向溢出，触控区至少 44px，长内容可滚动，控制台无脚本错误。
- 遮挡：实测发现横屏展开菜单与任务卡重叠时点按被任务卡截获，已提高展开菜单层级并通过交互复测；收起后只保留菜单按钮，不新增战场常驻面板。无新场景实体或碰撞，通行不变。
- 美术同屏：检查正式世界中的角色、载具、怪物、建筑与背包菜单昼夜截图，绿描边、奶油底和柔和草木色一致；小尺寸信封、钥匙、手机剪影可区分。另复核来信、钥匙详情、通话及窄屏/横屏正文，无裁字或按钮重叠。
- 动作真实性：本轮无角色、怪物、载具或武器动作改动，不适用新增动画帧验收；继续使用正式世界绘制器。
- 资源预算：UI、图标、手机逻辑与样式源码合计 13,949 字节，无新增位图、视频或网络素材请求；事件驱动更新，不逐帧重建背包 DOM。
