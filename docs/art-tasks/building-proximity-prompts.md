# 告示牌附近提示统一

依据：[游戏美术资源生成标准](../art-generation-standard.md)、[AGENTS.md](../../AGENTS.md)。按[任务单](../art-generation-brief.md)记录本次程序界面调整。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称、标识、类别 | 清缴告示牌附近提示；复用 nearby-interaction / clearing；场景 UI |
| 当前阶段与目标 | 动态交互调整：未接主线也能靠近看到提示，固定在告示牌正上方，仅保留一个入口 |
| 动态与交互 | 靠近显示、离开隐藏；未接清缴显示“点告示牌接取”，已接显示“查看清缴委托”；点击仍打开正式清缴页 |
| 数量与变体 | 一个持久节点、两种任务状态文案，不创建第二个浮层 |
| 保留项 | 告示牌本体、角色动作、独立操枪、碰撞、接取与导航权限；其他设施原有入口 |
| 制作路线 | HTML/CSS/JavaScript；复用手机 UI 框架，不需要生成新图片 |
| 参考 | 用户两张截图；src/styles/ui-foundation.css、src/ui/nearby-interaction.js |
| 确认目标及后续精修 | 本次检查位置、状态和触控；没有新增插画或 PNG 精修项 |
| 场景 | 普通森林营地清缴告示牌 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 剪影与变体 | 奶油色短圆角提示；状态只换文字，不改变告示牌造型 |
| 主次关系 | 告示牌为主体，提示位于顶边外，不覆盖人物和牌面等级 |
| 地面与活动空间 | 不修改道路、碰撞及前后遮挡；提示不参与世界碰撞 |
| 邻接组合 | 森林营地、回信驿与清缴告示牌，保留现有间距 |
| 光向与明暗 | 建筑沿用昼夜绘制，UI 用原森林绿文字与奶油底 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸与像素倍率 | DOM 自适应文字宽度、至少 44px 高；无新增图像尺寸或缩放 |
| 锚点 | 清缴牌底座的世界坐标向上 108 单位，提示底边固定到该点 |
| 分层与透明 | 原场景上方 DOM 层、圆角外透明；建筑及人物层不变 |
| 程序与图片职责 | 程序处理距离、状态、文字、点击和镜头投影；无新增图片 |
| 接口与保留项 | nearby-interaction 节点及 clearing 稳定 ID、正式 activate 路径与场景热点保留 |
| 碰撞与昼夜 | 不改碰撞；昼夜保持相同锚点与文字可读性 |
| 文件 | src/ui/nearby-interaction.js、src/ui/operation-guide.js、src/world/interaction-anchors.js、src/styles/ui-foundation.css |
| 资源预算与失败 | 复用单个节点，零新增贴图/画布/缓存；原素材失败策略不变 |

## 4 动画任务补充

本次无角色、怪物、载具或视频动作修改，动作时钟、裁切、起停、局部动作与独立部件均沿用原运行时。仅根据距离改变提示显隐，镜头移动采用原世界投影，不新增动画时钟。

## 5 生成指令

不使用 imagegen：修改已有程序提示，原图案与建筑均保留。正式实现入口为 createNearbyInteraction，移除 createOperationGuide 中重复的场景清缴提示，面板内指引保留。

## 6 验收记录

| 设计目标 | 实际验收结果 |
| --- | --- |
| 风格与空间 | 奶油底、森林绿字，牌顶保留10世界单位间隔；原牌面、角色、道路未改变 |
| 遮挡与短屏 | 发现320短屏路线卡遮挡后修订：到达清缴牌前收起重复“去告示牌”任务卡，离开恢复；复核截图已无重叠 |
| 动态交互 | 隔离触控浏览器实际 tap 打开清缴页并接取成功，接取后改为“查看清缴委托”；远离隐藏；未进入清缴主线也显示 |
| 任务去重 | 清缴主线进行中无第二层黄色操作提示，无绿色重复按钮；面板内引导继续工作 |
| 固定锚点 | 两侧走位均保持世界锚点(1000,882)，投影误差≤0.013px；手机触控区域96×44px |
| 昼夜与设备 | 390×844、320×568、1280×900既有竖版容器昼夜六张图通过；检查390白天与320夜晚实际画面 |
| 动作与通行 | 不修改角色/怪物/载具动作及碰撞，沿用原资源；本次只有DOM提示，相关机械动作测试不适用 |
| 资源与预算 | 零新增图片/画布，复用一个提示节点；浏览器pageerror为0 |
| PNG替换 | 不适用，本轮无图片替换 |
