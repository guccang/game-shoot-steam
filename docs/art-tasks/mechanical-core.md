# 机械核心与机械小猫美术任务单

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。

## 1 目标与范围
| 字段 | 内容 |
| --- | --- |
| 名称与稳定标识 | 机械核心 mechanical-core；固定武器编号 15 |
| 类别和用途 | 独立手持召唤控制器、地面近战机械小猫、工坊部件 |
| 目标 | 看清控制核心与追敌挥爪的小猫；初始 3 只，协同模块 1–8 级对应 3–10 只 |
| 数量和变体 | 至多 10 只；联动猎爪、重锤爪两种互斥结构；协同模块逐级增加连接端口 |
| 保留项 | 原角色视频帧、小手、后坐、无人机与浮游炮、所有载具动作和地图碰撞 |
| 制作路线 | Canvas 程序化独立部件与关节动画，不生成等级组合图集 |
| 参考 | 现有 characters.js、equipment-parts.js、森林昼夜美术基准 |
| 使用场景 | 战场、工坊、试射、装备介绍、正式视觉复核 |

## 2 造型与空间
| 字段 | 内容 |
| --- | --- |
| 剪影 | 手持六角能源核心；小猫双耳、面甲、四条关节腿、分节尾与背部能源舱 |
| 结构差异 | 区别无人机的旋翼与浮游炮的炮管；近战爪与腿部伺服机构独立 |
| 主次 | 玩家为主体，机械小猫约半身高；小面积薄荷能源灯 |
| 地面与活动空间 | 脚底接触影，按脚底深度排序；小猫遵守地形和树干，自己不阻挡角色通行 |
| 邻接 | 共享林地、营地、道路；不添加建筑或固定障碍 |
| 光照 | 森林绿描边、奶油装甲、草木绿壳；沿用场景昼夜处理 |

## 3 技术交付
| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸 | 核心约 56×54；小猫含尾和接触影约 54×44，爪击伸出约 12 单位 |
| 像素与倍率 | 运行时矢量 Canvas；无位图像素或图集倍率 |
| 锚点 | 核心握持点 (0,0)；小猫脚底 (x,y)，关节独立局部坐标 |
| 分层 | 接触影、远腿、尾、躯干、头耳、近腿、爪击 |
| 背景 | 透明，不包含不透明地板 |
| 碰撞 | 地面半径 9；不扩大玩家碰撞，不允许隔空或穿水近战命中 |
| 昼夜 | 共用形体与现有场景夜色，无夜间副本 |
| 文件 | src/combat/mechanical.js、src/rendering/mechanical.js；证据 output/playwright/mechanical-core |
| 预算 | 每装备最多 10 节点；无新贴图、离屏画布或组合缓存；场景复用主画布 |

## 4 动画
| 字段 | 内容 |
| --- | --- |
| 动作与时长 | 跟随、追击、挥爪约 0.24 秒、归队；移动相位随实际距离推进 |
| 帧率 | 正式 dt 驱动连续关节运动，暂停冻结 |
| 视频与裁切 | 不适用：机械结构程序动画，不替换玩家视频身体 |
| 起停 | 停止保留腿部相位，减少动态保留关键挥爪与工具进度 |
| 局部动作 | 四肢错相弯曲、脚掌落地、前爪伸展、尾节摆动；不整图拉伸代替步行 |
| 独立部件 | 核心可替换部件、协同端口、猫爪、伺服关节、背部能源舱 |

## 5 制作约束
沿用森林绘本配色和俯视比例，以轮廓和关节区分机械猫与飞行武器；使用小面积能源色。禁止复制玩家猫静帧、整体缩放替代升级、满屏辉光与新增图集。新武器基础单猫伤害 16、挥爪间隔 0.8 秒、行动半径 380、共享能源 36、充能 2.6 秒；协同模块按现有部件价格 35×等级金币与15×等级木材升级。

解锁：机械核心固定编号 15，累计击败 17 次领主；首次购买 12000 金币、4200 木材、140 机械零件、100 能源晶体、7 首领核心。协同模块七次升级共 980 金币、420 木材。首版未开放召唤武器车载；后续[机械伙伴扩展](mechanical-companions.md)已开放机械核心、无人机、浮游炮的独立车载购买和挂载，仍禁止递归挂入其他召唤器；受限制秘境使用独立一级部件，守护支架初始三只。

结论：**通过**。本轮新增功能、正式动作、工坊与试射交互及昼夜同屏验收完成。
