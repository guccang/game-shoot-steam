# 工坊武器单屏布局任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)、[手机 UI 框架](../ui-foundation.md)。由美术生成任务单复制并按本次界面范围填写。日期：2026-10-26。

## 1 目标与范围

| 字段 | 本轮约定 |
| --- | --- |
| 名称与稳定标识 | 武器工坊单屏布局 / workshop-weapon-focus |
| 类别与用途 | 正式 HTML/CSS 界面重排，不新增位图、视频或游戏实体 |
| 目标 | 不显示领地/营地等级；购买、升级、改装、成长只保留当前操作需要的信息；突出武器预览 |
| 用户补充 | 左侧划动区域展示枪械缩略图列表；仅左侧列表允许独立滚动，右侧详情和操作不用滚动 |
| 数量与变体 | 四个功能页；手机竖屏、短横屏复用同一底板 |
| 保留项 | 正式报价、归属筛选、材料来源、免费恢复、草稿保护、部件动画、触控施工、试射及装备事务 |
| 制作路线 | 重排正式 DOM/CSS，预览和缩略图继续调用正式 Canvas 绘制器 |
| 参考 | ui-foundation.css、原工坊、森林绿和奶油色手机底板 |
| 使用场景 | 森林中的武器工坊；共用成长页移除营地信息，载具保留原操作布局 |

## 2 造型与空间

| 字段 | 本轮约定 |
| --- | --- |
| 主体 | 左侧窄枪架、右侧大预览、固定页签和底部报价 |
| 结构差异 | 购买：六项核心属性和报价；升级：部件目录或试装对比与工具；改装：两种方案和当前效果；成长：熟练度和改装条件 |
| 主次关系 | 真实武器为主体，缩略图用于选型；不重复堆叠营地、完整属性和无关操作 |
| 地面衔接、活动空间、邻接组合 | 不适用：不修改地形、建筑、世界坐标或碰撞 |
| 明暗与字体 | 沿用森林绿 #315c43、深绿 #234333、奶油 #fff6dc、浅草绿 #e8edcf、麦穗黄 #edbd63；本地汉仪旗黑，标题20px，正文12–14px |

## 4 动画任务补充

不生成或替换动作素材。枪械、手、后坐、猫身体、怪物、车辆与环境绘制器均不修改。保留正式部件替换动画、工具施工及演练入口。试装只建立草稿，实际长按完成后才提交费用。

## 5 制作指令与设计复核

沿用手机 UI 框架的颜色、字体、底板、44px触控下限与安全区；武器为右侧主体。初版型号选择栏已按用户补充改为左侧独立划动枪架。购买价格只展示需要数量和不足缺口，材料图标保留来源入口；实际购买优惠照常由规则计算，不显示营地等级。

不新增另一套主题、不以缩小整个界面替代布局、不隐藏越界内容冒充单屏通过。升级的目录与施工状态复用空间。特殊召唤武器的购买页只给六项核心参数，详细配置在已有专用页面中保留。

## 6 验收记录

| 设计目标 | 证据与实际结果 |
| --- | --- |
| 系列一致、武器突出 | 复用正式枪械绘制器和手机底板；人工查看购买、升级、改装、成长及材料不足截图 |
| 落地、遮挡、通行 | 世界层未修改，不适用新增绕行和水界测试；工坊覆盖层按正式DOM检查控件边界 |
| 动作真实、部件独立 | 真实触摸拖工具到连接点，按住完成升级；改装和恢复原厂由正式按钮提交；试射进入并返回成功 |
| 左侧独立划动 | 真实触摸滑动枪架后选择末尾武器，右侧面板 scrollTop 保持0 |
| 手机/昼夜/宽屏复核 | 6种视口×昼夜×4页签；全部型号在320×568检查四页；129个状态采样无内部溢出、无领地文案、操作触控区至少44px |
| 资源完整与预算 | 浏览器运行无pageerror；无新增位图或动画资源，舞台保留原像素预算 |
| 交易与边界 | 免费购买、正常扣费购买、资源不足禁用、材料来源、免费草稿切页、触控升级、改装、免费恢复、空目录返回通过 |
| 针对性单测 | workshop、catalog、components、mastery共27项：25通过，2项载具炮塔失败；未修改master上同样复现 turret/0/damage 和 turret/19/reload 失败，属于已有问题 |
