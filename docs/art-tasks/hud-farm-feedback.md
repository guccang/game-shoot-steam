## 1 任务基本信息
动态效果开发；类型为 UI 状态与地面选址反馈。目标：生命面板置于钱包下方，低于 25% 时柔和红色呼吸；任务条紧凑且整条切换寻路；锄头显示真实田块范围与可用性。参考本轮用户两张截图及现有奶油纸、森林绿 UI。采用 CSS 与 DOM，不生成静态图片，保持角色、武器、地形及操作队列。

## 2 造型与空间
生命面板保留名称、血条、弹药与载具入口；任务保持方向、距离与标题。田块预览为 50×36 世界单位圆角矩形，绿色实线加勾表示可用，红色虚线加叉表示不可用，不单靠颜色。预览覆盖原地形但不占碰撞、不阻挡操作，生命面板与任务逐层避让。

## 3 技术交付
使用原动态视口与安全区。地块中心为世界锚点，复用镜头映射、最近地图镜像和 farmDigTarget 的吸附与校验；UI 位于场景上层且低于弹窗。状态由程序计算，预览不写存档、不扣资源。新增一个 DOM 预览，无位图或派生画布缓存，无新增必需素材。手机按钮至少 44px。昼夜使用同一可读纸色与边框，保留既有素材加载失败行为。

## 4 动画任务补充
低生命红色底色和边缘采用 1.8 秒 CSS 平滑呼吸；恢复至 25% 及以上停止，暂停时冻结，减少动态偏好显示静态红色。角色及载具真实动作不变；无视频、裁切或独立运动部件新增。
