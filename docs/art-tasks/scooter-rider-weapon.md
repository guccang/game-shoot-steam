# 电动车骑乘操枪任务单

## 目标与范围
- 稳定标识：ranger-scooter / scooter-rider-weapon。
- 目标：骑电动车时猫猫可见地使用当前手持武器；电动车在工坊与载具收藏中第一位。
- 参考：正式 characters.js、scooter.js；保持森林绿轮廓、奶油黄车身、真实视频猫身体、原车轮与动作。
- 路线：复用程序化手、枪、后坐、枪口分层，不新增位图或整图缩放。

## 造型、空间与技术交付
- 结构：原车体不变；猫脚底基准抬高 27 世界单位，握持锚点、弹道使用同一个座位偏移。
- 分层：后车体 → 猫身体 → 前车体 → 独立枪械与握枪手 → 正式弹丸特效。
- 尺寸：角色沿用 PLAYER_SCALE，枪沿用 GUN_SCALE；不改变碰撞体、地面锚点、通行或桥头。
- 变体：站立／骑乘共用同一武器与部件结构；不是新车型，无新增结构变体要求。
- 光向：沿用正式昼夜调色和左上受光；不新增灯光。
- 动画：沿用连续身体片段、轮胎转动、转向与后坐时钟；入职演出保持空手。
- 资源：零新增图集、解码像素、画布、缓存或音频；仅重用一次手持武器绘制。
- 生成指令：不适用位图生成；按上述正式绘制接口复用部件。
