# 章节目标导航美术任务单

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。由标准任务单复制并按本次UI范围填写。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 第一章目标罗盘 / story-target-navigation |
| 类别和用途 | 程序化SVG界面，显示当前任务目标的实时方向 |
| 本轮目标 | 圆圈中有箭头，移动时指向目标；靠近变浅绿，重合改中心点 |
| 数量和变体 | 一个圆盘，远处/附近共用剪影；附近改底色，精确重合以中心点避免无效方向 |
| 保留项 | 角色与载具真实动画、独立枪械、剧情与交互规则、世界通路 |
| 制作路线 | 正式DOM中的SVG圆盘与旋转箭头 |
| 参考与同类资产 | src/styles/story.css；docs/art-reference/sunleaf/final-guard-320.png；既有季节圆环 |
| 使用场景 | 第一章进行中；任务栏左侧，领主战移至血条左侧 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 奶油黄圆盘、森林绿箭头、清楚箭头尖端 |
| 与其他变体的区别 | 非系列资源；无新增角色或景物变体，不适用两项结构差异 |
| 主次关系 | 44像素辅助导航，与任务文本和血量并列 |
| 地面衔接 | 不适用：屏幕HUD |
| 活动空间 | pointer-events:none，不截获移动，不新增实体或通路阻挡 |
| 邻接组合 | 当前任务说明、领主名称与血量，分栏留出独立位置 |
| 光向与明暗 | 有限平涂，高对比绿描边；HUD不随世界夜色压暗 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 44×44 CSS像素，圆心22,22，半径20 |
| 像素尺寸与倍率 | SVG 44×44 viewBox，随设备像素比矢量栅格化 |
| 锚点与原点 | 圆心旋转；世界X向右、Y向下；沿最近镜像取方向 |
| 分层 | 既有HUD内，无新增世界层 |
| 透明背景 | 圆盘外透明，圆盘内部不透明奶油色 |
| 碰撞与可通行性 | 纯显示，无碰撞，不拦截指针 |
| 昼夜处理 | 同一轮廓与配色保持可读，无昼夜副本 |
| 文件格式与位置 | src/ui/story-navigation.js、src/styles/story.css；验收截图output/playwright/story-navigation，确认基准docs/art-reference/story-navigation |
| 内存与缓存预算 | 一个DOM/SVG、两个circle和一个path；无位图资源、无新增画布、无帧缓存；节点总数不随时间增加 |

## 4 动画任务补充

方向角由当前角色坐标与目标点计算，HUD刷新时更新；不做CSS旋转补间，避免跨360度绕圈。暂停隐藏，恢复重新取方向，减少动态不影响必要方位提示。真实身体、操枪、载具动作均未修改；视频、帧率、裁切与独立部件接合不适用。

## 5 生成指令

采用现有奶油黄和森林绿平涂界面，圆盘44×44，箭头绕圆心旋转。无位图生成、文字烘焙、强辉光、额外场景实体；保留正式剧情规则和全部角色动作。
