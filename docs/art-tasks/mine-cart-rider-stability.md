# 矿车乘坐稳定性修复

依据[美术标准](../art-generation-standard.md)与[项目合同](../../AGENTS.md)，由任务模板复制后按修复范围填写。

## 1 目标与根因
稳定标识 mine-cart-rider-stability。沿用现有矿车、猫与森林绘本风格，无新增美术资源。正式绘制时镜头使用插值玩家坐标，矿车却从未插值的progress.mining.carts读取25Hz逻辑坐标；车内猫跟随后者，导致每个模拟步周期相对镜头跳动。修复同一渲染帧内镜头、车体、乘坐位置和轮毂的时间对齐。不是冻结猫动画来隐藏问题。

## 2 结构、接口与资源
矿车原尺寸、车厢前后层、猫脚底相对车体y=-8与原PLAYER_SCALE全部保留。新增仅当前乘坐矿车的表现快照；不递归复制或改写progress，不改轨道、转弯选路、速度、碰撞、费用、停车位置及存档。按矿层、房间和cart.id识别同一车辆，原子保存替换对象后仍连续；上下车、暂停、切层、传送立即同步权威位置。内存仅一份历史及一份表现对象，无新位图或离屏画布。

## 3 动态与分层
原真实连续待机/移动视频帧继续由身体动画时钟和姿态匹配驱动，车内保持待机、下车恢复步行；不修改源图集、帧率、锚点，不复制静帧，不整体缩放拉伸。轮毂仍按真实距离转动，只平滑显示相位。镜头与车厢共享同一表现位置，人物保持在后车厢与前挡板之间。减少动态、暂停、起停状态沿用原有系统。

## 4 验收计划
按25Hz逻辑及60/90/120Hz采样验证直线、四向、转弯、折返、连续停启；验证保存替换、换车和深层同ID隔离、无权威状态写入。正式手机390/320与短屏昼夜，连续记录车体和猫锚点的屏幕误差，检查原真实帧仍在变化、停车位置轮毂冻结。正式入口render-interpolation与drawMining，inspectMineCartRider绑定designCriterion。截图录像及日志output/playwright/mine-cart-rider-stability，实际结论见下节。本轮无imagegen或PNG制作，也没有替换占位图的后续依赖。


## 5 实际验收（2026-11-03）

结论：本次乘坐稳定性修复通过。原资源尺寸、锚点、猫身体真实视频帧、上下车及驾驶时钟均保留。正式入口为 `createRenderInterpolation → createMineCartInterpolation` 与 `drawMining`；验收 `inspectMineCartRider` 读取真正绘制的座位、轮毂、镜头和身体时钟，绑定 `mine-cart-rider-stability`。

| 目标 | 证据与结果 |
| --- | --- |
| 复现抖动来源 | 新回归在旧代码上失败：同一帧存档车体x=557.04，插值镜头玩家x=551.76，相差5.28世界单位。旧版车体和车内猫周期性领先镜头，不是待机动作本身的问题。日志 `before.log`。 |
| 同帧位置一致 | 修复后25Hz逻辑配60/90/120Hz显示的四向、转弯采样全部同位；浏览器710次显示帧采样的cameraError均为0，屏幕锚点变化最大约1.42×10^-13像素（浮点舍入）。 |
| 保留真实动作 | 昼夜各140帧实测均播放44个不同原待机帧，行驶中的步行权重为0；下车后真实方向键步行权重恢复到0.989。没有复制帧、冻结身体、重置无关姿态或改动图集。 |
| 行驶与起停 | 实际从西侧经过路口转北、尽头折返；昼间累计行驶约733单位、夜间565单位。立即停车后50次采样的车位变化0、轮毂变化0，猫仍有23个待机帧；重启继续行驶，方向弹窗暂停身体时钟，关闭恢复。 |
| 事务与边界 | 行驶中正式miningCommit成功替换进度及矿车对象，后续60次采样仍无抖动；单测覆盖上下车、换车、不同深度相同ID、传送和重置，表现投影不写回进度。 |
| 手机与昼夜 | 正式390×844、320×568、844×390均昼夜采样并截图，沿用既有手机容器，无新增布局。见[行驶白天](../art-reference/mine-cart-rider-driving-day.png)、[行驶夜晚](../art-reference/mine-cart-rider-driving-night.png)、[320夜晚](../art-reference/mine-cart-rider-phone-320-night.png)、[短屏](../art-reference/mine-cart-rider-phone-844-day.png)。 |
| 减少动态与资源 | 减少动态时身体固定原设置的首帧，矿车和轮毂仍正常行驶，锚点误差0。仅保留一辆当前乘坐车的历史与表现对象，不复制整个进度；新位图0、离屏画布0、昼夜副本0。 |

检查范围：`mine-cart-rider.test.mjs` 4项全部通过；`mine-cart-directions.test.mjs` 9项全部通过；`fixed-step.test.mjs` 9项通过，1项既有射速用例失败。合计22项通过、1项既有失败，未运行全量测试。该失败为 `正式Game连射计时在25/60Hz一致，高速武器不受25发每秒上限限制` 的期望射击数断言；在未修改的main（586937f）上单独运行同一用例也失败，确认与本次只改表现插值无关，没有修改射速逻辑或放宽断言。新增矿车用例修复前失败、修复后通过。

浏览器 `tests/mine-cart-rider-browser.cjs` 全部通过，9张截图、710帧连续读数，页面异常0；录像、日志与结果 `summary.json` 保存在 `output/playwright/mine-cart-rider-stability/`，合并时复制到主仓库同一路径。测试曾用首尾位移检查驾驶，端点折返返回原处导致误判，已改成累计真实行程并完整重跑通过。测试源码默认4175，本轮为保留已有服务，以4176运行独立工作区临时副本。

本轮不适用：无新的角色、怪物、载具资源或PNG精修，无武器操控改动；原分层、怪物与地形显示由既有合同继续约束。静态截图用于检查座位遮挡和手机比例，稳定性结论以连续显示采样及录像为依据。没有尚未完成的本次修订项。
