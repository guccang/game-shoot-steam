# 美术风格目录隔离与设置切换

依据：[美术标准](../art-generation-standard.md)、[动作与开发合同](../../AGENTS.md)。

## 制作前合同

- 目标：将已确认清澈卡通与原版森林美术分别放入独立目录，在现有手机设置中即时切换；不更换引擎、不重启战斗、不合并master。
- 参考与范围：原版取美术试版前`884e703`的绘制源码，清澈版取`16906ce`；两套轮廓、颜色、密度和形体表现保持各自完整。同源角色视频、玩法配置、碰撞、地图坐标、血量、射击和昼夜天气继续共用。
- 制作路线：程序绘制入口分发到风格目录；没有新imagegen或PNG精修。本轮只隔离既有资产。小屋两套PNG分别保存，沿用360×328、逻辑180×164及锚点(180,296)，独立窗光/积雪仍由程序绘制。
- 动态与交互：切换时预载必需图片，失败明确提示并保留当前风格；清理旧地形/树木/怪物/建筑缓存，重建表现层而保持当前游戏对象、坐标、动作时钟、弹药、敌人、日历和天气过渡。设置沿用既有底板、中文文案和44px触控区。
- 文件布局：`src/art-styles/classic/`与`clear/`保存有差异的绘制模块，公共`src/rendering/`入口保持稳定；`assets/art-styles/`隔离两套小屋文件。只复制美术绘制，不复制Game、战斗或数值逻辑。
- 尺寸/分层/通路：不改原锚点、分层、比例、角色剪影、手持武器关系和可通行几何。静态资源更名不修改稳定装备ID。
- 缓存与预算：切换释放派生纹理，不随切换次数累积整套纹理；只额外保留两张小屋解码图，其他运行资源共用。
- 验收目标`art-style-switch`：320/390手机设置切换、刷新偏好、昼夜雨雪、四轮与主炮、地图/图标一致；切换前后玩法快照相同，缺图回退、连续切换缓存、图片实际加载与正式绘制器截图。非物理手机性能承诺。结果补录于文末。

## 后续阶段

图片精修及新风格另立任务；本次不生成新图，也不改变已确认清澈画面的造型。

## 完成与验收记录

56个美术/图集模块按原版与清澈版隔离，公共绘制入口保持函数名和参数；两套小屋PNG以及各5张720×560地图底图分目录交付。地图通过正式绘制器离线重导出，附像素尺寸、文件哈希及递归源码指纹。没有新imagegen调用，原角色视频图集和动作合成代码共用。

正式入口：`src/art-styles/controller.js`、`src/rendering/renderer.js#refreshArtStyle`、`src/ui/art-style-control.js`；`visual-contract.json#artStyleCriterion`绑定`visual-review.js#inspectArtStyle`。结构和具体配色/线宽/密度变化见[风格说明](../art-styles.md)。

| 设计目标 | 实际结果 |
| --- | --- |
| 同场景风格一致 | 手机390×844同地点分别检查两套风格晴昼、雨夜、冬雪；小屋、车体、树木、围栏、麦田和地面随风格同步。清澈版保持上一轮确认造型，原版恢复美术试版前外观。 |
| 设置与触控 | 320×568设置内两个按钮宽127、高44像素，使用现有底板与按钮样式；无横向溢出。刷新后仍保留上次风格。`settings-320.png`。 |
| 不改变战斗 | 设置暂停时，切换前后序列化的进度、角色、载具、敌人、战斗时间和日历完全相同；切换后两套风格均实际驾驶，位移与四轮相位正常推进。 |
| 主炮和图标 | 两套风格实际生成敌人并触发自动射击，弹药消耗及非零后坐通过；载具快捷图标图像随切换变化。`classic-firing.png`、`clear-firing.png`。 |
| 昼夜天气过渡 | 晴昼向雨夜渐变过程中切换，原EnvironmentTransition、SceneTone、SeasonTransition实例全部保持；没有重置过渡端点或替换Game.update。 |
| 地图总览 | 实际菜单打开地图，两套分别请求独立目录底图，配色与场景对应，玩家/任务信息继续动态。`classic-map.png`、`clear-map.png`。 |
| 必需资源失败 | 浏览器拦截原版小屋PNG，切换明确显示失败，原清澈选择和完整战斗快照不变；解除拦截后再次点击成功。`missing-resource.png`及资源验证JSON。 |
| 缓存与预算 | 连续切换后地面块不超过64上限，无context丢失；已停用风格的树木、建筑、山体、怪物图集均为0字节；角色图集共用，小屋最多两张合计944,640解码字节。地图仍两张解码上限。实际场景峰值见验收JSON，不声称手机GPU峰值/FPS。 |
| 存档与通行 | 试玩localStorage仅新增显示偏好键，没有写入正式进度；本轮不改地图/碰撞/足底排序，通路由既有地貌针对性检查覆盖。没有实体结构或交互热点变更。 |

针对性单测26项通过：风格接口与资源、地图缓存/指纹、车轮、季节/天气、地貌和内存试玩。首轮地图旧清单指纹检查指出资源路径迁移，已改为核验两套新交付地图并重新通过6项地图检查；未跳过哈希校验。未运行全量测试。全部新增/改动JavaScript语法与JSON另行检查。

浏览器证据：`output/playwright/art-style-switch/verification.txt`、`resources-verification.txt`、`switching.webm`；长期截图与结构化结果：[验收目录](../art-reference/art-style-switch/verification.json)。测试使用真实浏览器的手机视口与触摸模拟，未宣称物理手机安装包测试。

结论：本轮目录隔离、即时设置切换及相关动态检查通过。保留`codex/art-style-switch`独立工作树，不合并master；4176展示本分支。此前`codex/art-style-options`继续保留作为已确认画风版本。
