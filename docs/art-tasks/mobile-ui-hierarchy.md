# 手机 UI 三层统一任务单

依据：[美术生成标准](../art-generation-standard.md)、[任务单模板](../art-generation-brief.md)、[通用框架](../ui-foundation.md)。本次继续使用 frontend-design 的设计复核与实际截图流程。

## 1 目标与范围
| 字段 | 填写内容 |
| --- | --- |
| 资源名称 / 标识 | 手机 UI 三层统一 / mobile-ui-hierarchy |
| 类别与用途 | 程序化 HTML/CSS：战场 HUD、任务簿、清缴页、暂停弹窗、NPC 对话 |
| 本轮目标 | 从颜色接近提升为组件与页面结构统一，同时保留信息、功能、对话三层区别 |
| 数量和变体 | 战场轻底板；功能固定标题/滚动正文/固定操作；底部全宽对话与居中紧凑暂停 |
| 保留项 | 所有稳定 ID、存档、任务接取与导航、暂停归属、剧情计时、世界美术和独立操枪 |
| 制作路线 | 共享 CSS 变量与结构类，调整正式 HTML，不生成位图 |
| 参考 | 用户七张实机截图；docs/art-reference/ui-foundation；docs/art-reference/npc-bottom-dialogue-day.png |
| 使用场景 | 手机巡游、清缴、任务阅读与剧情暂停 |

## 2 造型与空间
| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | HUD 14px 小圆角薄边；功能页 22px 厚框；对话 18px 顶圆角；按钮 12px 圆角 |
| 结构差异 | 战场轻且紧凑；功能页深绿标题分区；对话浅色姓名和正文、底部阅读操作；暂停为紧凑纸页 |
| 主次关系 | 场景主体优先，HUD 不扩大遮挡；功能主要操作稳定在底部，次操作在左 |
| 地面衔接 | 不适用，屏幕空间 UI |
| 活动空间 | 保留 HUD 边缘位置和场景命中面；功能内容可滚动，触控不穿透对白 |
| 邻接组合 | 实际猫、怪物、载具、场景与昼夜同屏 |
| 光向与明暗 | 共用轻上亮边、深绿短底影，禁止厚重纹理与发光装饰 |

## 3 技术交付
| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 320/360/390/430 手机；标准底板扣除安全区，按钮触控至少44px |
| 像素与倍率 | CSS 逻辑像素，移动端 DPR 原生绘制 |
| 锚点 | HUD 保留原坐标；功能页视口居中；对白沿现有游戏区域底边 |
| 分层 | 原 Canvas → HUD → 底部对白/暂停遮罩 → 原生功能弹窗 |
| 透明背景 | HUD 保留轻透感；功能/对白奶油纸；遮罩只用于原模态页面 |
| 碰撞与通行 | 不变更世界碰撞和路面，透明场景命中控件不套用纸页按钮 |
| 昼夜 | 同一 UI 配色，原场景光照独立 |
| 文件 | src/styles/ui-foundation.css 与正式 UI 模块；工作证据 output/playwright/mobile-ui-hierarchy |
| 预算 | 无新增图像、字体或缓存；新增运行文本目标小于20KB |

## 4 动画补充
静态 UI，无视频帧、脚底或肢体任务。仅按钮按压反馈，减少动态关闭过渡。原角色与武器动作保持。

## 5 设计指令与复核
复用森林绿 #315c43、深林 #234333、奶油 #fff6dc、草纸 #e8edcf、叶灰 #879b78、麦穗 #edbd63；沿用汉仪旗黑。字号为标题22、正文14、辅助12，HUD受面积限制保留紧凑字号。功能页采用“标题 / 独立滚动正文 / 次操作 + 主操作”；对话不使用大块深绿标题，以姓名与细分隔组织。三层只通过描边厚度、标题组织和布局区别，不重复发明配色。复核后不增加木纹、角钉、装饰插画，金色只表示焦点、引导或真实进度。

## 6 验收记录
2026-10-26，使用正式游戏端口 4320、隔离存档和 Chromium 手机触屏模拟完成验收。尺寸为 320×568、360×640、390×844、430×932、横持 844×390；不包含 PC 设计或验收，也不将模拟环境等同于物理手机。

| 项目 | 结果与证据 |
| --- | --- |
| 功能页与暂停 | 五种尺寸分别检查白天/夜晚，任务簿、清缴和暂停共30组边界采样，无横向溢出；任务簿滚到底仍可关闭和回到游戏 |
| 战场同屏 | 320/390昼夜共4组：正式猫、车辆、怪物、场景、波次及生命HUD同屏；薄边奶油信息板与深绿波次板层级清楚 |
| 最大资源显示 | 9999w级余额在320/390不裁剪；窄屏图标上下排列，不增加HUD高度 |
| 操作 | 清缴接取/继续/暂停、暂停后进入设置和帮助再返回、恢复巡游正常；主线对白暂停/继续和进入地图正常 |
| 任务与邻里 | 320/390邻里底部对话正常，任务簿刷新保持滚动位置，切到巡林簿后正确关闭原页并恢复暂停归属 |
| 对话布局 | 320/390姓名、正文、阅读按钮和进度条清楚，沿底部全宽、保留场景主体；人物对话不增加大块深绿标题 |
| 触控 | 本轮采样可见按钮高度均至少44px，关闭44×44；底栏48px；长正文独立滚动 |
| 运行 | 专项脚本及补充交互段通过，无页面脚本异常；修改模块语法检查通过 |
| 遮挡和通行 | 未改世界碰撞、建筑路面及场景命中逻辑；同屏检查HUD保留边缘位置，底部对话保留原暂停与镜头规则 |
| 动作真实性 | 未修改角色帧、动作时钟、载具或武器绘制；此次静态UI任务不重新验收动作资产 |
| 预算 | 无新增运行图像/字体/缓存；运行文本净增约10.7KiB，低于20KB预算；截图仅开发证据，不进入游戏资源清单 |
