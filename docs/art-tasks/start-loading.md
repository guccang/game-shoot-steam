- 目标：每次点击开始游戏都显示原视频上的完整金杯过场，包括已建图后返回首页再开始。
- 布局：进度条移到游戏画面底边，宽度100%；百分比放在条内，小车在上沿行驶；底部安全区随条背景延展，不新增背景或解释文字。
- 保留：已建地图、玩家对象、存档与暂停弹窗都继续复用；过场期间不推进战斗。车身、轮辐、视频、调色和1–3秒目标沿用上一轮，无新增资源。

- 正式入口：createApplication.enterFromMenu/finishMenuEntry、start-loading.css，designCriterion：start-game-loading。战场资产、动作与碰撞没有修改，相关美术重新验收不适用。

- 证据：[320短屏](../art-reference/start-loading/bottom-320.png)、[390长屏](../art-reference/start-loading/bottom-390.png)、[短横屏](../art-reference/start-loading/bottom-844.png)、[浏览器结果](../art-reference/start-loading/bottom-results.json)。已逐张复核车体完整、百分比可读、底部无遮挡。首页视频与战场昼夜系统无关，本轮仅调整首页过场时序和布局，战场昼夜、通行及动作复核不适用。
- 结论：通过。

## 1 目标与范围

- 稳定标识：start-loading；类别：首页 UI 与独立车轮动画。
- 目标：点击开始立即隐藏首页操作文字，原首页视频继续播放；小金杯车沿进度条由左驶向右，0–100% 后进入游戏。正常准备约两秒，未准备好不能提前显示100%或进入空地图。
- 数量：一个过场、一辆侧视小金杯，无新的背景、解释文案或弹窗。
- 参考：正式 `src/rendering/jinbei-van.js` 的奶油白高顶车壳、金色腰线、森林绿描边及轮毂；现有首页视频和手机按钮色板。
- 保留项：视频与同片海报、开始/续档/清档逻辑、游戏内金杯绘制、司机与独立操枪。路线：代码内 SVG 车身，独立旋转轮辐，不使用位图生成。

## 2 造型与空间

- 轮廓：高顶平头、长侧窗和滑门、奶油白车身与金色侧条，车头朝右；这是同车的 UI 侧视插画，不替换战斗造型。
- 主次：原视频是背景，车和进度条贴近游戏画面底部；仅显示加载百分比，不向玩家展示建图等内部过程。
- 地面与邻接：进度条上沿充当行车基线；纯界面叠层，无地图碰撞、道路占用或场景遮挡。
- 光照：沿用浅暖车顶、灰绿底盘和绿色描边；不新增昼夜版本，视频背景不改色。

## 3 技术交付

- 逻辑尺寸：车身 SVG 160×86，页面显示宽112px；进度条宽100%、高度24px加底部安全区，百分比居中放在条内。
- 锚点：车轮底沿贴近进度条上方；车起点在屏幕左边外侧，完成时驶出屏幕右边。
- 分层：原视频/遮罩 → 独立车身与两只轮辐 → 进度条和百分比；SVG透明，不另铺背景。
- 文件：`src/rendering/loading-van.js`、`src/ui/start-loading.js`、`src/styles/start-loading.css`，宿主为正式首页HTML。
- 预算：单个内联SVG、两个轮辐节点、两条有限时长合成层动画；零新增媒体请求/纹理；退出或销毁取消动画与帧回调。

## 4 动画任务补充

- 时长：行驶与进度先用1.6秒到90%，准备完成后约0.26秒到100%，短暂保留100%后进入；慢加载保持90%并等待实际就绪。
- 帧率：浏览器合成动画与requestAnimationFrame，车轮独立持续旋转，不以拉伸/旋转整车替代车轮运动。
- 起停：每次点击开始都启动；已准备的地图复用；失败立即恢复原首页；销毁不再回调进入。重复点击只启动一次。
- 减少动态：车保持静止，保留百分比和进度，无轮辐旋转；视频遵守原有减少动态海报逻辑。
- 连续视频源/裁切：不适用，沿用首页现成视频，新增车为程序化SVG。司机、手、枪、炮塔不出现在本过场。

## 5 制作指令

沿用森林绘本风格和正式金杯车颜色，设计朝右的平头高顶小车，侧窗、滑门、金色腰线可辨。车身平移，轮辐独立旋转。保留首页视频，隐藏首页控件，只叠加车、细进度条和百分比；不增加地图、卡片底板、内部加载说明或广告文字。
