# 森林地图跨度扩展任务单

## 1 目标与范围
- 名称 / 稳定标识：三倍跨度森林 / forest-map-threefold。
- 类别：程序化地形、道路与树林分布；复用现有绘制，不生成位图。
- 用户确认：宽高各扩大三倍；3600×2800 → 10800×8400，面积 1008 万 → 9072 万世界单位²。
- 营地围栏 970×1020（98.94 万）；生活区外接矩形 970×1930（187.21 万）。最终地图分别约为两者的 91.69 / 48.46 倍；本次以用户确认的跨度为准。
- 保留：原营地、建筑、任务和秘境入口坐标，角色、载具、怪物、武器比例及动作；循环地图与近景相机。
- 参考：docs/art-reference/landscape-six-day.png、landscape-six-night.png，正式森林绘制。

## 2 造型与空间
- 新外圈以不同树冠的疏密林团和草地构成；维持林下留白，延伸林间支路。
- 原桥头、水界、门前保持可通行；不通过缩小营地来制造地图变大。
- 同源树根锚点、左上亮面与右下冷影；原场景及外围共用草木色系。

## 3 技术交付
- 逻辑尺寸：10800×8400；无整图放大、无新增图集或纹理。
- 分层：既有地面、道路、阴影、脚底排序主体、独立武器和特效。
- 碰撞：现有水界/树根/护栏；新树林同正式采集树。原湖谷的植被生成范围保持不变。
- 预算：地面缓存继续最多32块（384单位），静态寻路边4096条；地表细节按局部查询；生成林团使用空间分桶，避免平方增长。
- 文件：src/world、src/rendering；证据 output/playwright/map-expansion/。

## 4 动画任务补充
不新增动画；保留原版连续猫帧、独立武器、怪物弹跳、载具履带和树木风摆，实机同屏复核。

## 5 制作要求
延续森林绘本风格和既有尺寸，扩展外围探索空间；不要拉伸树木、建筑、角色或道路宽度。旧地点不搬移，外围草地连接林团，路径留白与通行一致。
