# 休息恢复提示与弹出入口配色

依据[美术任务单](../art-generation-brief.md)、[生成标准](../art-generation-standard.md)与[AGENTS.md](../../AGENTS.md)。

## 1 目标与范围

程序UI调整：休息成功明确显示“HP 已恢复至满值（当前/上限）”；床边以及共用附近交互组件的查看展品、建筑等入口统一为奶油底深绿字。参考手机UI框架，保留所有稳定ID、距离限制、点击行为及保存成功后才回血的规则。审查已挂载弹窗按钮和标题配色。不新增插画、PNG或图集，无后续精修项。

## 2 造型与空间

附近入口保持原锚点、字号、44像素以上触控范围和边框，去除目标切换时深浅底色翻转；睡醒结果在小屋底部现有状态区增加纸色底板，文字可换行，不阻碍中央移动。建筑、家具、角色和通行区域不变。

## 3 技术交付

正式入口为createNearbyInteraction、createCampHome及finishCottageSleep；CSS使用ui-paper、ui-text、ui-line、ui-sage变量。无需新图片、画布或派生缓存；无位图透明边缘或内存增长。结果提示保持role=status，失败显示原失败原因，重新休息清空前次结果。

## 4 动画任务补充

沿用1.2秒正式睡眠过渡与角色动画；仅取消场景弹出入口从深色主按钮到浅色按钮的颜色翻转，保留浅色悬停状态。无角色动作或视频帧变更。

## 5 生成指令

不使用imagegen，本轮是已有DOM组件和CSS变量修正，动态文字不能烘焙到图片。
