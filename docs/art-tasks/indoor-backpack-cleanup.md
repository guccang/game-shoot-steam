# 屋内背包与超载自救入口
依据：[美术标准](../art-generation-standard.md)、[项目约定](../../AGENTS.md)、[手机框架](../ui-foundation.md)。

## 目标与结构
修复猫猫在房屋内因误带车载弹药超载、无处打开背包的死锁。所有屋内保留背包入口，超载额外显示整理背包，直接打开现有滑条／一键清理页面；默认不丢物品，必须确认。复用已有统一手机底板及小屋footer按钮排列，不另设模型、图标或独立美术风格。

## 空间与资源
按钮放在室内底部提示下方，触控至少44px；沿用奶油黄与森林绿，注意320宽及横屏与出口、摇杆的命中关系。中央人物、售货员和场景保持原绘制器；房屋碰撞和一秒出门机制保留。复用既有背包、清理页与保存事务；无新增PNG、画布或计时器。此为UI交互，不涉及帧动画重制、PNG替换、世界锚点或地形边界变化。
