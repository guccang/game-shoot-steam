# 森林巡游美术生成任务单：伙伴救援与小气泡

## 1 目标与范围
- 标识：horde-rescue-neighbor-bubbles；用途：营地救援动作时序、居民与救援小气泡。
- 目标：伙伴逐个经过营门，再举枪战斗；对白只占头顶小块区域。
- 数量：两名救援伙伴，一次只显示一个短气泡；日常闲聊沿用单泡限频。
- 保留：原猫连续帧、独立枪械、车轮/履带/旋翼、炮塔后坐、怪物受击死亡、原镜头及 B/A/S 奖励。
- 路线与参考：复用 src/rendering/camp-defense.js 正式绘制器，气泡使用 DOM/CSS；参考原 resident-chatter 森林绿描边和奶油色，不生成位图。

## 2 造型与空间
- 剪影：短圆角框加小尾尖；无姓名标题行、操作按钮或任务进度条。
- 差异：较原任务大气泡更窄更矮，只有一至两行短句；救援伙伴依次出场而非同时堆叠。
- 主次：角色、怪物及攻击优先，气泡为次要点缀；超出视野或侵入 HUD 区域时隐藏，不钉到屏边。
- 通行：沿现有北/西门中央穿过，再向敌人展开；不新增实体碰撞。地面、建筑、道路不改。
- 光向：复用现有实体的左上亮面和右下投影；气泡共用奶油底与绿字。

## 3 技术交付
- 气泡最大宽 168 CSS 像素，字号 12，最多两行；锚定人物头顶，屏幕投影不改变镜头。
- 实体尺寸、图集倍率和脚底锚点完全沿用原正式绘制器；不新增图片、纹理或缓存。
- 分层：实体仍按脚底排序；小气泡在 HUD 下层且 pointer-events:none，不阻止点击/拖动。
- 透明：仅气泡形状不透明，周围透明；无新增碰撞；昼夜同一形体。
- 文件：core/camp-rescue.js、ui/compact-speech.js、相关配置与 CSS；截图置 output/playwright/horde-rescue-neighbor-bubbles/。
- 预算：每个面板仅一个稳定气泡节点，无每帧创建 DOM 或图集。

## 4 动画任务补充
- 动作：入场等待、依次驶出、瞄准/射击/装填；移动更新原动作时钟，暂停冻结。
- 源视频/帧率/裁切：未修改身体资源，沿用 assets/cat-front 原连续帧与锚点，不新增视频。
- 局部动作：原履带、车轮、主尾旋翼与独立枪口、后坐；不通过整图拉伸冒充动作。

## 5 生成指令
采用既有正式渲染和 CSS，只缩小对白外框、减少文字并修改援军动作时序。不得更改原角色身份、镜头、身体图集、装备所有权及奖励。
