## 合并主分支简短指引后的修订

主分支同期增加一句话主线提示、当前动作清单和直达操作。本任务保留这些功能，共享气泡的右侧按钮按上下文显示主线实际操作（如“查看地图”“收下奖励”），故事仍显示“跳过对话”；两者共用外框、姓名正文、44像素按钮、暂停/继续、阅读进度及尾角。此段替代前文两来源按钮文案完全相同及主线多句对白的描述。自动阅读时长沿用简短主线规则；完整操作说明留在折叠帮助。合并后针对主线、追踪重验21项通过，原故事规则与道路修复未改。

整合后正式浏览器复验通过：12组昼夜与尺寸采样无错误，主线按钮实际打开地图，动作清单正确显示完成项；目录重载与两份已领取请求保持一致，正式自动射击两侧均命中。上述截图及JSON均已更新为整合后的结果。
