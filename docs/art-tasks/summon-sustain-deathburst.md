# 召唤续航与小蜘蛛死亡爆炸任务单

执行标准：`docs/art-generation-standard.md`，复用现有正式粒子、机械伙伴和 HUD 圆环。

## 1 目标与范围
| 字段 | 规格 |
| --- | --- |
| 名称与标识 | 小蜘蛛死亡爆炸 / spider-death-burst；机械小狗逐只召唤 / mechanical-sequential；召唤能量持续恢复 / summon-energy |
| 用途 | 死亡提供近身范围伤害，狗群逐只入场，未满能量持续恢复支持长战斗 |
| 数量和差异 | 小蛛本体仍沿原八足，不更换形象；死亡原点短爆光与少量碎光，母体不自爆；狗逐只出现且保留远近战队形 |
| 保留项 | 猫视频动作、小手和炮塔、履带旋翼、机械猫步态/背枪、蜘蛛出舱、怪物扑击与远程预警、森林通路 |
| 路线与参考 | 程序逻辑＋复用正式 blast/spark 粒子；参照 `ranged-enemies-night-phone.png` 与原机械蜘蛛绘制 |
| 场景 | 手持、车载、守护支架、工坊隔离试射；暂停和收起不推进供给 |

## 2 造型与空间
| 字段 | 规格 |
| --- | --- |
| 主体与主次 | 小蛛死亡位置出现半径80世界单位短促爆光；亮芯小、边缘淡，不掩盖附近角色与载具 |
| 地面与邻接 | 原脚底爆炸、近邻敌人受击，玩家/伙伴/树木不受伤；不生成永久障碍或伤害池 |
| 光向与色彩 | 沿现有奶油黄/柔橙爆炸与森林绿机械部件；共用场景夜色 |
| 通路 | 沿原树干、水界和载具避让；召唤仍先找到合法落点 |

## 3 技术交付
| 字段 | 规格 |
| --- | --- |
| 尺寸与锚点 | 爆炸半径80，中心为小蛛命中中心；正式 Canvas 世界坐标，不加碰撞体 |
| 像素/格式 | 无新增位图/图集/字体；复用 `drawCombatFX` |
| 分层与透明 | 原怪物/角色实体层，爆光粒子独立叠加，透明渐隐；低动态使用既有弱光静态范围表现 |
| 预算 | 单次1爆光＋4碎光及原死亡火花；总量仍受FX_LIMIT=260约束，无离屏画布与缓存 |

## 4 动作
机械小狗首次立即出一只，其后每秒一只；死亡等待原2秒门槛且补召共享1秒间隔。切换归队保留生命、枪仓、冷却，重部署也逐只。小蛛死亡一次性伤害后0.5秒局部爆光；重新召唤重置本条生命的爆炸标记。原生召唤能量每格渐进恢复，基础空仓约10–13秒充满，补能升级继续加快；外挂普通枪的弹药、返航和换弹不变。纯程序变化，不涉及源视频、裁切或帧图集。

## 5 制作指令
只加强死亡反馈与逐只入场，不新增全屏震动、不改变机械主体比例或扩大通行体积。短状态表达恢复速率，避免大段说明。
