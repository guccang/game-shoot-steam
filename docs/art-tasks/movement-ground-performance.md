# 移动地块生成优化 / movement-ground-performance

依据[美术任务单](../art-generation-brief.md)六部分与[美术标准](../art-generation-standard.md)，日期2026-11-09。

## 1 目标与范围
程序绘制性能修订，减少移动进入新地块时的主线程长帧。正式运行复现315.6ms地面补建；地图扩大后，每块地面仍遍历整条36000单位河流和水纹。参考修改前正式地块昼夜像素，保留岸线、桥、瀑布、地色、细节与动作；不生成新图或改变生态布局。

## 2 造型与空间
主体剪影、变体结构、主次、光向、地面衔接与邻接组合全部沿用原版，本次不新增造型。视野外河道点不再提交，视野内沿用原始采样序号与网格；裁切边界外留边，防止接缝、缺水纹和岸线变化。所有活动空间及水界保持原几何。

## 3 技术交付
保留384世界单位地块和2单位采样边距；运行画布通常388×388，最后一行按世界尾块尺寸。锚点为原世界块坐标，地面先于角色实体，昼夜继续原矩阵转换。不新增资源、图集、网络请求或缓存副本，不输出替代半成品。原缓存24块手机上限、现有预热队列与稳定接口保留。正式入口ground-art.js、river.js、shore-art.js；性能日志和像素对照位于output/movement-profile。透明度、碰撞和通行规则不变；素材缺失仍由原启动校验明确失败。

## 4 动画任务补充
静态地块构建优化不新增动画。水面仍使用原动态时钟与独立纹理，角色视频连续帧、怪物及载具动作保持原运行时；无视频来源、额外裁切或PNG替换，相关生成项不适用。

## 5 生成指令
不使用imagegen：不需要新美术，而是把原有程序绘制限定在实际地块及留边内。禁止降低细节、替换低清地面或以空白纹理掩盖未命中。使用原绘制器前后像素和正式移动记录验收。

## 6 验收记录
通过（2026-11-09），designCriterion：movement-ground-performance。

| 设计目标 | 实际结果与证据 |
| --- | --- |
| 移动不因全河重画产生长帧 | 同机、同手机视口、相同12秒方向输入，正式帧最大耗时315.6ms降到47.8ms，最大回调间隔319.6ms降到52.3ms；保留全部慢帧与CPU采样于 `output/movement-profile/before.json`、`after.json` 及对应 `.cpuprofile`。12个春/冬完整昼夜地块平均构建98.6ms降到34.8ms。浏览器测试环境结果，不代表所有实体手机都恒定60帧。 |
| 保持几何、岸线及原图元 | 三项岸线测试验证原折点序列、两岸采样相位与冬景一致，局部岸线/水纹命令数低于整图8%。正式河道两种风格、六个位置、冬夏24种裁切对照逐像素一致。原完整地块前后24张昼夜图片中16张完全一致，其余8张仅岸线边缘栅格抗锯齿微差（平均通道差小于0.05/255），无细节删减。 |
| 手机真实操作和动态保留 | 320×568、390×844及844×390手机容器各昼夜移动，白天步行、夜间骑电动车，真实触控移动281～648世界单位；六场景同步补建增量均为0，帧内最大15.7～48.3ms，页面和正式帧错误均为空。原猫、怪物及载具动作、独立枪械不变。 |
| 同屏美术、遮挡和通行 | 已查看 `scene-320-day.png`、`scene-390-night.png`、`scene-844-night.png`，森林地面无空块；`shore-day.png`、`shore-night.png`显示正式猫、团子、木桥、瀑布、河岸与HUD，岸线和桥头连接无缺口。碰撞和通行代码未改，保留原世界几何；全图末行及负坐标留边由地块与岸线测试覆盖。 |
| 资源与缓存预算 | 无新增位图和下载、无降低清晰度或省略动作。正式补充采样手机地块缓存22～24块、动态河面8块，均在原上限内；`shore-review.json`记录正式缓存和主循环统计。 |

手机交互、河道裁切对照与截图位于 `output/playwright/movement-ground/`，`result.json`记录6组移动和24组像素对照。完整地块前后PNG位于 `output/movement-profile/`。正式绘制器入口：`paintGroundSteps`、`drawRiverGroundSteps`、`drawShoreGroundSteps`、`drawShoreWaterSteps`；工作台入口 `src/rendering/visual-review.js#inspectMovementGroundPerformance`，已登记 `visual-contract.json`。

专项逻辑11项通过（3项岸线、4项缓存预热、4项四向缓存）。原四向缓存测试包含旧地图尾块的固定字节数，修改为按真实尾块尺寸核对，失败项复测通过。手机测试准备阶段曾把电动车放在猫脚下触发自动上车；已修正夹具停车位置，再完成真实步行/骑车验证。没有运行全量测试。
