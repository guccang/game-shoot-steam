# 森林巡游美术生成任务单：地下室、矿道与矿车

执行依据：[生成标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。由美术生成任务单复制并按本轮动态开发范围填写。

## 1 目标与范围

| 字段 | 本轮约定 |
| --- | --- |
| 资源名称与标识 | 地下室 basement、矿道 mine、矿锄 pickaxe、轨道 rail、矿车 cart、矿灯 lamp、路牌 sign、洞口 shaft |
| 类别和用途 | 建筑入口、地下地形、工具、载具和方向UI |
| 当前阶段 | 动态效果开发；交付程序绘制与真实交互，PNG精修属于后续阶段 |
| 本轮目标 | 公司施工后可从小屋下矿；地表坐标对应矿道，永久开掘，矿车连通和起停、洞口双向通行 |
| 动态目标 | 矿锄独立挥动和开掘进度；车轮按行驶距离转动；停止冻结；暂停不推进；地图始终北朝上并指向小屋 |
| 数量和变体 | 普通岩壁、双块铜矿、三棱晶矿通过轮廓及内部结构区分；木梯与石拱通过结构和高度区分 |
| 保留项 | 原猫身体真实连续帧、固定脚底、原地表枪械、怪物与载具动作、小屋原楼层和存档 |
| 制作路线 | 复用既有Canvas正式角色，新增程序化局部部件；本轮未生成图片，先验证动态效果，不以图片替换作为前提 |
| 参考 | docs/art-reference/landscape-six-day.png、landscape-six-night.png；src/rendering/cottage.js和assets/cat-front |
| 已确认目标 | 奶油色矿道、绿灰岩壁、木枕双轨、独立轮毂；地下操作条遵循手机UI框架 |
| 后续精修 | 岩块、车厢、矿锄静态材质可在后续imagegen精修阶段替换，动态接口保留 |
| 使用场景 | 森林建筑公司、小屋一楼、地下矿区、地表新洞口 |

## 2 造型与空间

| 字段 | 本轮约定 |
| --- | --- |
| 主体剪影 | 岩壁大块平涂、矿脉尖角、木梯横档、矿车双轮开放车斗、石拱中空洞口 |
| 结构差异 | 普通岩无尖晶；铜矿两块、晶矿三棱；矿灯竖灯罩、路牌横箭头，不以换色充数 |
| 主次关系 | 角色与矿车为主，工具和目标格清楚；矿脉与装点稀疏，地图固定小窗 |
| 地面衔接 | 地下室木板过渡到土色矿道；地表洞口接触影落在原地形 |
| 活动空间 | 开掘后每格64单位，梯口可站立；摆件放左侧无碰撞，车与车保持间距 |
| 邻接组合 | 地下室与地表小屋共坐标；洞口不在建筑、水域或树干下生成 |
| 光向与明暗 | 左上岩顶受光、下缘暗面；夜晚形体不变，矿灯局部暖光 |

## 3 技术交付

| 字段 | 本轮约定 |
| --- | --- |
| 逻辑尺寸 | 矿格64×64；木梯60×48；矿车54×42；洞口80×64；小地图112×112 CSS像素 |
| 像素尺寸与倍率 | 游戏Canvas沿用DPR；小地图224×224，2倍像素；本轮无PNG |
| 锚点与原点 | 地下零格为COTTAGE.door世界坐标；角色脚底不变；矿车车轮接地；不使用房间局部坐标作为世界落点 |
| 分层 | 土地/岩壁→轨道/梯井→摆件/车/角色脚底排序→独立矿锄/车前板→地图/进度 |
| 程序与图片职责 | 全部状态、碰撞、进度、导航和动画由程序控制；猫使用原视频连续帧 |
| 替换接口 | MINING.tile、minePoint、稳定设施ID及锚点；未来PNG不可改变碰撞、挥锄或轮毂时钟 |
| 透明背景 | 直接Canvas局部绘制，无新增不透明图集或重复全屏纹理 |
| 碰撞 | 未挖格阻挡，已挖格以脚底半径10检查；矿灯与路牌纯装饰；地表出口核验正式碰撞 |
| 昼夜 | 正式历法决定同形体的材质明暗，灯光局部，不增加全屏雾 |
| 文件与入口 | src/config/mining.js、src/progression/mining.js、src/core/mining.js、src/rendering/mining.js、src/ui/mining.js、src/styles/mining.css |
| 内存与缓存预算 | 只有可见网格即时绘制；地图224×224×4约196KiB；无新增昼夜位图缓存。存档按实际挖掘与设施稀疏增长 |
| 必需资源与失败行为 | 原猫图集沿用正式加载错误；无新外部素材。保存失败显示错误，地形/矿石/费用均不兑现 |

## 4 动画任务补充

| 字段 | 本轮约定 |
| --- | --- |
| 动作时长 | 开掘0.65秒/格，向上开洞4秒，矿车176单位/秒，步行112单位/秒并受负重影响 |
| 时钟与循环 | 固定模拟步长≤0.05秒，暂停冻结；车轮按路程/8累积相位 |
| 动作源码或源视频 | src/core/mining.js#updateMining、src/rendering/mining.js#pickaxe/#cartBody；猫沿用assets/cat-front/animations.json，不制作新序列 |
| 尺寸裁切 | 身体PLAYER_SCALE和脚底锚点不变，无整图拉伸/旋转伪造身体动作 |
| 起停与状态 | 猫使用updateCatMotion姿态匹配，矿车急停保留位置与轮相位；关闭页面不补后台奖励 |
| 局部真实动作 | 手和锄柄独立摆动；左右车轮独立旋转；车厢不旋转变形 |
| 独立部件 | 猫身、矿锄、手、车轮、车厢前板独立；地表原枪械机制保持 |
