# 森林巡游美术生成任务单：逻辑与渲染时钟拆分

执行依据：[美术标准](../art-generation-standard.md)，结构沿用[任务单](../art-generation-brief.md)。

## 1 目标与范围

- 稳定标识：fixed-logic-smooth-render；类别：既有运行时动作。
- 目标：25Hz 固定逻辑、60Hz 绘制调度，中间帧的位置、朝向和动作时钟连续变化。
- 数量和变体：不生成资源或新增造型变体；正式角色、怪物、弹道、伙伴、载具共享表现插值。
- 保留项：森林绘本比例、真实猫身体序列、姿态衔接、独立持枪、怪物死亡、载具局部动作和逻辑碰撞。
- 路线与参考：复用 `assets/cat-front/animations.json` 与正式 Renderer；只插值连续状态，不制造身体图集帧。
- 场景：森林战斗、室内和秘境。

## 2 造型与空间

主体剪影、变体结构、主次关系、地面衔接、活动空间、邻接组合与光向均沿用现有正式资源。本次没有造型或地形修改，不改变开放区域、碰撞几何或单位比例；插值在原坐标系中进行。

## 3 技术交付

- 逻辑尺寸、像素倍率、脚底锚点与地面/主体/独立部件/特效分层沿用正式绘制器。
- 透明背景和图集编码不变；无新增位图和昼夜副本。
- 碰撞继续读取25Hz权威状态；表现状态不得回写生命、坐标、弹药或进度。
- 昼夜共用同一插值管线与原夜色处理。
- 文件：`src/platform/fixed-step.js`、`src/rendering/render-interpolation.js`；证据 `output/playwright/fixed-step/`。
- 预算：只保留当前动态对象的上一逻辑状态和可复用表现对象；不复制全图静态树木，不累积历史帧。

## 4 动画任务补充

- 待机/移动/受击/死亡/驾驶沿用原时长。逻辑25Hz、绘制目标60Hz；猫身体仍使用清单中的24FPS真实连续帧。
- 源视频、连续片段、帧索引、裁切与缩放不修改，沿用现有清单。
- 起停不重置身体对象身份；暂停与切场景清理插值历史；瞬移直接同步。
- 腿、尾、翼、履带和旋翼继续由正式图集或局部部件动画驱动；枪、小手、后坐与枪口独立。

## 5 生成指令

不调用图像或视频生成；在既有运行时状态之间插值连续字段，保留离散战斗事件和原资源。禁止复制静帧、拉伸或旋转整图替代局部动作。

结论：上述设计目标通过。浏览器录制时绘制约53/59FPS，调度目标60Hz；不宣称每台手机恒定60FPS，也未以桌面模拟代替Mate50Pro半小时温升实测。资源结构没有变化，因此沿用原版长期美术参考图。

正式入口：`Renderer.draw`；设计目标：`fixed-logic-smooth-render`。
