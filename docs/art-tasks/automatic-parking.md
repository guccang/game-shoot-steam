## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 房屋停车位与停车倒计时 / automatic-parking |
| 类别和用途 | 建筑周边地面标线、车顶交互图标 |
| 本轮目标 | 看清可停车位置；停稳3秒后连续对齐、倒入泊位；两类工坊停好自动打开 |
| 数量和变体 | 载具工坊1个室内位、武器工坊2个露天位、小屋1个门前位、北门西侧6个公共位，共10位 |

| 参考与同类资产 | 用户提供的载具工坊截图；src/rendering/garage.js；docs/art-reference/landscape-six-day.png |
| 使用场景 | 晴叶营地小屋、武器工坊、载具工坊与北门入口 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 开口朝道路的奶油色U形标线，低矮轮挡，车形倒计时徽标 |
| 与其他变体的区别 | 室内位复用门洞与地坪；露天位以淡土色地面、U形线及轮挡识别，不复制房屋 |
| 主次关系 | 车与房屋为主体，地面标线低对比，仅等待期间显示车顶倒计时 |
| 地面衔接 | 浅草土色停车地面接原草地；北门停车场使用380×300的土色场地和连接入口的弧形支路 |
| 活动空间 | 房门前踏石、营地西门和主路保持通行；泊位本身不添加碰撞 |
| 邻接组合 | 小屋移至(810,300)，门前1位；武器工坊(500,610)，门前并排2位；载具工坊(260,680)，门洞内1位；北门西侧两排各3位 |
| 光向与明暗 | 沿用左上光与右下冷影，夜间标线仍可读 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 露天泊位96×86世界单位；车顶徽标68×34屏幕逻辑像素 |
| 像素尺寸与倍率 | Canvas随正式镜头与设备像素比绘制，无新增位图 |
| 锚点与原点 | 泊位中心对应载具脚底；图标锚在驾驶员头顶上方 |
| 分层 | 标线属于地面；车体沿用实体深度；车库裁切沿用门洞；倒计时属于世界提示 |
| 透明背景 | 程序绘制透明叠加，无不透明贴图底板 |
| 碰撞与可通行性 | 沿用正式moveBody逐步碰撞；线路先检查，不穿建筑、树干或围栏 |
| 昼夜处理 | 同一形体经现有色调处理，地面标线按夜色调低亮度 |
| 文件格式与位置 | 配置src/config/parking.js、逻辑src/core/parking.js、绘制src/rendering/parking.js |
| 内存与缓存预算 | 无新增纹理或昼夜图集，10个泊位数据和单个停车状态；单独泊位按视野裁剪，公共地坪为固定矢量绘制 |

## 4 动画任务补充

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 静止等待3秒，低速对齐后向后入位，时长按实际距离计算 |
| 帧率、帧数和循环 | 采用正式游戏dt，不生成独立动画序列 |
| 源视频与连续片段 | 无新增角色资源；继续使用assets/cat-front原连续帧 |
| 统一裁切和缩放 | 原角色与车体尺寸不变；车库按正式洞口裁切 |
| 起停与状态衔接 | 输入重置倒计时，入位可取消；暂停冻结；停车后保留轮相，不重复打开工坊 |
| 局部真实动作 | 车轮按真实位移反向滚动，重坦履带按倒车位移推进，不旋转整图冒充动作 |
| 独立部件 | 继续正式角色、小手、车载主炮与后坐绘制 |

## 5 生成指令

沿用原森林绘本风格、奶油与草木色。停车标线留在地面，车顶只显示短倒计时，不增加大提示框。保留猫猫、车辆原尺寸和独立武器；倒车由实际移动与车轮/履带相位实现。不得瞬移、整图拉伸或用整车旋转替代行走部件。
