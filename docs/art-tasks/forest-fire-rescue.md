# 森林消防秘境美术任务单

执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。本轮采用正式 Canvas 程序绘制，沿用原猫连续视频帧。用户未附红色怪物参考图，本轮按三瓣火冠的红色火苗怪实现。

> 后续世界化改版见[世界森林消防任务单](forest-fire-world.md)。旧圈内玩法已由该版本替代，本文保留首版历史验收。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 森林消防 / forest-fire-rescue |
| 类别和用途 | 消防车、消防小屋、火点、火苗怪、消防帽、玩法卡片 |
| 本轮目标 | 小屋接警，驾驶消防车自动喷水扑灭六处火点并击败红色火苗怪，通关领取车体。 |
| 数量和变体 | 一辆长水箱四轮消防车；一间开门小屋；六处火点；有三瓣火冠和独立小脚的红色火苗怪。 |
| 保留项 | assets/cat-front 同源连续帧及独立手枪；车轮位移相位；怪物蓄力/扑击/受击/死亡。 |
| 制作路线 | 程序化正式 Canvas 绘制；消防帽独立叠加，不修改猫身体。 |
| 参考与同类资产 | docs/art-reference/landscape-six-day.png、landscape-six-night.png；src/rendering/pine-wheels.js |
| 使用场景 | 森林干地秘境、车库、秘境卡片 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 珊瑚红长水箱、奶油横带、车侧水带卷、独立消防栓和武器架；小屋开门与警铃。 |
| 与其他变体的区别 | 消防车较松果战车加长且有独立水箱/消防栓；怪物有分叉火冠和两只摆动脚，不是普通史莱姆换色。 |
| 主次关系 | 主景为车和火点，小屋作为补水落点，原森林树丛作为外围。 |
| 地面衔接 | 沿原草地铺浅土救援通路；火点有焦土接触影，灭火后留下湿地。 |
| 活动空间 | 小屋前、停车点、六火点之间连通；清除通路附近树冠遮挡。 |
| 邻接组合 | 沿用经过干地验证的森林区域，不新增水界和山体。 |
| 光向与明暗 | 左上亮面与右下接触影；警灯和火芯局部强调，使用现有场景昼夜合成。 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 车110×100，小屋156×140，火点60×68，火苗怪42×48，消防帽32×15。 |
| 像素尺寸与倍率 | Canvas 矢量按正式镜头倍率绘制；卡片480×320，不新增位图。 |
| 锚点与原点 | 车随玩家脚底；屋和火点世界脚底；水口相对玩家(-35,-26)。 |
| 分层 | 道路与焦土地面；小屋/火点按脚底排序；身体→消防帽→前车身→炮架；水流特效。 |
| 透明背景 | 透明程序绘制，阴影独立，不带不透明地板。 |
| 碰撞与可通行性 | 干地区域圆界沿用；小屋为可进入值守棚，屋体遮住人物时透显；火点为可穿行伤害区。 |
| 昼夜处理 | 全部共用正式昼夜环境色调；消防红保持有限平涂。 |
| 文件格式与位置 | src/rendering/fire-rescue.js 与 fire-truck.js；output/playwright/fire-rescue；验收图存 docs/art-reference。 |
| 内存与缓存预算 | 无新图集/解码内存/昼夜副本；火点6、怪物12、水流1；沿用粒子池。 |

## 4 动画任务补充

静态资产标注“不适用”。猫身体当前仅生成正面待机和移动，不增加多方向身体序列。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 车轮按位移滚动；火焰局部错相；怪物独立脚步、火冠、受击和消散；猫沿用原动画。 |
| 帧率、帧数和循环 | 程序按正式时钟逐帧，不生成重复帧；猫原24FPS清单不改。 |
| 源视频与连续片段 | 不适用：不生成猫身体或位图；原猫连续动作源与清单保持。 |
| 统一裁切和缩放 | 不适用：程序绘制，不裁切序列。 |
| 起停与状态衔接 | 暂停不推进；停车保留轮角；减少动态冻结火焰错相，保留必要喷水反馈。 |
| 局部真实动作 | 四轮轮毂与胎纹独立滚动；火苗怪两脚错相，三瓣火冠独立变化。 |
| 独立部件 | 独立消防栓(-35,-26)；武器架(0,5)沿用正式车载枪口。 |

沿用森林绿描边 #315c43、奶油黄 #f5df9e、珊瑚红 #c76a55、水蓝 #9ed8da 和草绿 #8ba873。消防主题依靠长水箱、水带卷、消防栓及警灯的结构表达；原无衬线字体和秘境卡片布局继续使用。程序文字展示规则和进度，图画不嵌文字。禁止整图伸缩假步态、烘焙枪械、不透明地板和额外图集。
