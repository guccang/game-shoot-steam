# 武器与载具工坊功能页签

依据 [美术标准](../art-generation-standard.md) 和 [任务单](../art-generation-brief.md)。

## 1 目标与范围

- 标识：`workshop-function-tabs`；类别：正式 DOM 工坊 UI。
- 将购买、部件升级、改装/挂载、挑战解锁分为四页，固定功能导航，减少寻找操作时的纵向滚动。
- 参考现有 `immersive-workshop.md` 与正式工坊；保留真实装备绘制、价格、挑战/熟练度规则、独立炮塔、施工、试射、来源追踪和退出草稿确认。
- 制作路线：原生 HTML/CSS/JavaScript，无字体或位图生成。

## 2 造型与空间

- 森林绿 `#315C43`、草木绿 `#90A875`、奶油色 `#F4EDCF`、木色 `#B68A51`；沿用现有中文字体。工作台为主，页签与费用为辅。
- 固定标题与四等分页签；桌面左侧装备架，中间工作台，升级/改装时右侧零件；购买只呈现设备和价格，解锁页只呈现资格与提升路径。
- 手机采用横向装备架，工作台、部件同屏优先；信息不再全部叠在工作台上方。文字左对齐，操作保持至少 44px 触控高度。
- 地面衔接、世界碰撞与通路不适用：本次只修改弹窗内容；保留场景层次、角色与装备比例。

## 3 技术交付

- 弹窗沿用固定顶边及宽度；320、390、1280 宽度验收。锚点：页签在标题下，结算在底部，不因切页重新居中。
- 分层：标题/功能导航、当前功能内容、资源结算；原生模态层，不新增遮挡属性的浮层。
- 透明背景不适用（DOM 面板）；昼夜沿用相同配色与原世界绘制。
- 不新增图集、音频、字体和常驻画布；舞台继续两层合计约 2.1MB，原图片缩略画布预算不增加。证据存于 `output/playwright/workshop-function-tabs/`，长期基准存于 `docs/art-reference/workshop-function-tabs/`。

## 4 动画与交互

- 页签即时切换；取消未提交草稿、指针拖拽、施工和试射，无扣费。关闭仍确认草稿。
- 保留部件替换、扳手/焊枪和正式装备动作；不创建新的世界动作或视频，连续帧素材、裁切、图集生成不适用。
- 页签支持左右键、Home/End；焦点与选中语义同步。主线引导定位当前功能页，不能指向隐藏按钮。

## 5 制作指令

沿用森林工坊材质和真实装备。将“购买 / 升级 / 改装（载具为挂载） / 解锁”作为清晰导航，不将挑战进度与所有操作堆叠。免费试装与正式施工继续分离，解锁页展示真实挑战和熟练度，不编造新门槛。

## 6 验收记录

| 设计目标 | 实际验收结果与证据 |
| --- | --- |
| 功能清晰分离 | 购买页不显示部件，升级页显示部件，改装/挂载页显示套件/炮塔；挑战与熟练度只出现在解锁页。已拥有默认升级，未拥有默认购买。正式浏览器共 48 个功能/尺寸/昼夜组合通过。 |
| 手机可读与少滚动 | 320×844、390×844、1280×900 实测；默认升级内容无须纵向滚动。较长目录只在装备架/零件列表滚动；功能导航固定可见。购买页五种材料自动换行，余额、缺口和按钮全部可见，无横向溢出。极短视口仍允许内容区滚动，未裁掉操作入口。 |
| 交易与玩法保留 | 实际购买、键盘升级、手机触控拖件与按住施工、车载挂载、炮塔升级、材料来源与追踪通过；取消指针/切页零扣费，关闭仍确认草稿。车体与主炮切换会清理旧部件选择，避免主炮伤害被误读为车体部件。 |
| 会话与引导 | 切页停止试射与施工；解锁问号可打开并返回，战场仍暂停。左右键/Home 切页通过；主线规则测试覆盖购买、改装、试射和专属主炮先定位正确功能页。 |
| 世界与美术保留 | 六组世界昼夜画面保留猫咪、电动车、团子及营地；工坊仍用正式装备绘制。无世界美术/动作/碰撞修改，不涉及新通路及视频帧生成；未遮挡工作台或原有舞台操作。 |
| 资源与性能 | 零新增运行美术资源、字体、画布数量；48 组采样总画布预算最高 5,045,272 字节，仍在原工坊约 5MB 量级，舞台双层约 2.1MB。正式素材加载成功、控制台无异常。 |

专项规则 30 项中 29 项通过；`workshop-components.test.mjs` 的“保存失败不扣费，升级保留余弹、蓄力、冷却、装填和车体状态”在第 66 行出现历史断言 `5 !== 0`，已在未修改主分支运行同名单项确认相同失败，非本次改动。主线页签引导追加覆盖后 6 项全通过。修改模块语法、导入路径、视觉合同 JSON 和差异格式检查通过；未运行全量测试。

合并兼容复核：同步主分支新增的原价/追赶折扣展示，保留正式报价与折后余额。`upgrade-price.test.mjs` 3 项通过；原折扣浏览器脚本在本任务端口运行，1440/390/320 昼夜六组、车体与主炮报价、材料不足及一次施工扣费通过（35/14 原价，11/5 实扣），手机底栏按内容自适应高度。证据在本地 `output/playwright/upgrade-price/`，脚本副本在本任务输出目录；本次合计相关规则 32 项通过、1 项已确认历史失败。

视觉修订：初版桌面底部属性有少量裁切，已缩减舞台高度及目录上限；320 宽购买原因与按钮同排过挤，已将短原因单独占一行。修订后复核全部功能与实际施工，48 组通过。
