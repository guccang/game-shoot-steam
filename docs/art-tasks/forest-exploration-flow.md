# 聚落边界与森林生活引导

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。

## 目标与保留项

让玩家从木栏、木门辨认安全聚落，从单一行动卡知道去找谁。新增木栏和双扇木门两种程序化结构；保持现有猫视频帧、独立武器、怪物、载具动作及森林绿描边、奶油色界面。参考正式营地围栏与邻里建筑，不生成位图资源。

## 造型与空间

木栏采用短立柱与两根横梁，木门采用两扇有转轴的门叶和聚落小招牌。营地、邻里小院分别围合，主道路与四边入口保持开放。地面接触影沿用右下冷影，木材左上受光；门前预留载具通道。围栏为次景，避免密集纹理压过角色。居民气泡一条一句，跟随头顶，不驱动镜头。

## 技术交付

- 世界尺寸：围栏段不超过 58 单位，实体厚度 10；木门宽 150–180。坐标与边界共用 `src/config/settlements.js`。
- 锚点：柱脚落地；地面投影、柱梁、门叶分层，在正式对象深度排序中绘制。
- Canvas 矢量运行时绘制，无新增贴图、昼夜副本或图片缓存。白天暖木色，夜晚降低明度；透明背景。
- 栏杆真实阻挡地面角色，门口允许穿行；安全边界另负责怪物与攻击隔离。飞行沿用原有规则。
- 木门随靠近绕铰链开合，无复制帧；角色和其他资产动作不改动，源视频、图集任务不适用。
- UI 使用既有 HTML/CSS，无新增插画，手机最小宽度 320。

## 制作指令

沿用森林绘本平涂，在既有地图上构建低矮木栏、可开合双扇木门。入口清楚、影子接地，不改变建筑比例与独立操枪。邻居面板先展示当前行动与报酬，把往来记录折叠；闲聊通过现场气泡表达。

## 完整交付参数

- 稳定标识：`sunleaf`、`neighbors`、`east-clearing`；类别：聚落围栏/木门/路牌、生活 UI。
- 变体区别：短木栏双横梁与可开合双门叶；横向门带中文聚落牌，纵向门按道路轴向开口。
- 图层：接触影 → 脚底排序的柱梁 → 独立门叶；气泡使用单独 HTML 层。桥面与河道不改动。
- 逻辑尺寸：栏段 ≤58，门宽150–180；Canvas 按现有 DPR（最高2）绘制，不交付额外像素图集。
- 锚点：柱脚/门轴世界位置；透明背景包含局部接触影。光向：左上受光、右下冷影，夜间共用几何。
- 文件：`src/config/settlements.js`、`src/world/settlements.js`、`src/rendering/settlements.js`；UI 在对应 `src/ui/` 与 `src/styles/` 文件。
- 动画时长/帧率/源视频：门为距离驱动铰链动画，无固定循环片段，此项源视频/裁切/帧数不适用；其余角色与载具保留正式资产和动作时钟。
- 缓存：98 段围栏与 8 座门为模块常量，无逐帧新增位图；清缴路牌沿用有界 112×128 道具缓存，不增加缓存上限。
