# 森林巡游美术生成任务单

复制本任务单，为每项美术任务保存一份至 `docs/art-tasks/<任务标识>.md`；已有对应任务单时继续更新。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)与 [AGENTS.md](../../AGENTS.md)。复制到子目录后，将这两个链接分别改为 `../art-generation-standard.md` 与 `../../AGENTS.md`，其他相对链接也按实际位置调整。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

默认按 **imagegen + 程序绘制 + SVG 实现动态效果与交互 → 实机确认 → imagegen精修 → PNG替换与复核** 推进。本任务单分阶段填写，开发阶段不要求最终PNG齐备；后续精修项明确标注“后续阶段”，不得以空白模板或生成预览代替当前阶段验收。用户明确要求本次直接生成或替换PNG时，记录该范围并验证已有动态逻辑。

## 4 动画任务补充

静态资产说明动画不适用原因。程序或SVG动画填写实际时钟、局部动作和录制路径，不虚构视频来源或序列帧；使用视频和序列帧时填写来源字段。猫身体继续使用真实连续帧，当前仅生成正面待机和移动，不增加多方向身体序列，也不以单张imagegen图片变形代替身体动作。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 猫 idle/move 沿用原图集；轮动按距离，警灯2秒循环 |
| 时钟、帧率与循环 | 猫源时钟不重置；轮角由位移推进，灯读取游戏时钟 |
| 动作源码或源视频与连续片段 | 猫源视频及连续片段见 assets/cat-front/animations.json；轮灯见 police-patrol.js |
| 尺寸、裁切和缩放 | 统一比例和锚点；帽子跟随每帧头部定位 |
| 起停与状态衔接 | 保持现有姿态匹配；停车保留轮角，暂停冻结时钟，减少动态固定灯光 |
| 局部真实动作 | 猫腿尾保留真实帧；车轮辐条按位移转动 |
| 独立部件 | 原正式小手、武器、后坐与枪口独立绘制 |

## 5 生成指令

本轮没有调用图片生成：项目同类猫与车使用正式 Canvas 分层，猫身体必须沿用真实视频连续帧，因此在现有代码原生资产体系内实现警帽、制服和车体。源码入口为 `src/rendering/police-patrol.js`。未生成新图集、源视频或 PNG 运行素材，也未以静帧变形代替脚步。

精修 PNG 留待后续阶段，届时按本轮已确认的逻辑尺寸、独立车轮、警灯、帽子与武器层级制作，不改变动作或碰撞接口。
