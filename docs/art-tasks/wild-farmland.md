# 野外方田美术任务单

2026-10-29追加范围：保留下文历史固定田，在森林大世界的道路旁空地新增零散2×2小田。使用独立可复现随机流，每区域最多一处，每格首茬随机为雏菊、胡萝卜或小麦，入场即可采集。避开路面、河湖山体、树冠、营地小院及当前清缴区。沿用50×36田埂、56×52格距、原作物根部/透明图集/昼夜转换、农具动作及金币收益；不新建美术资产或改变角色、载具与建筑。驾驶时也可发现田地，点击沿用安全下车收割。新旧档一次补充、保存失败回滚，收获和移除后不刷新补发；复种仍消耗玩家种子。完成后补充手机昼夜、实际触控与存档验收。

复制本任务单，为每项美术任务保存一份至 `docs/art-tasks/<任务标识>.md`；已有对应任务单时继续更新。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)与 [AGENTS.md](../../AGENTS.md)。复制到子目录后，将这两个链接分别改为 `../art-generation-standard.md` 与 `../../AGENTS.md`，其他相对链接也按实际位置调整。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 2026-10-29 野田一年未播种自动清理

- 目标与规则：仅带wild标记的自动生成田地适用；生成及最近一次成功播种记录绝对游戏历法时间。经过完整四季未再播种，移除田格及其作物；每格独立计时，不因进入新年份立即清理。收获和浇水不续期，自行开垦田保留。
- 存档与事务：旧档缺失日期从当前游戏日期起算，未来或损坏日期也回落当前日期；成功写盘后才移除田块及其农活队列，失败保留原状并限频重试。两图统一清理，生成记录保持，读档不补发野田、种子、金币或经验；已删除的教学目标按手动移除规则恢复。
- 结构与保留项：复用现有田埂、作物、角色、农具和地图渲染；到期只删除正式地块记录及操作目标，无新增图像、颜色、尺寸、锚点、布局、碰撞或动画。美术资源生成和额外动作录制不适用。
