# 森林巡游美术生成任务单：地图覆盖率重建

依据：[美术标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。本任务从正式任务单复制，保留各项设计与验收要求。

## 1 目标与范围
- 稳定标识：terrain-coverage；资源：森林、草甸、湖泊、山地及其他生态区域。
- 当前阶段：程序化地貌与交互实现，沿用现有 Canvas 2D 正式绘制器；重新导出地图预览 PNG，不生成替代角色资产。
- 当前目标（11月8日修订）：互斥地表面积森林30%、湖泊5%、山地5%、草地40%，保留20%用于营地、道路及其他生态。减小湖山腾出的面积补为草地。
- 山地通行目标：区域可进入，独立岩柱底座保留碰撞，峰间留连续通道；群峰沿各自脚底排序，避免整片山地遮住猫猫。底座76×32、峰高145，网格间距270×190并错位，独立锚点和绘制分层保持。
- 统计：湖泊和山地用实际多边形，不以包围盒计数；林地表示有成片植被的生态用地，树冠覆盖率与林地面积区分。
- 动态目标：水界、通行、两栖载具、绕行、存档落点和地图总览一致。保留怪物等级、营地编号、资源身份与采集再生。
- 参考：../art-reference/landscape-six-day.png、landscape-six-night.png；现有 natural-terrain.js、tree-art.js、habitat-ground.js。
- 制作路线：已有程序形态与资产组合，无需新建位图插画；PNG精修属于后续阶段，现有图集保持。

## 2 造型与空间
- 湖泊沿低地成组，保留六类不对称轮廓；山体保留多峰、台地、横岭差异，不能只改变颜色。
- 森林保留松、枫、柏、阔叶树种分区；草甸开阔，其他区域用灌丛、石坡和湿地过渡。
- 山脚草坡、单侧沙湾、林缘衔接。营地、道路、桥头、野外营地及其观察点保留通行空地。
- 光向保持左上受光、右下冷影；大地貌面积变化不拉伸角色或树木。

## 3 技术交付
- 世界尺寸：48000×36000世界单位（4800×3600米），不改变周期坐标。
- 锚点：山湖中心和原底座；树木脚底及地面分层保持。水域视觉与碰撞共用outline。
- 地面、实体、角色、枪械及HUD继续分层；静态地貌配置不烘焙交互或角色。
- 图像：地图预览720×560，两个美术风格各四季；运行地面继续384单位有界缓存。
- 大山不得生成随世界尺寸增长的巨幅常驻图集；按可视范围绘制，维持有限缓存。
- 必需资源沿用正式资产，加载失败必须报告；本轮没有可用备用图代替验收。

## 4 动画任务补充
无新角色或载具动画。保留现有猫视频帧、小手、武器、树木受击风摆和水纹时钟。实机复核移动、暂停、前后遮挡与两栖行驶；不得使用静帧替代既有动作。

## 5 生成指令
不调用imagegen：本次调整现有程序地形的真实面积与分布，沿用六类山湖、树种和已有绘制器。新数据固定种子复现，生成不足时明确失败；通过正式绘制入口重建四季地图底图。
