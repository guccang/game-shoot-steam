# 视野内田块对齐与道路开垦任务单

依据[游戏美术资源生成标准](../art-generation-standard.md)与[任务单模板](../art-generation-brief.md)。

## 目标与范围

本轮为既有程序交互修订，稳定标识farm-player-grid。移除道路/路边禁种与读档自动迁田；营地种田引导可就地开垦。点地时选当前视野内距离点击位置最近的已存在田块，以其中心X/Y和56×52间距对齐。视野没有田块则按点击位置原样创建第一块；野外田与自建田均可作为可见参照，各处独立田区无需共享世界原点。参考用户营地截图与正式田块绘制。

## 造型、空间与保留项

土壤50×36、作物上限49×67、根部锚点及原脚底排序不变。道路允许种田；水面、山体、设施、树木和已有田块仍使用正式碰撞检查。点击时确定目标，走近与落锄期间不随镜头或角色移动重新对齐。原农具、人物连续帧、挥锄时钟、选种、浇水、收割与存档接口保留。

## 技术交付与预算

程序坐标和资格规则修订，无imagegen、SVG、PNG或新画布。原两张作物图集与昼夜渲染复用，无新增解码和缓存。正式入口：src/world/farm-land.js、src/core/farming/farm.js、src/ui/farm.js；读档与旅行入口停止迁田。视野与点击使用同一正式镜头坐标，循环世界选择可见镜像。

## 动画及生成指令

不新增动作和素材；锄头仍走近后命中结算，既有起停、暂停与独立农具保持。没有图片生成请求或后续PNG精修项。

## 验收计划

针对性验证道路与营地开垦、无可见田精确落点、最近可见田对齐、多个不同原点、离屏/另一地图/野外田与循环镜像、目标在行走中保持、失败/取消不留下土地、读档旅行不搬田。手机真实触控完成营地任务开地与种收，昼夜同屏验证点击、目标、实体位置一致。完成后记录证据；当前待验收。

designCriterion：world-farm-delivery。
