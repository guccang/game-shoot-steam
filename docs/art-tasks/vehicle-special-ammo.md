# 载具营地增强弹与三域照明

当前阶段：动态效果开发。参考已有炮口压力波、地貌团子元素配色与营地灯光，执行游戏美术资源生成标准。玩家目标是提升坦克单发清群、控制和夜战能力。

造型：冰冻用三角冰晶、火焰用上窄下宽火舌、毒气用低矮圆云、电弧用跳跃光线、高爆和震荡用扩散冲击圈。照明弹为小伞灯芯，覆盖三个固定世界光池。保持绿色描边、奶油亮部，不遮角色和敌人预警。主体为实际载具与敌人，弹药特效只作局部强调。

技术：图标64×64 SVG，粒子与范围为世界坐标Canvas；特效锚点为真实炮弹首次碰撞/耗尽落点，照明为发射位置与炮塔方向。地面区域在实体下层，炮口与弹丸使用既有独立后坐；照明进入正式迷雾与索敌管线。装填、库存、时间、范围和开关由程序控制。无新增位图、无新增碰撞，最多8处持续区域和3个照明光池；暂停冻结，低动态关闭摆动。照明单发45秒、半径300、中心间距220，离所有中心270以外重新发射。尺寸为游戏单位，库存采用真实重量。

保留项：炮塔后坐、履带运动、真实角色连续帧、原有弹匣、升级、穿透、地图循环和迷雾。每次主炮射击额外消耗一枚增强弹，缺少增强弹仍使用基础弹；照明独立消耗，所有营地通售。默认开启，可在当前载具页关闭。六种增强弹对应六座营地，不能异地购买或制作。
