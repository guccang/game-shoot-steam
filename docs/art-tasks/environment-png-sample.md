本单按 [任务模板](../art-generation-brief.md) 的六部分填写，执行 [生成标准](../art-generation-standard.md)。2026-10-27，首组样品；不代表全 UI 图标已迁移。

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | HUD26–28px、档案32px；触控目标44px |
| 像素尺寸与倍率 | 原生图1448×1086；按实际像素定位12块，等比缩小为96×96，主体最长边86px；坐标见manifest |
| 锚点与原点 | 图片几何中心(48,48)，等比缩放，四周留透明边距 |
| 分层 | 按钮底板 / PNG图案 / 动态SVG圆环 / DOM辅助名称，各自独立 |
| 透明背景 | 原生Alpha；禁止把棋盘格或不透明底色当透明 |
| 碰撞与可通行性 | 不适用：仅界面图片，不改变世界碰撞 |
| 昼夜处理 | 共用一套PNG；在正式昼夜场景检查对比，无夜景副本 |
| 文件格式与位置 | assets/environment/*.png；source/png-sample-v1 保存原图、请求、响应及处理脚本；运行清单manifest.json |
| 内存与缓存预算 | 12×96×96×4=432KiB理论RGBA；运行PNG实测131101字节（128.03KiB），低于180KiB；原图1009662字节仅在source，游戏不加载 |

## 4 动画任务补充

图案为静态，不适用动作帧率、源视频、姿态衔接及局部肢体检查。现有SVG圆环按真实时钟继续更新；PNG不包含圆环与进度数字。角色与独立操枪绘制器不修改。

## 5 生成指令

按已查看的实机参考生成4列3行共12枚透明图标，顺序为春、夏、秋、冬；白昼、黄昏、夜晚、晴；阴、雨、雷、雪。强调森林绿描边、奶油高光、大色块和不同剪影。原图透明，不绘制底板、外圈、字母、汉字、网格、棋盘格、水印或背景。每个图标完整居中，格间宽留白。完整中文提示词与实际提交参数保存至 source/png-sample-v1/request.json。
