# 森林巡游美术生成任务单

复制本任务单，为每批资源填写一份。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 1 目标与范围
- 尾怪边缘导航 / wave-tail-navigation：普通清缴波次剩余 1–3 个名额时，最多 3 个屏外怪物方向与直线距离提示。
- 参考现有 story-navigation 圆形罗盘；新提示使用暖奶油小箭头与深绿距离牌，区别于任务罗盘，不新增可点击按钮。
- 程序化 SVG 与 DOM，保留角色、怪物、载具动画、镜头、波次数值与奖励。
## 2 造型与空间
- 32px 箭头盘，下方距离短牌；整体 56×54px。透明外缘，森林绿描边，有限平涂，无闪烁。
- 屏幕边缘定位；避开任务、波次、资源、菜单、血条、摇杆及提示。多个方向提示错开。
- 纯界面，不改变地面、碰撞、道路或地图通行；锚点取正式镜头投影和循环地图最近镜像。
## 3 技术交付
- 原 SVG 逻辑坐标 36×36，CSS 显示 32×32；无位图、纹理缓存或昼夜副本。
- 层级在战场上方、原有操作 UI 下方；pointer-events:none，不拦截鼠标和触屏。
- 共用昼夜形体与奶油/深绿对比，保持夜间可读；最多复用 3 个节点。
- 源码 src/core/battle/wave-tail-targets.js、src/ui/wave-tail-navigation.js、src/styles/wave-tail-navigation.css。
## 4 动画任务补充
不适用：无新身体或部件动画。箭头实时跟随目标与镜头，不使用呼吸闪烁或自动镜头移动。
## 5 生成指令
延续现有森林绘本 UI，优先小箭头和距离，避免长文字。目标入镜、死亡、清波、休整、Boss、暂停、弹窗与离开清缴场后及时隐藏。
