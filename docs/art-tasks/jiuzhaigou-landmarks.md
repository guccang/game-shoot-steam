# 九寨沟林坡与地名牌美术任务单

依据 [美术生成任务单](../art-generation-brief.md) 及 [游戏美术资源生成标准](../art-generation-standard.md) 1.0。标准在本轮实现后随主分支同步，因此根据原定目标、正式源码与实际验收补齐记录；未倒填制作前审批。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 九寨沟林坡与地名牌 / `jiuzhaigou-landmarks-v01` |
| 类别和用途 | 地形、植被、摆件；补足外围生态层次，帮助玩家辨认景点 |
| 本轮目标 | 湖瀑之外有连续林坡和林下层；每处已生成景点都有现场木牌 |
| 数量和变体 | 7 片林坡、15 块牌；四类地被：多面苔石、羽状蕨草、圆冠灌丛、放射草簇；树木沿用针叶、阔叶、桦木 |
| 保留项 | 原森林、地图切换、湖瀑轮廓及碰撞、原角色真实连续帧、独立操枪、怪物与载具动作、战斗和通行空地 |
| 制作路线 | 扩展原 Canvas 2D 程序绘制及世界数据，无外部图像生成 |
| 参考与同类资产 | `docs/art-reference/landscape-six-day.png`、`landscape-six-night.png`；`src/rendering/signposts.js`、`forest-art.js`；[UNESCO 九寨沟地貌说明](https://whc.unesco.org/en/list/637/) |
| 使用场景 | 湖滩与瀑布干岸、日则沟／则查洼沟／树正沟、外围混交林坡 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 木牌双柱、护檐、叶标；缓坡三层弧形等高带；林下地被保持低矮 |
| 与其他变体的区别 | 苔石为多边形亮顶与匍匐苔层，蕨草为分叉中轴和羽叶；灌丛由分组圆冠组成，草簇为弯曲长叶；林坡位置、长宽与弯折不同，不宣称为七种新山型 |
| 主次关系 | 湖瀑为主景，林坡形成外围背景；牌面及少量灌草帮助识别与衔接 |
| 地面衔接 | 原草地 → 低对比坡带 → 林缘灌草与苔石 → 原树木；岸线保持原钙华带 |
| 活动空间 | 两岸游径树干避让 63 单位，地被避让 46 单位；出生点与牌前专门清空 |
| 邻接组合 | 五花海混交林、长海针叶林、珍珠滩与诺日朗岸边疏林、树正群海林间通道 |
| 光向与明暗 | 沿用左上亮面、冷绿暗面、贴地小影；不新增局部发光材质 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 地被约 50×40 单位；木牌含护檐约 164×111 单位；林坡半轴 rx=300–520、ry=370–490 |
| 像素尺寸与倍率 | 程序绘制，无新增位图图集；牌面广角缩放 1–2.2 倍，脚底固定，最终随正式相机等比投影；DPR 由 Renderer 控制 |
| 锚点与原点 | 世界坐标 3600×2800 周期地图；木牌 `(x,y)` 为两柱脚底中心，地被为贴地中心 |
| 分层 | 林坡／地被进入 GroundCache；树影在地面层；树与牌按 y 排序；水流保留正式动态层 |
| 透明背景 | 无整图背景；低矮地被绘入地面，路牌独立画在透明场景上下文上，包含小范围接触影 |
| 碰撞与可通行性 | 林坡、地被、路牌为可通行装饰；水体、跌坎、树干仍由正式几何阻挡 |
| 昼夜处理 | 同一地面经 nightTexture 生成夜色；牌面沿用既有夜色叠加并受 SceneTone 统一处理 |
| 文件格式与位置 | 世界数据 `src/world/jiuzhaigou.js`；绘制 `src/rendering/jiuzhaigou-landscape.js`、`signposts.js`；截图与视频 `output/playwright/`；长期样例见文末 |
| 内存与缓存预算 | 新增纹理下载 0 字节；复用 384+双侧2 单位地块，常规至少32块、全景按可见块自适应上限。实测近景24块，日间13,185,792字节、保留昼夜后26,371,584字节；后续切尺寸命中缓存，无持续重建。数值是RGBA画布估算，不是GPU实测 |

## 4 动画任务补充

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 新增牌、林坡和地被为静态，不适用新动画生产；原树摆和瀑布动态继续运行 |
| 帧率、帧数和循环 | 不新增图集；湖／瀑／林坡昼夜案例在0、0.125、0.25、0.375秒各采4帧 |
| 源视频与连续片段 | 不适用，未生产或修改角色／载具源视频；原资源 `assets/cat-front/` 保留 |
| 统一裁切和缩放 | 不适用位图裁切；场景由原相机等比缩放，牌脚不随放大移动 |
| 起停与状态衔接 | 真实键盘绕牌走位仍使用正式 Game 更新；静态地被无需动作切换；减少动态水流回归通过 |
| 局部真实动作 | 不改变猫腿、怪物、履带或旋翼；既有全套动作测试继续运行，未用静帧代替 |
| 独立部件 | 不修改小手、枪、后坐、枪口、炮塔和控制器连接 |

## 5 生成指令

延续《森林巡游》的森林绘本风格，基于原木牌绘制器扩展现场景点牌。按双柱脚底中心制作护檐、奶油牌面与绿叶标；名称、沟谷和方向均用程序文字绘制，不烘焙进贴图。外围使用低对比三层林坡、现有针阔混交林及四类低矮地被；主步道、出生点和牌前留空。湖瀑边界、原角色比例及操枪动作保持原实现。

排除写实噪点、纯黑厚内纹、满屏装饰、高饱和辉光、整图背景、文字水印和新增隐形碰撞。蕨叶与石面内部分色已去掉多余粗描边，避免正常缩放下形成黑色纹理块。
