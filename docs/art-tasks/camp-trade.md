# 营地订单与商路

## 营地订单板进度改版

参考本次实机截图中的单柱小木牌，将营地主牌改成双柱公告板，脚底仍锚定原交接点。主体宽 144、高 84 世界单位，上栏写名称，奶油色面板分栏显示任务总数和已完成数。地面影、支柱、木框、牌面与实时数字由正式 Canvas 绘制；使用现有字体与场景排序，无新增贴图或动画。原有驿站木牌、导航和道路沿用现有配置。手机触控区跟随新牌面大小，昼夜及桌面竖版用现有商路场景复核。

## 目标与范围

本轮为动态效果与交互开发。在晴叶营地设置订单板，在旧哨站和琥珀林设置交接点。玩家可在手机查行情、跟车领路，在场景里点木牌出售作物或交付任务。依据[美术标准](../art-generation-standard.md)、[手机底板](../ui-foundation.md)及[仓库动作合同](../../AGENTS.md)。

## 造型、空间与资源

- 营地和旧哨站沿用木牌，远站以单顶奶油色帐篷、收货桌和营灯围出交接空地。远站选在林道旁树冠留白处，桌前可步行和停车。三个地点的稳定标识和脚底坐标见 [商路配置](../../src/config/camp-trade.js)。
- 木牌宽度由正式短名称木牌决定，支柱高 40 世界单位。帐篷、桌台、营灯与人物按各自脚底排序。屋外点击区最小 44 × 44 CSS 像素，订单要在地标 110 世界单位内办理。
- 商队使用第 14 号铜箍货运马车的原车体尺寸、挽具、车轮和马匹锚点。轮相按真实位移更新，挽马沿用既有正面迈步、姿态匹配和待机序列。世界排序和昼夜调色沿用战场绘制器。猫和武器沿用主角独立动作层。
- 正式入口为 [商路世界物件](../../src/rendering/camp-trade.js) 的 `tradeObjects`、`drawTradeObject` 及[野外摆件](../../src/rendering/outdoors.js)的 `drawOutdoorObject`。动作来源为 [载具运动](../../src/combat/vehicle-motion.js) 和 [马匹清单](../../assets/vehicle-eras/horse.json)。本次复用已有图集和程序木牌，新增图片、解码纹理和离屏缓存均为零。没有图像生成请求、PNG 导出或视频源替换。

### 订单板改版复核

初次同屏检查发现，停靠的商队名牌挡住完成数。将牌面及触控区域上移 32 世界单位，延长双柱至原脚底。复查 [390 宽白天](../../output/playwright/camp-trade/390-day.png)、[320 宽夜晚](../../output/playwright/camp-trade/320-night.png)及上表两张桌面竖版截图，商队、持枪角色和 HUD 同屏时均可读到总数 4、已完成 1。沿用原世界遮挡排序与可通行地面，双柱和落影不参与碰撞。

实际触控接单、交货后，[订单页](../../output/playwright/camp-trade/phone-orders.png)与世界牌面同步更新。两条护送分别认定首次完成；重复交货、保存失败和读档由商路规则用例验证。复用 Canvas 图元、运行时字体和两列文字，无新增图像、离屏画布或动画。正式入口为 `drawTradeObject` 中的 `drawOrderBoard`，对应 `designCriterion: camp-trade`。本次程序绘制与手机交互验收通过。

## 护送马车连续移动修订（2026-11-09，制作前）

目标：消除25Hz护送坐标直接显示在插值镜头中的阶梯抖动。参考本次用户商队97%截图与正式铜箍货运马车；只修改表现快照接入，不调整跟随速度、路线、碰撞或存档。尺寸、脚底锚点、世界遮挡、马匹正面连续帧及独立装备沿用前述合同；不新增造型、图像生成或PNG替换。

程序以每个固定逻辑步之前的护送坐标和车轮相位生成连续表现，暂停、结束护送、传送与场景切换即时复位。只新增一份小型对象历史及投影，无位图或纹理缓存。正式入口：render-interpolation.js、tradeObjects、drawTradeObject；designCriterion沿用camp-trade。验收待连续帧、昼夜手机移动及专项规则检查后填写。

### 本轮验收结果

通过：390×844白天及320×568夜间使用真实触控带队，分别采集160/144个正式绘制帧，其中84/78帧在逻辑未推进时车身仍连续移动。`output/playwright/trade-interpolation/result.json`记录实际车身、权威坐标、镜头、马匹帧及轮相；`day-0～2.png`、`night-0～2.png`记录连续画面，已查看白天和夜间中间帧。马匹正面动作、车体、猫和枪、地面与HUD同屏保持原比例和锚点，名牌与车体同位置更新。暂停后连续采样位置一致，恢复场景后继续护送；无页面或正式帧错误。

13项专项测试通过：60Hz显示/25Hz逻辑的同速相对位置稳定、轮相跨整周、受损值即时显示、暂停、移除、读档替换、传送、周期接缝，以及原商路交接与两条路线结算、失败重接。存档仍共享权威进度，表现投影不会写回碰撞坐标或任务值。全量测试未执行。

本次不修改碰撞、道路、地形遮挡、动作资源或PNG；没有新增资源下载与位图内存，历史只增加护送车与运动状态的小型数值快照。正式验收入口`inspectCampTrade`可传入`renderer.renderGame`同时记录显示坐标与权威坐标，对应`designCriterion: camp-trade`。程序连续移动修订通过，PNG精修不适用。

## 2026-11-10 六营地商路互通

本轮只调整订单业务、存档字段与原面板中文内容，沿用现有商站、车马、按钮、尺寸、锚点及绘制器，不新增美术资源。目标为各站接单、跨站交付、地区营地直接接返程；采用原手机底板和正式交易提交，不新增货物库存系统。

已实现：主营地和五方商站均可接取/交付作物与货签；六站任意不同站点之间接取运货。订单新增稳定 `origin` 标识，旧订单缺省主营地；目的地、护送货车和击退数量均须满足才结算。途中伏击按真实起点到终点的距离判定。主营地也作为返程目的地，任务目录保留旧完成标识并增加主营地交付项；完成统计按订单类别/目的地计算，不是30条有向线路各计一项。当前所在地不出现在可接目的地清单，后端同样拒绝同站订单；离站查看会引导最近商站。

验收通过：原商路10项回归、新增2项检查（内部覆盖30种方向、跨站作物/货签、错误站点、货车未到、重复领奖、失败不扣货和旧档起点）均通过。浏览器真实触摸在苔溪接单到赤炉，交付作物与运费后原地接赤炉→苔溪返程。测试直接布置到站状态以验证交付，不宣称全程驾驶走完所有远程商路。

人工查看 `route-320.png`、`return-order.png`、`station-night.png`，320×568和390×844无横向溢出，起终点与反馈完整；昼夜场景沿用既有渲染，商队与猫猫、建筑保持同屏，无新增图片或画布预算。`designCriterion: camp-trade`，正式入口仍为 `inspectCampTrade`；合同关联新增测试。没有美术替换，PNG/图集生成与新动作验收不适用。仅浏览器手机模拟，不宣称实体手机硬件验收。
