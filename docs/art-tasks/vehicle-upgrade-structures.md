# 载具装甲与动力结构成长任务单

依据：[美术标准](../art-generation-standard.md)，从[任务单](../art-generation-brief.md)复制并填写。

## 1 目标与范围
| 字段 | 填写内容 |
| --- | --- |
| 资源与用途 | 六款正式载具：pine-tank、heavy-tank、helicopter、hovercraft、fire-truck、ranger-scooter。战场和工坊共用。 |
| 目标 | 初始造型不变，装甲与动力升级获得明显外露结构；不靠整车放大或换色。 |
| 数量和变体 | 六款×装甲20级/动力5级；装甲分护片、加强梁、侧挡与复合板阶段，动力分外置壳、散热、管路和辅助机组。 |
| 保留项 | 车轮/履带/风扇/主尾旋翼、悬挂后坐、驾驶猫动作、独立操枪、碰撞与通行规则。 |
| 制作路线与参考 | Canvas独立部件；参考vehicle-models、pine-wheels、hovercraft、fire-truck、scooter及已确认的weapon-upgrades。 |

## 2 造型与空间
| 字段 | 填写内容 |
| --- | --- |
| 剪影与区别 | 轮式战车短护板，重坦折面侧甲，直升机流线防护舱，气垫船舷侧防撞板，消防车红色防护/泵舱，电动车前罩/电池盒。 |
| 主次关系 | 原车型、驾驶员与炮塔优先；强化件只占侧面、前罩和外缘，不挡座舱与旋翼。 |
| 地面/邻接/活动空间 | 沿用原投影和世界排序；不添加地形或实体碰撞，桥头/林间道路保持原几何。 |
| 光向 | 左上浅色顶面、下侧深绿，奶油铆钉；沿用各车型底色。 |

## 3 技术交付
| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸与像素 | 沿用原车体坐标；单个升级件约40×40以内，挂点0.72倍率。程序矢量图元，无新位图像素/倍率。 |
| 锚点 | 以车体原点(0,0)定义车型专属挂点；电动车单件，其余左右成对。 |
| 分层/透明 | 原后层和运动结构→猫→前装甲/强化件→独立炮塔；升级件透明背景，保留开口。 |
| 碰撞/昼夜 | 纯外观，碰撞不变；共用正式场景色调，不新增夜间副本。 |
| 文件与预算 | src/config和src/rendering分层；试玩src/art；验收docs/art-reference/vehicle-upgrades。无新增纹理、解码缓存或预生成组合。 |

## 4 动画任务补充
| 字段 | 填写内容 |
| --- | --- |
| 动作 | 正式连续驾驶、停下、重启、转向、暂停与后坐，沿用真实游戏时钟。 |
| 帧与源视频 | 不生成动画资源，无新增源片和裁切；录制正式运行作为验收证据。 |
| 局部动作 | 不改变履带/轮辐相位、旋翼角度、风扇及猫视频。 |
| 独立部件 | 升级件随原车体悬挂，炮塔仍单独瞄准；部件卡/施工/战场使用同一绘制器和挂点。 |

## 5 制作指令
保留原装车体，升级以短护板、折面侧甲、机舱、电池和散热组件形成结构成长。避免覆盖履带纹路、轮毂、风扇开口及旋翼，不用大型通用方块拼满车身。保持原比例和柔和森林配色。

## 6 验收记录
制作前计划：六车原装多相位像素对照；装甲/动力分别升级和拆装；同倍率原装/中期/满级；320/390及桌面昼夜同屏；正式驾驶录像及实际工坊施工。对应designCriterion为vehicle-upgrade-structures。完成后在此补充逐项结论和路径。

主分支 6919524 将电动车改为正面朝前造型，本任务保留该更新，装甲挂点改为前罩中央 (0,-2)，动力挂点改为左侧 (-23,0)，不再沿用旧侧视车的挂点。其余五车无此次整合差异。

- `catalog-service-current.png`、`scooter-front-390-day.png`、`scooter-front-390-night.png` 是正面电动车最新视觉证据，覆盖前述旧侧视电动车截图的验收结论。车灯、猫脸、窄前胎均保留，新增前罩与侧电池和当前车型一致。
- `motion-scooter-front.webm/json` 是满级装甲20/动力5的正式连续驾驶、停止、暂停、恢复录像，44次状态采样；覆盖旧侧视电动车录像。暂停6次采样中时钟、轮角和步态相位不跳变；恢复后真实位移继续。

整合结论：通过。旧侧视电动车证据仅作为开发过程记录，以本节的正面车证据为准。
