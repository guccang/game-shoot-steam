# 九秒入职短剧美术任务单

依据：[美术标准](../art-generation-standard.md)，从[任务单模板](../art-generation-brief.md)复制并按本次范围填写。

## 1 目标与范围
| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 公交到站与退休接送 / short-arrival-story |
| 类别和用途 | 程序化公交载具、独立信封和风线、正式入职动画、信件阅读界面 |
| 本轮目标 | 三场九秒小喜剧；下公交站定一秒；老人从远处带风接走玩家，营门塞信后骑车开心离去 |
| 数量和变体 | 一辆公交、一辆老人专车；玩家获赠车辆仍留在车库，不是老人骑走的车 |
| 保留项 | 原猫连续帧、脚底、操枪、场景坐标、深度、昼夜；采木、维修、购买仍走正式任务和保存 |
| 制作路线 | 原 Canvas 2D 绘制器扩展；不生成位图 |
| 参考与同类资产 | src/rendering/scooter.js、ranger-arrival.js；docs/art-reference/landscape-six-day.png 与 night.png |
| 使用场景 | 原公交站与晴叶营地北门 |

## 2 造型与空间
| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 公交为窄长奶油车身、草绿车顶、独立车门与车轮；信封折线和封口可辨 |
| 与其他变体的区别 | 公交车厢与四轮区别于电动车窄前罩、双轮和双座；不新增同类换色变体 |
| 主次关系 | 猫与车辆为主体，风线和信封局部点缀，不增加全屏运动模糊 |
| 地面衔接 | 沿原北林道进站及进营，接触影贴地 |
| 活动空间 | 北门、站棚与林道开放；公交只在短剧内出现，不新增持久碰撞 |
| 邻接组合 | 原站棚、营地木门、林路；不迁移建筑 |
| 光向与明暗 | 原左上受光与右下冷影，正式昼夜合成 |

## 3 技术交付
| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 公交约70×140；信封24×17；风线限车辆附近80单位 |
| 像素尺寸与倍率 | Canvas 按正式世界倍率及DPR渲染，无新增贴图 |
| 锚点与原点 | 公交地面中心、猫脚底、双座延用 passengerFootY；信封以玩家手侧锚定 |
| 分层 | 接触影→车后部→乘员→前罩和手；独立信封与速度线参加世界合成 |
| 透明背景 | Canvas透明部件，车下独立接触影 |
| 碰撞与可通行性 | 剧情车纯演出，沿现有路网；任务落点在北门内，不改变正式障碍 |
| 昼夜处理 | 同一形体进入正式夜色，不新建昼夜副本 |
| 文件格式与位置 | src/config、core、rendering、ui 分层；截图录制 output/playwright；长期图 docs/art-reference |
| 内存与缓存预算 | 无贴图、视频和新增缓存；仅瞬时路径对象及少量Canvas图元 |

## 4 动画任务补充
| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 公交0.6秒、下车0.6秒、等待1秒、接近0.8秒、上车0.3秒、送达2.8秒、下车0.5秒、塞信0.3秒、离开1.1秒、风中1秒，共9秒 |
| 帧率、帧数和循环 | 正式运行时dt；角色仍由原24FPS连续帧驱动；剧情单次播放 |
| 源视频与连续片段 | 不新增身体资源，沿用 assets/cat-front/animations.json 记录的原源片与片段 |
| 统一裁切和缩放 | 原160×160格与正式角色比例，不重新裁切 |
| 起停与状态衔接 | 存档版本3；旧导览迁移交接，完成档不重播；暂停不补时 |
| 局部真实动作 | 上下车真实步态，车轮随路程；风只影响信角和独立飘带，猫继续同源待机 |
| 独立部件 | 老人手连接把手；玩家手与信封独立，不烘焙身体与枪械 |

## 5 生成指令
延续森林绘本、森林绿描边、奶油黄和草木色，复用现有猫与电动车。程序绘制窄长公交、折角信封与少量风线。保持脚底、深度与正常手机比例；不复制帧、旋转整张角色或添加全屏模糊。信件使用手机UI底板与44px操作区，中文正文可滚动。

## 6 验收记录
| 设计目标 | 实际结果与证据 |
| --- | --- |
| 系列一致、变体可辨 | 原猫与电动车保持原比例；公交窄长车厢有侧窗、车顶通风盖、独立车门和轮纹。output/playwright/short-alight-390-day.png、short-ride-390-day.png |
| 落地、遮挡、真实动作 | 公交下车与上车使用原连续步态；双座依原后座遮挡；老人始终独立坐车，不步行离开；车轮按路程转动。short-arrival-verified.webm 保留完整连续实录，short-verified-sequence.png 为逐秒复核 |
| 保留活动空间与真实边界 | 路线逐点检查水界、木栏和树干；公交保持驶出镜头而非提前消失。任务流程从营门正式寻路并发移动输入采木，没有传送或填充物资，两轮分别30/31次采集目标累计296份木材，真实点击工坊扣280修复、扣8购买首枪 |

| 资源和性能 | 无新增运行位图、视频、昼夜副本或缓存；使用现有cat-front资源与少量Canvas图元。浏览器无pageerror；减少动态关闭风线并保留原身体帧，不用静态备用画面。长期参考PNG仅在docs，不进入战斗资源 |
