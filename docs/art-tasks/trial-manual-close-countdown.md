# 试射自主结束与统一倒计时

## 1 目标与范围
- 标识：`trial-manual-close-countdown`；类别：程序化 UI 徽记。
- 目标：试射击中任务靶后持续运行，由玩家结束；自动关闭的奖励面板在卡片正上方显示圆环加数字。火警、停车、候门及施工使用同一图形语言。
- 数量：一个共用徽记绘制器，停车、时钟、小屋、床和施工图标按动作区分。
- 保留：奖励三秒、火警十秒、停车/候门三秒、施工五秒；奖励装备画像、角色真实动作、碰撞与任务结算保持。
- 参考：`src/rendering/parking.js` 原停车候停徽记、当前任务截图及 `docs/art-generation-standard.md`。
- 路线：现有 Canvas 2D 与 HTML/CSS；无需位图生成。

## 2 造型与空间
- 圆角奶油底、森林绿描边，左侧图标与进度环，右侧单个数字；保留停车原形体与尺寸。
- UI 层在卡片正上方居中留白；仅内容卡片滚动，徽记不会被长奖励裁切。
- 图标轮廓区分车、钟、屋顶、床及锤子；圆环方向、颜色和字号共用。
- 地面衔接与邻接地形不适用：此轮仅覆盖层。角色、门口、通行与车辆实体不变。
- 有限平涂，无发光或场景光照修改。

## 3 技术交付
- 徽记逻辑尺寸 68×34，含描边画布 70×36；UI 最高三倍像素比。
- 原点为徽记中心，世界提示固定屏幕大小；奖励徽记与卡片同属原生弹窗顶层。
- 分层为独立覆盖层；透明背景；无碰撞，无昼夜副本，无新增图集。
- 正式入口：`src/rendering/action-countdown.js#drawActionCountdown`、`src/ui/action-countdown.js#createActionCountdown`。
- 预算：每个徽记最大 210×108（约 89 KiB）；无新增循环或缓存，复用功能时钟。

## 4 动画任务补充
- 仅倒计时圆环随进度增长，非角色动画；连续角色帧、小手枪械等均保留。
- 无视频、帧图集或动作变形任务；计时暂停/重开仍由功能控制器负责。

## 5 制作指令
按原倒车入库徽记统一 UI。试射不自动切页；奖励以独立上方徽记表达自动关闭，不在内容里堆叠倒计时文字。保持森林绘本风格、颜色和触控标准，移动端不遮挡关闭按钮或奖励图像。
