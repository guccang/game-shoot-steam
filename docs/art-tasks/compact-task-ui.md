# 清缴任务面板紧凑布局任务单

依据：[美术标准](../art-generation-standard.md)、[任务单](../art-generation-brief.md)、[项目合同](../../AGENTS.md)。

## 1 目标与范围

- 资源：清缴 HUD，`quest`、`wave-help`、`task-navigation-toggle`。
- 本轮为现有 HTML/CSS/SVG 布局调整；沿用用户截图中的奶油底、森林绿、波次圆点和领主头像。
- 目标：寻路开关排在问号右侧，与波次同行；标题取消 44px 操作行留白，面板高度约 80px。
- 保留：44×44px 按钮命中区、任务文字、五波进度、领主按钮、寻路开关与详情弹窗的现有行为。
- 使用场景：林区清缴；其他任务卡维持原锚点规则。无需生成新位图或后续 PNG 精修。

## 2 造型与空间

- 顶部一行目标，下方依次为波次、领主、问号、寻路开关；按手机宽度约束面板，缩短纵向占用。
- 问号与寻路开关各自独立，标题使用完整可用宽度，长文本仍省略。
- 地面衔接、投影、物理碰撞与通行不适用：仅调整屏幕 HUD，不修改场景或角色。

## 3 技术交付

- 沿用 292px 面板宽度及手机边距限制；寻路图标 viewBox 32×32、显示 28px，按钮 44px。
- 锚点为正式任务面板与问号的 DOM 矩形；按钮仍是 game-frame 的独立子节点，避免嵌套按钮。
- 实现：`src/ui/task-navigation.js`、`src/styles/clearing-flow.css`，正式审核 `inspectTaskNavigation`。
- 层级、稳定 ID、事件接口不变；昼夜沿用现有 UI 色板。无新位图、解码缓存或网络资源。
- 动画、帧图集、身体动作、武器连接、透明边缘与 PNG 替换均不适用：本轮只有布局。

## 4 动态效果与交互

波次和倒计时仍由游戏状态更新；寻路仅开关现有路线，问号仍打开清缴详情。检查开启、关闭、弹窗返回与领主阶段。
