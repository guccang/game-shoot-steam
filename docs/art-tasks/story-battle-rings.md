# 任务战斗圈与剧情试玩验收单

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。本单记录本轮程序化边界和镜头调整。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 剧情任务战斗圈 / story-battle-rings |
| 类别和用途 | 既有地面边界扩展至普通任务遭遇 |
| 本轮目标 | 玩家和怪物留在可见战斗圈内，清场后解除；不再追逐被击飞到远处的敌人 |
| 数量和变体 | 一种已有绿黄边界，普通波次半径220，领主保留280 |
| 保留项 | 伤害、血量、奖励、击退和真实动作不变；保留河岸与树干碰撞 |
| 制作路线 | 复用正式drawStoryGuidance，无新增位图 |
| 参考与同类资产 | docs/art-reference/story-campaign 与原野猪王战斗圈 |
| 使用场景 | 六章主线的任务波次与守点 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 森林绿外沿、奶油黄色内线、等距向内短刻度 |
| 与其他变体的区别 | 不适用：复用一套边界，按实际碰撞半径缩放 |
| 主次关系 | 角色与攻击为主，地面环只提示范围 |
| 地面衔接 | 原草地与岸线不变，圆环不覆盖地形 |
| 活动空间 | 沿原通道进入；来敌只从圈内同岸可达位置生成；完整清场解除限制 |
| 邻接组合 | 原任务站点旁的林木、河岸与场景道具 |
| 光向与明暗 | 复用昼夜可辨的绿黄描边，无新光源 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 普通圈直径440世界单位，领主560 |
| 像素尺寸与倍率 | Canvas按正式镜头倍率投影，不新增图集 |
| 锚点与原点 | 当前任务站点的世界坐标，与player.arena共用数据 |
| 分层 | 地面提示位于实体、预警、武器和气泡下方 |
| 透明背景 | 不适用：仅Canvas描边，无位图背景 |
| 碰撞与可通行性 | 所有参战实体共用arena圆形碰撞，继续遵守森林地形 |
| 昼夜处理 | 沿用现有昼夜提示色，无局部新灯光 |
| 文件格式与位置 | 配置src/config/story.js；逻辑src/core/story-encounters.js；验收output/playwright/story-playthrough |
| 内存与缓存预算 | 无新增图集、纹理、画布或缓存；每圈固定24组短刻度 |

## 4 动画任务补充

不适用：未生成或替换角色、怪物、机械猫和载具动画。保留原连续帧、脚底锚点、独立枪械、履带、旋翼与受击动作。战斗镜头平滑缩放至容纳整个圈，圈内移动不重新居中，离开战斗平滑恢复跟随。

## 5 制作记录

复用正式 `drawStoryGuidance` 的绿黄边界与24组内侧刻度。配置表增加默认战斗圈，普通遭遇和守点共享半径220；野猪王仍为280。实体与绘制引用同一个 `arena`，出生点继续拒绝树干、水域与跨河直线不可达位置。没有图片生成、视频生成或新的源资源，因此没有生成服务记录、裁切或图集处理。

## 6 验收记录

| 设计目标 | 实际结果与证据 |
| --- | --- |
| 系列一致、变体可辨 | 沿用原野猪王边界；任务目标仍是小椭圆光圈，大圆表示战斗限制，二者可区分 |
| 落地与遮挡合理 | 正式地面层绘制，树木和角色仍在圈之上；第三章林间实战保留树干碰撞，未用装饰层覆盖实体 |
| 保留活动空间和真实边界 | 玩家、飞行载具和重复重击敌人均无法越界；普通清场、守点结束、重试与暂离解除；同岸出生和伙伴跨桥逐步移动专项通过 |
| 动作柔和且部件独立 | 未修改动画；自然战斗截图保留机械猫挥爪、独立主炮和击退；伙伴沿正式碰撞移动，不瞬移到目标 |
| 白天与夜晚可读 | 第六章实际战斗切换环境采样；[桌面白天](../art-reference/story-playthrough/ring-1280-day.png)、[桌面夜晚](../art-reference/story-playthrough/ring-1280-night.png) |
| 手机与桌面合格 | [320白天](../art-reference/story-playthrough/ring-320-day.png)、[320夜晚](../art-reference/story-playthrough/ring-320-night.png)、[390白天](../art-reference/story-playthrough/ring-390-day.png)、[390夜晚](../art-reference/story-playthrough/ring-390-night.png)；全圈在画面内，边界、目标与HUD能同时辨认 |
| 资源完整且预算合格 | 无新位图、纹理、画布或解码资源；圆圈复用原24组刻度，镜头仅计算矩形；正式资源加载复核见试玩记录 |

正式绘制器入口：`src/rendering/story-guidance.js#drawStoryGuidance`、`src/rendering/renderer.js#draw`、`src/rendering/story-camera.js#storyBattleView`。
`designCriterion`：`story-battle-rings`；读数入口 `src/rendering/visual-review.js#inspectStoryBattleRing`。
验收结论及完整交互记录见[剧情试玩报告](../story-playthrough.md)。本轮不主张已完成实体手机性能测试。
