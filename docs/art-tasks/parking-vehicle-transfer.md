# 森林巡游美术生成任务单：北停车场换乘

依据：[游戏美术资源生成标准](../art-generation-standard.md)，本记录沿用[任务单](../art-generation-brief.md)六项结构。制作前已确定复用正式车辆与停车场，完成后补全以下结果。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 北停车场换乘 / parking-vehicle-transfer |
| 类别和用途 | 载具工坊UI及现有停驻车显示 |
| 本轮目标 | 新购车停在北停车场；页面说明去向，现场换乘仅带一辆；电动车骑乘弹夹容量增加30% |
| 数量和变体 | 复用六种车体、六个北停车位；不生成新剪影 |
| 保留项 | 猫正面连续帧、独立操枪、履带和旋翼、三秒倒车、任务借车、工坊与小屋泊位 |
| 制作路线 | 既有Canvas正式绘制器与HTML/CSS文案布局 |
| 参考与同类资产 | src/rendering/parked-vehicles.js、src/rendering/vehicle.js、src/ui/workshop/markup.js |
| 使用场景 | 营地北停车场、载具工坊、主线首次购车 |

## 5 生成指令

复用现有森林绘本风格的车体与北停车场，不生成图像。工坊说明沿森林绿文字与奶油底色，简短说明车辆停放地点、每次携带一辆和电动车容量加成；移动端自然换行。任务对白保留购买理由和到场换乘介绍。保持两条通道开放，不改角色、枪械、履带或旋翼资源。

## 2026-10-30 停车提示跟随车位
目标：修正小屋泊位移到东侧后提示仍停在房屋的问题。普通停车提示和对齐/倒车徽记统一读取PARKING_SPOTS实际坐标，保留上移16世界单位的锚点；显示内容改为24px停车标识加「点击」，完整读屏名仍为「点击 · 停车入位」，触控至少44px。复用森林绿奶油底板及正式世界投影，新增一个程序SVG图标，无PNG、图集或画布缓存；车辆动画、路径与占位逻辑保留。入口interaction-anchors.js、ui/nearby-interaction.js，designCriterion对应building-interaction-anchor与parking-off-road。验收通过：320×568日间、390×844夜间截图确认图标与点击文字同行；小屋、武器工坊、公共位和载具工坊共5次实机点击全部完成停车，提示中心与车位投影误差小于0.02px，触控高度44px且无溢出。11项停车与锚点专项测试通过，覆盖坐标、缩放与地图环绕。截图见下方；无新增运行位图资源。
