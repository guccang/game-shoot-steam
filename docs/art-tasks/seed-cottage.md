# 种子小屋与掉落解锁

## 目标、参考与结构
营地东侧田地与任务广场间加入种子小屋，双坡绿色屋顶、奶油墙、独立种子招牌、门前木架，与快递棚区分。参考既有森林房屋和农田图集；复用作物SVG，程序绘制建筑。主体120×110世界单位，底部锚点1000,830，门前1000,872，实体参与Y排序。柜台两侧可绕行，不占主路，农田和树木避让建筑。保留真实角色、手持工具和载具动作。

## 功能与界面
菜单、门前提示和选种页均能打开种子小屋；远处可看来源并导航，门前购买。标题栏X、金币库存、八种商品、购买1/5/10粒。首次获得永久解锁购买，旧档按已有等级和库存保留解锁；播种只消耗库存。雏菊10金币，其他原价。普通野怪25%掉一粒，连续7次未掉后下一次必掉；领主掉3粒，品种权重40/20/10/10/7/5/4/4。来源同时说明礼物、入门奖励。活动试射不产永久种子。

## 技术与预算
现有HTML手机框架、CSS与Canvas，最小44px触控，单列商品和正文滚动，奶油底/森林绿字。无新增位图或缓存，建筑随昼夜使用同一绘制器；既有两张农田图集不增量。正式入口src/ui/seed-shop.js、src/rendering/seed-shop.js；目标seed-cottage。PNG精修与新角色动作不适用。新建筑加入底座碰撞、禁种和树冠净空。

## 验收计划
真实击杀到入库解锁、重复命中不重复发放、保底、购买保存失败/余额/容量/距离/数量、库存播种不重复收费、旧档迁移、导航入口、手机昼夜与建筑同屏和通行检查。
