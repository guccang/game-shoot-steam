## 4 动画任务补充

静态资产标注“不适用”。猫身体当前仅生成正面待机和移动，不增加多方向身体序列。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 追击双腿交替；0.95秒抬盾蓄力→0.42秒盾击→0.55秒回位→1.1秒恢复；护甲碎裂死亡 |
| 帧率、帧数和循环 | 正式dt连续计算；位移驱动步相，不依赖独立计时器 |
| 源视频与连续片段 | 不适用：程序化怪物，猫视频不修改 |
| 统一裁切和缩放 | 原生尺寸不整体缩放、拉伸代替步行 |
| 起停与状态衔接 | 停步保留步相，暂停冻结；低动态保留攻击姿态与预警，关闭大幅运动 |
| 局部真实动作 | 左右靴独立抬落，肩肘与盾按攻击阶段变化 |
| 独立部件 | 肩甲与盾独立局部变换，身体不挤压变形 |

## 5 制作要求
森林绿轮廓、金属灰绿甲片、奶油铆钉与木色内衬。粗靴、肩肘、盾分别活动；受击闪亮和护甲裂纹沿真实生命变化。禁止整体拉伸假步行，不新增地图占地。

## 7 玩法参数

- 同地区同阶级生命约4.5倍（波次公式分步取整可能相差1–2点），速度50%，质量3.2倍。通过高生命与质量表现耐打，不引入隐藏减伤。
- 近战伤害系数1.1；82距离进入0.95秒蓄力，0.42秒盾击、0.55秒回位、1.1秒恢复。只在盾击去程结算一次伤害，前摇锁点后可走位躲避。
- 第3波/野外当地3级起，每7个名额中的第3个以80%概率尝试替换普通陆地近战，存活上限3；不增加总波次怪物数，远程/飞行优先，脚本/秘境/Boss援军不混入。
- 继承现有击杀、材料及波次奖励流程；重装物种的基础奖励系数1.5，清缴奖励继续服从现有整波预算。
