# 统一物品背包与弹药车库任务单

依据：[美术标准](../art-generation-standard.md)、[项目约定](../../AGENTS.md)。

## 1 目标与范围
本轮为功能与程序绘制阶段。背包展示真实持有物品，取消空格占位，分类、数量、图标和重量可读；弹药铺增加宽门车库，停车完成直接进屋。保留角色连续帧、武器独立绘制、手机来信与通讯功能。参考 src/rendering/garage.js、farm.js、farm-tools.js、src/ui/keepsake-icons.js。不新增位图，复用既有正式绘制器，补给图标使用同系列 SVG。

## 2 造型与空间
背包采用森林绿描边、奶油底板，三列实际库存，分类标题与顶部负重。弹药铺沿用宽门、双侧墙、屋顶结构；以弹药招牌和炮弹标识区别其他车库。底座为原点，门洞与车位同轴，车头朝下；车库两侧与背墙不可穿透，正面进出通道开放。地坪、阴影、建筑、车辆继续正式深度排序，沿用世界昼夜光照。

## 3 技术交付
建筑宽 212、侧墙高 114 世界单位；门洞半宽 62、车位 y=-42。背包图标 48 CSS 像素，武器/农具使用 96 像素画布；其他图标 SVG 64 视框或既有农作物图集。无需新增贴图内存或生成资源。稳定物品 ID 对应分类/描述/用途/千克质量，交互、数量和状态独立于图标。菜单复用手机底板和至少 44px 点击区域。

## 4 动态与保留项
复用 P 停车、停车后入屋、离屋和车头一秒上车。背包点击打开详情，使用道具后刷新实际库存和负重；滚动、关闭和暂停归属沿用统一弹窗。武器射击、车辆四轮及炮塔动画不修改。

## 5 生成指令
本轮无需 imagegen：已有正式车库、武器、农具和作物足够复用。新增弹药、医疗、维修包图标在 src/ui/inventory-icons.js 按现有描边和平涂实现。PNG 精修为后续阶段。
