# 工坊任务导航接入验收

依据： [美术资源生成标准](../art-generation-standard.md)。本任务复用已有导航绘制器，不生成或替换位图。

## 1 目标与范围

- 标识：workshop-task-navigation；类别：任务交互与导航特效接入。
- 目标：入职修复、制枪能够沿光点到达真实工坊门口；点击后续主线任务立即导航。
- 数量、结构差异：复用一套光点、终点光圈和悬浮箭头，不新增造型变体。
- 保留：建筑、人物、镜头比例、装备数值、资源奖励与实际建筑提交流程。
- 路线及参考：复用 src/rendering/navigation-markers.js、story-guidance.js 的正式效果；入职卡保持现有奶油底色与森林绿文字。
- 使用场景：营地和返回工坊途中。

## 2 造型与空间

- 剪影与主次：原光点路径及箭头；目标位置仍在武器工坊门口，不为提示移动建筑。
- 地面衔接与邻接：路径绕开正式碰撞；光圈贴地，建筑、人物继续按脚底遮挡。
- 活动空间：不增碰撞、不扩大门口实体、不接管角色移动。
- 光向明暗：沿用正式昼夜，无新灯光和全屏遮罩。

## 3 技术交付

- 逻辑尺寸、像素倍率：沿用 NAVIGATION_STYLE；入职任务卡最大宽250 CSS像素，点击区域至少44像素高。
- 锚点：武器工坊 x=480、y=675，与施工判断使用的门前坐标相同。
- 分层透明：光点、光圈位于人物下方，终点箭头在提示层；透明运行时绘制，无不透明地板。
- 碰撞通行：复用正式路线缓存与树木、围栏碰撞；纯导航不修改物理。
- 昼夜：复用原导航高对比描边。
- 文件：核心导航与 UI 代码；验收产物 output/playwright/workshop-navigation/。
- 预算：无新图集、无额外全屏画布；复用原每段最多24个光点及路线会话。

## 4 动画任务补充

不适用新动作、视频、帧率、裁切和独立部件制作；角色连续帧、枪械及载具动画未修改。光点使用原时钟、原减少动态规则。

## 5 生成指令

不调用图片或视频生成。只接入已有正式导航效果；保持已有任务卡样式，将可导航目标作为原生按钮，资源不足及施工阶段不错误引导回工坊。

## 6 验收记录

检查范围：320/390/桌面昼夜路线、卡片点击、抵达建筑、修复制枪阶段切换、资源不足与后续主线按需导航。

正式绘制器入口：src/rendering/story-guidance.js 的 drawStoryGuidance / drawStoryDestination。
对应案例：tests/workshop-navigation-browser.cjs，workshop-task-navigation。
结论：通过，结果见下方记录。

- 动作及独立部件：未修改角色、武器和载具绘制器；实机步行、停止、持电锯保留正式动作。新动画生产不适用。
