# 成群清缴与新装备实战任务单

依据：[美术标准](../art-generation-standard.md)、[AGENTS](../../AGENTS.md)。本轮为玩法动态与同屏验收，不生产或替换美术资源。

## 1 目标与范围

| 字段 | 本轮内容 |
| --- | --- |
| 资源名称与稳定标识 | 既有团怪、特殊怪、散弹、激光、松果战车；身份与图集不变 |
| 类别和用途 | 战斗场景密度、枪械群攻、清缴续战和任务引导 |
| 当前阶段 | 动态玩法开发与正式绘制器复核 |
| 目标 | 同方向小队让散弹、穿透与车炮能连续清群；买枪后立即使用 |
| 动态交互 | 真实刷怪、移动、自动射击、暂停、结算与原地续战 |
| 数量与变体 | 首轮6/10/14/18/24；以后每轮每批加4、封顶64；同场最多24 |
| 保留项 | 原版击退、独立操枪、团怪翻滚、飞行与重装动作、车体和主炮、领主技能 |
| 制作路线 | 修改现有逻辑和数值；没有绘图或资产生成，因此不调用imagegen |
| 参考 | 现有正式战场及docs/art-reference/clearing-continuous-waves |
| 确认目标 | 成群可辨、移动空间充足、昼夜看清角色与预警 |
| 后续精修 | 不适用：本轮不新增或替换静态图案 |
| 场景 | 常驻森林清缴；野外遭遇、剧情、秘境保留各自规则 |

## 2 造型与空间

沿用全部既有剪影、比例、锚点、光向、地面衔接和深度排序。团怪是数量主体，特殊怪每八个名额至多一个。每组沿60度扇区接近，沿用180–300世界单位的安全距离、地形路径、树干和单位间距校验；无合法点不消耗名额，下一节拍换方向重试。地图、道路、水界和营地不改。

## 3 技术交付

逻辑尺寸、像素尺寸、脚底锚点、透明背景与分层均沿用原资产，无新增PNG/SVG、解码像素或图集缓存。玩法逻辑负责数值、进度、刷怪和导航，动画继续使用正式时钟和绘制器。现场实体上限保持24，尸体、弹丸、特效仍受既有预算限制；需实机检查密度与帧耗时。素材缺失仍明确失败，不添加替代画面。

入口：src/config/waves.js、src/config/clearing-difficulty.js、src/core/wave-manager.js、src/core/enemy-manager.js、src/core/enemy-arrival.js、src/ui/clearing.js、src/ui/task-reward.js。

## 4 动画

不新增或修改动画。保留assets/cat-front真实连续帧、独立小手与枪械、怪物死亡翻滚、载具轮履/炮塔动作。实际移动、攻击、停步和暂停在同一运行场景复核，不能用静止摆拍代替自然战斗。

## 5 生成指令

不适用：没有生成或修改美术素材，全部复用正式资产。程序变更仅调整怪群调度、普通怪属性、任务目标和结算交互。

## 6 验收记录

本轮结论：通过本次范围的桌面 Chrome 手机视口验收。未进行真实手机硬件性能测试，不据此声明达到 60 FPS。完整数据、命令、历史失败及修复记录见[验证报告](../verification/horde-feel/README.md)。

| 动作真实性 | 保留现有连续帧、独立枪械和车炮，移动、受击、射击、装填、死亡均由正式循环执行；未使用静态摆拍代替战斗。录像见验证目录 |

正式入口：`src/rendering/renderer.js`、原角色/怪物/载具绘制器，`src/ui/clearing.js`、`src/ui/task-reward.js` 与手机统一底板。
