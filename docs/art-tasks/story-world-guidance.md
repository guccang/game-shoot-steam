# 第一章场景引导与头顶气泡任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)。由标准任务单复制，制作前填写如下。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 中文名称与标识 | 章节场景引导 / story-world-guidance |
| 类别和用途 | 地面战斗边界、目标光圈、角色头顶剧情气泡 |
| 目标 | 看见不能越过的野猪战边界；看见当前目标落点；在角色头顶自动阅读剧情 |
| 数量和变体 | 一个战斗边界、一个当前目标光圈、一个当前发言气泡；轮廓与位置承担不同语义 |
| 保留项 | 原HTML/Canvas、碰撞半径、地形、所有真实角色/载具动画及独立枪械、剧情与奖励逻辑 |
| 制作路线 | 正式Canvas地面绘制、DOM气泡；雪团复用已有布偶猫真实图集，薄荷复用现有银渐层 |
| 参考 | docs/art-reference/story-navigation/guard-390-day.png；src/rendering/story-props.js；现有奶油黄绿描边UI |
| 使用场景 | 第一章剧情、探索、守点及野猪战 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 边界为大范围金色实线环；目标为小型青绿与奶油双层发光椭圆；气泡圆角矩形与指向说话者的尾巴 |
| 结构差异 | 边界与目标靠大小、实圆/扁椭圆、金色/青绿区分，不混淆射程虚线圈 |
| 主次关系 | 任务提示低于攻击预警；气泡只在安全剧情阶段出现，战斗冻结 |
| 地面衔接 | 地面光环在实体、角色和技能之前绘制，不新增实体地板 |
| 活动空间 | 保留现有半径280的碰撞范围，不改地形或通路；边界直接读取player.arena |
| 邻接组合 | 营地雪团、薄荷、中继站、路标、野猪战场；对话镜头跟随当前说话者 |
| 光照 | 双层轮廓确保昼夜可见，无全屏罩色；气泡保持奶油底与森林绿文字 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸 | 边界半径直接取实际arena；目标半径48×25世界单位；气泡最大260CSS像素，320屏幕内留12像素边距 |
| 倍率 | 光环经正式世界zoom和DPR绘制；气泡为DOM文字，不随zoom缩小 |
| 锚点 | 光圈世界目标坐标；气泡尾巴对准真实说话者头部，沿最近世界镜像投影 |
| 分层 | 地面边界/目标在实体和预警之前；气泡在场景上方，避开HUD |
| 透明 | 环外与气泡外透明，禁止整场景半透明遮罩 |
| 碰撞 | 无新增碰撞；NPC沿用无碰撞摆件；边界显示与真实限制共用数据 |
| 昼夜 | 同轮廓，亮芯和深色外描边保持可读 |
| 文件 | src/rendering/story-guidance.js、src/ui/story-speech.js及现有章节/渲染接入；output/playwright/story-guidance工作截图，docs/art-reference/story-guidance长期基准 |
| 预算 | 一个气泡DOM，光圈与气泡不新增位图或离屏画布；NPC沿用原40帧展示缓存上限，两个角色按品种和帧索引共用有界缓存 |

## 4 动画任务补充

只新增小范围光环呼吸，减少动态时固定形态；边界本体稳定，避免闪烁误导碰撞位置。NPC沿用真实连续图集与暂停姿态，不制作新视频；角色动作与独立小手不改。剧情在安全暂停中自动按阅读时长推进，可暂停或跳过；后台、其他弹窗和手动暂停不得消耗阅读时间。

## 5 生成指令

延续森林绘本平涂与绿描边。程序化绘制金色大边界与青绿目标光圈；将剧情挂在实际发言角色头顶，复用真实雪团/薄荷身体，不制作替代静帧。边界不得压扁导致视觉与碰撞不一致；目标装饰可呈地面椭圆。
