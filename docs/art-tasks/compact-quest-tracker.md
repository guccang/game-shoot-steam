# 森林巡游美术生成任务单：两行任务提示

依据：[美术生成标准](../art-generation-standard.md)，按[任务单](../art-generation-brief.md)填写。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 两行任务提示 / compact-quest-tracker |
| 类别和用途 | 现有 DOM HUD 排版，不新增 UI 插画 |
| 本轮目标 | 第一行任务名与括号计数；第二行发现提醒；左侧放大导航跨两行 |
| 数量和变体 | 单个任务栏；有发现提醒时优先显示，无提醒时沿用目标说明；无导航时让出左列 |
| 保留项 | 任务数值、方向计算、距离、领主栏、全部战斗和角色动作 |
| 制作路线 | 现有 HTML/CSS 与正式 HUD 更新 |
| 参考与同类资产 | 用户附件 effb18a9；src/styles/story.css 的森林绿面板及奶油罗盘 |
| 使用场景 | 世界章节任务提示 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 左侧圆形导航，右侧上下两行文字 |
| 与其他变体的区别 | 从分散三层改为两行；计数并入标题行，提醒不再跨过导航底部 |
| 主次关系 | 任务名与计数为主，发现提醒为次，距离保留在圆盘下缘 |
| 地面衔接 | 不适用：屏幕 DOM，无世界地面形体 |
| 活动空间 | 减少 HUD 遮挡，继续透传战场移动输入 |
| 邻接组合 | 资源栏下方；沿用现有领主栏导航布局 |
| 光向与明暗 | 原森林绿底板、奶油文字，昼夜同用清晰对比 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 任务栏宽不超过 340px 与视口减 28px，左右内边距 10px，上下 8px；导航 52px 跨两行 |
| 像素尺寸与倍率 | CSS 逻辑像素，SVG 沿用矢量，无位图倍率 |
| 锚点与原点 | 沿用 HUD 左上角位置 |
| 分层 | DOM 界面层；无场景层修改 |
| 透明背景 | 沿用半透明绿底；距离贴片与面板同色 |
| 碰撞与可通行性 | 无实体或碰撞，pointer-events:none |
| 昼夜处理 | 原 UI 固定配色，正式昼夜场景同屏验收 |
| 文件格式与位置 | src/styles/story.css、src/ui/story.js；证据 output/playwright/compact-quest-tracker/ |
| 内存与缓存预算 | 不新增图片、图集或缓存；复用现有 DOM |

## 4 动画任务补充

不适用：静态布局调整。导航沿用真实目标旋转、到点圆心与暂停隐藏，保留角色、枪械和载具独立动作及原缩放。

## 5 生成指令

沿用正式 HUD 森林绿与奶油黄。两行布局固定，标题与计数同排，发现提醒占右侧第二行。长文本不推挤计数或增加第三行，完整内容保留原文本和提示。无发现时显示目标说明。领主栏不放大导航；不生成资源。
