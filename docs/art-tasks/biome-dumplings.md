# 森林巡游美术生成任务单

执行依据为[游戏美术资源生成标准](../art-generation-standard.md)与 [AGENTS.md](../../AGENTS.md)。

默认按 **imagegen + 程序绘制 + SVG 实现动态效果与交互 → 实机确认 → imagegen精修 → PNG替换与复核** 推进。本任务单分阶段填写，开发阶段不要求最终PNG齐备；后续精修项明确标注“后续阶段”，不得以空白模板或生成预览代替当前阶段验收。用户明确要求本次直接生成或替换PNG时，记录该范围并验证已有动态逻辑。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |

| 类别和用途 | 怪物：森林自由遭遇与地貌清缴 |
| 当前阶段与本轮范围 | 动态效果开发；本轮交付程序化正式造型、攻击与区域分布 |
| 本轮目标 | 雪山、火山、湖泊、雨林、岩台、裂谷出现可辨认的本地团子 |
| 动态效果与交互目标 | 位移驱动软体步态、受击、死亡、锁点蓄力、释放及恢复；水团不离开真实湖水 |
| 数量和变体 | 15种；雪帽/冰角/叠雪、火山口/灰烬冠/曜石甲、莲叶/泡泡/旋涡、蕨叶/兰花/藤鞭、页岩/砂铃、裂晶 |
| 保留项 | 保留猫真实帧、武器和载具独立部件、原怪物家族及剧情编成 |
| 制作路线 | 扩展现有 Canvas 2D 团子正式绘制器；本轮不生成位图，PNG精修为后续阶段 |

| 后续精修项 | 后续专门美术阶段可精修静态部件PNG；动态软体与预警继续由程序驱动 |
| 使用场景 | 森林真实地貌外围、湖中；普通森林仍保留原团子 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 统一软团身体，冠饰改变外轮廓；详情见配置 shape |
| 与其他变体的区别 | 每种具有不同宽高和独立冠饰或侧部：非单纯换色 |
| 主次关系 | 团子为战斗主体；冠饰有限平涂，不新增场景装饰 |
| 地面衔接 | 地面投影沿用；水团有低对比水纹和侧鳍 |
| 活动空间 | 不新增障碍；沿用地形通路与聚落保护 |
| 邻接组合 | 地貌由 NATURAL_TERRAIN.earth 决定；湖水由 isLakeWater 决定 |
| 光向与明暗 | 左上亮部与森林绿描边；不新增全屏或常驻光源 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 身体宽36–58、高27–43世界单位；冠饰最高另加30 |
| 像素尺寸或SVG视框与倍率 | Canvas原世界坐标绘制，无新增图集；PNG后续阶段 |
| 锚点与原点 | 世界(x,y)为脚底；冠饰依附软体顶点 |
| 分层 | 地面投影/水纹 → 软体 → 冠饰侧鳍 → 独立预警与弹丸 |
| 程序与图片职责 | 状态、数值、动画时钟由程序；静态冠饰将来可拆图替换 |
| 替换接口与保留项 | dumplingVariant 稳定ID、原species=slime、脚底、半径与奖励保持兼容 |
| 透明背景 | 需要透明合成；只画局部接触影与水纹 |
| 碰撞与可通行性 | 原团子圆形碰撞；aquatic只允许整个脚底留在湖内，玩家通行规则不变 |
| 昼夜处理 | 共用正式场景光照和夜间视野，不创建昼夜贴图副本 |
| 文件格式与位置 | src/config/biome-dumplings.js、src/world/dumpling-habitats.js、src/combat/biome-dumplings.js、src/rendering/biome-dumplings.js |
| 内存与缓存预算 | 新增位图0字节；无派生画布；共享全场6颗弹丸、首领1颗的预算 |
| 必需资源与失败行为 | 必须加载上述ES模块；缺失由模块加载明确报错；未知绘制ID明确抛错 |

## 4 动画任务补充

静态资产说明动画不适用原因。程序或SVG动画填写实际时钟、局部动作和录制路径，不虚构视频来源或序列帧；使用视频和序列帧时填写来源字段。猫身体继续使用真实连续帧，当前仅生成正面待机和移动，不增加多方向身体序列，也不以单张imagegen图片变形代替身体动作。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | idle连续局部呼吸、move原位移步态、hit原0.6秒回弹、death原爆裂；施法时长见配置 |
| 时钟、帧率与循环 | 使用实际游戏dt推进ecoClock与gelStep；暂停冻结，不修改世界随机流 |
| 动作源码或源视频与连续片段 | 程序动作入口 drawBiomeDumpling/advanceDumplingMotion；非视频资产，无虚构源片 |
| 尺寸、裁切和缩放 | 固定脚底与配置宽高，冠饰随软体局部锚点运动 |
| 起停与状态衔接 | 步态停止保留相位，低动态关闭冠饰摆动；击退中断施法 |
| 局部真实动作 | 波峰、冠饰、藤蔓与鳍叶错相变化；不使用静帧整体变形模拟肢体 |
| 独立部件 | 冠饰、侧鳍、软体、预警、弹丸各自绘制；原武器系统不改 |

## 5 生成指令

本轮未使用imagegen：延伸正式Canvas软体与局部结构，先验证动态及交互。精修PNG为后续阶段，不计入本轮交付。
