# 森林巡游美术生成任务单

执行依据为[游戏美术资源生成标准](../art-generation-standard.md)与 [AGENTS.md](../../AGENTS.md)。

默认按 **imagegen + 程序绘制 + SVG 实现动态效果与交互 → 实机确认 → imagegen精修 → PNG替换与复核** 推进。本任务单分阶段填写，开发阶段不要求最终PNG齐备；后续精修项明确标注“后续阶段”，不得以空白模板或生成预览代替当前阶段验收。用户明确要求本次直接生成或替换PNG时，记录该范围并验证已有动态逻辑。

## 4 动画任务补充

静态资产说明动画不适用原因。程序或SVG动画填写实际时钟、局部动作和录制路径，不虚构视频来源或序列帧；使用视频和序列帧时填写来源字段。猫身体继续使用真实连续帧，当前仅生成正面待机和移动，不增加多方向身体序列，也不以单张imagegen图片变形代替身体动作。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | idle连续局部呼吸、move原位移步态、hit原0.6秒回弹、death原爆裂；施法时长见配置 |
| 时钟、帧率与循环 | 使用实际游戏dt推进ecoClock与gelStep；暂停冻结，不修改世界随机流 |
| 动作源码或源视频与连续片段 | 程序动作入口 drawBiomeDumpling/advanceDumplingMotion；非视频资产，无虚构源片 |
| 尺寸、裁切和缩放 | 固定脚底与配置宽高，冠饰随软体局部锚点运动 |
| 起停与状态衔接 | 步态停止保留相位，低动态关闭冠饰摆动；击退中断施法 |
| 局部真实动作 | 波峰、冠饰、藤蔓与鳍叶错相变化；不使用静帧整体变形模拟肢体 |
| 独立部件 | 冠饰、侧鳍、软体、预警、弹丸各自绘制；原武器系统不改 |

## 8 PNG精修阶段制作计划（2026-11-10）

本轮按用户要求使用内置imagegen逐种生成15套透明PNG部件图。现有十五种宽高、冠饰、侧部区别、稳定ID、世界脚底、攻击方式与参数全部保留。每套图分为无脸软体、顶部冠饰、左侧件、右侧件，程序继续绘制表情、水纹、攻击预警和弹丸；身体以局部条带网格变形保留错相边缘，冠饰与侧件独立锚定，不将完整角色静帧缩放代替动作。

参考：本任务既有目录及实机昼夜截图。配色沿用各变体配置，森林绿/灰绿描边、奶油高光、有限平涂、左上受光。先用雪帽团子校准，再按同套结构精修其余14种。运行图计划每种512×512透明部件图集（原始生成图保留source），单种解码1MiB，15种总预算15MiB；无昼夜副本。必需PNG或清单缺失直接报错，不静默回退程序原型。

输出：assets/biome-dumplings/manifest.json及15张PNG；提示词、原图、来源记录保存assets/biome-dumplings/source/并从运行包排除。正式接入src/rendering/biome-dumplings.js；保留原状态机、出生、碰撞和软体时钟。本阶段完成后补记alpha/裁切/预算、连续动作、手机320/390和既有竖版桌面昼夜验收；当前尚未通过。

## 9 PNG精修阶段验收（2026-11-10）

结论：通过，替代第8节的待验收状态；第7节为上一阶段的历史记录。本轮使用内置imagegen逐种完成15次生成，没有使用CLI；原图与各自完整提示词保存于assets/biome-dumplings/source/。统一森林绿描边、奶油高光、柔和地貌配色，保留原宽高和冠饰差异。身体、冠饰、侧件分别绘制，表情、水纹及攻击效果保留程序动态。

- 透明与裁切：15张512×512 RGBA运行图均通过真实浏览器像素检查，完全透明像素占比43.6%至82.8%，分区中心线透明，部件四周留白。近不透明像素以alpha≥240统计，允许原画柔和透明材质，不强制主体全为255。没有烘焙底板、棋盘格或投影背景。
- 资源：运行PNG合计2,056,506字节，解码15MiB；不新增昼夜副本、逐帧缓存或网络服务依赖。原图、请求从运行包排除，manifest只引用处理后的15张图。构建脚本只做透明裁切、等比缩小及分区打包。
- 正式绘制：src/rendering/biome-dumpling-png.js#drawBiomeDumplingPng，复用原pose、游戏时钟和攻击状态机。目标空间裁条修复了初版分数源裁切的横缝；水团侧鳍按身体底部锚定，黑曜中央晶体缩回原冠饰范围。
- 连续动作：15种各4相位实际像素均不同，减少动态模式每种4帧一致；独立冠饰、藤鞭局部曲率和水团浮动保留。正式黑曜追赶、冲刺、返回、受击与死亡回收通过，猫、独立武器、气垫船与怪物昼夜同屏检查通过。
- 世界与交互：6地貌×320/390/1280宽×昼夜共36张截图，无横向溢出，无pageerror；真实触控模拟移动约104世界单位。夜间水团在灯光下可辨，保留树冠遮挡、湖界、道路和既有手机竖版布局。此为浏览器尺寸/触控模拟，不宣称实体手机硬件测试。
- 验证：9项专项单测通过（原战斗7项、PNG资源2项），三份浏览器专项通过；阻断snowcap.png时首页明确显示启动失败，无旧程序怪物兜底。未运行全量npm test。
