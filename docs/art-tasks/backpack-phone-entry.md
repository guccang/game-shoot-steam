# 背包格子与手机入口

由美术任务单复制并按本轮 UI 范围填写。依据：[美术标准](../art-generation-standard.md)、[手机 UI 框架](../ui-foundation.md)。

## 1 目标与范围

背包仅展示三列物品格，点击信、钥匙弹出详情，点击手机打开独立手机页。主菜单第一项为手机，删除独立地图按钮；任务和旅行从手机进入地图。保留既有图案、物品 ID、存档、电话、导航、地图缓存和正式游戏绘制器。

## 2 造型与空间

沿用森林绿、奶油纸、浅草色与原 64×64 SVG。信封、钥匙、手机剪影不变；方格内上图下文，空格仅作收纳空间，不产生可点击按钮。手机地图为首个应用，通讯录位于其下。弹窗标题、滚动正文、底部操作使用统一底板；不修改角色、碰撞、通行或世界锚点。

## 3 技术交付

手机各尺寸共用三列格子，触控不小于 44px；最大页宽 480px，正文独立滚动。背包、物品详情、手机、地图使用原 dialogs 管理暂停与层级，返回逐层恢复。正式入口为 src/ui/keepsake-backpack.js、src/styles/keepsake-backpack.css、src/ui/panels/map.js、src/ui/mainline.js。只在打开或操作时更新 DOM，不新增帧循环、纹理、图片或画布。资源缺失沿用现有明确失败，不使用替代图片。

## 4 动画

不新增动画，保留世界与角色原动作；本轮验收关注弹窗切换、触摸、暂停、任务进度和导航。无视频、图集、脚底或操枪修改。

## 5 生成方式

复用既有 SVG 与统一 CSS，未调用 imagegen；本次改变页面结构和操作入口，无新增插画或 PNG 精修范围。

## 6 验收

正式浏览器使用独立手机存储、触屏事件和原应用主循环。4175 已有预览服务，本工作树在 4186 验证，测试脚本默认地址仍为 4175。

## 手机载具与邻居头像补充

目标是在定位和拨号前认出对象。每行左侧使用 40×40 逻辑像素、80×80 透明画布；按车体编号和居民身份绘制正式车形、猫及林中伙伴，保留按钮、世界比例、通行与动作。仅打开页面时绘制，无新纹理。验收关注昼夜、窄屏换行、操作区和勾选反馈。

正式入口为 `createKeepsakeBackpack`、`drawVehicleIcon`、`drawPhoneResidentPortrait`，对应 `designCriterion: keepsake-backpack`。三辆车与六位居民的实机头像均有有效像素。390 宽昼夜、320 宽短屏和既有桌面竖版容器检查通过，无横向溢出；勾选保存、拨号、挂断和载具定位已通过触控检查。复核图见 `output/playwright/phone-portraits/neighbors-390-day.png`、`neighbors-390-night.png`、`contacts-320-night.png` 与同目录设定截图。每个头像最多使用约 25 KiB 像素缓冲，随通讯录释放。本轮静态 UI 验收通过，世界遮挡、通行、动作与 PNG 替换不涉及。
