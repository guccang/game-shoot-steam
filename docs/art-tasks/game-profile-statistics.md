# 游戏档案累计统计任务单

依据：[美术生成任务单](../art-generation-brief.md)、[美术标准](../art-generation-standard.md)。

## 1 目标与范围

| 字段 | 规格 |
| --- | --- |
| 名称与稳定标识 | 游戏档案累计统计 / game-profile-statistics |
| 类别和用途 | 设置二级 DOM 页面；显示击败怪物、伐木、累计收入与各玩法参与次数 |
| 目标 | 分组清楚、短标签配大数字；旧档不伪造历史、零值明确展示 |
| 数量和变体 | 战斗采集两卡、五种资源行、十种玩法行；大数字整数缩写，悬浮与无障碍提供完整数量 |
| 保留项 | 原有设置返回、暂停恢复、时长与天气数据；角色、怪物、载具、地图绘制全部保留 |
| 制作路线及参考 | HTML/CSS；沿用 chronicle-cards、resource-icons.js 与奶油底色，不生成位图 |
| 使用场景 | 设置 → 游戏档案，桌面与手机 |

## 2 造型与空间

| 字段 | 规格 |
| --- | --- |
| 主体剪影及结构差异 | 顶部双卡、下方紧凑资源行和玩法行，天气移入可展开区，减少无关滚动 |
| 主次关系 | 累计数据优先、统计口径置于问号式说明；旧历史提示一行 |

| 光向与明暗 | 奶油色背景、深森林绿文字、淡草绿卡片；沿用既有弹窗昼夜遮罩 |

## 4 动画任务补充

静态信息页；动作时长、帧率、源视频、裁切、起停、局部动作和独立操枪均不适用。保留既有战场动作和弹窗暂停行为。

## 5 制作指令

沿用森林绘本 UI、现有中文字体和资源 SVG。短标题与两列布局呈现数量，小屏允许标签换行而不挤压数字。天气记录放入折叠区域，不引入新插画、动画、字体或全屏复杂仪表盘。

## 6 验收记录

### 装备明细扩展规格（2026-10-25）

本次在战斗采集总数下面增加武器／载具切换和三列表格（装备、杀怪、伐木），沿用奶油底与森林绿文字。显示已拥有或有历史战绩的装备，零值明确显示；未拥有且无记录的不占据页面。名称允许换行，数量保持整数缩写，320/390 手机不横向滚动。统计说明移入既有问号区，旧装备历史无法追溯时明确说明从更新后累计。

归属以致命攻击的发射快照为准，召唤物归所属核心；车载攻击同时记入武器及对应车型，两者是不同维度，不能相加作为总击杀。搭乘电动车的手持攻击计入该车型。工坊试射、调试与无装备来源的友军攻击不计装备战绩。固定 ID 保存，不改伤害、熟练度、奖励或旧总数。

技术规格：既有 DOM 流内增加区块，无新的场景层、锚点、碰撞、动画、图片、字体或 Canvas；表格上限为正式装备目录数量，按打开页面更新，不新增逐帧 UI 或缓存。设计目标沿用 `game-profile-statistics`，完成后补充专项测试及正式截图结果。

#### 装备明细扩展验收

- 结论：通过。正式入口仍为 `createChroniclePanel`，复核函数 `inspectGameStatistics` 新增当前装备类别、行数及内部滚动区溢出检查。固定标题及关闭区已消除长列表滚动时对页签和数字的遮挡；切换使用即时高亮，避免过渡中颜色对比不足。
- 实际浏览器操作：真实手枪弹道击杀与伐木后重新打开立即显示各 1；武器／载具点击与键盘切换、零值、大数 `1Y/11w`、关闭返回设置、保存刷新、旧档历史提示均通过。3 种视口 × 昼夜 × 两页签共 12 组明细检查无溢出、无浏览器异常。全装备视觉夹具展示 23 把武器及 7 种载具，不冒充实际成长数据。
- 截图：`output/playwright/equipment-statistics/{weapons,vehicles,field}-{1280,390,320}-{day,night}.png`，共 18 张；实测结果保留在同目录 `result.txt`。已复核桌面武器页、320 载具页、390 夜间战场与桌面白天战场；角色、怪物、载具、植被和 HUD 仍使用正式绘制器，比例与通路不变。
- 专项规则：`tests/equipment-statistics.test.mjs` 新增 10 项全部通过；连同既有档案、弹道、潮汐炮及新引力枪／红狼范围炮击相关检查共 36 项通过。另有 `tests/combat.test.mjs` 的旧单怪金币预期失败（实际 88、预期 81），已在未修改主分支复现，不改动现有奖励规则。
- 资源与缓存：无新增图片、字体、音频、Canvas 或缓存；运行时仅给攻击快照增加装备及车型稳定 ID，随弹丸或实体回收。当前正式目录共 30 行，可切换为单个表格；存档校验每类最多 128 条，防止损坏数据无限扩展。无新增动画，录制与动作资源检查不适用；本次不改变伤害、弹药、冷却、熟练度或碰撞计算。

验收日期：2026-10-25。结论：通过本次累计统计功能及界面验收。
