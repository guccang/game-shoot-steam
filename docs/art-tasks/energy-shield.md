# 能量防护盾美术与交互任务单

执行依据：[美术标准](../art-generation-standard.md)、[AGENTS](../../AGENTS.md)。本轮为动态效果开发，使用既有 Canvas/SVG；没有生成或替换 PNG。

## 1 目标与范围

| 字段 | 本轮设计 |
| --- | --- |
| 名称、稳定标识 | 能量防护盾 / energy-shield，手持目录追加编号18 |
| 类别、用途、场景 | 防御装备及战斗反馈；森林、高塔、守护、工坊 |
| 本轮目标 | 玩家能看出屏障覆盖角色或所驾驶载具，读到剩余容量与充能等待 |
| 动态交互 | 自动格挡、受击短亮、破盾消失、逐点恢复、随移动、暂停冻结 |
| 数量与差异 | 一种发生器；步行61×68半径、驾驶102×84半径屏障；与枪口/炮弹区分 |
| 保留项 | 猫身体连续帧、载具主炮/履带/旋翼、原碰撞、手机仪表和存档稳定编号 |
| 制作路线与参考 | 程序 Canvas 屏障与盾形发生器 + SVG 盾形仪表；参考现有控制器和森林昼夜场景 |
| 已确认效果目标 | 半透明薄荷屏障、奶油色容量弧线；中心留空，人物与载具保持可辨 |
| 后续精修 | 发生器可在专门美术轮次替换透明 PNG；动态屏障与数值保留程序实现 |

## 2 造型与空间

| 字段 | 本轮设计 |
| --- | --- |
| 剪影与结构 | 盾形外壳、中央能源核、独立侧把手；没有枪管、枪口和射击后坐 |
| 主次与邻接 | 角色/载具为主体，屏障边缘和三枚稀疏六边形为次要反馈 |
| 地面与活动空间 | 使用角色插值世界位置；纯效果，不新增地面实体、碰撞或挡路区域 |
| 光向明暗 | 森林绿描边、薄荷平涂与奶油亮部；共用昼夜场景染色，受击0.22秒短亮 |

## 3 技术交付

| 字段 | 实现 |
| --- | --- |
| 尺寸与原点 | 发生器约45×55逻辑单位，手持武器原点；屏障中心在角色脚底上方32或39单位 |
| 像素倍率 | 复用正式 Canvas 世界投影与 SVG 24×24视框，无独立位图 |
| 分层 | 发生器走角色独立手持绘制；屏障附着玩家实体深度，与场景树木保留前后遮挡 |
| 程序职责 | 护盾余量、受击亮度、恢复计时、升级属性与HUD；无烘焙文字 |
| 接口与保留 | id/index、武器槽、独立载具炮塔、切枪余量、升级部件、角色与车辆锚点 |
| 透明与碰撞 | 屏障低透明度平涂；世界碰撞未改变，保护只通过正式伤害入口 |
| 昼夜 | 同一形体跟随场景色调，盾环和容量弧线保持可读 |
| 正式入口 | src/rendering/energy-shield.js，由 renderer.js、characters.js 和 workshop.js 调用；HUD为 status-rings.js |
| 资源预算 | 每角色一枚椭圆、一段弧线、三枚小六边形；无离屏画布、纹理或派生缓存，无新增解码内存 |
| 必需资源 | 本轮只使用代码与既有角色/载具资源；不依赖外部生成图或静帧回退 |

## 4 动画补充

受击亮度使用武器供给槽 shieldFlash，0.22秒衰减；容量弧线直接读取正式护盾值。使用游戏更新步长，暂停和切枪不推进恢复。减少动态时不播放受击短亮。移动跟随正式插值位置，无独立屏幕坐标或计时器。猫身体、手持连接和载具主炮动作沿用原模块；没有新增生物动作或伪造视频帧。

## 5 生成记录

本轮没有调用 imagegen：屏障属于随数值变化的程序特效，发生器为代码原型。后续 PNG 精修仅涉及静态发生器外观，不替换格挡、容量、恢复、移动与暂停逻辑。

## 盾面立体效果与真实拦截（2026-10-30）

本节记录本次修订后的效果与验收；前文容量弧线、六边形及纯视觉碰撞说明保留为首次实现记录，以本节为当前实现依据。

- 目标：罩体由平面圆环改为前后分层球罩；近战、远程弹与领主羽刃命中盾面，按方向显示局部涟漪，完整格挡不闪烁猫猫身体。
- 几何：保留步行61×68、驾驶102×84半径及原中心偏移；绘制与碰撞读取 energyShieldShape。底部椭圆、曲面经纬线、左上窄高光、右下透明阴影形成厚度，保持中心透明。
- 分层与预算：后罩在车轮前绘制，前罩在猫和车壳后绘制；每次受击最多四处0.42秒涟漪，暂停冻结，减少动态时显示静态局部亮痕。渐变始终裁剪在椭圆内，无整页白色底板、位图、离屏画布或常驻缓存。
- 规则保留：护盾容量、恢复速度、受击保护间隔、破盾溢出、车辆火力不变。扩大的受击面只用于敌方攻击拦截，不阻挡玩家走位、道路或己方弹丸；树木与伙伴按首次碰撞排序。
- 稳定接口：energy-shield，手持编号18，原握持点；发生器增加侧面与斜切边，不变更身体动作或枪炮编号。本轮程序效果开发，PNG精修仍为后续阶段。
- 正式入口：src/combat/energy-shield-surface.js 与 src/rendering/energy-shield.js；designCriterion 为 energy-shield-surface。
- 逻辑验收通过：energy-shield-surface、energy-shield、enemy-attack、boss-skills 共34项通过，覆盖近战回收、树干先挡、弹丸与重炮截停、领主羽刃/冲锋、移动扫掠、跨地图接缝、破盾溢出及车辆火力。
- 直接相关 ranged-enemies 测试另有5项既有失败；在未修改的 master 上复跑同文件得到相同5项失败（预警世界镜像、分段解锁、树干扫掠、画外蓄力、秘境现场恢复）。本轮未扩展修复这些旧问题。基线记录 output/shield-surface-baseline.txt。
- 浏览器验收通过：tests/energy-shield-surface-browser.cjs 覆盖390×844白天驾驶、320×568夜晚步行、1100×800夜晚既有手机容器。真实敌弹抵达盾面时消失，护盾480→440，人物/载具HP不变，局部命中角度随移动保留，页面错误0、横向溢出0。采用浏览器设备模拟，未进行物理手机验证。
- 已人工查看上述昼夜同屏截图：罩体曲面和发生器厚边可辨，人物、载具与场景保留；局部亮痕位于盾面，渐变未溢出为白色方块。结论：通过。

## 连续承伤修正（2026-10-30）

- 按玩家反馈取消护盾格挡触发的共享无敌间隔。每次有效攻击独立扣盾并刷新充能等待；只有破盾溢出伤害进入角色或车体的原有受伤保护。
- 已有身体无敌也不能免除盾值消耗；此时破盾的溢出伤害仍遵守身体保护，格挡不会刷新身体无敌时间。完整格挡不再触发身体闪烁，盾面涟漪继续逐次播放并保留四处上限。
- 本节替代前文“受击保护间隔不变”的护盾规则。盾面几何、美术资源、恢复数值、攻击自身的一次命中判定不变。
- 针对性回归37项通过，涵盖同帧多弹、步行/驾驶连击、破盾溢出、已有无敌、充能等待及近战/领主一次攻击不重复结算。记录：output/shield-continuous-tests.txt。
- 复用本地服务进行浏览器验证：三种窗口尺寸的昼夜步行/驾驶场景均在三发同帧命中后从480扣至360，身体无敌计时为0，人物与车体HP不变，页面错误0。已复核昼夜截图，盾面反馈保留，完整格挡不触发身体受伤闪烁。记录：output/playwright/shield-impact-surface/continuous-result.txt。
