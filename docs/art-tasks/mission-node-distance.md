# 任务节点距离调整

依据：[美术生成标准](../art-generation-standard.md)。由美术生成任务单复制，按本次仅调整任务落点的范围填写。

## 1 目标与范围

- 标识：mission-node-distance；用途：故事任务地点编排。
- 目标：第一章、陆路章节、飞行章落地段、终章转发站及邻里委托长短交错，长途节点间距1000–2000米。
- 保留：地点ID、任务顺序、奖励、怪物数值、动作、操枪、世界尺寸及渡口上下岸教学点。
- 制作路线：调整现有配置坐标；不生成或替换图片。
- 参考：现有故事正式场景、docs/art-reference/landscape-six-day.png 和 landscape-six-night.png。

## 2 造型与空间

- 主体剪影、变体结构、材质光向：不适用，本次不改资产造型。
- 主次关系：任务目标与交谈人物沿用原配置偏移；背景仍由原场景绘制。
- 地面衔接及邻接：新落点避开山湖，依照原路径清树规则连接森林。
- 活动空间：普通战斗圈330、领主圈420，避开聚落保护区；正式通行和刷怪检查必须通过。

## 3 技术交付

- 世界尺寸3600×2800；距离使用循环世界最近镜像，与HUD一致。
- 像素尺寸、倍率、透明背景：不适用，不新增贴图。
- 锚点：沿用脚底/底座，以章节sites坐标定位，不改人物与道具偏移。
- 分层：沿用地面、实体、独立装备、特效和HUD原绘制层。
- 碰撞：沿用正式山湖、河流、围栏与树木；不修改通行能力。
- 昼夜：原运行时转换；无额外昼夜副本。
- 文件：src/config/story.js、story-campaign.js、monster-stories.js。
- 预算：新增运行图片和解码内存均为0；无新缓存。

## 4 动画任务补充

动作和时长、帧率、源视频、裁切、起停、局部动作及独立部件均不适用：本次只调整任务落点，继续使用原动画及正式操枪逻辑。

## 5 制作指令

以可通行地面为落点，编排1000–2000米的不同长短路段。保持故事阶段、路线分支、河道教学与所有资产身份。不得只改显示数字，不得通过删除碰撞或缩小战斗圈通过验收。

按用户实测反馈，将主要赶路路段下限从500米提高至1000米，上限保持2000米。基于现有可通行空地调整坐标，保留长短变化、近道短于主路、稳定地点ID、教学短途及原战斗半径。上文验收数字为v1历史记录，本轮结果如下。
