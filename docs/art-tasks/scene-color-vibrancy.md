# 场景鲜明色彩 · scene-color-vibrancy

## 1 目标与范围
调整正式 Canvas 材质与环境光，减少灰暗，维持森林绘本、奶油 UI 与独立猫猫动作。范围是营地草甸、树冠四季色阶、土路、四境怪物底色与夜色/天气合成，不新增资源。参考 landscape-six-day/night、scene-clarity-day 和本次同机位 before 截图。

## 2 造型与空间
不新增变体、不改任何剪影、尺寸、密度、道路、水界、锚点或碰撞。草地使用更明确的黄绿亮面和偏青绿阴面，土路暖沙色、树冠暗叶与亮顶拉开。夜晚保留冷光与暖灯，但减少蓝灰混色及叠加压暗。角色和战斗提示仍高于背景对比。

## 3 技术交付
程序化色值调整；现有逻辑单位、DPR、图集尺寸、透明边缘、地面/实体/特效分层全部沿用。禁止添加全屏 CSS filter、逐帧像素读回、额外常驻纹理、泛白或荧光罩层。向量夜色与缓存夜色使用同一矩阵。新增纹理内存为 0，缓存上限不变。

## 4 动画补充
不生成或剪辑动作，帧率、帧数、源视频、统一裁切沿用 assets/cat-front 清单；保留手、武器、后坐、炮塔、履带与旋翼独立。昼夜、天气和季节仍按现有时间连续过渡，无跳色。

## 5 制作约束
有限平涂、森林绿描边、左上受光右下冷影，暖木与冷水关系清晰。背景不能压过角色，雪地保留层次。纯调色无新增碰撞、位图透明背景、独立变体及源视频要求，相应生产项不适用。
