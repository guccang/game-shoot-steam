# 巡林手机浅色手绘纸页

## 1 任务与阶段

开发阶段UI美术调整。用户参考截图 codex-clipboard-15641290-52c6-4ef1-8e59-c684b2bf7139.png，要求去除沉重大块深绿，活泼手绘。当前范围为巡林手机，使用统一框架新增 ui-panel--sketch 表面变体。保留全部入口、事件、暂停归属、中文、资源图标与原尺寸逻辑。

## 2 造型与空间

杏黄标题、暖奶油正文、浅草绿主按钮；功能卡采用杏黄、浅绿、桃粉、淡蓝纸片色。深色仅用于文字及图标轮廓。轻描边、不完全对称圆角、两像素短阴影与虚线分隔表现手绘纸页；不倾斜正文、不增加运动或杂纹。

## 3 技术交付

src/styles/ui-foundation.css 定义统一表面变体及手机内容配色；src/ui/keepsake-backpack.js 给正式手机节点加类。原底板、标题、正文滚动和底栏结构不变；按钮至少44px、功能卡48px。没有独立PC布局。
没有新增位图或SVG；CSS原生形状不需要透明素材、图集锚点和解码预算，新增图片内存0。原图标、人物头像和状态环继续由正式绘制器控制。昼夜同用纸页，背景场景沿用环境色调，不增加素材失败回退。

## 4 动画任务

不适用：只修改静态表面配色，保留原按压、焦点和禁用状态，不修改角色或载具动画。

## 5 生成方式

未用imagegen。现有代码原生UI适合用CSS直接修改；没有PNG精修后续项。

本轮以用户提供的巡林手机截图为参考，推广到共用手机框架的功能页及设置。标题、分区、页签和固定操作栏复用纸页配色。地图、工坊拖拽舞台、底部对白、原生滚动和安全区继续由各页面控制。使用 CSS，无新增图像资源。验收目标沿用 uiFoundationCriterion。
