# 营地装饰场景摆放任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)、[AGENTS.md](../../AGENTS.md)。由美术生成任务单复制并按本轮程序交互范围填写。

## 1 目标与范围

- 名称及稳定标识：营地装饰场景摆放 / `camp-world-placement`。
- 类别、阶段：手机 UI 与装饰预览，动态效果开发；本轮不新增或替换位图。
- 目标：从我的装饰进入正式场景，点选或拖动位置，预览后确认；已摆放物品支持场景移动。
- 动态交互：触摸更新草稿；取消与 Escape 返回管理页；确认复用摆放事务，失败保留编辑；模态层隔离角色输入并传递暂停归属。
- 数量及变体：一个透明编辑层，复用全部既有装饰目录，不新造装饰变体。
- 保留项：原地图调整、购买回收、完整碰撞校验、存档结构、角色和武器及载具真实动作。
- 制作路线与参考：HTML/CSS/Canvas，复用 `src/rendering/camp-decor.js` 和手机 UI 框架；风格参照既有营地装饰和 `docs/art-reference/landscape-six-day.png`、`landscape-six-night.png`。
- 确认目标：真实比例预览、触控不带动角色、碰撞提示可读，手机按钮完整。
- 后续精修：无新增静态图案需要精修，本轮不声明 PNG 替换。
- 使用场景：地面营地当前可视区域；远处位置继续使用原地图调整，或先走近再打开。

## 2 造型与空间

- 剪影及差异：沿用既有装饰原型、尺寸和轮廓，无新变体，差异设计不适用。
- 主次关系：正式场景保留，单件草稿以 80% 透明度显示；绿/红虚线底框强调可放置/冲突，文字同时说明原因。
- 地面衔接和邻接：预览使用原底座坐标；确认后由正式场景脚底队列及灯具系统绘制。
- 活动空间：复用建筑、道路、停车位、其他装饰、田地、树木和角色避让规则，不更改碰撞几何。
- 光照：预览共用正式装饰画笔和昼夜参数；不改原场景照明。编辑草稿在透明层上，便于看到无效位置；正式实体仍按原遮挡排序。

## 3 技术交付

- 逻辑尺寸：装饰目录 width/depth/height 原值，十单位网格，原底座锚点；循环世界映射到营地最近镜像。
- 画布：与正式游戏画布 CSS 尺寸一致，DPR 上限 2，单张透明 Canvas。390×844、DPR 2 时像素缓冲约 5 MiB；退出不参与逐帧绘制，无新图片请求或缓存。
- 分层：正式世界 → 草稿与底框 → 统一手机底板。原装饰正式分层不变。
- 程序职责：点选、拖动、方向键微调、校验、文字、保存、暂停恢复；无静态图案烘焙。
- 接口：`createCampWorldPlacement`；保存复用 `placeCampDecor`，校验复用 `campDecorPlacementError`，稳定 uid/type 不变。
- 格式和入口：`src/ui/camp-world-placement.js`、`src/ui/camp-management.js`、`src/styles/camp-management.css`。
- 透明与碰撞：透明背景，预览不是实体；确认后应用既有实体规则。
- 资源缺失：复用正式画笔和现有资源，不添加备用图或新位图。

## 4 动作与连续性

预览无新行走动画；装饰动态采用暂停后的游戏时间及减少动态模式，避免编辑时动作跳变。猫猫、小手、枪械、怪物、车辆独立动画不修改，不需要新视频、裁切、帧率或动作片段。底座固定，不以整图旋转模拟动作。跨面板保持暂停，退出管理页恢复进入前状态。

## 5 生成指令

本轮扩展现有程序绘制器和手机交互，无 imagegen 调用、提示词或新图片。正式绘制器为 `src/rendering/camp-decor.js::drawCampDecoration`，动态编辑入口为 `src/ui/camp-world-placement.js::render`。
