# 森林巡游美术生成任务单

复制本任务单，为每批资源填写一份。执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。未确定的尺寸、锚点或碰撞关系，应先对照现有同类资源核实。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 任务导航清晰度 / navigation-clarity |
| 类别和用途 | 程序化导航特效 |
| 本轮目标 | 正常镜头下看清路点、前进方向和被建筑遮挡的终点 |
| 数量和变体 | 光点、间隔箭头、终点光圈与悬浮标记；不新增任务类别 |
| 保留项 | 原有按需导航、碰撞寻路、战斗圈、人物动作、镜头和奖励 |
| 制作路线 | Canvas程序化绘制 |
| 参考与同类资产 | src/rendering/story-guidance.js；docs/art-reference/landscape-six-day.png 与 landscape-six-night.png |
| 使用场景 | 主线、故事与邻里任务赶路阶段 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 深绿边奶油光点，间隔箭头，指向脚底的终点标记 |
| 与其他变体的区别 | 中途小光点与箭头；终点为较大光圈和竖直标记 |
| 主次关系 | 终点主标识，路线细节；不新增满屏线条 |
| 地面衔接 | 光点及光圈贴地；标记尖端对准真实坐标 |
| 活动空间 | 不增加实体，全部通行空间保留 |
| 邻接组合 | 复用正式寻路避开树木、建筑与河流 |
| 光向与明暗 | 有限局部亮芯，深绿轮廓在浅色地面保持对比 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 光点直径11；箭头约16；终点110×56；悬浮标记约30×44逻辑单位 |
| 像素尺寸与倍率 | Canvas矢量；低缩放适度补偿，至多1.65倍 |
| 锚点与原点 | 实际路线折点和目标世界坐标；统一周期镜像 |
| 分层 | 地面路径与光圈在实体/攻击预警下；悬浮标记在实体后、战斗特效前 |
| 透明背景 | 透明，无位图接触影 |
| 碰撞与可通行性 | 纯提示，不改变碰撞与路线规划 |
| 昼夜处理 | 昼夜同形，颜色保持可辨，不新增全屏辉光 |
| 文件格式与位置 | src/rendering/navigation-markers.js；证据output/playwright/navigation-clarity/ |
| 内存与缓存预算 | 无新增位图/缓存；沿用每路最多24点、640单位可见长度 |

## 4 动画任务补充

静态资产标注“不适用”。猫身体当前仅生成正面待机和移动，不增加多方向身体序列。

| 字段 | 填写内容 |
| --- | --- |
| 动作和时长 | 光点微弱脉动；终点轻微上下起伏 |
| 帧率、帧数和循环 | 正式运行时按时间连续采样；无图集 |
| 源视频与连续片段 | 不适用：程序化导航，没有视频素材 |
| 统一裁切和缩放 | 目标与地面坐标固定，仅小范围标记浮动 |
| 起停与状态衔接 | 减少动态关闭脉动与浮动；任务结束沿用清理 |
| 局部真实动作 | 不适用：不修改角色/怪物/载具动作 |
| 独立部件 | 不适用：不修改枪械、操枪和载具部件 |

## 5 制作指令

沿用森林绿描边与奶油黄，增强路点轮廓而不是铺满光晕；箭头沿真实可通行路线，终点标记对准世界坐标。保留原有导航出现/清理条件，不改变镜头和实体美术。
