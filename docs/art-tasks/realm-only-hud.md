## 1 目标与范围

DOM HUD 显隐与布局任务。四种秘境进入后仅保留秘境入口和局内必要操作；故事、地图、角色、武器、载具收藏以及森林资源、环境图标、追踪提示隐藏。保留生命、弹药、局内载具操作、波次、祝福、布防、计分与退出。以现有秘境界面为参考，不生成新插画。

## 2 造型与空间

沿用原秘境门图标、奶油底、森林绿描边。手机直接露出秘境按钮，不再需要展开菜单；桌面同样只显示此入口。回收顶部森林资源栏空间，秘境状态上移。守护模式保持左下秘境按钮与原布防空间。场景、锚点、碰撞、光照、通行不变，地面衔接与邻接造型不适用。

## 3 技术交付

CSS 像素和屏幕安全区定位；手机秘境按钮沿用 54×60，桌面保持原尺寸。使用正式 DOM、原 SVG 和原事件，不增加图片、画布、缓存或解码内存。显隐按 `game.realm` 判定，覆盖准备、战斗、暂停、休整和结算，退出自动恢复。

## 4 动画与保留项

无新增动画，源视频、抽帧、帧率、裁切不适用；保留主角、小手、怪物、车体、炮塔及召唤物正式绘制与动作。不要改变秘境战斗、奖励、装备规则或永久存档。

## 5 制作要求

只调整本任务显隐和布局，不隐藏秘境专属功能，不让折叠菜单吞掉秘境或退出入口；关闭面板后焦点回到可见按钮。退出后恢复森林界面与手机折叠菜单。

## 6 验收记录

结论：通过。四种模式在 320、390、1280 像素宽度分别完成真实入口、准备、战斗、暂停、退出；共 39 个显示状态检查。手机直接显示秘境入口，森林资源、天气及五个非秘境入口均不可见；退出后全部恢复，手机菜单收起。触摸打开、键盘 Enter/Escape、320/390/1280 间缩放、刷新续玩、休整、失败结算及退出焦点均通过。

正式场景昼夜同屏检查已完成：角色、武器、随机载具、怪物及地形仍按正式绘制，秘境入口与生命/弹药仪表分开，守护方格和布防按钮可用，滚滚史莱姆分数及退出保留。该修改只改变 DOM HUD，不改比例、动作、碰撞、通行及奖励。无新动画，故连续帧录制不适用。

截图见 `docs/art-reference/realm-only-hud/`：`rogue-{320,390,1280}-{day,night}.png`、`tower-390.png`、`guardian-390.png`、`football-390.png` 和 `result-320.png`。针对性浏览器脚本为 `tests/realm-only-hud-browser.cjs` 与 `tests/realm-only-hud-transitions-browser.cjs`，运行于隔离端口 4218，未操作正式存档；浏览器无脚本异常。新增运行 CSS 1,266 字节，无运行图片、Canvas、离屏缓存或纹理预算增长；验收 PNG 仅在 docs，不能分发到游戏资源包。修改 JS 的语法、合同 JSON 解析及差异空白检查通过；未执行全量测试。

正式入口 `src/ui/panels/realms.js`、`src/ui/mobile-hud.js`、`src/rendering/visual-review.js#inspectRealmHud`，设计标准 `realm-only-hud`。
