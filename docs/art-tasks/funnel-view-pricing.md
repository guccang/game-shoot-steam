# 浮游炮默认视野与高级武器价格调整

本记录沿用[美术任务单](../art-generation-brief.md)的目标、空间、交付、动画和验收结构，执行[美术标准](../art-generation-standard.md)与 [AGENTS.md](../../AGENTS.md)。本轮为既有场景镜头逻辑校准，不生成或替换美术资产。

## 1 目标与范围

| 字段 | 本轮内容 |
| --- | --- |
| 名称与标识 | 星环浮游炮 `funnel`；`normal-scene-camera` |
| 阶段、类别和用途 | 运行时镜头校准，恢复玩家默认视野 |
| 目标 | 携带浮游炮时，场景倍率和跟随中心与普通武器一致 |
| 交互目标 | 切枪恢复默认镜头；出击、充能、环绕和暂停缩屏仍保持炮体可见 |
| 数量和变体 | 一个既有武器镜头；无人机、狙击保留独立镜头 |
| 保留项 | 猫身体连续帧、独立控制器与三炮、武器弹道和攻击节奏、场景实体与 UI |
| 制作路线与参考 | 复用 `CombatCamera` 默认倍率和正式 `Renderer`，没有新增图片需求 |
| 使用场景 | 普通森林战斗；专项检查怪潮镜头切换 |
| 后续精修 | 无，本轮不替换纹理、PNG、模型或动画素材 |

## 2 造型与空间

主体剪影、光照、材质、地面衔接、图层与锚点沿用现有资源。只改变画布镜头取景和炮体允许活动范围；没有新增资产变体，不改变道路、建筑、湖山或树木碰撞。

普通镜头宽度小于 500 时倍率为 0.85，其余为 1.05；观察中心保持猫猫下方 30 世界单位。浮游炮飞行边界按相同倍率计算，短屏顶部适配紧凑生命条及任务条的 150 像素留白。三炮保持完整环绕，不贴入身体或互相拥挤。

## 3 技术交付

- 镜头配置：`src/config/camera.js`，`defaultCombatZoom` 与 `DEFAULT_CAMERA_Y`。
- 正式投影：`src/rendering/camera.js` 的 `CombatCamera.update`。
- 正式场景与预热：`src/rendering/renderer.js` 的 `draw`、`prepareGround`，分别传入真实控制器类型。
- 炮体边界：`src/combat/funnel-movement.js` 的 `funnelFlightBounds`。
- 图片、图集、透明裁切和解码预算：没有新增资源，不变；加载现有猫猫及炮体素材。
- 配方：`src/config/economy.js`，首次购买金币基价统一用于目录、工坊报价与正式支付，营地折扣继续生效。

| 武器 | 原金币基价 | 新金币基价 |
| --- | ---: | ---: |
| 脉冲 | 15,000 | 30,000 |
| 无人机 | 18,000 | 36,000 |
| 机械核心 | 22,000 | 44,000 |
| 浮游炮 | 24,000 | 48,000 |
| 机械蜘蛛 | 28,000 | 56,000 |
| 引力聚束枪 | 10,000 | 20,000 |

按原万元以上档位调整；材料、木材、升级费用和基础武器保持原规则。独立炮塔配方依原机制继承对应武器价格。

## 4 动画与交互

沿用 `funnel-movement.js` 的持续相位、驻点、返航与充能状态；`funnel.js` 绘制炮体和独立控制器。动作时钟、帧率、现有素材尺寸、脚底锚点、射击部件不变。30/120 帧完整环绕、暂停、缩屏、切枪和减少动态模式由现有专项测试验证。本轮不生产源视频或序列帧。

## 5 生成指令

未使用 imagegen：本轮只校准镜头和逻辑边界，已有美术资源可以直接复用。没有 PNG 替换阶段或新增必需素材。
