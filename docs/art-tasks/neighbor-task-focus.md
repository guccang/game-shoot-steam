# 邻居任务聚焦界面

依据 [美术生成标准](../art-generation-standard.md) 与 [AGENTS](../../AGENTS.md)，沿用美术任务单的六个阶段记录。

## 1 目标与范围

- 标识：neighbor-task-focus；动态交互开发，既有HTML/CSS任务面板调整。
- 目标：交接时只显示当前委托；任务名、步骤、目标明显；一个继续或导航按钮；移除重复确认。
- 三种委托共用；接取、交接、护路、完成、闲聊与目录状态均检查。
- 保留原任务事务、报酬、稳定ID、真实角色与场景渲染；参考用户铁牙午餐截图与手机UI框架。
- 不生成图片：本次为信息层级和交互改动，复用现有森林绿/奶油纸材。无新增PNG精修项。

## 2 造型与空间

任务名 → 步骤/当前目标 → 唯一行动；回应和奖励按需展开。日常闲聊不进入任务交接。
纯DOM面板，不改地形、碰撞、角色比例、光向或通行；背景仍是正式昼夜世界。

## 3 技术交付

复用480px手机底板、44px触控与既有居中/底部锚点。标题、滚动正文与关闭入口沿用统一框架；移除确认底栏。
源码：src/ui/living-world.js、src/ui/living-request-view.js、src/styles/living-world.css、src/ui/mobile-panels.js。
无新图片、画布和派生缓存；动态文本、阶段、导航与奖励由生产状态计算。

## 4 动画任务补充

无新增动画或位图。角色真实连续帧、场景、昼夜处理原样复用；检查暂停/恢复，不修改动作时钟。

## 5 生成指令

不使用imagegen；生产DOM重排与现有样式实现，无素材加载替代路径。

## 6 验收记录

- 5项专项单测通过：追踪优先、共享居民、完成页保留、保存失败、目录与闲聊隔离。

- 当前追踪午餐时，其他居民不推荐无关任务；邻里目录仍可主动查看其他委托。
- 导航保持当前委托；恢复自动到点入口后仍正确暂停，关闭后恢复游戏且不反复弹出。
