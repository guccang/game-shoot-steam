# 阵风天气

## 制作目标
以片头 assets/title/background.mp4 的右来左去的风为参照。耳尖先压低，树冠随后倾向下风处，水纹成组掠过，风歇时有明显空拍。身体沿用 160×160 真实视频帧和脚底锚点；树以原树根为锚；水纹限定于现有水域。环境入口沿用 64×64 天气图标与中文按钮。保持四季、昼夜、动作时钟、独立操枪、阴影、桥面与碰撞分层。开发阶段使用程序和 SVG。

## 随机阵风叠加改造

目标为晴、阴、雨、雷雨、雪均可间歇起风；风只改变原有树冠、水纹、猫耳和围巾。共享游玩时钟驱动随机静歇、风长与强度，保留传播顺序、锚点、透明分层与减少动态设置。环境设置将阵风从主天气选项移到独立开关。复用原绘制器和图集，不新增分发美术文件。检查降水叠加、暂停、手机触控与昼夜同屏。

### 本轮验收

- 正式入口为 Renderer.draw → GustCycle.sample → gustStrength，各地物继续使用实际坐标。开场静歇 5–14 秒，单点阵风长 3–5 秒，峰值逐阵抽取，传播结束后静歇 18–42 秒。随机阵风与主天气各自运行，设置保存时只记录开关。
- 4175 端口真实触屏打开环境面板，选中小雨后关闭并重新打开阵风，小雨保持选中。正式画面复核见[手机白天小雨](../../output/playwright/gust-overlay/rain-wind.png)、[短屏夜晚降雪](../../output/playwright/gust-overlay/snow-wind.png)、[桌面竖版夜间雷雨](../../output/playwright/gust-overlay/thunder-wind.png)。风峰时采样到角色位置风强高于 0.3 且相应降水权重为 1。减少动态时风场停止。
- 工作台 weather-gust 与 weather-gust-night 共用正式采样函数及已有材质。新增分发位图、纹理与帧缓存为零。随机间隔、五种主天气、旧设置迁移、降水过渡与天气时长存储检查通过。环境回归中另有两项失败，断言分别涉及初始弹匣存档及瀑布河道坐标。
- 结论：本次间歇阵风动态与手机交互验收通过。
