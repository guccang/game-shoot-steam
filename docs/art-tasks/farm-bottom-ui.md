# 种地底部工具栏与状态面板

依据[美术任务单](../art-generation-brief.md)、[美术标准](../art-generation-standard.md)与[AGENTS.md](../../AGENTS.md)。

## 1 目标与范围

本轮为程序UI布局调整：进入种地后隐藏右下角玩家状态面板，六个工具入口改为底部单行排列；退出种地后恢复状态面板。保留现有奶油底森林绿风格、工具图标、中文文案、稳定ID和点击行为。参考现有farm-tools及手机UI框架，无新插画或PNG精修范围。

## 2 造型与空间

工具栏固定底部安全区居中，左右至少12像素，最大440像素，六列等宽；按钮至少44像素触控尺寸。状态卡不占位也不能拦截田块操作；原菜单保持在工具栏上方。种子浮层、田块位置、人物比例、碰撞和行走空间保持。

## 3 技术交付

复用farm.css和createFarm现有工具栏显隐，CSS :has同步状态卡，无额外状态、事件或存档字段。无新画布、纹理或内存缓存，保留刘海及底部安全区。

## 4 动画任务补充

仅布局与显隐变化，工具动画、角色和作物运行时保持；无需新增视频或序列帧。

## 5 生成指令

不使用imagegen，原生CSS布局足以实现本轮调整，现有图标直接复用。
