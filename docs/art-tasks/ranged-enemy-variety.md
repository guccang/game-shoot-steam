# 远程怪物种类与低密度攻击任务单

执行依据：`docs/art-generation-standard.md`；程序化延伸原怪物体系。

## 1 目标与范围
| 字段 | 规格 |
| --- | --- |
| 名称 / id | 孢子喷吐怪 / spore-spitter；橡果投手 / acorn-slinger |
| 类别和用途 | 普通巡游远程怪物，森林与九寨沟使用原波次名额；秘境专属阵容保持 |
| 目标 | 远程作为少量威胁，有明显蓄力、单发慢弹与长空档，近战始终占多数 |
| 数量与差异 | 两种；宽菌盖＋喷嘴，尖橡果壳＋独立树枝弹弓；不是换色变体 |
| 保留项 | 猫视频与小手枪械、近战扑击、叶翼蝠飞行、载具履带旋翼、领主预警、通路与地形 |
| 制作路线与参考 | Canvas 部件动作，复用 `enemies.js` 的受击及脚底关系；参照 `art-reference/slime-football-day.png` 的同屏配色 |

## 2 造型与空间
| 字段 | 规格 |
| --- | --- |
| 剪影 | 孢子怪为宽扁伞盖与短根足，喷嘴朝真实射线；投手为尖果壳、双脚与 Y 形弹弓 |
| 主次与邻接 | 小型敌人，轮廓不压过猫或载具；沿现有林区出生、树前树后排序 |
| 地面与光照 | 脚底椭圆接触影，左上亮、右下暗，森林绿描边、草木绿、奶油与木色 |
| 活动空间 | 不新增场景障碍；实体碰撞半径沿原阶级，攻击弹丸遇树干消失 |

## 3 技术交付
| 字段 | 规格 |
| --- | --- |
| 逻辑尺寸 / 锚点 | 主体约 56×54 世界单位；(0,0) 为脚底，阴影独立；实际倍率沿 drawSlime |
| 像素 / 格式 | 无位图与字体，直接 Canvas；源码 `src/rendering/ranged-enemies.js` |
| 分层 / 透明 | 地面预警→阴影与主体部件→空中弹丸；透明绘制，无不透明地板 |
| 碰撞 / 昼夜 | 原怪物圆形体；共用运行时夜色，不分配昼夜副本 |
| 预算 | 不新增图集或离屏画布；远程存活最多3，普通远程弹丸最多3，领主在场最多1；不留持续伤害区 |

## 4 动画
脚步按实际移动距离推进，停步保持相位；孢子喷嘴蓄力后伸缩，投手独立拉弦后释放；受击保留翻滚、高度、恢复，死亡碎裂淡出。前摇 0.85 / 1.05 秒，冷却 3.6 / 4.6 秒；攻击锁定旧位置且不追踪。减少动态保留预警与弹丸位置，关闭弹性形变。程序化动作不涉及源视频、裁切、复制帧。

## 5 制作指令
延续森林绘本风格、有限平涂和森林绿轮廓；用菌盖喷嘴与果壳弹弓区分身份。只有单条细射线与少量短促粒子，不绘制弹幕、毒池或满屏光晕。部件动作和正式战斗状态同源。

## 6 验收记录
2026-10-22 实际验收通过。前两波没有远程；每五个名额抽签一次，第3–5波抽签通过率60%，第6波起90%，因此名额理论占比上限12%/18%，飞行名额和存活限制会进一步降低。刷入一只远程前须已有至少四倍近战，存活最多3只；此规则不改变秘境专属编队和领主援军。
