# 小屋装扮美术生成任务单

依据：[游戏美术资源生成标准](../art-generation-standard.md)、[项目约定](../../AGENTS.md)。本单复制自美术生成任务单，当前为动态效果开发，PNG精修为后续阶段。

## 1 目标与范围

- 资源：小屋装扮 `cottage-decoration`；15件家用家具及3种盆栽，室内陈列与商店小图。
- 目标：金币购买、摆放、重新布局、收纳、播种、生长、采收连成可保存的玩法；购买前显示价格，操作失败不扣款。
- 保留：原版小屋360×360坐标、固定床与出门锚点、真实猫连续帧、室外地图和独立操枪。原书桌、椅子、柜子、盆景免费迁移为可移动家具。
- 路线：本轮以Canvas正式绘制器和手机底板完成动态交互；不调用imagegen，不新增临时位图。图片精修等待玩法确认。
- 参考：`src/rendering/cottage.js`现有家具、`docs/art-reference/landscape-six-day.png`及夜景对应图、`docs/ui-foundation.md`。
- 确认目标：手机正常尺寸可区分15件物品，实际摆放和预览共用绘制器；后续PNG保持稳定ID、宽高、底座与分层。

## 2 造型与空间

- 花盆为陶土梯形与土面；电视为圆角屏与两脚；收音机有提手、网罩和旋钮；玩偶有圆耳、躯干与四肢；窗帘为左右垂布与叶纹。
- 沙发双垫宽扶手、茶几椭圆桌面短脚、书架三层书格、灯具长杆伞罩、地毯叶芽纹、挂钟尖屋顶钟面、篮子编纹提手、小凳斑点圆顶、花瓶细颈野花、壁画内框远山。区别同时体现在轮廓与部件结构。
- 森林绿`#315c43`描边、奶油`#fff6dc`、草绿`#91ae86`、木色`#c7a276`、陶土`#c99378`；沿用本地字体，左对齐中文内容。房间预览为主体，下面使用简洁单列目录，不引入桌面布局。
- 保留木地板与窗景；左上受光、右下小接触影；地毯在地面层，墙饰先画，家具与猫按脚底排序。床与门之间保持可达，实体底座禁止重叠和覆盖猫。
- 窗帘固定左右窗位，壁画和挂钟限于两窗之间；室外山湖植被邻接不适用，本轮仅改室内。

## 3 技术交付

- 逻辑尺寸：目录配置`src/config/home-decor.js`逐件记录宽高；底座中心为锚点，房间360×360。无新增位图倍率和SVG视框；手机预览720×720物理画布、360×360逻辑单位。
- 分层：地面/地毯 → 墙饰 → 接触影与家具主体/猫脚底排序 → 编辑选框。独立窗帘不烘焙窗景，植物独立于花盆绘制。
- 程序职责：金币、库存、位置、校验、历法成长、状态文本与采收。后续图片仅替换图案，保留`type/uid/x/y/plant`与当前接口。
- 透明：直接绘制至现有Canvas，不额外铺不透明底板；地面影单次绘制。
- 碰撞：实体家具共用宽高并加10单位角色边距；墙饰与地毯可通行。寻路保留门内落点、床边和出口。
- 昼夜：同一形体，沿用室内日历夜景，灯罩局部暖色；不新增独立夜图。
- 入口：`src/rendering/cottage.js`、`src/rendering/home-decor.js`、`src/ui/home-decor.js`；价格和状态分别位于config/progression/core。
- 预算：家具实例最多40；无新增网络位图、常驻纹理或离屏动画缓存。预览画布720×720×4约1.98MiB；目录图标每件128×128；当前家具页最多40件，隐藏商店最多15件，总上限55张约3.44MiB；连同预览总计约5.42MiB，无逐帧新增画布。
- 必需资源：现有猫图集、字体及源码模块；保持现有加载失败行为，不生成备用猫画面。

## 4 动画任务补充

家具本体静态，不虚构视频或序列帧。盆栽按正式游戏历法分幼苗、生长、成熟阶段，巡林与睡眠推进；成熟日期按播种当天起第1/2/3个清晨计算；商店暂停、离线不推进，收纳保留生长时间。猫沿用原身体动作时钟与真实帧、脚底和起停行为，操枪与载具未修改。本轮无新增腿、翅膀、履带、旋翼动作。

## 5 生成指令

本轮未生成图片：优先确认摆放和种植交互，Canvas正式入口完成有限平涂与结构差异。后续精修使用本轮确认的昼夜截图与既有PNG样式作为imagegen参考，分别交付家具、植物与窗帘，禁止烘焙数值、进度和操作文字。
