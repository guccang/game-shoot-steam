# 武器独立演练场任务单

## 2026-10-27 红狼耐久靶数值调整

按玩家反馈，将红狼试驾靶标从240血调为1200血，仅调整隔离演练配置；基础主炮首发直击后剩640血、溅射后剩836血，6个目标均存活，方便比较掉血。场景选择读取 Game 初始化后的实际主炮，购买前试驾同样生效。其他载具默认靶标仍为240血；正式战斗数值、布阵、美术和动作不变，本轮不制作新美术资产。

验收：13项相关测试通过；320×568、390×844、844×390、1280×900浏览器验证首炮存活、连续掉血、暂停、重新布阵和来源存档隔离，零浏览器异常。[白天](../verification/redwolf-target-health/day.png)、[夜晚](../verification/redwolf-target-health/night.png)保留实际运行证据，未进行实体手机测试。沿用正式演练绘制器和 `weapon-trial-scenes` 设计目标。结论：通过。本节替代下方历史记录中的默认240血秒杀配置。

## 2026-10-27 红狼命中反馈修订

制作前目标：解决一炮清空后同帧满血补靶造成的“爆炸不掉血”观感。保留真实伤害、红狼装填与炮塔、原布阵和怪物比例；整组击毁后等待1.2秒补靶，绘出正式死亡动作及真实伤害飘字。

参考为本单原载具昼夜截图。结构与尺寸、脚底锚点、碰撞、林缘缓存沿用第2、3节；新增表现位于实体层（死亡残影按脚底排序）和特效层（奶油白数字、森林绿描边，17/22世界单位）。复用正式死亡与数字寿命，最多20个残影、65个飘字，不添加运行图片、视频、图集或缓存。无新造型变体、视频抽帧和地形边界，相关新增资产项不适用。沿用 `weapon-trial-scenes` 设计目标。

修订验收（通过，2026-10-27）：

| 目标 | 实际结果与证据 |
| --- | --- |
| 命中与击毁可辨 | 正式红狼主炮直击560、溅射364；默认6个240血目标一炮清空，实际扣血合计1440。死亡后1.2秒无满血靶覆盖；较高血量目标保留扣血结果。15项相关测试通过，含原战场死亡奖励与动量回归 |
| 正式动作与分层 | 复用 `leaveEnemyRemnant` 和 `drawSlime`，保留真实击退、腾空、爆裂与回收，不复制静帧；飘字绘制于特效后。补靶文字位于场地下方，不遮挡命中区。见[运行录像](../verification/redwolf-feedback/session.webm)与[过程抽样](../verification/redwolf-feedback/sequence.jpg) |
| 昼夜与比例 | [390白天](../verification/redwolf-feedback/390-live-day.png)、[320夜晚](../verification/redwolf-feedback/320-live-night.png)、[横屏](../verification/redwolf-feedback/844-live-day.png)、[桌面同一手机页面夜景](../verification/redwolf-feedback/1280-live-night.png)；沿用车辆、靶标和场景比例，数字与击毁均可辨 |
| 真实交互与资源 | 320×568、390×844、844×390、1280×900浏览器实测，暂停冻结补靶，重来重置，关闭返回工坊，来源存档不变；浏览器无异常。未进行实体手机测试。没有新地形、阻挡、下载媒体或缓存；桥水与新通路检查不适用 |

正式入口：`src/core/weapon-trial-scene.js#createWeaponTrialScene`、`src/rendering/weapon-trial-scene.js#drawWeaponTrialScene`；工作台读取仍为 `src/rendering/visual-review.js#inspectWeaponTrialSceneReview`。对应 `designCriterion`：`weapon-trial-scenes`，真实火力特点、动作与昼夜可读性。结论：通过；无遗留修订项。

执行依据为[游戏美术资源生成标准](../art-generation-standard.md)。本任务使用正式 Canvas 绘制器构成独立演练场，未生成新角色或媒体资产。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 武器独立演练场 / weapon-trial-scenes |
| 类别和用途 | 场景、地面标线与全屏操作页 |
| 本轮目标 | 点击工坊试玩后切换可移动场景，清楚展示每件武器机制 |
| 数量和变体 | 18件武器各有目标布阵；车辆沿用相应火力演练 |
| 保留项 | 真实猫连续帧、独立操枪、怪物动作、召唤物与车辆组件 |
| 制作路线 | 程序场景，复用正式角色/树木/怪物绘制器 |
| 参考与同类资产 | 现有森林靶场与 src/rendering/workshop.js |
| 使用场景 | 隔离演练场，不写巡游存档 |

## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 林缘围合的开阔草地，土色射道与距离刻线 |
| 与其他变体的区别 | 纵列、扇形、密集阵、多方向、远射道；布阵与站位不同 |
| 主次关系 | 武器与敌人为主，林缘装饰避让射线 |
| 地面衔接 | 草地接土路，边缘少量树木；无独立位图地板 |
| 活动空间 | 圆形练习边界内自由移动，不布置假掩体 |
| 邻接组合 | 林缘和射道连成一体；采集演练使用真树 |
| 光向与明暗 | 左上受光；夜景共用形体与偏冷低亮地面 |

## 5 生成指令

程序制作指令：沿用森林绘本配色和统一脚底比例，以草地、土色射道、稀疏距离线和外围树木形成演练空间。纵列适合贯穿，扇形适合近距散射，圆形空间适合召唤和走位；目标使用真实敌人，采伐使用真实树。按第3节坐标与分层实现，保持射线和绕行空间开放。猫身体、独立枪械、弹道、召唤物、车辆与怪物动作全部调用正式模块。

> 排除：写实摄影、另一套三维风格、纯黑厚描边、满屏碎纹、规则对称岸线、漂浮影子、主体比例跳变、复制帧假动画、额外方向、烘焙操枪部件、文字水印和不透明地板。
