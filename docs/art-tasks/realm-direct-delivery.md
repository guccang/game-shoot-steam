# 秘境直达交付与设置入口收拢

## 1 目标与范围
- 标识：realm-direct-delivery / settings-only-home。现有 HTML 界面调整，无新增插画。
- 目标：秘境委托退出或战败后直接显示领取页；保存返回主菜单只在设置中出现。
- 保留：原角色视频动作、武器载具独立绘制、地形通路、资源奖励与存档事务；普通秘境结算不变。
- 参考：现有 story-dialog、realm-dialog、settings-dialog 和森林绿/奶油黄视觉体系。
- 制作路线：复用既有交付布局与设置图标，删除重复返回按钮。

## 2 造型与空间
- 主体：交付标题、现有奖励图标与领取按钮；设置齿轮置于既有标题栏。
- 结构区别：不再出现底部返回菜单条；退出无需目录和对白中转。
- 层级/邻接：原生弹窗叠加在正式营地场景上；设置可嵌套并正确恢复焦点。
- 地面、光向、碰撞：不适用，本次不改场景或世界几何。

## 3 技术交付
- 尺寸：沿用原弹窗自适应尺寸，检查 320/390/1280 宽度；齿轮沿用已有按钮尺寸。
- 锚点：原生 DOM 标题栏。分层：场景、交付弹窗、设置弹窗；无位图透明背景需求。
- 昼夜：原运行时环境与同一 UI 样式。文件：src/ui、src/core、src/config；无运行资产新增。
- 预算：零新增贴图、画布或派生缓存，减少重复返回按钮节点，仅两个可释放设置入口。

## 4 动画任务补充
不适用：不改动画、帧率、视频、裁切或操枪部件；原动作时钟保持。

## 5 制作要求
沿用现有绘本 UI，不新增主题、装饰图或长说明。交付页直接给奖励与领取动作；设置入口短小且可键盘访问。
