# 送药回营场景与移动恢复任务单

依据：[美术标准](../art-generation-standard.md)、[项目合同](../../AGENTS.md)。由美术生成任务单复制后按本次修复范围填写。

## 1 目标与范围

标识：story-camp-return。阶段：既有程序场景恢复，不生成或替换图片。仅送药章节 HOME、END 节点恢复营地常驻建筑、农田、门牌和停驻车辆；结尾对白播放时保持交谈，读完后关闭交付页可移动，奖励仍主动交付。其他章节、借用装备、实际航线、桥栏、任务条件和奖励事务保留。

参考为用户送药回营截图及同一存档的普通营地。复用原建筑与角色资源，不增加造型变体；无后续 PNG 精修项。

## 2 造型与空间

剪影、尺寸、森林绿描边、柔和草木配色、左上光向、脚底锚点和地面衔接不变。恢复常驻景物读取永久营地进度，不使用借用装备的空白成长。营地底座碰撞随可见场景恢复，河桥阻挡仍沿故事规则。主体仍为角色和对白，建筑按原深度排序，不增加路上摆件。

## 3 技术交付

正式入口为 Renderer.draw 和 storyCampScene。视图不修改权威对象；常驻建筑、地面与停驻载具复用既有绘制器，剧情人物、角色、独立武器仍使用原会话。逻辑尺寸、像素尺寸、透明度、锚点与各层接口不变。昼夜沿用正式光照，零新增图片、画布或长期位图缓存，仅每帧一个有界只读视图。原图集必需，缺失继续报告失败。

## 4 动画任务补充

没有新动画；保留猫真实连续帧、独立操枪、气垫船和原场景时钟。只调整回营待交付的开始、暂停与恢复条件，暂停面板继续冻结游戏，关闭后恢复。验证连续行走、停止、交谈、交付失败重试和完成后的状态。

## 5 生成指令

不使用 imagegen：本次没有美术资产制作，修复正式场景筛选条件和状态迁移。实现位于 src/rendering/story-camp.js、src/rendering/renderer.js、src/core/story-definition.js、src/core/story-manager.js、src/core/game.js 及送药章节配置。
