# 滚滚史莱姆返回与暂停面板任务单

依据：[美术标准](../art-generation-standard.md)、[任务单模板](../art-generation-brief.md)、[手机 UI 框架](../ui-foundation.md)。

## 1 目标与范围
本轮为现有 HTML/CSS 交互调整：比赛改为60秒，结束结算后直接返回可操作主场景；暂停面板移除设置和玩法说明，仅保留继续巡游。参考用户提供的暂停截图与现有 mobile-ui-hierarchy。保留奶油底板、森林绿描边、月亮图标、标题与正文、继续按钮 ID、原角色与世界绘制。不新增图片，无需 imagegen 或后续 PNG 精修。

## 2 造型与空间
居中紧凑纸页，正文在上，单个主操作在下；删除两枚次操作后自然缩短高度，取消空行。共用现有明暗、字体和按钮状态。不新增变体；地面衔接、世界通行和碰撞不适用，因为只修改屏幕空间面板。

## 3 技术交付
沿用 CSS 逻辑尺寸、视口中心锚点及 HUD 上方暂停层，按钮触控高度至少44px。验证320/390手机短长屏、昼夜及桌面既有竖版容器，不新增桌面布局。HTML负责结构，原控制器负责暂停与继续，比赛核心负责计时和一次结算。正式入口为 index.html 的 #overlay、src/ui/title-menu.js 和 src/styles/ui-foundation.css；无新增图片、画布或缓存，沿用必需资源及原有缺失报错。

## 4 动画补充
静态面板，不新增动画；保留既有角色连续帧、独立武器和载具动作。

## 5 制作指令
直接删除暂停面板两枚次操作及对应监听、样式；保留共享奶油纸与深绿主按钮。比赛返回不用模态窗口阻断操作，以简短提示反馈得分。
