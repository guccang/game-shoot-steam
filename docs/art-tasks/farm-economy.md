# 营地实景种地验收

> 此页保留上一版营地十二格与瞬时播种的验收历史；当前行为和替代测试以[世界种地与快递站](world-farm-delivery.md)为准。

本页替代旧版全屏农田验收。用户最新要求为营地内挥锄逐块开地，点击空田选种、拖动播种、成熟后点击收割并直接取得金币。

- 稳定验收标识：`camp-world-farming`，合同 `visual-contract.json#farmEconomy`。
- 正式入口：`src/ui/farm.js:createFarmPanel`；世界表现：`src/rendering/farm.js`；规则与存档：`src/core/farming/farm.js`、`src/progression/farming/farm.js`。
- 地点：营地原装饰麦田，四列三行；未开垦保持原草地，拿锄头才显示候选格。
- 动作：既有角色站立/走路动画不变，手持锄头独立挥动；猫猫走近后，锄头落地才保存土地。操作期间不自动射击，不暂停世界。
- 图像来源：`game-slg@c57eb86`，沿用 `assets/farm/manifest.json` 与两张透明作物图集，没有新增位图。八种作物各有种子、幼苗、成熟独立图像；正式运行缓存两张，共 3,145,056 像素。
- 层次：土地在脚下，作物以每格的脚底参与世界深度排序；东侧路灯避开田块。循环地图采用最近镜像。
- 控件：田块是随镜头移动的透明命中区；种子和收割控件贴近所选田块弹出。种子价格、成熟时间分行，所有已解锁种子同屏四列显示。
- 旧档：v1 原田块、作物、经验保留，旧库存显式领取；新收获不入仓库。新档从草地开始，雏菊种子免费。

## 实测证据

`tests/farm-economy-browser.cjs`：390×844 手机尺寸，实际点击让角色走近并挥锄两次；选种本身不播种，原生触摸连续播种两格且角色不移动。时间夹具只推进成熟时间，实际点击地块和收割按钮，两次分别到账60金币，总计120金币，无新增库存、无页面错误。

`tests/farm-world-edges-browser.cjs`：四格胡萝卜快速拖动并来回经过，800金币只扣四份种子费至600；取消触摸不回滚已经成功的单格交易。仍持种子时点击成熟田能弹镰刀，拖动收割四份至1280金币，重复经过不重复奖励。模拟存储失败后金币和空田不变。390×844白天、320×568夜间、844×390横屏无页面横向溢出。

`tests/farm-loading-browser.cjs`：图集缺失明确报错，恢复后重试成功，仍只解码两张图集。
