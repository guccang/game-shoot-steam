# 数值工作台内嵌说明任务单

## 1 目标与范围
标识 balance-inline-help；用途为数值工作台DOM说明。顶部提供可收起的六步使用指南，参数旁显示用途和调整影响，结果区说明统计口径，导出区说明保存与正式接入区别。
参考：docs/art-reference/cadence-balance-workbench-desktop.png 与现有工作台样式。保留所有数值规则、交易、工作台编辑/模拟/下载功能和游戏视觉。
制作路线：原生HTML/CSS/JavaScript，纯文字，无新位图或动画。

## 2 造型与空间
森林墨绿 #294f3b、草地 #d7e3c8、奶油 #fff4cb、纸白 #f8fbf4、链接蓝绿 #347e87。标题沿用宋体，正文微软雅黑。指南在参数册之前，正文左对齐，连续步骤用有序列表；参数用途在输入框下方常显，较长调整影响点击或键盘展开，无悬浮依赖。
对照目标后保留既有视觉，不新增装饰卡片或弹窗。手机单列，提供参数/结果页内跳转以缩短滚动。
主体剪影、地面衔接、邻接场景、世界光照不适用：本次只修改独立工具DOM。

## 3 技术交付
桌面1440宽，手机320/390宽；流式布局、原字号层次，说明关联aria-describedby。锚点、透明贴图、碰撞与通行不适用。分层为独立工作台文档；正式游戏无新覆盖层。
新增 src/balance/help.js 保存提示文案；不复制经济公式。无外部字体、图片或常驻图集，说明不影响Worker。

## 4 动画任务补充
不适用：不生成动画、视频、连续帧或独立战斗部件；保留正式运行时全部既有动作。

## 5 实施说明
说明覆盖新手操作、常见瓶颈、比例单位、调高/调低的影响和可能不生效的条件。区分产出木材比例与升级木材比例；保底次数增大代表更慢；回访/出征是玩家行为假设；不能把模拟当真人实测或把候选导出当游戏发布。
