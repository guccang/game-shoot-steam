# 剩余手机页面统一任务单

依据：[美术生成标准](../art-generation-standard.md)、[原任务模板](../art-generation-brief.md)、[手机框架](../ui-foundation.md)。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称与标识 | 剩余手机页面统一 / mobile-ui-pages |
| 类别和用途 | HTML/CSS 功能页、说明、确认、奖励和装配 UI |
| 目标 | 剩余弹窗迁移到同一底板、按钮与滚动框架，保留玩法操作和层级 |
| 变体 | 功能页深绿标题；说明/确认浅色紧凑；装配页保留工作台；NPC沿底部；奖励保留倒计时 |
| 保留项 | 原ID、节点事件、委托与购买规则、存档、暂停归属、Canvas绘制、场景透明热点 |
| 制作路线 | 显式页面合同搬移现有DOM，不复制业务组件；共用颜色和按钮状态 |
| 参考 | docs/art-reference/mobile-ui-hierarchy、ui-foundation.html |
| 使用场景 | 地图、装备/载具、工坊、玩法、档案、环境、说明及确认 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 功能页22px圆角、3px森林绿边；按钮12px；选项轻边；对话18px顶圆角 |
| 变体差异 | 功能页标题/正文/底栏分区；轻说明浅标题、窄底板；工坊保持舞台及工具托盘 |
| 主次关系 | 页面标题和退出固定，长正文滚动；选择项与执行按钮区别 |
| 地面衔接 | 不适用，屏幕空间UI |
| 活动空间 | 不增加战场常驻遮挡，关闭恢复原场景；装配保留拖拽目标 |
| 邻接组合 | 正式场景猫、车辆、怪物及昼夜光照同屏 |
| 明暗 | 奶油底、森林绿轮廓、短底影，沿用原字体及插画 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 尺寸 | 320/360/390/430竖屏及844×390横持手机，按钮至少44px |
| 倍率 | CSS逻辑像素，原DPR绘制 |
| 锚点 | 原生功能弹窗居中，NPC底部、奖励原倒计时分层 |
| 分层 | 既有Canvas→战场信息→原生弹窗，不另建状态系统 |
| 透明背景 | 功能纸底不透明，原生遮罩透出场景，透明热点不改 |
| 碰撞与通行 | 不修改世界坐标、碰撞或导航 |
| 昼夜 | UI共用材质，世界使用原环境渲染 |
| 文件 | src/ui/mobile-panels.js、src/styles/ui-mobile-pages.css、正式模块接入与专项验收脚本 |
| 预算 | 不增加运行图像/字体；运行文本增量目标小于30KiB |

## 4 动画

静态UI；视频、连续帧、脚底与武器部件不适用且不修改。工坊Canvas及拖拽保持原绘制与事件。

## 5 设计指令

严格沿用森林绿#315c43、深绿#234333、奶油#fff6dc、草纸#e8edcf、叶灰#879b78和金色焦点#edbd63；汉仪旗黑、22px标题/14px正文/12px辅助。只统一框架，不改装备画像或玩法语义。长页面采用固定标题、独立滚动内容、固定操作；说明与确认用浅标题区分，不把NPC对话变成居中菜单。横持手机保持单列，不引入PC侧栏。
