## 2 造型与空间

| 字段 | 填写内容 |
| --- | --- |
| 主体剪影 | 粗木柱、双横梁、开放框架门扇与斜撑；连接土路为圆角分岔。 |
| 与其他变体的区别 | 横向看正面与亮顶，纵向保留柱帽、梁截面与暗侧；门叶独立旋转。 |

| 光向与明暗 | 左上亮顶、右侧暗面、脚底接触影；夜间共用形体转换。 |

## 3 技术交付

| 字段 | 填写内容 |
| --- | --- |
| 逻辑尺寸 | 柱高44、宽10，梁高7、厚6；栏段≤58，门洞150–180；公交棚沿用原120×110。 |
| 像素尺寸与倍率 | 矢量按正式Canvas DPR绘制（最高2），不新增位图或图集。 |
| 锚点与原点 | 世界坐标柱脚、门轴、棚脚；UI气泡锚定说话者头顶。 |
| 分层 | 地面土路 → 接触影 → 深度排序柱梁/门叶 → 独立角色与武器 → HTML气泡。 |
| 透明背景 | 程序绘制透明层，接触影局限脚下，不附加不透明底板。 |
| 碰撞与可通行性 | 沿用SETTLEMENT_FENCES与原门洞；建筑操作继续检查步行、距离、钥匙和材料。 |
| 昼夜处理 | 同形体材质换色并叠加正式环境光；无单独夜间贴图。 |
| 文件格式与位置 | src/rendering/{settlements,road-art}.js；src/ui/ranger-arrival.js；截图/录像在output/playwright/arrival-world-polish。 |
| 内存与缓存预算 | 围栏仍98段、8门，无位图缓存；道路仍用384单位地块及既有32块上限，无新常驻画布。 |

## 5 生成指令

> 延续森林绘本的三分之四俯视。厚木柱、双梁门框与斜撑使用森林绿描边和三层木色，左上亮顶、右侧暗面，脚底接触影随锚点固定。道路一次描边合成圆角主支路。保持工坊入口与8座门洞畅通，角色、武器、载具仍用原连续动作与比例。交付正式Canvas与HTML/CSS代码，无新位图。

> 排除：写实摄影、另一套三维风格、纯黑厚描边、满屏碎纹、规则对称岸线、漂浮影子、主体比例跳变、复制帧假动画、额外方向、烘焙操枪部件、文字水印和不透明地板。

## 制作前约定

木柱脚底为锚点，高44、宽10；梁高7、厚6，门叶开放框架带斜撑，不再用整块薄片。地面影、厚梁、立柱与门叶分层，左上亮顶、右侧暗面；98 段和8门不变，门洞150–180不变。道路进入现有384地块缓存，同色路径一次合成，不新增常驻贴图。公交站保留原木棚尺寸，移动到营地北方路肩。入职短提示位于左上，建筑页使用奶油纸与森林绿描边，按钮至少44像素；气泡复用 createSpeechBubble。角色/枪/车动作与原资源无变动，相关源视频和裁切参数不适用。
