# 顶部图标、资源缩写与小蛛追敌优化

依据 docs/art-generation-standard.md，按 art-generation-brief.md 的目标、结构、技术、动画和验收项目登记。

## 制作前规格

- 目标 / designCriterion：hud-compact。季节、昼夜、天气仅显示原有 SVG 和圆环，删除可见短标签，保留辅助名称、悬停提示及点击轮转。资源上千用 k、上万用 w、上亿用 Y，不截断；玩家受伤飘字向下取整。
- 参考：用户两张顶部截图，以及上一轮 spider-motion-day.png。原森林绿/奶油配色、28 像素图标、44 像素触控区保持；圆环与图标同心，不新增资源或字体。必要时窄屏排列分行，不能遮挡下方波次提示。
- 结构与分层：现有 DOM 顶部层，资源图标与数值独立；图标无文字后上下居中。精确资源值保留在钱包与辅助提示。没有新增实体、碰撞、图集或透明图片，运行画布和缓存预算不变。
- 动作：小蜘蛛移动速度 165→300，出舱 85→140，继续使用真实位移驱动八足，停步不重置。母体、猫群、地形及原始玩家连续图集不变。伤害数值仅显示取整，不改变扣血。
- 验收：数字阈值和伤害取整规则；十蛛追敌、死亡补召、暂停和碰撞相关回归；桌面/390/320 昼夜同屏及资源未截断检查。记录截图、录制、正式入口及资源预算。视频素材生产不适用。
