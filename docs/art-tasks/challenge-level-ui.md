# 挑战等级界面任务单

执行依据：[美术生成标准](../art-generation-standard.md)。沿用美术任务单的目标、空间、交付、动画与验收结构。

## 1 目标与范围
- 名称/标识：挑战等级 / challenge-level。
- 类别用途：现有 HTML/CSS 购买和成长界面；不新增 UI 插画。
- 目标：挑战等级与消耗资源分离，当前阶级、下一阶所需清缴次数、购买所需阶级明确。
- 数量变体：成长概览、装备购买条件，共用一个排版组件；交易门槛/资源和战斗逻辑不变。
- 保留项：纸色、森林绿、原面板宽度、角色/武器/载具正式绘制与动作。
- 制作路线：原生 HTML/CSS；参考 src/styles/materials.css、src/styles/workshop.css。
- 使用场景：角色与载具收藏、装备追踪详情、武器/载具工坊。

## 2 造型与空间
- 剪影/差异：等级采用横向文字分组和分隔线；资源仍为图标网格，不给等级资源图标或库存数字。
- 主次：当前阶级为主，购买门槛并列，剩余清缴次数为次。
- 地面/邻接/活动空间：不涉及场景物件；文档流占位，不覆盖工作台和操作按钮。
- 光照：奶油色底、森林绿字，昼夜保持原面板对比度。

## 3 技术交付
- 逻辑尺寸：容器宽度自适应，手机 320/390 与桌面 1280；不新增固定位图。
- 像素尺寸/倍率、透明背景、锚点：不适用，DOM 文档流。
- 分层：独立挑战等级区域位于资源列表之外，工坊置于装备名下方。
- 碰撞通行：不适用，不改地图；弹窗沿用原暂停和关闭行为。
- 文件：src/ui/challenge-feedback.js、materials.css 及调用页面。
- 预算：无图片、纹理、Canvas 或计时器新增；复用已有渲染刷新缓存。

## 4 动画补充
不适用：仅 DOM 排版与文案，不更改帧率、源视频、动作片段、起停、身体或独立操枪部件。

## 5 制作约束
沿用森林绘本面板配色，不生成额外插画。等级不作为资源卡、掉落图标或扣费项目；保留秘境进度替代路线和主线购买条件。

## 6 验收记录
- 设计目标 designCriterion：challengeLevelSeparation（等级不混入资源，当前/需要/剩余清缴明确）。
- 正式入口：challengeLevelMarkup、requirementsMarkup、createWorkshop.renderQuote。
- 实机验收：320px 白天、390px 夜晚、1280px 白天/夜晚，正式启动、接取清缴、击杀 Boss、打开装备详情、转入工坊；等级区域无横向溢出，窄屏自动换行，操作按钮可点击。达到 2 阶后实际购买激光枪成功，清缴战绩仍为 3；未达到时按钮禁用。
- 载具验收：正式载具入口选择重型主战坦克，独立显示当前 2 阶、购买需 3 阶、还差 3 次清缴，消耗栏只有资源。
- 相关自动测试：tests/clearing-boss-qualification.test.mjs 共 5 项通过，覆盖正式胜场结算、全部阶级门槛、秘境替代路线、武器/载具/炮塔需求分区及购买保留战绩；未运行全量测试。
- 浏览器脚本：tests/clearing-boss-qualification-browser.cjs 的 4 种尺寸/时段流程全部通过，无页面异常。
- 系列一致/资源预算：通过；沿用奶油纸色、森林绿描边与原字体，保持正式装备展示；新增零图片、零纹理、零计时器。
- 场景遮挡/通行、实体动作真实性：不适用，未变更战场或资源绘制器。
- 截图：output/playwright/challenge-level-ui/details-320-false.png、workshop-390-true.png、workshop-1280-false.png、details-1280-true.png、vehicle-1280-night.png；同目录 result.txt / vehicle-result.txt 记录流程结果。
- 结论：通过 challengeLevelSeparation；等级/购买门槛与材料图标分区，下一阶所需清缴次数明确，桌面手机昼夜可读。
