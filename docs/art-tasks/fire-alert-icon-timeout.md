# 火警图标与十秒收起

执行依据：[美术标准](../art-generation-standard.md)，沿用[任务单](../art-generation-brief.md)六部分记录。

## 1 目标与范围

稳定标识 fire-alert-icon-timeout。将未接受火警的长条文字及“暂不参与”按钮替换为单个火警图标和 10 秒倒计时；点击仍打开正式救援详情，未响应自动结束本次邀请并进入原冷却。参考用户截图、原森林奶油色 UI 和消防配色；制作路线为代码原生 SVG 与 DOM/CSS，不生成位图。正式救援、返程和结算的操作栏保持。

## 2 造型与空间

图标为橙红警报灯中的小火焰、两侧警示线及深绿底座；与季节/角色图标的自然物剪影区分。外层奶油圆角小卡，倒计时置于下沿。沿原左下方告警锚点缩小占地，保留右侧菜单与底部生命/驾驶区。背景与笔触用森林绿、奶油及低饱和陶红，不闪烁或强光。地图、建筑、地面和通行边界不变。

## 3 技术交付

SVG viewBox 0 0 48 48、显示 40×40；按钮 60×72，外框随 DOM 定位，无像素图集、解码和缓存副本。倒计时从正式 offerRemaining 读取，暂停/详情/其他场景不倒计时，保存刷新续接；过期静默调用原清理与冷却流程。源文件 src/ui/fire-rescue.js、src/styles/fire-rescue.css、src/core/fire-rescue.js 和 src/progression/fire-progress.js。中文可访问名称包含查看火情与关闭剩余时间。

## 4 动画与保留项

静态 SVG，不适用视频、连续帧、肢体动作生产。仅倒计时数字逐秒更新，不使用闪烁。保留原火焰世界效果、角色操枪、消防借车、出入库及路线动作。

## 5 制作说明

删除未接警条幅中的长说明与拒绝按钮；以火警图案为主，简短“10秒”数字为辅。点图标进入原详情，详情暂停游戏及关闭计时；点击参加后取消邀请倒计时，切回原救援导航栏。10秒结束无需点击、无追加关闭吐司；消防站与玩法目录仍可再次接警。

## 6 验收记录

计划：实际10秒自动关闭、详情打开跨越10秒不误关、关闭后继续余时、临界接受不取消救援、刷新续接与下一次邀请重置；桌面1280与手机390/320昼夜同屏、触控区域与菜单避让。designCriterion: fire-alert-icon-timeout。实机结果制作后填写。
