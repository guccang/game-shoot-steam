# 世界森林消防美术任务单

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。本单从美术任务模板复制结构并填写，制作前方案如下。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称与标识 | 世界火警与消防站 / forest-fire-world |
| 类别与用途 | 常驻消防站、河岸取水设施、原树火焰/烟/余烬、水流、导航与告警面板 |
| 目标 | 在真实森林巡逻时看到原树着火；收到可拒绝的随机火警，或主动接警；从消防站驾车按真实道路到火场、到河岸取水。 |
| 数量与变体 | 1 座消防站、3 个取水点；两片随机林区，每片 3 棵起火树与 1 棵可蔓延邻树，最多 8 棵；最多 4 只火苗怪。 |
| 保留项 | 原森林树/湖山/道路/桥梁与碰撞；原猫视频连续帧、独立小手枪械、车轮位移相位、怪物完整动作与奖励车。 |
| 路线与参考 | Canvas 正式程序绘制；原消防车、树图集、消防基准与六类景观基准。 |
| 场景 | 真实四境森林；不创建圈内地图，不清空树林。 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 原红瓦值守屋拓展为双区消防站：值班门、车库、钟塔及水带架；河岸采用低矮泵与深入真实河道的吸水管。 |
| 结构差异 | 消防站区别于旧单门小屋的车库与塔楼；取水设施区别于建筑的低矮底座、泵轮和吸水管。 |
| 主次与留白 | 主体为着火的原树、消防车和水流；火焰沿树干与冠侧叠加，烟不盖满人物；站前停车与河岸干地开放。 |
| 地面衔接 | 站前踏石、泵下接触影；救援导航为细虚线路径，不画竞技场圆圈或覆盖原草地。 |
| 光向与邻接 | 左上亮顶/右下影；真实森林树冠、水界、道路共存；火焰局部暖亮，不全屏发光。 |

## 5 生成指令

沿用森林绿描边、奶油墙面、柔和珊瑚红消防主题；消防站突出车库与钟塔，取水设施真实接到河水。火焰贴着原树干向树冠攀升，用暖黄芯、珊瑚红外焰与少量灰烟体现火情。不得用独立火堆代替树、不清场、不覆盖水界，不用整棵树拉伸代替燃烧动作。

## 7 返站与音效修订（制作前，2026-10-23）

本轮目标：扑灭全部火点并清怪后保持同一消防车、位置和耐久，沿真实路网回消防站；在站前停车位停稳后结算，车仍保留在玩家身边。返程保存并可刷新续接，不再消耗救火倒计时；首通奖励在停靠后发放。

视觉范围：复用原消防车、消防站、原有路线、停车终点圈及HUD；不新增或修改美术形体、锚点、比例、碰撞或动画。路线终点使用既有站前(1460,1170)，停车范围34单位，停稳1秒。HUD明确“返站”和“停稳交接”。新结构差异、图集、源视频不适用（仅改变现有对象的生命周期和文案）。保留原猫、小手、独立挂载和车轮动画，沿用上一节资源预算。

音效计划：独立消防柴油机怠速/行驶、启动/停车、出警双音警笛、喷水、河岸泵补水及到站气刹，原创WebAudio合成并缓存。警笛仅在出警移动且未喷水/补水时播放，返程关闭警笛；遵守用户解锁、音效音量、暂停、后台、静音与卸载。

验收计划：真实驾驶灭火到返站停靠；返程与到站刷新；重复救援不撤车；停稳与奖励幂等；桌面/320/390昼夜截图；浏览器音频输出和循环停止验证。正式入口继续使用inspectFireWorld，新增设计目标fire-return-audio。完成记录如下。

### 返站与音效验收

- 结论：**通过**；designCriterion：`fire-return-audio`。新美术形体/动画不适用，沿用第6节原车、猫、建筑和树林基准。

## 8 车库待命修订（制作前，2026-10-23）

目标：交接后猫猫恢复步行，原消防车作为独立车库对象保留；关闭结果、离开和刷新不撤车，下次接警再取车。保留车辆耐久、成长、挂载和原猫连续帧。参考第7节消防站/原车基准。

结构：原车等比例1:1复用正式车体与挂载绘制，不缩小塞进原卷帘。将左车库拓宽为130单位净开口，卷帘收在顶部，深绿内壁、地板与门框包住车体；右值班塔、消防栓和原奶油/珊瑚红配色保留。建筑最大逻辑边界256×142，原底座锚点(1420,1100)；车脚底为站点偏移(-49,-27)，门前接车点不变。

分层：地面接触影→站房内壁/库内车体/独立挂载→门框与屋顶，建筑仍按原底座深度排序，背后猫猫使用原透显。车库是静态停驻，不伪造轮转或新增上下车视频；驾驶继续用正式位移车轮，步行继续用原同源视频帧。新增位图、视频、解码纹理均为0，仅增加至多一辆停驻车的绘制；无额外昼夜缓存。

碰撞与通行：沿用原建筑可通行和透显规则，扩大树林留白范围以容纳完整车库，不改河岸、水界或站前路网。验收覆盖站前/侧面/后方走位、320/390/桌面昼夜同屏、真实交接/离开/刷新/再接警、车辆唯一性与音效熄火。新地貌变体/视频源片/图集规格不适用，未生成新位图。designCriterion：fire-station-garage。
