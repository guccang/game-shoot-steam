# 对话打字机交互任务单

执行依据：[美术标准](../art-generation-standard.md)、[AGENTS](../../AGENTS.md)。日期：2026-10-30。

## 1 目标与范围

名称与标识：故事对白 `story-speech`、主线对白 `mainline-speech`。本轮为现有手机 UI 动态交互改造，无新增插画或位图。参考用户提供的雪团对白截图及正式奶油底板、森林绿描边。

目标：移除暂停讲述、倒计时与自动结束；打开对白逐字显示，点击正文或主按钮补齐全文，再次点击逐句继续；跳过结束当前完整对白并进入原后续操作。保留正式章节状态、选择、任务核验、奖励事务、姓名和场景构图。

实现路线：HTML/CSS 与正式渲染帧驱动；本轮不使用 imagegen，现有底板足够表达交互，没有精修图片需求。共享组件中的入职演出头顶短句维持原演出流程，仅适配移除的控件接口。

## 2 造型与空间

两种对白沿用统一底部停靠，姓名、正文和两个操作按钮分区。故事显示“显示全文／下一句／继续”，主线全文后显示具体任务动作；右侧统一“跳过对话”。正文预留完整文字高度，隐藏排版层与可见字层重合，不随换行抬升按钮。底板不改变镜头、地图碰撞或人物位置。

颜色、圆角、字体与昼夜场景沿用正式样式；不新增桌面布局。正文可聚焦，支持 Enter、空格操作；无障碍名称直接提供全文，避免逐字播报。触摸滚动与按钮操作留在对话内部。

## 3 技术交付

- `src/ui/dialogue-text.js`：可见文字时钟、全文显示、会话重置。
- `src/ui/speech-bubble.js`：共用文字、按钮与事件生命周期。
- `src/ui/story-speech.js`、`src/ui/mainline.js`：接入正式逐句、跳过和任务动作。
- `src/core/mainline-manager.js`：取消计时自动接取／交付。
- `src/styles/story.css`、`src/styles/ui-foundation.css`：文字稳定排版、触控及倒计时样式移除。

没有新增图集、纹理、音频或 Canvas 缓存；每个对白组件只保留一份当前文字状态，关闭与销毁分别重置状态、移除监听。后台与其他弹窗遮挡时不推进文字，不使用独立计时器自动跳句。

## 4 动作结构

正式渲染帧以每秒30字推进显示；长帧最多计0.05秒，避免后台恢复后瞬间跳完。真实角色动作、枪械、地面层和光照不变。入职头顶气泡仍读取同一帧演员坐标。人物动作源、序列帧生成、遮挡绕行和通行修改不适用于本次 UI 任务。

## 5 生成指令

未请求生成图片。用既有 UI 组件实现交互，保留尺寸、颜色和定位接口；不把动态文字或操作状态烘焙为图片。
