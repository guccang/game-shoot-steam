# 怪潮朝向镜头任务单

执行依据：[游戏美术资源生成标准](../art-generation-standard.md)。本任务只调整正式镜头构图，不生成或修改角色、环境及 UI 资源。

## 1 目标与范围

| 字段 | 填写内容 |
| --- | --- |
| 资源中文名称与稳定标识 | 怪潮朝向镜头 / horde-facing-camera |
| 类别和用途 | 营地守门怪潮的战斗构图 |
| 本轮目标 | 稳定观察方向前方七成、后方三成；自动攻击转向不再推动镜头，持续改变移动方向才平滑调整 |
| 数量和变体 | 北门、西门共用；手机和桌面自适应 |
| 保留项 | 原有缩放、角色真实连续动作、独立操枪、载具、碰撞、HUD 和普通玩法镜头 |
| 制作路线 | 程序化镜头偏移与按时间缓动 |
| 参考与同类资产 | 用户提供的北门手机截图；src/rendering/camera.js 原有安全边距 |
| 使用场景 | campDefense 全局内；离开怪潮平滑恢复原镜头 |

## 5 生成指令

不调用资源生成。按现有森林绘本美术绘制，仅修改怪潮镜头；前场七成、后场三成，斜向保持偏移与朝向共线，窄屏安全边界优先。转向持续缓动，不跟随新目标瞬切，不改变缩放、伤害、碰撞或 UI。

## 后续修订：自动攻击频繁转向导致镜头晃动

用户反馈原算法即使缓动，追随频繁变化的枪口方向仍导致来回晃动。本轮将镜头观察方向与自动攻击解耦：入场取营门外方向；使用原移动驱动速度判断主动行进，忽略攻击朝向和受击冲量；方向变化超过约 30° 且稳定约 0.45 秒后再调整。短暂走位、轻微摇杆摆动和停止不重新构图，保留已有七三比例、缓动、倍率、安全边界和暂停规则。

本节覆盖初版按 `player.angle` 实时跟随的合同。本轮验收通过：

- 正式自动攻击：白天、夜晚分别连续采样 197、219 帧，实际开火 6、7 次，枪口反复变化约 110°；角色相对视口的位置漂移均为 0 像素，观察方向保持朝营门外。
- 真实输入：三轮短促 A/D 闪避不翻转镜头；持续键盘向右、触摸摇杆向上后平滑调整，前方空间分别为 69.995%、69.994%。原移动、碰撞、受击和后坐分量不变。
- 昼夜同屏与设备：320、390 手机宽度及 1280 桌面窗口各完成昼夜截图；人工复核窄屏夜景和桌面日景，角色、坦克、敌群、拒马、地形及紧凑 HUD 清晰，保留原比例、遮挡和资源。没有新增美术或纹理，资源预算不变。
- 定向检查：`node --test tests/horde-camera.test.mjs tests/camera-safety.test.mjs tests/story-camera.test.mjs` 共 23 项通过，涵盖快速瞄准、短促移动、暂停、跨角度边界和会话切换；未运行全量测试。浏览器未记录页面或资源错误。

正式绘制器入口仍为 `src/rendering/renderer.js → CombatCamera.update`，设计目标仍为 `horde-facing-camera`。浏览器案例为 `tests/steady-horde-camera-browser.cjs`。证据保存在主工作区 `output/playwright/steady-horde-camera/`：`results.json`、`aim-and-movement.webm`、`320/390/1280-day/night.png`、`keyboard-east.png`、`touch-north.png`。本轮结论：通过，无待修订项。
