# 手推条播机（row-seeder）

## 2026-11-08 行列与建造权限

本轮扩展同一机具为按行、按列两种轨迹；尺寸、种斗剪影、锚点及图标不变。机具朝向、地轮、落种弧线、目标队列同步方向，身体仍使用原连续帧。先在加工厂制造成品并运回仓库后开放，选择和方向随存档恢复。无新增图片、图集或缓存，PNG 精修不在本次范围。

`designCriterion: row-seeder` 动态验收通过。[列向播种](../../output/playwright/farm-axis/seeder-column-moving.png) 来自正式手机运行；farm-axis-browser.cjs 触控选择空田和种子，完整播完同列三格，邻列已有作物保留。方向、建造门槛与读取存档均核实。主体轮廓及绿色描边沿用原机具，车轮与落种仍独立运动。行列单测涵盖反向、间断田区、重复安排、保存失败；共用短屏底栏检查见[本轮总验收](ox-plow.md)。正式绘制入口仍为 drawFarmTool，工作台 inspectRowSeeder 新增方向采样。

依据[美术标准](../art-generation-standard.md)与[项目合同](../../AGENTS.md)。本次使用现有 Canvas 2D 开发手推条播机及工具栏图标。目标为点一块田选种，猫推着播种机沿同一行逐格落种；有作物的格子保留。
## 造型与空间
参照正式单行推镰的轮径、木把和小猫的真实脚底，改用上宽下窄的种斗、可见金色种粒和下种管。轮毂按移动距离转动，种粒在每一格落种时从料斗下方排出。森林绿描边、草木绿机壳、奶油黄色斗口。工具约 44×35 世界单位，从握把至前轮独立于猫身体，图标复用同一绘制函数，按 88×88 画布输出。无需新增位图与图集。
## 交互与验收
既有武器、迎敌、作物图集、脚底排序与存档扣种事务沿用正式入口。验证手机触摸选行与选种、既有作物、缺种和中途取消，检查昼夜、短屏与原竖版容器。提供实际播种过程展示；静态 PNG 精修留待后续阶段。

## 正式实现与复核结果

- **程序与分层**　稳定标识为 `seeder`。主体、随行程转动的轮辐与手部握点由 `src/rendering/farm-tools.js#drawFarmTool` 绘制，脚底位置取自角色。单格动作共 0.68 秒，0.34 秒落种结算，图标通过同文件的 `paintFarmToolIcon` 复用主体。采用现有土壤、作物和角色资源，仅增加一张 88×88 图标画布，原始 RGBA 约 31 KiB。机械体无独立碰撞，行走沿用角色碰撞与安全站位；新程序图形无需外部素材或生成图提示词。
- **田行和库存**　浏览器实测从带胡萝卜的田格选中横行，点选 3 粒雏菊种子，实际种满同行其余 3 格，下一行 4 格仍空。定向单测覆盖反向行进、余种不足、分隔的田区、重复安排、行走取消和存档失败后的重试。
- **画面与触控**　手机浏览器触摸模拟的 390×844 白天与夜晚实测，料斗、地轮及握把随猫在作物前移动，既有作物可辨。320×568 工具按钮实测宽高至少 44 px；1280×720 窗口使用原竖版容器。完整交互在浏览器中运行，未使用实体手机。
- **证据**　[实录动图](row-seeder.gif)。原始录屏和选种、播种、白天结果、夜景、短屏及宽屏截图由 `tests/row-seeder-browser.cjs` 写入 `output/playwright/row-seeder/`。其中 `demo.webm` 为完整录屏。
- **结论**　`designCriterion: row-seeder` 通过本轮开发验收。工作台入口 `src/rendering/visual-review.js#inspectRowSeeder` 采样正式队列和实际轮程，正式画面由游戏浏览器实录复核。
