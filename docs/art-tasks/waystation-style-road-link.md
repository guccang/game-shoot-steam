# 驿站站牌换装与营门道路衔接

## 任务与参考
动态交互开发阶段。参考用户驿站木牌与营门截图，延续森林绿描边、奶油牌面和草木平涂。目标：五款站牌可预览购买，单站独立应用、全站共用解锁；站点位置、名称、编号、用途与导航不变。营门内外道路在同一开口衔接，门位或营地扩建后同步更新。

## 结构、尺寸与分层
原木屋檐沿用旧牌；石拱采用石质双柱与圆拱；金属采用铆钉框与金属横梁；春节采用红檐与双灯笼；圣诞采用积雪屋檐与松枝。主体牌面94×42，屋檐及挂件约110×100，脚底锚点不变。文字由程序绘制，夜间统一压暗，碰撞沿用原标牌无实体障碍。装饰不进入可搬迁摆件列表。道路为地面层程序绘制，门宽与围栏碰撞保持既有规则。

## 技术交付与预算
使用Canvas正式画笔及手机UI底板，不生成位图，无新增解码内存。站牌菜单折叠时不绘制商品预览，只有打开项创建画布。门外连接按布局缓存，不在每帧扫描整张地图；保持有界数量。保存失败金币、外观、坐标与导航状态均不改变。

## 动画与素材
本轮无新增角色或机械动作，真实连续帧与独立武器不变。无imagegen或PNG替换，新增造型由程序开发；不以静帧变换代替动作。资源加载继续使用既有明确失败流程。
