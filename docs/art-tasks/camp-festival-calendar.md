# 营地节日日历、装饰扩展与庆典广场

依据：[美术资源标准](../art-generation-standard.md)、[AGENTS](../../AGENTS.md)、[手机 UI](../ui-foundation.md)。本任务从美术生成任务单复制，以下按实际范围填写。

## 1 目标与范围

| 字段 | 内容 |
| --- | --- |
| 名称与标识 | 营地节庆，camp-festival-calendar |
| 类别和用途 | 手机日历、营地摆件、路灯、庆典环境与舞狮程序动画 |
| 阶段 | 动态效果开发；Canvas/HTML 正式实现。PNG 精修为后续阶段 |
| 制作前目标 | 手机查看游戏节日；已购套装自动或手动换用；50种装饰、8种路灯；中央广场留白；春节春联舞狮及夜间烟花 |
| 数量 | 12套节庆陈列、50种可购装饰（含8款路灯）；实例上限60 |
| 保留项 | 猫猫真实视频连续帧、独立枪械、怪物、载具动作；原建筑位置、入口、停车位、道路和用户已摆物品 |
| 制作路线 | 沿用现有程序画笔延伸独立剪影，本轮无需 imagegen 位图；以后精修不能替换独立动作时钟 |
| 参考 | camp-decor.js、lighting.js、art-reference/landscape-six-day.png 与 landscape-six-night.png |
| 已确认目标 | 森林绿轮廓、奶油黄和柔和草木色、三分之四俯视，脚底排序及低密度庆典陈列 |
| 后续精修 | 可替换摆件静态纹样为透明PNG，保留尺寸、ID与灯光、舞狮独立部件；不计入本轮完成项 |
| 使用场景 | 地面主营地；剧情、室内、秘境、营门战不增加节庆陈列 |

## 2 造型与空间

| 字段 | 内容 |
| --- | --- |
| 主体剪影 | 盆景、花箱、座椅、桌台、石雕、水轮、井、各节日陈列均使用独立结构 |
| 变体差异 | 八款灯分别为红灯笼、球灯、双枝、莲花、蘑菇、星形、竹节、石亭；改变灯头轮廓、横臂、杆件与底座，不只换色 |
| 主次关系 | 中央庆典广场为主景，生活庭园、营门迎宾和工坊休憩为装扮建议区；春节两件边缘陈列，中央舞狮 |
| 地面衔接 | 广场使用低对比奶油石地和四角纹样，保留原横向通路；不添加实体围栏或台阶 |
| 活动空间 | 广场中心(90,740)，200×100世界单位；禁新建筑、开垦和永久摆件，完整高摆件也不能遮进广场 |
| 旧档兼容 | 旧档占用不强制迁移；暂停表演和主题陈列并在日历提示，手动收纳或搬迁后恢复 |
| 邻接关系 | 两工坊之间、猫窝西侧，门口、停车及大门规则继续沿用正式放置校验 |
| 光向 | 延续现有左上受光；路灯使用原局部光池、迷雾清除和照明采样；夜景共用形体 |

## 3 技术交付

| 字段 | 内容 |
| --- | --- |
| 逻辑尺寸 | 每件目录独立宽深高，新增宽36–100、深22–44、高40–124；沿用原摆件规格 |
| 画布与倍率 | 商品图128×128；世界按相机投影。节庆边缘陈列缩放0.55，日常购买摆件原尺寸 |
| 锚点 | 摆件/路灯底座；狮舞脚底位置与局部迈步分开；春联绑定正式小屋门框和营门柱 |
| 分层 | 广场地面→脚底实体（摆件、狮舞、角色）→局部烟花；路灯进入原灯具队列 |
| 程序职责 | 日期、收费、存档、自动/手动切换、碰撞、灯光、暂停和动作时钟 |
| 替换接口 | 保持catalog id、width/depth/height、脚底坐标、事件与交易接口 |
| 透明背景 | Canvas局部图元无不透明底板，接触影独立；商品底板由UI提供 |
| 碰撞 | 购买摆件沿用底座矩形碰撞；节庆临时陈列、舞狮与烟花不新增阻挡 |
| 昼夜 | 正式夜色合成；购买灯具接入visibleLights、局部照明与地面迷雾 |
| 文件 | config/camp-festivals.js、world/camp-festivals.js、world/camp-plaza.js、rendering/camp-festivals.js、rendering/camp-decor-expanded.js、ui/camp-calendar.js |
| 内存预算 | 无新增位图、无额外常驻离屏场景；60件实例；节庆2件陈列+1个狮舞；烟花最多24粒。广场占用按存档/布局/农田引用和数量缓存 |
| 缺失行为 | 扩展目录的未知绘制form明确抛错；坏存档ID由白名单排除，不回退为另一款资源 |

## 4 动画

| 字段 | 内容 |
| --- | --- |
| 动作与时长 | 狮舞16秒周期，前段低头、中央摆步、末段行礼；水轮转动独立轮辐；烟花8秒循环、单次2.2秒 |
| 时钟 | 使用正式game.time，暂停保持姿态；减少动态固定舞狮与水轮，关闭烟花 |
| 来源 | drawFestivalLion / drawExpandedDecoration / drawFestivalFireworks 程序部件，无声称源视频或复制帧 |
| 尺寸与锚点 | 固定舞者脚底，前后舞者四条腿局部交替，头、眼、下颚、布身各自变化 |
| 起停 | 暂停不重置姿态；手动切换套装不重置游戏时钟 |
| 局部动作 | 前后迈步、布身错相起伏、狮头行礼、眨眼、下颚开合；不对整图缩放或旋转模拟舞蹈 |
| 独立部件 | 舞狮各部件与猫猫操枪互不关联；原小手、武器、后坐和载具机制未修改 |

## 5 生成指令

本轮未调用imagegen：属于现有Canvas系列的动态开发，新增代码画笔与程序图元作为本阶段正式交付。后续PNG精修需以本轮正式场景截图为参照，沿用森林绿描边、柔和有限平涂、统一俯视比例、底座与独立部件，禁止烘焙动作、UI文案或不透明地板。
