# 原版击退恢复

用户明确指定 adc572d（首次削弱松果战车之前）作为手感基准，并要求连续命中继续补充向上速度。

- 恢复全目录冲量：手枪 32、散弹每颗 19、狙击 110、脉冲 165；松果机枪 80、坦克炮 1150、火神炮 45、潮汐炮 340。其他武器及榴弹爆炸也恢复同版本配置。
- 撤去后来逐武器增加的低推力上限与地面滑动模式，使用原版普通怪逐轴限速；普通 520、重炮 760、潮汐 620。
- 连续命中正常叠加推力、补充向上速度、刷新失衡并打断攻击；没有松果专属连射衰减、距离预算或腾空抑制。
- 保留分体型动作：圆形团怪翻滚，铁甲踏步护盾，植物根足踉跄，炮车轮胎及悬挂缓冲，飞行怪收翅振翅。
- 对未达到失衡阈值的弱击退，同步平移扑击轨迹的起终点，避免下一次 AI 更新抵消位移。
- 伤害、射速、射程、弹药、成长、奖励与获取条件不变；领主独立抗性与营地援军显式推力限制继续有效。恢复后的更强动量仍会影响碰撞附加伤害、控制与后续命中机会。

验收：37 项直接相关测试通过；另与 adc572d 正式物理作 126 组、每组 360 帧对照，位置、速度、高度和硬直误差为零。12 组正式战斗覆盖手机/桌面昼夜及八类枪炮，六秒连续录制验证连射、走位与停火落地。未运行全量测试。
