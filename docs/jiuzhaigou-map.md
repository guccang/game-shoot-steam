# 九寨沟地图与旅行入口

战场功能菜单 →「地图」→「九寨沟」→「继续探索」。同一面板可以返回四境森林；手机先展开右侧功能菜单。

地图以九寨沟的日则沟、则查洼沟与树正沟组织 Y 形谷地，使用五花海、珍珠滩、长海、五彩池、诺日朗和树正群海的景观特征。地理距离、湖泊尺度与高差按游戏压缩，不是等比例导览地图。八个湖滩、三条连接水系和四组叠瀑采用共享轮廓；林地混合原有针叶、阔叶和桦树，湖岸分布低矮草木、苔石及少量秋色。

外围增加七片连续林坡，以高处针叶林、谷地针阔混交林、低矮蕨草灌丛和苔石形成景观层次。坡地与地被可通行，水体、跌坎和树干保留正式碰撞；两岸游径、出生点和牌前清空树木，不以密集障碍填满地图。

八个湖滩、四组瀑布各设一块地名牌，另有日则沟、则查洼沟、树正沟三块沟谷牌，共十五块。沿用森林木柱、奶油黄牌面和绿叶徽标，副标题注明沟谷与景观方向；广角适度放大，遮住玩家时透显。区域地图上的 1–15 号标记与文字目录一一对应。树正上湖、下湖及上下叠瀑是游戏中的群海分区名称，并不表示额外官方景点。

参考：[UNESCO 九寨沟生物圈保护区](https://www.unesco.org/en/mab/jiuzhaigou-valley)、[世界遗产景观说明](https://whc.unesco.org/en/list/637/)。保留原版森林绿描边、奶油色钙华、有限平涂和原有角色比例。

湖、溪流和瀑前浅滩现在先取几何并集，再按弧长收圆接岸，整条水系只保留一条可见外岸。该轮廓同时用于步行碰撞和周期地图，索引边段降低查询成本；导航仍使用各湖瀑的局部包围盒节点。瀑坎采用独立曲线边界继续阻挡两栖载具。岸带使用圆帽短弧改变宽度，低对比草岸与钙华衔接浅水，避免法线外扩产生新的凹角折叠。

## 游戏状态与边界

- 两图共享成长、波次、生命、弹药与车辆耐久。旅行不重新发放奖励、不补血补弹；现存敌人保留血量和波次配额，在目的地周围重新落位。
- 同页往返保存各地图树木、树桩和上次位置，首次抵达落在入口。刷新保存所选地图，沿用原巡游检查点规则，在该地图入口恢复；不承诺刷新保留精确坐标或全部现场实体。
- 湖水阻挡步行和战车；气垫船可过湖，不能攀过瀑布跌坎；直升机可飞越，下车使用当前地图寻找安全干地。
- 领主战、死亡与秘境内禁用旅行。秘境沿用原森林选区，退出恢复进入秘境前的地图；秘境检查点刷新同样处理。
- 图块缓存切换时释放。雨滴表面、区域等级、出生点、追击和降落显式携带地图身份，不使用全局可变地图状态。

## 文件职责

- `src/world/jiuzhaigou.js`：湖滩、水道、叠瀑、植被与通行数据。
- `src/world/water-outline.js`：裁去水体内部重叠边、闭合接岸、等距平滑及同源碰撞索引。
- `src/world/maps.js`：地图名称、入口和玩家说明。
- `src/rendering/jiuzhaigou.js`：正式地表、水帘、涟漪和白沫；减少动态模式冻结流动。
- `src/rendering/jiuzhaigou-landscape.js`：可通行林坡与低矮地被，进入静态分块缓存。
- `src/rendering/signposts.js`：森林区域牌和九寨沟地名牌共用正式绘制器。
- `src/core/map-travel.js`：旅行事务、共享战斗状态及各地图运行时植被。
- `src/ui/panels/map.js`：旅行卡片、同源小地图和区域说明。

`visual-contract.json` 的 `jiuzhaigouCriteria` 绑定正式绘制器，`src/rendering/visual-review.js` 提供湖泊／叠瀑／林坡地名牌 × 昼／夜六组连续案例。

| designCriterion | 验收证据与结果 |
| --- | --- |
| `jiuzhaigou-water-system` | 实际地图预览呈现 Y 形连通水系；湖中心、岸边、周期镜像与瀑坎由集成测试验证。正式场景复核青碧水层、沉木和浅色钙华。通过。 |
| `jiuzhaigou-flow` | 四组工作台案例各采样 0／0.125／0.25／0.375 秒；帧图发生变化，减少动态模式的水流单独比较保持不变。浏览器复核连续水幕和落点白沫。通过。 |
| `jiuzhaigou-vegetation` | 所有生成树木检查水域排斥；正式五花海、珍珠滩和入口画面检查混交林、岸边草木及留白。通过。 |
| `jiuzhaigou-day-night` | 390 和 1280 宽度实际同屏小猫、持枪、怪物、履带车、湖瀑与 HUD；检查昼夜轮廓。320／390／1280 面板无横向溢出。通过。 |

| `jiuzhaigou-landmarks` | 十五处逐站检查正式 Canvas 提交名称和副标题；单测检查每个湖滩瀑布有且仅有一块同名牌，牌脚与牌前在干地。白天／夜晚同屏检查五花海、诺日朗与日则沟木牌。 |
