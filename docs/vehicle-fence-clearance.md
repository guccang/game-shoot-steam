# 载具栅栏碰撞修复

驾驶沿用步行12单位检测导致松果战车45单位宽的车轮穿栏。栅栏改用车型底盘的横纵占地，正面底盘不随瞄准旋转，炮管与阴影不计入地面占地。其他地形碰撞保持原规则。

当前载具在上车、每次模拟步和正式移动前绑定，自动停车、导航、后坐共用检测；下车立即恢复步行范围。旧档压栏允许向原侧退开，禁止继续穿栏；飞行沿用原跨栏规则。

验证：vehicle-fence-clearance.test.mjs三项通过，defense-current-gates.test.mjs一项通过。覆盖横纵围栏、重型履带、斜向贴栏滑动、大步长接近、宽门通行、下车及旧档退开。手机正式浏览器昼夜检查见output/playwright/vehicle-fence-clearance/day.png、night.png、report.json与video/，实际轮子保持在栅栏内侧，无页面异常。

纯物理逻辑修复，不修改美术资源、绘制器、动作或UI；昼夜画面作为碰撞与实际轮廓对照。
