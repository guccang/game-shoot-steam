## 中后期配套与长周期结果

只移除怪物木材会放大木材瓶颈，原450金币升级上限使后期金币持续闲置。因此分离费用上限：单次金币上限改2400，木材上限保留180；追赶仍按同类3折，部件不追赶。手持与角色1→5、教学部件1→2价格不变，现有属性收益不变。高级车体/部件可能更早触及旧金币上限，不承诺它们的所有低级价格不变。不追扣旧投入、不撤销资产。

每条路线100个固定种子（1–100），按时间顺序交易，失败、入职、移动、休整、施工同预算。默认自由活动权重为森林45%、远征20%、塔15%、守护15%、采集5%；主线指定活动另行执行，5%不是全程固定扣除的时间。

**限制保留：** 包含当前入职成本与演出，首次升级标准5.39分钟、低效7.15分钟，原「前5分钟」目标仍未达；低效率前中期最坏空档28.97分钟，后期指标通过不代表全程通过。随机清缴地点、主动路线选择和实际战斗技术仍用显式速度/返程假设，长周期不是逐帧战斗或真人全程实测。此次未重新做真人30分钟试玩。
