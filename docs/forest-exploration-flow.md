# 安全聚落与森林探索流程

## 玩家循环

在木门内整理装备、听邻居闲聊、接故事或清缴任务；出门沿真实道路到野外地点，完成探索与战斗，再回聚落交付、升级。主线给资源与目标，永久装备继续按原有购买和任务资格规则取得。

## 安全聚落与清缴

- 晴叶营地、邻里小院采用共享配置的矩形边界、木栏与四向木门。栏杆阻挡地面移动，门前让角色和载具通行；野外敌人不能通过门洞或飞行侵入。
- 聚落内禁止随机遭遇与清缴刷新，敌方伤害、越界弹道、领主技能及援兵均受保护规则约束。
- 在告示牌接取 **Boss 清缴任务**，前往东林清缴场 `(1600,400)`、半径 300 的区域才启动节点和波次计时。该点在营地外的低等级林地，避免把第一场手枪教学搬进高等级区。
- 每组固定五波，清完自动进入领主战；胜利后可在结算页直接领取下一次清缴，以点击领取时的玩家位置为起点，在1000–3000米范围内随机生成新地点并更新导航，无需回营；也可关闭结算后回告示牌接取。清缴结算等待玩家选择，不再三秒自动关闭。离场、回营暂停清缴，进度保留。接取尚未到场时，野外移动仍有独立随机遭遇。配额、在场上限及属性成长见[清缴节奏](clearing-pacing.md)。
- 常规波次不在九寨沟或教学试射区自动出现。故事、秘境及消防继续使用自己的流程。

## 故事空间

战斗半径和伤害、人数、奖励不变；所有故事战场整圈与聚落边界分离。实际碰撞规划允许绕桥、绕山和走门，不再要求远方地点之间能直线走通。

主要长途任务节点间距为1000–2000米，使用循环世界最近镜像距离，与导航读数一致；每条线路保留明显长短变化，第一章近道仍短于主路。该规则取代旧的“每段基础步行10–20秒”，详见[任务节点距离调整](art-tasks/mission-node-distance.md)。

实际步行路径仍须绕桥、绕山和走门；导航距离不等于绕障后的路程或固定耗时。测试保留正式路径规划与逐段移动到达检查。载具更快；试航、水面转向、桥面和同一工作点内交互为局部操作，不刻意拉长。普通远行不再从交谈点直接传送进守点或领主战，章节完成后需要带回信走回营地。

## 邻居与导航

- “帮个忙”先列当前请求，明确下一步、资源报酬和“在这里继续/带我过去”。可接请求显示“接下请求”，远处可先“去找某位邻居”。
- “找邻居”展示本人当前生活与愿望，“回信”保留完成后的关系变化。整组谢礼折叠展示进度，办妥全部故事后展开。
- 居民在镜头内随机说一句短话，6 秒消退，间隔 10–20 秒。一屏只出现一条，不移动镜头；菜单、主线对白、剧情期间让位。探索线索均对应现有花圃、集市、武器、气垫船、高塔或清缴。
- 会面、交付、已接清缴的赶路阶段自动导航；购买、升级、攒资源默认不画路线。点任务后才定位操作地点，当前操作改变时解除旧导航。
- 手动找邻居与已追踪任务共享唯一地面指引，抵达后返回原任务；清缴战斗中不画返回教学 NPC 的路线。

## 接送旅程

公交站位于营地北侧林道 `(490,-650)`（循环地图的北侧镜像）。小电动车沿纵向林道向南穿过北门，20 秒到达当前小屋门前；路线终点随小屋位置同步，不再要求旧版大于1200单位的路长或大于60单位/秒的速度。其余导览在建筑前展开。松伯谈邻居的生活、工具成长和真实可探索的地点。右下角“跳过这段旅程”完成原定工具交接，仍停在采木教学；不会发手枪或跳过修复、制作。
