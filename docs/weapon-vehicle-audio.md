# 新枪械与载具音效更新

2026-10-29：现有电锯合成音杂音明显，项目暂无合适的电锯录音，正式播放和试听导出均禁用电锯音效。手持及伙伴的空转、切割接触、命中和充能提示保持静默；伤害、采集和其他武器声音继续正常工作。静音在音频缓存与声源创建前拦截，不占用循环声源或影响其他声音的混音。

2026-10-22。本任务仅修改音频与真实动作事件，不修改画面、碰撞、数值、弹药或存档。程序化绘画、美术图集、昼夜同屏比例及通行验收不适用。

## 声音与动作

| 对象 | 音色与触发 |
| --- | --- |
| 车载机枪 | 短爆音、低频枪体与延迟枪机声，每发触发 |
| 125 滑膛炮 | 压力爆音、低频炮声、空气尾响及炮闩回位 |
| 火神炮 | 更短、更轻的连续机械爆音，支持升级后的最快射速 |
| 潮汐炮 | 低频水压脉冲与喷流，每根喷口实际发射时播放，间隔 0.12 秒 |
| 机械核心 | 独立重装爪声，逐只部署的伺服启动及锁扣声 |
| 机械蜘蛛 | 小蜘蛛短促爪击，与机械猫区分；成功出舱时响舱门伺服及锁扣声 |
| 四种载具 | 分别使用轻型发动机、低频重型发动机、旋翼拍击、气垫风扇；启停声按车型匹配 |

手持/挂载武器继续按实际枪型路由；蜘蛛母体的脉冲或挂载枪沿用对应枪械音色。声音由真实攻击/部署事件触发，不创建延迟计时器补播。停车后依据真实速度回到怠速，不再把持续累积的行走相位误当成行驶速度。

## 实现与预算

- 正式入口：`src/platform/audio-machines.js`、`audio-sounds.js`、`audio.js`；游戏事件经 `src/app/game-events.js` 分发。
- 音色使用独立确定性随机源，不消耗战斗随机数。按需生成 22050 Hz 单声道 PCM，并沿用缓存、并发上限与总线压缩器。
- 新模块源码 3772 字节；16 种机械/启停音色全部加载为 678716 字节 Float32 PCM。四车型循环合计 705600 字节；瞬态最多 20 个，载具循环至多 1 条，不逐发生成缓存。
- 不新增运行音频素材下载。试听 WAV 位于忽略的 `output/` 下，不进入游戏资源。
- 浏览器实际重采样后，六种攻击峰值约 0.423–0.666；规则测试验证全部音色有限、非静音、无单音色削波且各自不同。
