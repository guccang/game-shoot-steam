# 清缴与任务成长节奏验收（2026-10-25）

基于 `4af06d9` 的当前玩法实施，旧评估见 [task-economy-audit.md](task-economy-audit.md)。本次只合并清缴、主线及工作台相关改动；原 `codex/economy-json-runtime` 保留独立，不纳入合并。

## 实施结果与适用范围

默认混合战斗、入职后不额外伐木、基础失败率8%、移动占比22%、约4分钟回访工坊、6分钟短途秘境。标准路线100种子全部完成，P50在8–12小时；标准及低效率默认路线后期空档全部不超过12分钟。[验收门槛](balance-reports/task-cadence/acceptance.json)全部通过。

这不是所有打法都达标的保证：纯清缴、严格囤装及高失败率路线仍有明显长空档，详见下表。低效率完整主线需要更长总时长，不能把旧模拟的15小时上限当成新主线承诺。

## 奖励与成长调整

- 清缴金币改为五波固定预算 **250／250／300／300／400**，合计1,500；木材为40%，合计600。每组增加10%，最高2倍，即3,000金币／1,200木材。怪数、怪物属性、领主快照不变。
- 材料抽取预算为 **4／4／5／5／6**，同组倍率增长并封顶；按击杀序号分配整数份数。抽取为0的怪不推进保底，非清缴遭遇继续原掉落。死亡和刷新沿用已结算序号。
- 29步主线金币 **12,700→7,760（减少38.9%）**；木材 **4,570→3,110**；零件39、晶体25、核心1保持。前四项教学420金币／170木材不减。
- 购入高级控制器后的奖励集中为 **1,500金币／600木材**，帮助新装备追赶成长，避免买完装备后余额过低、连续失败造成长等待。并不返还购买费用或免除首次材料。
- 领主教学增加手枪/散弹枪5级、栗子5级；登塔前一件主力武器10级；高级资格前一件主力武器15级；收尾要求控制器15级、栗子12级、一辆主力车体10级和一门主炮12级。
- 现有购买配方、升级450金币封顶、30%同类追赶与属性成长保持。主线引导随未达标项切换到真实工坊或角色入口。
- 已完成任务记录、库存、所有权、部件及等级不追扣、不撤销、不补发。未完成任务使用新目标和新奖励。已有大量库存继续保留；进行中清缴只对后续击杀应用新预算，已领取部分不追扣。

静态最低消费台账：[budget.json](balance-reports/task-cadence/budget.json)。按指定条件第一分支计算金币总成本74,085；它只核对交易，不代表实际通关消费或通关时间。

## 模型同步与证据边界

1. 正式游戏、工作台与命令行共用 `clearingKillReward`、`mainlineReward`、`awardMainline`、正式交易及成长规则。任务以稳定ID关联；奖励展示、克隆候选和最后到账一致。
2. 模拟从入职最低钱包开始，显式计90秒入职；按29步主线、五波清缴、领主及任务资格执行。活动、往返、施工、失败和故事使用同一时钟，任务奖励按顺序领取。局内钱包不记入永久收入，剧情借装不算购买。
3. 工坊4分钟回访是玩家策略，不是冷却；平衡策略在停顿4分钟后可用余额支付一次升级，优先攒装备保留严格预算。秘境逐关结算，结束出征才进行永久交易。余额不足用共享缺口先预检，减少无效存档克隆；优化前后代表种子逐字段一致。
4. 收尾要求实际形成武器15／角色12／车体10／主炮12的可用配置，同时完成主线和购买清单；不能只攒齐价格就宣布通关。
5. [combat.json](balance-reports/task-cadence/combat.json)使用正式 `Game.update`、射击、装填、走位、受伤与结算，共15个固定装备样本。首组双5级2/3完成、1死亡；双7级步行和轮式车各3/3完成，均值209.3/201.1秒，因此车炮速度收益保守取4%。中期1/3完成、2超时；后期0/3在600秒内完成。固定环形走位会漏掉尾怪；这些失败不当作玩家失败率，也不用于假装完整通关。
6. 后期正式样本600秒内约190–208击杀，加入补怪约束：一级基准22只/分，中后期原始吞吐上限为基准×1.3×效率，另计22%现场移动。伤害提升不会无限提高模型击杀率。该上限是样本校准近似，非逐帧模型。
7. 故事时长、生活委托、失败率与返程仍是显式假设，集中在 `campaign-timing.js` 和情景输入。默认不计误击树木的有限额外资源；实际首组可能因此更宽裕。全程8–12小时属于模拟估计，不是真人连续长周期实测。
8. 配置版本3新增清缴与逐项任务奖励。导入版本1/2时补当前任务/清缴预算，保留原有其他价格；严格验证缺项、非法数值。旧费用对照使用当前任务结构，不是旧版本全流程复现。游戏仍读仓库正式配置，工作台编辑不会直接发布。
