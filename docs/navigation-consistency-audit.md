# 任务导航一致性检查

检查日期：2026-10-28。本轮延续登塔任务修复，核对正式任务提示、插值画面的路线目标与终点标记；不修改任务完成条件、奖励或建筑权限。

| 类别 | 当前内容表覆盖范围 | 核对内容 |

## 发现与修复

1. 临时访问意图存储在正式游戏对象的WeakMap中，插值快照有不同身份，因此地面可能回到主线旧目标。新增明确的快照来源登记，导航选择与抵达判断读取正式游戏对象；角色位置仍可正常插值。
2. 有邻里追踪时，主线修复前置可能只接管地面路线，任务卡仍显示邻里，且邻里路线和终点继续叠画。任务卡采用相同的修复/临时访问优先级；这些目标或施工接管时隐藏邻里路线，未改邻里进度与追踪存档。
3. 临时目标的抵达判断只比较坐标，跨地图同坐标可能提前撤销导航。加入地图一致性要求；异地图不画出本地图的假终点。
4. 移动居民的目标读取正式当前位置，与任务卡共用来源，避免插值快照反向影响临时访问目标或委托终点。
