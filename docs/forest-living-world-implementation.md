# 森林常驻生活圈实施记录

本期范围为四境森林的晴叶营地、旧哨站与怪物邻里。沿用 HTML/CSS/JavaScript、Canvas 2D 和现有角色、美术与战斗系统。九寨沟、秘境和六章主线继续使用原有战斗流程。

## 已接入的体验

- 正式世界日历：24分钟一天，白昼12分钟、黄昏4分钟、夜晚8分钟；每季7天、每年28天。暂停、阻塞对话、后台及离线不补算时间。安全地点可休息到下一时段，已有委托不失效。
- 旧版独立累计的年、天保留在游玩档案，新增日历单独迁移。正式日期决定季节与光照；原快速切换收在 Debug 环境预览中。
- 安宁的聚落与连接道路：普通森林默认不刷连续波次。邻里面板接取巡护后，在危险区域恢复原有完整波次与领主成长。生活区约束出生、移动遭遇、追击、远程弹丸、领主羽刃与伤害。
- 六位常驻居民拥有工作、关系、愿望和昼夜作息。人物沿路移动，天气变坏时去厨房、哨站或栖架避雨，交谈期间保持位置。小夜连续升降到栖架，不瞬移到高处。
- 玩家选用薄荷或雪团时，对应独立居民隐藏，相关交付由另一位关系人物承接。林外领主挑战明确标注为训练投影，与生活居民分开。
- 三条邻里委托在大地图原地推进，委托板与当面发现共用状态。夜班包含实际击败五只受惊野团的护路段；刷新或中断只重建尚未击败的数量。
- 午餐留下木碗、次日白昼末段的洗碗和阿团吃饭；夜班留下大字交接表与轮班；集市留下陶盆，并在每七日开放摆摊作息。
- 三条故事复用旧首通奖励账本及整组装备谢礼；旧已完成记录直接显示后续，不要求重做。保存失败时任务和钱包不提交。
- 六章主线完成结果直接投射为常驻补给、木料、维修、工具、夜灯、广播设备及回信。章节快照不能回滚永久结果。
- 临近只展示一个交互按钮；完整记录收在可选手记。厨房、工具、信纸和夜虫使用低频、按距离触发的合成音效。

## 入口与操作

1. 入职完成后，打开“邻里”，或走近晴叶驿牌、怪物邻里委托板。
2. 在“委托”接取请求，沿地图中的生活道路寻找人和物。人物会换班，目标距离和地图位置跟随本人。
3. “近况”查看关系和日程，“回信”查看帮助后的结果，“手记”回顾已听过的短句。
4. 面板底部可安全休息、接取或结束巡护。结束巡护保留已有波次资格。

## 实现边界

配置位于 `src/config/living-world.js`；历法与空间规则在 `src/world/living-*.js`；状态白名单在 `src/progression/camp/living-world.js`；常驻规则和事务在 `src/core/camp/living-world.js`。绘制、声音与界面分别位于 rendering、platform 与 ui，继续使用现有存档服务和弹窗暂停归属。

居民使用稳定标识和独立动作时钟。六人始终更新，不依赖第一次进入镜头才开始活动。当前未建设复杂经济、好感刷取、衰老、饥饿、离线灾难或全地图扩建。

## 美术与性能

验收入口为 `visual-contract.json` 的 `forestLivingWorldCriterion`，正式采样函数为 `inspectLivingWorld`。任务单、截图与录像见[生活圈美术任务单](art-tasks/forest-living-world.md)。

没有增加下载图集、音频或运行视频。新增运行源码初次统计约52KB，合并压缩约20.5KB；最终数值记录于证据目录。设施透明缓存最多18份320×320画布，上限7,372,800字节（约7.03MiB）；居民及工具动作不缓存，卸载释放设施缓存。

性能比较使用同一桌面浏览器1280×900、晴天、邻里位置，旧版基线单独关闭强制刷怪以比较生活场景。它记录主线程工作与回调间隔，不代表实体手机性能。初次新增场景绘制耗时上升，因此增加静态设施缓存后复测；原始采样保留在证据目录。

缓存后五秒采样301帧，回调间隔均值16.67ms，主线程工作均值6.29ms/P95 10.9ms，绘制均值5.14ms/P95 7.0ms。基线绘制均值9.17ms/P95 17.8ms。宿主负载和采样时刻不同，这些结果用于记录本机可运行性，不把全部差值归因于缓存优化。
