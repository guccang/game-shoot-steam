## 结论与现状

采用「永久建设＋按实际使用消耗的效率服务＋余料兑换」。基础功能不需要供料，额外效率需要持续供料。不能靠无限涨价或离线欠费强行清空库存。

关键问题是联产：矿物卸货每份同时增加1原石和1份本层原矿。铜、铁、稀有原矿分别来自第1、2、3及更深层；不是三种矿同时获得。金属需求越多，伴生原石越多。原石存于 `mining.ore`，切制石块存于 `materials.stone`，两者不能混称或重复扣款。

现行原石用于矿轨、矿车、竖井、开层和农矿设施；石块用于部分车体。小屋加盖、阳台、电梯没有矿产费用。已有反复消耗包括金属提炼用木材、弹药、维修和农产补给，因此应补齐原石和工业材料的经营用途，而不是重做所有消耗。

## 时间口径与当前产出

下列采矿、伐木速度是规划假设，不是真人测量。采矿按运到仓库30／45／60份每分钟三档，主表取45；木材按200每分钟。必须区分主动采集时间、机器占用时间、作物自然生长时间；不同来源的产率不能直接相加成为每分钟总收入。

矿格收益为1／2／4，按散列近似均匀分布均值12/7≈1.714；对整数坐标[-200,199]²共160000格调用正式 `mineOre`，样本均值1.71518125。纯挥镐0.65秒对应158.32份/分钟；每格再串行走64/112秒，对应84.25份/分钟。两者都没有包含矿洞空地、找矿、战斗、承载、回程和卸货，不是可入账的实测收入。每辆矿车仅32份容量，不应使用挥镐上限设计维护费。

金属和石块共用一座提炼厂，同一时刻只有一个批次，每批最多99份，处理时间按份数相乘。20块/分钟是全厂合计能力，不是每种材料各20块。机器计绝对完成时间，可与其他玩法重叠；不会自动连续开启无限批次。以上工时不含厂间装卸、领货和物流，不能直接当作完整生产用时。

例如100原矿及100原石全部加工，只能得到50金属块和50石块，提炼厂合计5分钟，并消耗50木材。不能将两条产线分别都计成满速。

零件、晶体按每分钟16次普通材料抽取计算（不是所有模式的16次击杀）：带保底的期望概率为 `p / (1-(1-p)^N)`。因此零件约3.62/分钟，普通区晶体1.02/分钟，偏好林区晶体4.08/分钟；获得10份分别约2.76、9.76、2.45分钟。清缴会分摊整波抽取预算，应从实际抽取次数换算。精英、任务、秘境另计，不重复叠加。

领主每次稳定产8零件、6晶体、1核心，特定形象首胜另1核心；若假设每8分钟一次，长期核心0.125/分钟。8分钟是情景条件，非当前实测；核心不适合自动维护费。

混合原石与金属建设按各矿层采集量分别计算：原石是采矿联产，需求总采矿量为 `max(原石需求,各类原矿需求之和)`，不能把两者简单相加。例如加层需160原石、16铁原矿，至少16份必须来自铁层，其余144份可选层；不是另采176份。金币、木材、跨层解锁和运输时间仍需另算。

首次地下室保留2400金币＋180木材，不加必须先下矿才获得的材料，防止解锁死循环。首次石质加层所需铁矿应允许按已解锁渠道购买或选购施工代料，不能在未提供铁矿来源时强制收费。家具、石墙后续风格变化不重复收费。

8田小麦赚3000金币理论需14.61分钟，400木材约2分钟；加层新增矿物劳动约3.56分钟、提炼4.40分钟，可与作物生长重叠。因此这一档新增费用有存在感，而非把数十秒的石料变成数小时门槛。

石墙不收时间租金，也不引入强制损坏；石墙是原石的一次性出口，不能冒充持续出口。核心保持稀缺建设/收藏用途；可手动换服务券，但不设置自动核心消耗。

效率成本需小于收益：假设地面基础速度200、每小时在石路行进的原始距离180000（相当于土路15分钟），养护耗90原石，采矿2分钟。未养护1.10倍用13.64分钟，养护1.35倍用11.11分钟，额外省2.53分钟；开采伴生原矿另有收益。低效30原石/分钟需3分钟，纯为赶路补采就未必划算，应让低效玩家选择不养护或用已有余料，不设必开引导。站点等候不受道路加速影响。

道路范围按实际寻路折线长度报价，末段按长度比例累计取整；不是两站直线距离。只在已铺且合法可走的地面段生效，不能越水、穿建筑或跳过障碍。飞行、瞬移、地下矿车不吃地面道路加速；地面角色和车辆共用，速度不能重复叠加。首期只统计玩家控制实体的实际位移，随从与环境NPC不重复收费。

维护按距离或成功生产量累计，消耗记在真实完成事务，失败、撞墙、停步、暂停和离线不扣。保留不足一单位的使用进度防止刷新免单。重复道路连接共享路段状态，不能多次扣费或叠加倍率。关闭服务后保留已付额度；拆除不退已用服务和建材，防止反复拆装套利。

默认手动补给；玩家可开启自动补给并设置原石/木材/金属保留底线和每小时上限。默认保护一笔正在追踪的扩建/装备预算；不会自动兑换或动用核心。界面显示「基础可用」「额外效率」「剩余可用距离/件数」，不使用即将停摆的提示。

## 余料兑换：避免只把石头堆积改成金币堆积

建议接入现有驿站/订单板，用统一服务积分兑换基础材料或服务。积分不兑换金币，不允许买核心，不绕过矿层、装备、种子解锁。原石买卖必须按 `rawStone` 与 `stone` 分开。

| 物品 | 玩家交售每份积分 | 玩家购入每份积分 |
| --- | ---: | ---: |
| 原石 | 1 | 4 |
| 石块 | 2 | 10 |
| 木材 | 0.2（5份起） | 1 |
| 铜原矿 | 1 | 4 |
| 铁原矿 | 1.5（2份起） | 6 |
| 稀有原矿 | 2（发现后） | 8 |
| 铜块 | 2 | 10 |
| 铁块 | 3 | 14 |
| 稀有金属块 | 4 | 18 |
| 机械零件 | 8 | 24 |
| 能源晶体 | 12 | 36 |
| 首领核心 | 80，手动单独确认 | 不出售 |

账本用最小整数单位存储，避免小数积分误差。整数批量报价先显示再确认；工厂成品、赠送种子、战利品及不明来源道具首期不收，不能利用免费赠品刷积分。核心兑换是自愿降级用途，界面明确不可换回。

示例：100原石可换100木材，或10铜块，或7铁块并余2积分，或2晶体并余28积分。100原石约2.22分钟采矿；直接伐100木材约0.50分钟，绕道兑换显著打折，因此适合处理伴生产物，不替代主产出。分层开采原矿可一并交售，但它也有工业机会成本，不应在估值中把伴生原矿和原石都当作免费的。

加工不增发价值：2原石交售2积分，与切成1石块交售2积分相同；2铜矿＋1木材交售2.2积分，加工成铜块仅2积分。铁、稀有同理；买入后再出售有价差损失。任何新配方、新订单必须检查完整转换环路，不能只检查两向兑换。

玩家还可将积分用于每30分钟实际生效一次的驿站便捷装卸服务，建议100积分/次，额外装卸速度＋10%，与其他装卸加速合计最多−25%耗时；没有装卸行为时不倒计时。首期不做无限付费抽奖或强制积分过期。兑换库存无限不等于自动收购，必须玩家明确选择数量与保留量。

## 每小时收支压力样例

情景：每小时主动采矿10分钟，30／45／60三档产原石300／450／600；该小时加工100金属块需要200原矿、100木材并伴生至少200原石。其余原矿留作未来生产或兑换，三种金属份额由实际矿层决定。

| 原石用途 | 每小时消耗 |
| --- | ---: |
| 常用道路180000世界单位养护 | 90 |
| 住宅实际休息服务5分钟（长期均摊） | 2 |
| 玩家选择余料订单/兑换 | 100 |
| 合计 | 192 |
| 低/标准/高效率原石净增加 | 108/258/408 |

这是诚实的压力样例：固定轻维护不能自动吸收高强度开采。建设期另铺1000单位道路＋四分之一层加盖的均摊石料需100原石，合计消耗292，标准尚余158；满建设后必须允许玩家按余料数量扩大兑换，不承诺固定小额维护使库存永远不涨。

标准情景若希望原石持平，可在道路与住宅消耗92后，自愿兑换358原石；低/高效率分别兑换208/508。换到的物资用于生产、补给或服务，仍可留库存。长期目标是有可用出口与用途选择，不是每小时强制清零。

100金属块基础提炼5分钟，工业精调可省45秒；2铁块＋1零件供200件，100件均摊1铁块＋0.5零件，保留收益与成本的选择。日常原石养护不占提炼厂，只需住宅均摊1石块占3秒。建筑大项目继续消耗切石工时，避免所有资源都是立即变现。

## 落地顺序与验收门槛

1. 优先接原石/石块的独立报价、小屋新增矿物成本、驿站连接石路及按距离养护；同步提供余料兑换，避免建设结束后再次无出口。
2. 第二阶段加入农具和工业精调，沿用已有农产补给的成功动作计费；有真实装卸时钟后才开放装卸服务。住宅保温需复核现有恢复逻辑后接入。
3. 数值、纯规则、存档事务、手机UI、正式绘制器分层。住宅、道路、石墙美术实施前按美术标准建任务单，绑定对应 `designCriterion`，昼夜同屏、手机短长屏、遮挡通行和实际驾驶验收；本文没有替代该验收。
4. 定向检查零库存仍可通行/居住/生产，准确扣料，暂停离线不欠费，保存失败回滚，刷新不刷额度，道路交叉不重复加速，旧资产不追扣，兑换和加工无增益闭环，资源容量满不吞料。
5. 各做30分钟低效采矿、正常混合玩法、高效开采样本，记录真实入库率、运输时间、每小时资源净变动、维护额外劳动、通行节省时间和主动兑换量。目标：日常效率服务补料劳动通常不超过有效游玩时间的5%–10%，低效玩家基础流程零新增阻碍。未得到实机数据前，上表是候选参数。
