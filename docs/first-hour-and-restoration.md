# 首小时体验与小镇修复规划

当前实现采用主线任务推进，不用游玩时长硬锁功能。下表为体验节奏目标，尚不是新玩家实测完成时间。武器与怪物数值、五批清缴规则保持现有配置。

| 阶段 | 预期游玩内容 | 核心感受 |
| --- | --- | --- |
| 1分钟 | 约9秒开场、采木、走到门前自动修好武器工坊、购买手枪 | 有工具、有武器、知道下一步 |
| 1–10分钟 | 修复清缴告示牌，完成一批清缴；修复小屋；武器升级、配件和首次领主战 | 战斗—升级—再挑战形成闭环 |
| 10–30分钟 | 修复回信驿、载具工坊、营门守备台、邻里设施，体验故事、驾驶、防守和居民任务 | 小镇逐步恢复，新功能一次只教一种 |
| 30–60分钟 | 修复远征光门、赛道站、高塔与祭坛，逐步体验装备变化、运动与挑战 | 形成喜欢的武器路线和下次目标 |
| 60分钟后 | 远行、消防、足球与高阶伙伴 | 继续拓展玩法，而非首屏全解锁 |

## 统一修复循环
1. 完成前置主线，任务卡切换为当前设施的采木目标。
2. 使用锯子采集真实树木；只累计当前阶段实际采集量，奖励木头不替代采集目标。
3. 采够后走到门前55世界单位内，自动提交木料；不需要点击或站立等三秒。
4. 木料从猫猫飞入建筑（0.9秒），随后构件施工（普通设施2.2秒，武器工坊5秒）。
5. 完工保存成功后开放功能，并将对应当前主线从待接取改为进行中，无需返回 NPC 领取这项任务。进屋、接取清缴、进入玩法仍由玩家在现场点击。

暂停和离线不会推进施工；施工记录与投料同时保存。保存失败不扣料，完工保存失败保持施工且重试，避免重复扣款。不兼容旧存档权限。重新开始使用新的修复流程。

## 野外刷新规则（现有实现）
- 随机遭遇：走出安全生活区后，只在实际主动移动时累计2–4秒，每次一只，同时最多14只。
- 位置：距角色200–340世界单位，校验水域、地形、树木、其他敌人和通路；可能在视野内出现，不保证屏外。
- 强度：读取出生林区的等级与种类，不随清缴轮数增强。
- 清缴：修牌后主动接取，到地点开始五批怪物与领主战；清缴区域内不混入随机遭遇。离开清缴区域后仍可能遭遇当地怪物。
- 安全区、原地停留、暂停、剧情、秘境、领主战、消防及守门战不继续计随机遭遇；原有敌人不因玩家站住就消失。
- 重新进入巡游、死亡重建与切图重新等待，不累积离线怪物。

游戏内“地图 → 野外刷怪规则”、清缴页及修复页均可查看。说明中的遭遇数值直接读取 src/config/encounters.js，防止与实际规则脱节。

## 2026-10-30 修复后就地衔接任务

修复与接取在同一候选存档提交。清缴告示牌修好后，当前主线直接开始，目标指向告示牌；现场点击「接取并出发」即可前往清缴场，无需回 NPC 交修复或再接主线。沿用设施目录 before 与当前任务的映射，其他建筑前置同样衔接。提前修好的设施或旧档待接任务会在下一次正常游玩时补接；不会跳过未到达的任务，也不会改动 doing/report 阶段。首次小屋休息等独立教学仍保留。

这只是接取阶段调整，不自动结算主线，不发放完成奖励，不自动启动战斗。完工写盘失败时建筑和接取均不生效，原地重试不再扣木头；旧档补接失败按1秒间隔重试，成功后不重复保存。运行入口为 progression/restoration-task.js、core/town-restoration.js 与 core/mainline-manager.js。

专项 tests/restoration-task-flow.test.mjs 的5项全部通过，覆盖13个设施映射、修复现场接取清缴、完工原子性、旧档重试及普通任务隔离。相关既有 mainline.test.mjs 与 town-restoration.test.mjs 共39项中27项通过、12项失败；未修改master上同样12项失败（旧主线夹具及电动车停车坐标预期），本轮无新增失败。
