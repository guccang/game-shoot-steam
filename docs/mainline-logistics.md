# 主线后勤教学接入

新增六项任务，复用巡林簿、原有建筑和手机面板，不新增美术资源或布局。

| 接入位置 | 稳定任务 ID | 实际完成条件 |
| --- | --- | --- |
| 认路后、找种子前 | `supply-ammo` | 在弹药铺购买猫猫通用子弹；旧库存、制作和车载购买不计 |
| 首次种田后 | `warehouse-lesson` | 在小屋仓库手动取出、存入物品各一次；自动木材入库不计 |
| 仓库教学后 | `bag-cleanup` | 实际丢弃至少一份背包物品 |
| 首次购车驾驶后 | `vehicle-weight` | 查看载具仓库载荷，再从仓库给附近车辆装一份货物 |
| 载重教学后 | `cargo-cleanup` | 实际丢弃至少一份货舱物品，背包清理不计 |
| 松果战车巡护后 | `repair-center` | 现场查看维修页；店旁当前车完好可通过检查，否则等待正式维修完成 |

购弹费用由任务谢礼补回；清理建议仅用一份木头。空背包或空货舱会引导到小屋仓库取料；有货的远处车辆使用真实车位导航。货舱和驾驶员背包分别记账，清理与数量确认继续使用既有保护及保存规则。

标记仅在对应任务接取后登记。购买、仓库存取和清理的任务标记与物品写入同一候选存档，预览、取消、非法操作及保存失败不推进任务。维修下单不视为修好。任务版本更新到 11，保留旧档当前任务、待交付阶段和已完成集合；旧主线全通存档从新增教学见面阶段继续，不重复领取原奖励。

此次实测同时修复了维修页读取首次维修记录为空时的异常，并接入原操作指引，使猫爪指向商品分类、存取来源、物品、数量确认及维修确认。
