# 动作与统一美术合同

沿用原版 HTML/CSS/JavaScript、Canvas 2D、坐标与分层，不更换引擎。主体维持森林绿描边、奶油黄与柔和草木配色、有限平涂和统一俯视比例；角色、怪物、载具、地形及 UI 必须实际同屏检查白天和夜晚。

角色正面身体使用 assets/cat-front 的真实视频连续帧，保留同源待机/移动片段、姿态匹配、固定脚底及动作时钟；手持武器、手、后坐和枪口继续由正式运行时绘制。禁止复制静帧、整图拉伸或旋转代替腿、翅膀、履带及旋翼。停止不得重置为不相干姿态。不要将原版角色替换成其他游戏的主题角色。

浮游炮体、手持控制器、普通枪械、无人机必须独立。怪物行走、飞行、受击、死亡，载具履带与主尾旋翼，领主蓄力、释放和恢复均须保留。

运行资源分发已处理图集、清单和音乐；首页宣传背景另允许分发处理后的 MP4 与同片 WebP 海报（assets/title/manifest.json 列明运行文件），不作为战斗角色图集；source 中视频、请求与服务记录保留在源仓库，不混入游戏包。素材缺失须明确失败，不能静默以备用画面通过验收。

visual-contract.json 和 src/rendering/visual-review.js 绑定正式绘制器，工作台逐项采样连续帧；验收结果必须以 designCriterion 对应设计目标。机械动作检查不代替真实交互与同屏审美复核。新增文件、函数使用中文注释，逻辑/UI/数值继续分层。

在禁止创建子进程的工作区，执行 `node --experimental-vm-modules scripts/check.mjs`，使用相同 V8 解析器检查语法，同时保留导入、分层和循环依赖检查，不能跳过检查。

胶质怪物保留原版挤压节奏，同时必须有左右边缘、波峰、表情的局部错相形变；脚底锚点固定，受击结束回到原轮廓。整体缩放只能辅助表现，不能单独作为合格动作证据。

具体资产的造型、配色、分层、景观组合、生成提示与交付验收见[游戏美术资源生成标准](art-generation-standard.md)。开始新资源任务时使用[美术生成任务单](art-generation-brief.md)；其中动作与交互要求继续遵循本合同。
