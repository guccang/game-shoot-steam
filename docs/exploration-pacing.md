2026-11-02。主线从48项串行任务改为8阶段：认路、首次巡护、烽火断线、强渡封锁线、抢下反攻补给、无人退队、穿云夺标、破晓反攻。其余40项教学、整备、休闲与复习战斗通过任务簿 → 打开巡林簿 → 自选体验主动选择，保留原条件与一次性奖励。

建筑只对当前任务构成前置，不再因为后续任务排序要求修完此前所有设施。与故事无关的赛道站不再阻挡第三封来信。小屋休息不再是室外主线必修步骤。提前修复仍保留。

森林1–3级营地周边沿用正式等级圈：移动累计18–28秒尝试出现遭遇怪，存活上限3只，清完后增加12秒移动喘息。停止、暂停和专属活动冻结计时；从危险区返回至少给予18秒等待。其他林区和九寨沟保留2–4秒、14只上限，清缴与专属战斗不改配额。以上是首次调优参数，尚未作大样本体验评估。

按用户最新要求不兼容旧存档。世界存档修订号为`forest-exploration-pacing-2026-11`，旧游戏进度和回放在首次读取时重置，声音/环境/操作设置保留；主线结构版本12。新版本内的任务切换与刷新正常保存。

数值工作台以8个必经阶段判定主线完成，邻里赠礼路线不再依赖自选教学任务。模拟假定主动连续推进，不能据此推算玩家实际探索时长。
