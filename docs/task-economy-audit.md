# 最新任务经济评估（2026-10-25）

> 本文与原始JSON保留为调整前快照。当前实施与复测见[清缴及任务节奏验收](task-economy-cadence.md)；审计脚本现在默认写入 `output/task-economy-audit/report.json`，不覆盖历史证据。

评估基线：`ec31aae`。本次交付审计脚本、正式战斗采样与建议，没有更改正式奖励、价格、玩家存档或工作台默认方案。

结论：当前存在明显的阶段性资源过剩。主要原因是**清缴仍按历史怪数分配不断增长的收入，而升级费用封顶、任务要求的养成等级很低**。任务奖励进一步放大了“持续到账、很少需要花钱”的体验。不能将此归结为全部材料、全流程都足够，更不能只把所有价格提高。

## 任务和其他收入的边界

- 主线29步：一次性资源奖励；针对性测试确认保存失败不发放、成功后不能重复领取。
- 回信故事：第一章600金币、240木材、6零件，第二至六章及两条支线本身没有额外货币奖；主线完成这些故事后另有一次奖励，这是两套合法奖励叠加。
- 邻里三项：共1,100金币、300木材、5零件、2晶体；生活委托与旧故事共用完成奖励标记，不能各算一次。故事怪与邻里任务怪不另发普通森林掉落。
- 故事借用装备：只在临时配置内使用，不赠永久所有权，也不会因玩家永久升级而提高该套借装。大量任务可不投资主力就继续推进，消费动力因而减弱。
- 邻里整板谢礼：可选萤火冲锋枪或气垫船。若选择气垫船，可免去10,000金币、3,800木材、136零件、45晶体、3核心的购买，并满足拥有条件；须完成额外委托，不能算作零耗时现金收入。回信整板另有武器/资源包选择，不能把所有选项相加。
- 守门：B/A/S为300/750/1,200金币及相应木材零件，可重复；守门怪不再按普通森林怪掉落。本次没有重跑守门时长，不能仅按奖励量断言它是最优刷法。
- 秘境：第一关250金币、111木材；三种玩法材料倾向不同，层间休整必须计时。足球为90秒、每进球8金币3木材；消防成功80金币加每棵扑灭树10金币。均应纳入后续完整路线，不能只算主线面板。
- 收支记录存在覆盖缺口：旧故事、生活委托、整板谢礼、消防及足球部分入账没有调用统一经济日志。因此旧账本的来源合计可能小于实际钱包变化；需要补齐后才能用真实档可靠归因。

## 建议的首轮调整顺序

1. **先统一活动预算。** 清缴收入改为按当前完整五波加领主的标准耗时定预算，取消第二、第三组沿历史怪数自动成倍增长的奖励份数；金币、木材和材料抽取一起重算。可以继续逐怪分摊固定预算，但不能一边缩短清缴、一边完整保留老时长的收入。不要简单恢复一怪一份，导致小波次断粮。
2. **保住教学起步，再降低无消费任务的现金奖。** 前四步及第一波必须保证手枪3级、角色2级、弹匣/装填2级的293金币、118木材实际可支付。之后纯看地图、打开配置、交谈类奖励可从目前300–800金币降至50–150的候选范围；战斗、完整故事和购买里程碑按总活动收益统一预算。29步主线总现金可先试6,000–8,000金币，当前12,700；这是待验证候选，不是已通过的正式值。
3. **把消费与接下来要用的装备连起来。** 新一段清缴前提示主武器/角色的关键等级与击杀差异，购买后安排使用和少量强化，不只检查“已拥有”。剧情借装继续承担新玩法预览，不能靠强迫升级一个剧情中根本不用的物品来清空钱包。保留任选主力与追赶折扣，避免全收藏才有支出。
4. **先保留早期价格和450上限作对照。** 当前现金产出量级远高于费用，先修收入和消费时机，随后再测试分段费用。不能在现有高收入上反推几十倍价格，也不能收回玩家已得库存。材料只做首次购买也意味着已完成主力路线后会自然积累，应区分正常储备与提前失去成长目标。
5. **按有效时间验收，而非余额越低越好。** 首轮可测试标准玩家全活动混合收入180–240金币/有效分钟的区间，包含移动、对话、休整与失败；该区间仅是实验预算，不是当前实测值。以“最近一次关键提升后的等待、下一目标的缺口、已开放且有价值的消费”判断积压。将等待主线资格而不能花的钱单独列为资格瓶颈，不误算成材料不足。

不建议新增强制维修费、死亡掉钱、每日上限或无意义重复消费来吸收多余资源。

## 验收缺口与下一轮标准

现有工作台模型仍使用固定击杀率与“12次击杀出现领主”的旧近似，没有执行29步主线、固定五波清缴、任务资格、整板赠礼、守门和新的剧情流程。它输出的旧8–12小时结论不能作为最新版已达标的证据。

下一轮必须按实际解锁顺序执行任务/活动/购买/升级，分别统计0.65、1、1.35效率，每路线至少100固定种子；保留失败与未完成比例，不能用时长直接除效率代替真实战斗。目标继续采用标准零伐木8–12小时完成主力路线，后期最长有价值成长空档不超过12分钟，并单独验收低效率玩家能支付前期必要升级。故事阅读、回营与工坊操作需要重新计时，10月23日旧故事报告也不是最新完整路线耗时。

本次100个独立战斗夹具只完成局部诊断，不宣称已通过上述长周期验收。未读取玩家个人存档，无法对某个真实钱包余额做精确归因。
