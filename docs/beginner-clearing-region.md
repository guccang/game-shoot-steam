# 首轮清缴区域与强度修复

2026-10-25

## 原因与修复

原随机地点覆盖全部区域，怪物基础生命、攻击和速度先读取落地区域等级，再叠加清缴成长；初始手枪也可能面对 7–9 级甚至更高等级怪物。

- 尚未完成清缴的首轮任务，在营地草甸 600–1300 米内随机选点，校验真实碰撞与步行路线；路线不得穿越高等级区域。
- 首轮重接地点至少相隔 250 米；后续轮次沿用原 1000–3000 米范围、600 米间距。
- 正常森林清缴和领主援军以 1 级为基础，再应用现有阶级、兵种及完成轮数成长。区域不再额外放大生命、伤害、速度和掉落。
- 旧档任务地点、波次、击杀数不迁移；继续生成的清缴怪物立即使用修复后的规则。
- 野外移动遭遇、剧情、秘境、营地保卫和工坊试射保留原区域规则。五波配额、配比、间隔及领主生命配置不变。

## 验证

- 35 项定向测试最终通过：新手跨区域属性与旧档、随机地点、清缴伤害、五波编成、告示牌交互、野外遭遇流程。新手选点覆盖 32 个种子，每个执行接取与重接，逐段验证实际步行路线。
- 另验证清缴密度与前三轮领主成长的 11 项既有回归，通过。
- 修改的 JavaScript 文件通过语法检查，差异通过空白检查；未运行全量测试。
- 浏览器脚本：`tests/beginner-clearing-region-browser.cjs`，隔离端口 4289。新档只拥有初始手枪，实际点击告示牌、接取、逐段碰撞移动到场，使用正式刷怪调度验证完整五波；测试以直接伤害清怪推进，不作为自动战斗难度模拟。
- 浏览器实测地点 `(1419.61, 1440.84)`，距接取位置 773 米，27 个路径点；首怪等级 1、生命 20、伤害 8；各波数量 2 / 4 / 6 / 8 / 10；领主生命 1200；浏览器异常 0。
