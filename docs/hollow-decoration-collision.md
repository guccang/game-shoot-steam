# 镂空装饰碰撞

此前把装饰摆放外框直接当作实体，蔷薇拱门和单杆鸟屋都形成了看不见的整块墙。

现在保持摆放占地不变，行走碰撞单独读取可见结构：蔷薇拱架和爆竹架仅检测两侧支柱；鸟屋、风铃、信箱、指路牌、中国结、香囊和花环架仅检测支杆。盆景、水井、花坛等实心装饰继续检测可见底座。车辆按已有底盘宽深检测立柱，猫猫恢复步行半径。

五项针对性测试通过，覆盖步行穿拱门、立柱阻挡、松果战车宽度、下车通行、鸟屋支杆、实心底座及栅栏回归。正式手机浏览器用moveBody连续穿行，昼夜均通过；战车停在门柱前，猫猫完整穿过。证据位于output/playwright/hollow-decoration-collision/：walk-through-day.png、walk-through-night.png、vehicle-day.png、vehicle-night.png、report.json及video/。

纯碰撞修复，沿用原装饰美术、脚底锚点及遮挡，不新增贴图或改变动作。
