# Debug 批量领取与武器入库验证

日期：2026-11-02。基线：main `bdb0754`。

## 修改范围

- 领取所有载具时显式发放原生主炮，并在保存成功后同步运行中的主炮模块；不再调用仅允许临时守护活动使用的换炮接口。
- 按真实营地泊位安排车队，保留驾驶、已有换装、耐久、冷却和维修记录。停车校验按完整载具目录接受寻宝坦克；领取寻宝车后记录唯一奖励已领取。
- 一级领取和武器满级都按正式负重计算。本批新武器会导致满载时统一放入小屋仓库，保留当前装备及正在使用的挂载。重复领取可整理此前已超重的闲置武器。
- 仓库增加武器存取和分类，保留等级、改装、弹匣；取出超重仍需明确确认。在仓库的武器不能隔空装备、挂载或计入背包负重。
- 使用现有库存图标绘制器和手机底板，没有新增图片资源或改变角色、载具、环境美术。分类按钮保持至少 44×44 像素，小屏可横向滚动。
- 保存失败不提交候选进度。未新增旧存档迁移逻辑。
