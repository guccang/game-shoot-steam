# 分组怪潮与手动领主节点

2026-10-23。普通地图巡游改为「随机3–5波 → 等待手动Boss → 胜利后下一组」。剧情章节和秘境保持自身任务表与波次规则。

## 刷怪与推进

- 普通波次从当前视野外围进入，校验可通行地面、树干和单位间距；没有合法点时延后，不消耗名额。远离的波次怪回收并退还名额，不算击杀。
- 随机刷怪仅在等待领主的探索时段开启；整组波次（含预警、休整）期间暂停，不计入波次配额、清波击杀和补兵等待，见 [地图遭遇说明](roaming-encounters.md)。本页先前描述的全地图散布波次已按用户澄清纠正。
- 每组开始抽取3、4或5波，目标记录在 `bossWave`。组内清波后保留3秒休整与下一波3秒预警；最后一波清空时设置 `bossReady`，停止波次怪刷新与波次时钟（移动遭遇仍独立运行）。
- 领主头像角标显示剩余波数；节点就绪显示「领主节点 · 待挑战 / 点头像」。玩家可以继续探索，只有点击头像才召唤Boss。
- 胜利按原规则结算奖励、恢复生命并抽取下一组长度，休整3秒后继续；重复命中尸体不重复结算。
- Boss失败保留当前节点和强度，重新出发后手动重试，无需重新清怪。普通怪潮死亡保留当前波、已击杀配额、组起点与领主节点；复活只重建未击败的怪物，休整接续，不重抽整组。
- 刷新、切图、暂离剧情与秘境往返保留节点。旧巡游档缺少节点字段时，从当前波开始一组4波；正在进行且有合法强度快照的旧Boss战直接迁移到领主节点。伪造血量而无合法强度快照不能解锁节点。

原敌人数量、生命、伤害、成长、奖励及Boss技能与援兵参数不变。新增移动遭遇沿用当地基础属性与原有奖励结算，不随波次成长。

## 实现入口

- `src/config/waves.js`：`WAVE_GROUP` 与组长度抽取。
- `src/core/wave-manager.js`：组内自动推进与组末等待。
- `src/core/enemy-arrival.js`：`findArrivalSpot` 周围安全选点。
- `src/core/boss-manager.js`：手动资格检查与胜利衔接。
- `src/core/patrol-session.js`、`src/progression/patrol-progress.js`：节点保存、迁移与失败重试。
- `src/ui/hud.js`、`src/app/game-events.js`：正式头像、状态文本与节点事件提示。
