# 装备购买资格与邻里故事

首次购买下表装备时，必须先完成对应故事并交付。完成任务只开放购买资格，金币和材料仍使用原配方。故事期间免费借装，退出后归还，避免“先拥有才能做任务”的循环。

| 装备 | 对应故事 | 其他故事前置 | 委托人 |
| --- | --- | --- | --- |
| 引力聚束枪 | 别让他们挤上邮路 | 无 | 枭爵 |
| 潮汐水枪 | 给新芽一场小雨 | 无 | 小夜 |
| 霜枝冰晶枪 | 把清凉送到夜班 | 无 | 阿团 |
| 机械核心 | 没有名字的小队员（复用第四章） | 无 | 薄荷 |
| 机械蜘蛛 | 够不到的那盏灯 | 无 | 薄荷 |
| 红狼坦克 | 把最后一车木料接回来 | 无 | 铁牙 |
| 金杯面包车 | 这回，大家一起去 | 无 | 雪团 |
| 直升机 | 树冠上方的灯（复用第五章） | 无 | 薄荷 |

以上八项体验任务均可独立接取：任务建筑开放后，来到关联委托板或委托人身边即可开始，无需完成其他故事。机械核心与直升机沿用第四、第五章内容和存档标识，但同样取消前置。任务用于了解装备的特性、历史和故事，首次购买只要求完成本装备对应的任务。

六条新故事分别围绕清理邮路、照料花圃与清洗空篮、制作冷源并送补给、守护两段灯线并收回蜘蛛、驾驶碾树接运木料、接送邻居并共同护路展开。完成后留下回信，以及交接表、浇水记录、补给箱、巡检本、运输记录、合乘表等生活设施反馈。

玩家可从邻里面板的“装备故事”、相关居民或任务目录查看；工坊购买栏直接显示对应故事和当前状态。查看只打开说明，点击追踪才改变导航；接取仍需到居民或委托板附近。暂离恢复到已保存阶段，另一条故事未结束时不会覆盖其进度；可以完成当前任务，或返回其接取地点取消后，再接取想体验的装备任务。

原有装备继续使用和升级，已完成的旧第四/第五章直接承认资格。原整组谢礼仍为8篇森林故事和3篇邻里委托，霜枝冰晶枪的谢礼获取方式保留；新增购买限制不改变赠礼。手持武器与独立车炮按类别和稳定ID区分，避免相同数组编号串用任务。
