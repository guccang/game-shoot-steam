# 连续击飞命中检查

## 结论与玩法决定

2026-10-24 检查未发现浮空高度导致免伤、减伤或子弹漏计的问题。弹道碰撞使用怪物的世界平面坐标，浮空高度不参与目标碰撞中心或伤害倍率计算。地形遮挡仍生效，穿透弹仍只对同一目标计伤一次。

开放区域的清怪减慢可以由强击退将目标推离武器射程解释。按用户确认，保持原射程，玩家需要靠近后继续攻击；不添加超远锁定，不调整伤害、击退或连续命中的向上速度。本次仅新增专项回归测试及本记录，没有修改游戏运行代码。

## 针对性回归

- 电锯、榴弹范围伤害不因目标高度变化而漏伤。
- 穿透弹不会因目标高度改变重复计伤，也能命中后方目标。
