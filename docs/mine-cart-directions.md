# 矿车与交叉路口方向

## 停车选向

乘坐矿车后点击「立即停车」，再点「开车方向」，选择北、东、南或西。选择后仍保持停车，点击「开车」出发。没有相连轨道的方向禁用。

停在格心时可选择任一相邻出口，包括原路掉头；停在两格之间时只能沿当前轨段前进或后退，车体保持原位。行驶中方向按钮禁用。

本次起步选择优先于脚下路口，只生效一次；抵达下一个格心后继续按路线规则行驶。刷新保留所选起步方向、车位、当前轨段与车轮相位。

## 交叉路口

下车后走到三岔或十字路口旁，点击「路口方向」。选择方向自动保存，轨面出现对应箭头；后续所有矿车经过该路口时都会朝所设方向开。从所设出口反向驶入时会原路折返。

不同地下层独立保存。设置免费，不消耗矿石、木材或原路牌；无法隔墙、远程或在车上改路口。点击「恢复自动选路」清除该路口的固定方向。

默认规则：直行优先；没有直行时先右转，再左转；尽头自动停车，选择返程方向后可重新起步。起步没有历史方向时使用矿车记录朝向，旧档默认朝东。

矿车在抵达轨道尽头的当帧停止，剩余移动距离不用于倒车；车轮、车位、朝向和整列挂接保持。持续按住原前进方向不会自动重启，松开后选择返程方向可重新出发。挂接列车返程沿用换到另一端车头的规则。
