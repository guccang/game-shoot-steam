# 地面与地下生产配合：首批功能

2026-11-03。当前实现沿用原生HTML/CSS/JavaScript、Canvas和统一手机底板。收割小推车、花生/向日葵制油和PNG精修属于后续阶段。

## 入口与逐步解锁

地面右下角「农矿生产」打开设施、原料、补给三页；地下操作条「补给」打开同一页面。只有下车并靠近已建加工台100世界单位内可以加工，矿区可以使用已制作补给。

1. 通过正式岩壁开掘累计获得12矿石并回到地面，解锁洒水器。天然洞厅的走访勘探不产矿，不计入开掘次数。旧档首次迁移可把现存矿石计入门槛，不补发材料。
2. 在田边空地放置洒水器。收获一茬真正由设备首次加速的自种作物，解锁加工台。野田、已成熟作物、先被手浇/雨水照料的作物不会冒记设备贡献。
3. 初次建台赠小麦、胡萝卜种子各2粒，同时开放该品种购买，不依赖随机掉落。移动设备不重复发种子。
4. 加工便当并完成20次受加成的开掘，原料保留从「全部出售/保留2份」扩展为0至20份。
5. 获得水果品种后开放果饮；实际乘过矿车并发现玉米后开放植物油。两条分支独立，无饥饿或强制补给门槛。

## 配方与效果

| 设施或成品 | 一批成本 | 产出与用途 |
| --- | --- | --- |
| 简易洒水器 | 12矿石＋16仓库木材 | 1台；上下相邻52单位、左右相邻56单位各覆盖一格 |
| 农产加工台 | 8矿石＋20仓库木材 | 1台；在旁边加工背包原料 |
| 矿工便当 | 小麦1份＋胡萝卜1份 | 3份；每份支持100次成功开掘，单格耗时减少20% |
| 探路果饮 | 自选已发现水果1份 | 3瓶；地下实际步行180秒，速度提高15% |
| 植物油 | 玉米1份 | 3罐；指定身旁或乘坐的矿车实际行驶180秒，速度提高20% |

每份原料是一块田的一茬收成。配方显示原料可出售的金币价值，果饮选择框逐项显示水果售价。首批数值沿用确认草案，已验证真实时间和交易规则，尚不宣称长期经济收益最优。

## 原料、出售与运输

保留策略默认0，继续原有收获入背包/视野内载具、到仓库或收购站出售的流程。每个出售事务按背包、在场货舱顺序共同保留设定份数，多余按原售价兑换。原料保留不另发金币、不改变负重；设回0后恢复出售。远处车辆不被隔空出售或加工。

加工只使用背包库存；货舱原料需通过既有装卸取回背包。补给放入独立生产补给栏，每种上限999；没有新增消耗品负重和耐久机制。

## 布置、动作与保存

建造选择空地预览，再确认；可以取消或免费移动附近设备。不允许占田、水域、道路、建筑或树干，设备间保持农田间距。最多32台洒水器和1座加工台。矮设备不新增通行墙体，猫和车辆可通过。

洒水器只在线照料当前地面；与手浇、雨水共用每茬25%生长减时上限，不叠加、不自动收获。只有真实施水的设备短暂显示水弧，暂停冻结，减少动态关闭水弧。离线只保留原有作物成长规则。

便当仅在成功挖通岩壁并保存后扣次数，矿镐动作、进度和结算共用有效时长。果饮停步、撞墙、乘车时不消耗；润滑只附着当前层指定矿车，停车、其他矿车与其他层不消耗。效果未耗完时拒绝重复使用；暂停和离线不消耗。

建造、移动、赠种、加工、保留设置与使用均先保存再提交。保存失败保持原库存、资格和设备。旧档补齐新字段，矿车归一化保留润滑秒数；设备不会因重载重新发教学奖励。
