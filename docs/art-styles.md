# 可切换美术风格

设置 → 画面风格，可在「原版森林」和「清澈卡通」之间即时切换。默认清澈卡通；选择以`forest-art-style-v1`独立保存，不进入角色/装备存档。无需刷新页面。原版取样于`884e703`，清澈版取样于`16906ce`，不是恢复整份旧程序。

## 目录与调用关系

| 目录 | 职责 |
| --- | --- |
| `src/art-styles/classic/profile.json` | 原版配色、描边、尺寸、色阶与局部细节开关，只有数据 |
| `src/art-styles/clear/profile.json` | 已确认清澈版的同结构配置，只有数据 |
| `src/art-styles/config.js` | 两份只读配置与当前配置的实时绑定 |
| `assets/art-styles/<风格>/cozy-cottage/` | 各风格的小屋PNG及清单 |
| `assets/art-styles/<风格>/map-preview/` | 各风格五张总览图及尺寸/哈希/源码指纹 |
| `src/rendering/` | 唯一绘制主体、共同动作合成、天气、镜头和公共渲染设施 |
| `src/art-styles/state.js`、`controller.js` | 显示偏好、资源预载、提交切换与旧缓存释放 |

56个美术模块已收敛为公共实现，原调用接口保持稳定。绘制器直接读取`style`实时绑定，配色、线宽、屋顶接缝位置和树叶色阶等来自配置。麦穗、水纹等确有造型差别的局部细节由配置选择，世界坐标、分层、动作相位与缓存流程共用。风格目录不再存放JavaScript绘制器，也不拦截Canvas命令换色。

## 切换和资源边界

切换先通过公共加载器解码目标风格的必需小屋图片。缺图/尺寸错误时显示中文错误，保留当前风格，允许资源恢复后重试。成功后释放唯一一组派生图集、旧地形与河水缓存，再提交配置；换季双池各自重建纹理，保持调度器和季节时钟；顶层材质常量随配置同步，地图取消旧异步请求，装备HUD和室内画像失效重绘。

Game、角色、敌人、轮角、弹药、战斗与动画时钟、镜头，以及昼夜/天气/季节过渡对象保持原实例。设置原有暂停规则继续生效。未启用风格不保留派生图集，两张小屋原图可保持解码，约0.90MiB合计；地图仍使用两张缓存上限，角色视频与字体共用。

## 后续维护

- 新功能只实现一次玩法、交互和绘制主体，放入原公共模块。先按imagegen＋程序绘制＋SVG流程完成动态效果，确认后再精修PNG；不要求同时制作两套新图片。
- 颜色、线宽、色阶、接缝位置等差异放入两份同结构配置。比如全局描边为`primitives.outline`，多边形默认线宽为`primitives.polygonStrokeWidth`，车库接缝为`garage.roofSeams`，树冠色阶为`treeCanopy.leafRamps`。新增字段同时补齐两份配置，公共形状或动作修复只改一份绘制器。
- 保持`style`模块实时绑定；不要在模块初始化时解构并永久缓存风格字段。必须保留的顶层材质常量通过`onArtStyleChange`同步；新派生图集需接入公共缓存释放流程。不得将函数、脚本或玩法判断塞入JSON。
- 新静态PNG放入对应`assets/art-styles/`目录，保持尺寸、锚点与层级。精修流程仍按[美术标准](art-generation-standard.md)，不要把移动部件合成静态整图。
- 地图底图：本地浏览器运行`scripts/build-art-style-previews.cjs`并保存工具结果到日志，再执行`node scripts/save-art-style-previews.mjs <日志路径>`。脚本校验两套共10张图，并记录递归绘制依赖指纹。
- 原`assets/cozy-cottage/`与`assets/map-preview/`保留为旧导出工具兼容资源；当前风格运行链使用隔离目录，不能仅更新旧目录就认为新画面已更新。
- 浏览器验收见`tests/art-style-switch-browser.cjs`与`tests/art-style-resources-browser.cjs`，在已打开的本地页面源上运行，默认开发端口仍为4175。本轮隔离验证使用4177，完成后4176提供本分支。固定相位比对见`tests/shared-art-parity-browser.cjs`，需在同一浏览器版本及字体环境比较前后结果。

本轮按用户确认合并到master；前序工作树已归档；当前工作树因应用的主检出保护暂时保留。详细验收见[共用绘制任务单](art-tasks/shared-art-rendering.md)，历史隔离过程见[风格切换任务单](art-tasks/art-style-switch.md)。
