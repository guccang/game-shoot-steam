# 百种鱼与钓具规则

入口：四格菜单→野外→鱼竿与鱼饵；地下可直接点底部「钓具」。购买请到弹药补给铺售货员→选购露营与钓鱼装备→采购钓具与露营装备。图鉴中可搜索每种鱼，查看栖地、稀有度、最低鱼竿、偏好饵和当前搭配概率。

鱼类共100种，分鳞鱼、溪鱼、叶鱼、须鱼、珠鱼、帆鱼、带鱼、洞鱼、灯鱼、甲鱼10个幻想生态家族；森林、湖谷和地下各有专属种群。鱼护同时容纳60条，出售后收藏历史保留，可以逐渐完成百鱼收藏。原三种鱼ID、价格、重量、颜色和收藏继续保留。

每种鱼有一个确定的偏好饵，以图鉴为准。其他饵也能钓到，但权重较低。每类鱼饵独立计数，上限999份；真正抛竿且保存成功才扣当前鱼饵1份。用完后提示换饵或补货，不自动扣另一种饵。正在钓鱼时禁止换竿换饵。

## 概率定义

一次抛竿先按水域和鱼竿阶级筛选鱼种，再计算权重。未满足栖地或鱼竿条件的鱼概率为0。

```
鱼种权重 = 稀有度基础权重 × 鱼饵偏好倍率 × 鱼竿倍率
基础权重 = 常见100、少见45、稀有18、珍奇5、传说1
偏好倍率 = 使用该鱼偏好饵时4，其他饵1
鱼竿倍率 = 1 + 0.2 × (鱼竿阶级 - 1) × (鱼种阶级 - 1)
鱼种概率 = 此鱼种权重 / 当前候选鱼种权重总和
```

例如森林中，入门竿搭配谷物饵，银鳞鲫鱼为22.222%、青背鲈鱼为5.556%、金鳍鲤鱼为22.222%，剩余概率分配给其他常见鱼。换装备后全部概率重新归一化，不是直接在百分比上乘4。页面显示三位小数，会有舍入误差。

这是抛竿选中、等待咬钩的鱼种概率，不代表必定钓上岸；早提竿、错过咬钩、断线或放流都不会增加鱼获。钓中后体长在该鱼独立配置的区间内生成。所有地下一层及更深层目前共用地下鱼群，未额外增加深度门槛。

湖面可见鱼群独立于玩家装备，按栖地与基础稀有度分布；它们是生态表现，不意味着画面中某条鱼必定被本次抛竿钓中。
