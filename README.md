# 森林巡游 · 喵喵小队

一个无需安装依赖、支持手机与电脑的卡通森林自动射击小游戏。使用原生 JavaScript、Canvas 2D 和 CSS；场景与枪械由代码绘制，小猫主体使用随项目提供的视频抽帧图集，运行时无需外部生成服务。

Docker 部署使用仓库中的 `compose.yaml`，默认开放本机及局域网 4173 端口；构建、更新和防火墙设置见 [Docker 局域网部署](docs/docker-deployment.md)。

Windows 本地测试：安装 Node.js 后，双击根目录的 [start-game-4175.bat](start-game-4175.bat)，然后访问 http://localhost:4175。保持命令窗口开启，关闭窗口或按 Ctrl+C 停止服务；脚本固定使用4175端口，无需安装 npm 依赖。

后续美术资源制作请遵循 [游戏美术资源生成标准](docs/art-generation-standard.md)，并使用 [美术生成任务单](docs/art-generation-brief.md) 记录结构、锚点、分层和验收。标准附有六组景观的昼夜实机参考。

中文文案统一保存在 [中文语言表](src/i18n/locales/zh-CN.json)。后续翻译只需复制语言 JSON、翻译值并修改 [语言配置](src/i18n/settings.json)，无需修改游戏代码；操作与验收见 [国际化说明](docs/i18n.md)。

### 主菜单与森林背景视频

打开游戏先进入主菜单：首次点击「开始游戏」，已有存档点击「继续游戏」。暂停页或设置可以保存并返回主菜单；秘境和剧情面板也提供返回入口，继续时保留原有必选步骤。刷新后的恢复范围仍是现有检查点，不承诺恢复全部战场瞬态。

「重新开始」经确认后清空成长、资源、波次及玩法进度，保留操作和环境设置；死亡页「重新出发」继续保留成长。损坏存档不会被首页自动覆盖；无法访问存储时明确提示临时游玩。

背景采用用户指定的 Seedance 2.5 原片第3–6秒，首尾重叠融合0.25秒后形成2.75秒原速竖版静音循环。运行仅加载 `assets/title/background.mp4`、`poster.webp` 与清单；打包必须排除 `assets/title/source/**`。源片、请求、失败原因及处理命令保留供复现，运行无需连接生成服务。详见[主菜单验收](docs/art-tasks/title-menu.md)、[视频验收](docs/art-tasks/title-background-video.md)。

开发验收：`node --test tests/title-menu.test.mjs`；浏览器脚本 `tests/title-menu-browser.cjs`、`tests/title-menu-visual.cjs` 和 `tests/title-video-browser.cjs` 使用隔离端口4186。旧浏览器脚本在刷新后需显式点击继续，不能依赖页面加载后自动进入战场。

### 晴叶营地第一章

第一章采用完整表驱动：剧情、阶段流转、人物出场、道具清理及遭遇参数集中在 `src/config/story.js`，通用执行器不判断具体阶段编号。配置格式与旧档兼容约束见[第一章内容合同](docs/story-table-driven.md)。

剧情会回应实际枪车体验：激光贯穿、水电协同、冰晶接重炮和冲锋闪避都是可选发现，未完成不影响通关。战斗短气泡不暂停、不拉镜头；结尾按真实体验推荐工坊查看与试射，借用装备仍在结束时归还，不自动购买。见[装备体验叙事验收](docs/art-tasks/story-equipment-journey.md)。

在晴叶营地点击「故事」接取《没有寄出的回信》。借用林线游击、潮电围控或霜炮守卫，沿主路或近道寻找薄荷，保护中继站三段修复、击退铁牙野猪王，再关闭错误广播、回营交付。故事道具仅在章节中显示，完成或暂离后移除，营地仍可继续或重玩。准备阶段可换整套装备，也可先试射；战场临近目标点击按钮或按 E 调查。

任务栏左侧的圆形箭头随移动指向当前目标；靠近时圆盘变浅绿，精确到点显示中心点。领主战期间导航移至血条左侧。

剧情对白在说话者头顶以气泡自动讲述，可暂停或跳过；整段对话保留当前取景，只有人物或气泡越出安全区时才最小平滑调整，换人不重新居中；装备和路线仍通过面板选择。当前目标地面显示双层光圈，野猪战的金色地面圆环标出实际移动边界，战斗结束后消失。见[场景引导验收](docs/art-tasks/story-world-guidance.md)。

章节按阶段保存，失败可重试，暂离与完成会恢复森林装备及供给；刷新从当前阶段起点暂停恢复。章节击杀不发永久掉落，首次交付奖励600金币、240木材、6零件、4晶体、1核心，重玩不重复领取。实现参数、已验证范围与真人体验待验项见[第一章验收报告](docs/story-reports/sunleaf-01.md)。

复现规则与实战：`node --test tests/story.test.mjs`、`node scripts/story-simulation.mjs`、`node scripts/story-balance.mjs`。浏览器脚本位于 `tests/story*-browser.cjs`，仅允许隔离端口4217，避免覆盖日常存档。

### 地图旅行

展开战场功能菜单，点击「地图」，可在保留的「四境森林」与新增「九寨沟」之间往返。九寨沟采用 Y 形湖谷、青碧湖水、钙华叠瀑和针阔混交林，沿用原版画风。切换保留成长、波次、生命、弹药及车辆耐久；同页返回保留树木与位置，刷新在已选地图入口恢复巡游检查点。湖水须绕行或使用气垫船，瀑坎不能直接攀越。详细说明与昼夜验收见 [九寨沟地图](docs/jiuzhaigou-map.md)。

### 时空秘境

展开战场功能菜单，点击「秘境」进入。三种玩法沿用已有角色、小手瞄准和载具机制。肉鸽远征通过补给机领取本局装备；时空之塔和守护女神沿用进入前的工坊配置。

入口以三张主题插画展示玩法，玩法规则与存档说明通过标题旁的「？」按需查看。原图和完整提示词保存在 `assets/realms/`，由内置 image_gen 生成；手机实际加载 768×512 WebP；卡片创建时直接加载，失败自动重试一次，重新打开面板会重试仍未加载成功的插画。需要重新编码时在本地服务运行 `scripts/export-realm-art.cjs`。

三种秘境从已有主场景随机圈选干地区域，面积为原秘境的 3 倍（半径约 537），共用主场景地形、昼夜与角色跟随镜头；同一挑战跨关和刷新保持选区，退出恢复森林现场。守护准备和波间可拖动战场或使用 WASD 移动布防。

- **肉鸽远征**：先点击老虎机领取枪械，再领取载具，最后独立摇动第三个老虎机抽取载具武器；三槽齐备后选择祝福开战。完整目录都可抽取，包括未解锁装备；相邻两次同槽不重复。枪械、浮游炮挂载、炮塔和车体等级等于当前关卡，每过一关自动升级，耐久比例、弹药和修复冷却保留。首次开战自动驾驶抽中的载具，并装好抽中的载具武器，无需手动上车；之后可主动下车，载具损毁后仍需等待修复并手动召唤。开局和过关后三选一祝福（各项最多 5 次），装备和祝福仅本局有效；偏重晶体。
- **时空之塔**：无尽逐层挑战，层间回复 15% 最大生命，可主动继续或带奖励撤退。
- **守护女神**：无尽四向进攻，多数怪物与领主攻击祭坛，波间选择修复、治疗或火力强化；偏重零件。

三模式每 5 层／波出现真实领主，五种领主轮换，清除领主和全部杂兵才结算。每层总数量、生命和伤害递增，同屏最多 24 个敌对单位，移速封顶，保留走位空间；强度不追随装备变化。每个 Boss 关卡获得 1 核心，其中爬塔仍按对应楼层首次通过发放，远征与守护保留每次挑战奖励。失败、撤退保留已结算奖励，旧版终点存档转为休整继续，无尽最高纪录保存在浏览器。
- 清关奖励即时入账；失败、撤退保留已获奖励，森林波次不回退。秘境击杀不计入森林击杀、领主资格、材料保底或武器熟练度。
- 同页面返回时恢复森林坐标、弹药、载具和敌人现场。刷新采用关卡检查点：未完成关卡从该关开始时的生命、女神生命、祝福和载具耐久／供给／修复时间重试；已完成关卡不重复发奖。森林仍按原有巡游存档恢复。
- 抽取结果在点击时立即保存，刷新不会重抽；补给转轮按逐渐放慢的机械卡嗒节奏滚动，以和弦揭晓结果。音效遵循声音开关和音效音量，首次点击进入后默认开启。永久装备所有权、等级和配置不受远征试用影响；旧版正在进行的远征仍按原装备继续。
- 模式配置与祝福在 `src/config/realms.js`，会话和结算在 `src/core/realms/realm-manager.js`，存档校验在 `src/progression/realms/realm-progress.js`，独立平台与女神绘制在 `src/rendering/realms.js`。
- `tests/realms.test.mjs` 覆盖三模式完整流程与存档隔离，`tests/realms-browser.cjs` 验证手机入口、实际选择、结算和刷新；`node scripts/simulate-realms.mjs` 可运行固定种子、自动走位的实战模拟（远征按新规则抽取装备）。初版数值仍需结合人工试玩调整。
- `tests/expedition.test.mjs` 验证全目录实战、抽取存档和升级隔离；`tests/expedition-browser.cjs` 在隔离端口 4197 检查真实点击、音效、320/390/1280 布局及昼夜设置下的同屏效果。补给绘制绑定及 `designCriterion` 见 `visual-contract.json`，连续相位入口见 `src/rendering/visual-review.js`。秘境保留原有恒定照明。

### 小猫正面视频动作

栗子与薄荷的主体仅使用正面待机和原地移动两种序列帧，按 24 FPS 播放，主体不会随瞄准方向旋转或镜像。小手、枪械、后坐、蓄能和实际枪口继续使用原有 `weaponPose` / `muzzlePosition` 链；碰撞、攻击判定、存档和移动速度不变。

六品种共享这套连续动作。`src/config/cat-appearance.js` 分别定义橘猫椭圆脸与尖耳、英短圆脸与小圆耳、美短宽实下颌、暹罗楔形脸与大耳、布偶脸颊毛束与颈毛、孟买猫圆耳与贴服短毛。`src/rendering/cat-breed-shapes.js` 从每张源帧识别颈线，再衔接局部头部；眨眼、口型、身体、脚步和尾巴继续来自真实视频帧。薄荷露出小耳朵，保留原来的配饰颜色。毛色处理仍由 `cat-coats.js` 完成，营地与实战使用同一资源，小手、瞄准、后坐和枪口机制保持独立。

衍生帧缓存最多 48 张，连同共享工作区与原图集总解码预算不超过 20 MiB。六猫的编号、名字、等级和选择保持兼容。`tests/cat-breed-shapes-browser.cjs` 检查全部 414 张品种帧的轮廓、耳尖边界、脚步像素和缓存，并录制走停/持枪演示；`visual-review.js` 的 `hero-breed-0` 至 `hero-breed-5` 使用同一正式绘制链逐项采样。

不可达目标由 `src/physics/cautious-pursuit.js` 独立处理：河面、湖心、山体和搜索失败时，地面近战单位不向目标接近，射程内单位寻找可通行的短撤退路线。距离按当前枪械、浮游炮和载具炮塔计算，规划每 0.25 秒更新；回到陆地后恢复追击，飞行目标掠过岸线有 0.5 秒稳定期。正常绕山、过桥、飞行怪与远程领主仍可作战，不增加无敌或跨水近战能力。

- 参考同目录 `char-animation` 的首帧生视频和源时间抽帧方法，从本游戏原有无枪主体导出首帧，生成两段 10 秒原片。蓝幕抠像保留绿色衣服；每名角色采用固定脚底、统一缩放和 160×160 帧格，不逐帧拉伸或底部对齐。原片、参考图、请求及服务结果保留在 `assets/cat-front/source/`。
- `assets/cat-front/animations.json` 记录原片 SHA-256、源帧编号、源时间、裁切与缩放、动作帧率、固定锚点和姿态匹配表。栗子待机 45 帧 / 移动 24 帧，薄荷待机 39 帧 / 移动 30 帧；各一张 1280×1440 PNG，解码 RGBA 总量约 14.1 MiB，不在游戏中播放视频。
- `src/core/battle/cat-motion.js` 按实际位移切换动作，阻挡、停车和驾驶使用待机；暂停与死亡冻结动作。`src/rendering/cat-animation.js` 选择相近姿态衔接并短暂平滑校正位置，每次只绘制一个主体，不淡入淡出叠加双重轮廓。减少动态模式固定待机首帧，资源缺失则回退原矢量角色。
- 复现首帧：在隔离端口 4174 运行 `scripts/cat-reference-browser.cjs`；`python scripts/cat-video.py collect` 只查询既有请求并获取原片。`submit` 会真实计费，已有请求记录时不会重复提交；本机客户端路径沿用 `char-animation`，其他机器需配置 `GENERATE_CLIENT`。
- 已有原片重新抽帧：`python scripts/extract-cat-frames.py`，需要 Python、Pillow、NumPy、OpenCV。无需重新生成视频；循环选段依据首尾轮廓和速度相似性自动选择，仍应检查输出预览。联系表、GIF 和录制预览位于忽略目录 `output/cat-front/`。
- 验证：`tests/cat-animation.test.mjs` 覆盖动作时钟、真实图集与源片哈希、枪口规则和失败回退；`tests/cat-animation-browser.cjs` 检查实际图集播放、起停、八方向持枪、载具待机、减少动态和 320/390/580 宽度，使用正式绘制链输出 `preview.webm`。

### 场景层次更新

- 现有六种山体与六种湖泊组成六组景观：岩壁分层、藤蔓、山脚投影与角色前后遮挡，湖面有深浅色层、单侧浅滩、睡莲和零散岸草。河流沙湾按左右岸独立生成，位置、长度、宽度均错开；山湖外围保留步行带，既有营地、田地和主路继续留白。
- 建筑瓦面增加受光边与搭接暗面，墙面区分亮面、背光面、檐影和墙根，地面投影收向石基；麦穗使用交错高度、亮穗顶和暗茎根，田埂补齐接触影。屋角与屋前透显平滑恢复，麦田仍逐行遮挡角色；建筑、麦田位置及活动空地保持原布局。
- 河岸使用错位沙湾和变化的草岸轮廓，干沙、湿沙、浅水、深水逐层衔接；淡色水纹沿原河道缓慢流动。`rendering/shore-art.js` 集中绘制水岸，少量苔石与水草放在外缘，桥头与沙滩中央留空。沿用原碰撞、桥面和瀑布遮罩，以及分块缓存和减少动态模式。
- 营地装饰集中在麦田后侧、屋旁和草场外缘：四段低栅栏、少量圆木堆、石簇及小花，屋前踏石延伸到主路。中央活动区和麦田正面留空；装饰沿用脚底遮挡与昼夜缓存，不增加碰撞障碍。位置在 `world/scenery.js` 的 `CAMP_PROPS`，图元在 `rendering/camp-props.js`。
- 营地核心区只保留少量边缘景观树，南侧草场连通桥头和屋前；小屋、帐篷、麦田与沙岸按完整树冠范围留白，外围疏林逐渐过渡到密林。`src/world/forest-clearings.js` 集中管理这些规则，采集树仍在原位再生。
- 草甸、林下和田边使用不规则大色块分区；河湾新增草岸断面、干沙、湿沙和浅水过渡，原有水域碰撞与桥梁通行不变。
- 全地图树冠统一使用亮顶、中间色与冷底影；右下投影和树根接触影先画在地面层，树冠随后参与实体排序，影子不会盖住前景角色。
- 小屋、帐篷和麦穗从地面绘制中分离。建筑按脚底排序，角色走到屋后时适度透显；麦田逐行排序，让前排麦穗遮住下半身。建筑补齐瓦顶、侧墙、檐影和石基，田埂保留侧面厚度。
- 装饰位置在 `src/world/scenery.js`，图集在 `src/rendering/scenery.js`。昼夜图集按需复用并纳入性能诊断；不增加采集奖励或改变存档。地图预览复用同一套地标。
- `tests/scene-depth-browser.cjs` 在隔离端口 4174 检查 320/390/580 像素布局、昼夜透显、真实麦田排序、地面分块与循环镜像，截图输出到 `output/playwright/scene-depth/`。通过 Playwright CLI 的 `run-code --filename tests/scene-depth-browser.cjs` 执行。

### 自然地貌模块

`src/world/natural-terrain.js` 是纯数据生成入口，当前场景统一使用 `NATURAL_TERRAIN`（版本 2、固定种子 743），刷新不会重新洗牌。调用 `generateNaturalTerrain({ seed })` 可以复现其他种子的山湖与沙湾数据；支持传入 `lakeZones`、`mountainZones`、`beachZones` 和 `reserved` 定制候选区域及保护区。输出包含可 JSON 序列化的轮廓、阻挡包围盒、绘制范围和生成版本，后续可接入地图种子选择与存档；当前没有在每局开始时随机替换地图。

`src/world/landscape-compositions.js` 在这些地貌上生成组合景观：山脚草地、花石组团，湖畔单侧宽沙滩、芦苇、漂木、小木凳及萤火虫栖息地。`generateLandscapeCompositions(terrain, { reserved })` 返回可序列化的 `sites / props / habitats`，与输入地貌种子一起复现，不修改水界和障碍。底色进入原地块缓存，摆件共用昼夜图集并按脚底排序；草沙交界避开营地、秘境入口与主路，外围树林保留。`tests/landscape-compositions.test.mjs` 和 `tests/landscapes-browser.cjs` 覆盖组合留白、湖岸漂浮、手机昼夜同屏与图块接缝。

- 湖区配置使用 `{ x, y, rx, ry }`，山区额外提供 `height`；候选点小幅偏移，自动避开道路、河流、保护区及其他地貌。尝试次数有上限，找不到安全位置就省略该地标。
- 沙湾配置使用 `{ side: -1 | 1, y, rise, fall, depth }`，分别描述岸侧、中心、前后长度和最大宽度。`riverBeachWidth(y, side)` 是沙滩绘画及植被避让的共同入口。
- `src/world/paths.js` 独立提供道路数据及距离查询，生态区保留原导出兼容入口。山湖轮廓查询同时供碰撞、出生点、降落、植被和雨滴使用，避免出现画面是湖水而逻辑仍可行走的情况。
- `src/rendering/natural-terrain.js` 负责绘制：湖泊与山影进入既有地块缓存，岩山使用按需昼夜图集并按脚底排序，小地图复用同一数据。性能诊断新增 `naturalTerrain` 图集占用。
- `src/physics/terrain-navigation.js` 负责湖山绕行及安全干地搜索，追兵仅在受阻时规划路径并复用结果，跨河继续经过木桥；飞行单位可越过地貌，近战追兵遇到不可达目标会停止靠岸，并从射程内退开；飞行怪和远程领主保留攻击能力。
- `tests/natural-terrain.test.mjs` 覆盖种子复现、保留区、非对称沙湾、高速碰撞、实际敌人绕行、飞行与降落、周期镜像和雨面。`tests/natural-terrain-browser.cjs` 在隔离端口 4174 检查三种屏宽、昼夜、地块接缝、山体遮挡和地图预览，截图在 `output/playwright/natural-terrain/`。

## 玩法

- 游戏使用全高竖版布局：手机占满动态视口，横屏电脑居中显示竖版战场；支持的浏览器可点击右上「⛶」进入或退出浏览器全屏。页面本身不滚动。
- WASD、方向键或左下摇杆移动，自动优先攻击范围内的怪物，没有怪物则攻击树木。
- 四片区域以道路旁的木质站牌标注区域名与等级范围，移除地面刻字；站牌仅作装饰，按脚底参与遮挡，角色走到牌后时透显。位置在 `world/signposts.js`，绘制在 `rendering/signposts.js`。
- 栗子（橘色田园猫）、薄荷（英短银渐层）、银豆（美短银虎斑）、摩卡（暹罗）、雪团（布偶）和墨墨（孟买猫）六名角色，十四把武器：松果手枪、萤火激光步枪、蜂群加特林、橡果散弹枪、星籽弹射枪、潮汐水枪、松雷榴弹枪、赤枫火焰喷射枪、苍隼狙击枪、雷霆重型脉冲枪、鸣雷电弧枪、霜枝冰晶枪、蜂群无人机和星环浮游炮。新枪均可购买、装备与升级，旧存档自动补齐锁定槽位。
- 射击时枪身后退、枪口抬升并以阻尼弹簧回正：手枪为强单发后坐和套筒动作，激光步枪为双手持枪的小幅连续后坐。闪光跟随枪口，曳光从发射时的枪口位置飞出。
- 手枪子弹以 920 世界像素/秒实际飞行，命中后才扣血、跳字并回收，树干会阻挡子弹；激光用短脉冲束贯穿沿途目标。弹道在开火时锁定方向，走位可以躲开实弹。
- 命中交点产生定向火花、木片或怪物碎片，暴击反馈更强；击杀增加扇形碎片、烟尘与扩散环。手枪另有抛壳和枪烟，怪物受击会短促形变并沿弹道被推离，领主体重更大、击退更小。
- 击败怪物获得金币，破坏每棵树木获得 4 金币和 8 木材，资源自动收集；调整只影响后续采集，不改变已有库存。
- 普通怪和精英怪靠近后会停止追踪、变红蓄力，头顶出现「!」并在地面显示锁定的扑击路线。横向走出红色区域可躲开；扑击后会回到出手位置并短暂收招，此时可以安全反击。
- 点击战场右侧「角色」打开角色养成面板，招募、切换或升级角色；「武器」打开武器工坊，也可在面板内切换分类。最高 20 级，升级效果即时生效，资源与头像同步刷新。
- 打开养成面板自动暂停战斗，关闭或按 Esc 后恢复；如果打开前已暂停、尚未开始或已倒下，关闭面板保持原状态。弹窗独立滚动，桌面侧栏和页面下方的营地已收进弹窗。
- 地图遭遇：仅在等待领主的探索时段，主动移动时累计 4–8 秒，在周围安全的画外位置随机出现一只当地怪物，最多同时 6 只；停下不继续刷新。遭遇怪不占波次配额、不计入清波，等待领主时仍可探索遇怪，整组波次（含预警、休整）、领主战、剧情或秘境期间停止随机刷怪。开战不清理场上已有怪物，它们不影响波次结算。
- 分组怪潮：第 1 波 36 只，此后每波增加 8 只，按现有数值成长。波次怪从当前视野外围逐只进入；每组随机 3–5 波，组内清波后休整 3 秒自动继续，组末清波后停止波次刷怪，等待手动挑战领主。
- 每波入场前在原波次卡显示 3 秒金色预警。怪物从镜头范围外、距离角色至少 440 单位的位置逐只进入，入场间隔沿用波次表，开场逐渐增加同时在场上限；总配额和属性成长不变。首次进入、死亡续游与刷新恢复不再预置近身怪物。`core/enemy-arrival.js` 负责河岸、树干、环形边界及实际视口选点，无法安全落点则延后重试；Boss 战和暂停冻结入场计时。
- 每组 3–5 波全部清空后，点击左上波次栏的 Boss 头像挑战领主；角标显示距节点剩余波数，就绪时提示“点头像”。胜利获得原有资源并恢复生命，休整后自动进入下一组；领主失败保留节点，重新出发后手动重试。
- 倒下后显示抵达波次，保留资源与成长，点击重新出发回退 3 波（最低第 1 波），累计击杀、伐木、领主战绩保留；空格或右上暂停按钮可以暂停。
- 切到其他窗口会暂停；成长使用浏览器 localStorage 自动保存，波次、击杀进度、休整计时及 Boss 战斗进度一并保存；刷新后暂停等待继续，未击败普通怪按剩余配额重建。
- 顶部齿轮打开游戏设置，可查看玩法说明或清空进度。清空需要再次确认；确认后回到首次开始界面，资源恢复 60 金币 / 30 木材，角色、武器、等级、领主战绩与当前战场全部重置。天气、昼夜和声音偏好保留；取消不会改变存档。
- 首次点击进入后默认开启声音，设置中的声音开关可静音。
- 右上角天气按钮可选择晴朗、多云、小雨、雷阵雨，以及白昼、黄昏、夜晚；自动昼夜和随机天气可以分别关闭。
- 环境沿用 `game-slg`：每六分钟一轮昼夜（3 分钟白昼 / 1 分钟黄昏 / 2 分钟夜晚），20 秒柔和过渡，天气每 90 秒变化。环境依真实时间运行，暂停战斗时仍流转。
- 向东北探索可以看到瀑布、落水泡沫、溪流波光和木桥。雨天增加雨丝与涟漪，夜间呈冷色环境并出现萤火虫；角色和 UI 保持可辨。
- 环境设置单独保存在 `forest-patrol-environment-v1`，兼容原有角色与武器存档。系统选择减少动态时，河流恢复静态、停用雨丝，萤火虫保留静止光点，保留环境配色。

新枪购买同时要求领主战绩与资源达标，工坊会显示累计进度。每组 3–5 波清空后可手动挑战领主；战绩跨巡游、倒下与刷新永久保留，不因购买扣除。已拥有的旧枪保留使用和升级资格，初始手枪、角色购买及升级费用不变。

工坊按领主解锁门槛升序排列，同门槛按金币、木材价格排序。`WEAPON_DISPLAY_ORDER` 只保存展示索引，原武器数组及存档编号不重排，画像、购买、装备、升级、熟练度和改装沿用原编号。`tests/weapon-display-order.test.mjs` 与 `tests/laser-balance-browser.cjs` 验证旧存档和排序后的真实购买升级流程。

`src/config/weapons.js` 管理目录；`src/combat/ballistics.js` 管理发射快照、扇射、扫掠碰撞、去重弹射、射程回收与尾迹。自动瞄准优先怪物/领主，再选树木；实弹仍会撞到弹道上的树干，绕开树木可建立射线。

`src/physics/motion.js` 是轻量物理模块：角色加速/刹停、4 像素分步移动与滑动碰撞、按质量缩放的击退冲量、碎片高度轴重力/回弹/摩擦。玩家、怪物和领主不能直接穿河，只能走木桥；怪物从桥头绕行，扑击与击退也受河岸限制。碎片平面速度沿来弹方向，重力单独作用于高度；这是二维游戏的近似物理，不是完整刚体引擎。

`src/rendering/forest-art.js` 参考 `game-slg/assets/art-direction-v2.png` 的分层树冠、暖色木材、苔藓石块、花圃与蕨叶，独立绘制四组树冠配色、花树、蘑菇、河岸踏石和营地小屋。树木持续轻摆，受击后在 0.7 秒内弯曲回正一次。水纹沿共享河道中心线向下游流动，桥面遮罩保持固定。

源项目当前仍是 60 秒周期；本次按放慢节奏的要求主动延长到 360 秒，光照渐变由 6 秒改为 20 秒。环境存档带周期版本，旧存档保留选定时段并重新建立计时锚点。

## 材料解锁与装备目标

怪物新增机械零件、能源晶体随机掉落和保底，精英稳定掉落，Boss 每次必掉首领核心。新材料只用于首次购买枪械、炮塔与高级载具；已有装备、累计资源和养成不变，升级仍用金币木材。

武器与载具工坊显示材料库存、完整需求和掉落来源，可追踪一件未拥有装备。战场只显示紧凑目标提示，材料齐备后可直接跳转对应工坊。死亡、刷新保留材料、保底与目标；设置确认清档会一起重置。

配方、迁移、前 1–3 小时路线假设与验证方式见 [材料经济说明](docs/material-economy.md)。运行 `node scripts/economy-sim.mjs` 可复现 100 组收益模拟；这是经济估算，不代表已完成三小时真实战斗测试。

`tests/portrait-browser.cjs` 使用真实浏览器检查 1440×1000、390×844 和 320×568 视口、角色招募升级切换、武器购买、面板暂停恢复、摇杆复位与成长存档。通过 `playwright-cli -s=portrait run-code --filename tests/portrait-browser.cjs` 运行，截图保存在 `output/playwright/portrait-*.png`。

`src/combat/recoil.js` 统一后坐参数、弹簧积分与持枪坐标；后坐只作用于射击表现，不额外改变命中、伤害或角色位置。连射限幅，换枪与重生归零，暂停冻结动作，减少动态模式降低幅度。`tests/recoil.test.mjs` 验证上述状态与不同帧率的回弹一致性。

## 攻击与特效参考

参考 [guccang/TopDownShoot](https://github.com/guccang/TopDownShoot/tree/20439afc3fabe1de76f07d5bbcde158ed58b41c0) 的 `Gun.cs`（枪口生成、射速与初速）、`Projectile.cs`（逐帧扫射线、出生重叠检测、生命周期）和 `Enemy.cs` / `Enemy Death Effect.prefab`（按命中方向定向喷散死亡粒子）。本项目独立实现 Canvas 2D 版本，没有复制 Unity C#、预制体或素材。

`src/combat/collision.js` 用线段扫圆代替三维射线碰撞。手枪首次命中即销毁，激光每发对同一目标只结算一次，修正参考源码未回收命中弹体可能重复伤害的问题。

激光步枪定位为早期清线武器：基础伤害 12、射击间隔 0.24 秒、射程 300、弹夹 20 发、换弹 2.2 秒。每束最多命中 3 个目标，伤害比例为 100% / 50% / 25%，树木、怪物与领主均计入，光束停在第三个命中点。累计衰减保留小数，每个目标结算时四舍五入，取整为 0 后停止结算；基础伤害依次为 12 / 6 / 3。近枪口重复交点和已死亡目标不额外消耗名额，每次射击重新计算。暴击、升级、熟练度与两种改装同样遵循此规则，其他枪械不变。计入换弹的理论单目标持续输出约 35.5（无成长、无暴击且持续命中）。`tests/laser-falloff.test.mjs` 验证真实扣血、光束终点、混合目标、去重、死亡目标、改装、暴击及循环边界。

`src/combat/effects.js` 使用有上限的 260 个瞬态粒子，独立随机源不影响暴击与刷怪。战斗暂停冻结弹体和特效，重生清空，换枪不修改在途子弹。减少动态模式隐藏烟雾、抛壳、扩散环和受击形变，保留弱化的命中提示。`tests/combat.test.mjs` 覆盖高速跨越、首次碰撞、贴身穿透去重、脱靶、奖励去重与清理。

浏览器启动后可运行 `playwright-cli -s=combat run-code --filename tests/combat-browser.cjs` 生成六种战斗效果的联系图；`tests/recoil-browser.cjs` 检查两种武器的实际巡游、装备状态、手机布局和低动态模式。截图写入 `output/playwright/`。

怪物攻击在 `src/combat/enemy-attack.js` 实现「追击 → 前摇 → 扑击 → 回位 → 收招」状态机，参考同版本 `Enemy.cs` 的锁定落点和往返位移。普通怪前摇 / 扑击 / 回位 / 收招分别为 0.48 / 0.18 / 0.32 / 0.55 秒，精英怪为 0.64 / 0.24 / 0.40 / 0.65 秒。前摇开始即固定方向，扑击去程用相对运动线段扫圆判定接触，每次最多结算一次伤害（基础值随区域等级与怪物阶级增长）；回程、收招和单纯贴身不造成伤害。攻击去程的伤害判定替代源项目的固定时间直接扣血，因此玩家确实能通过走位躲避。

地面预警对应扑击扫掠区域；低动态模式仍显示关键预警和真实位移，但取消额外的蓄力压缩与弹跳。暂停冻结攻击，击杀取消攻击，回位后收招完成才继续追击。`tests/enemy-attack.test.mjs` 验证躲避、单次伤害、回程安全、帧率一致性与状态清理，`tests/enemy-attack-browser.cjs` 生成各阶段画面并验证手机及低动态渲染。

## 循环森林与等级分区

地图以 3600 × 2800 为一轮（原地图宽、高各扩大一倍，总面积为原来的四倍），走出四边会连续进入另一端；镜头、河流、道路、跨边界瞄准和资源吸附均使用同一循环坐标。保留原营地和木桥，向东、向南扩展林团、支路及河道，四个等级带重新覆盖整张地图。角色、树木、道路宽度和武器射程保持原尺寸。河岸仍不可直接穿越，必须走桥。右侧「区域」可查看地形、当前位置与四个等级带，打开时暂停战斗。

| 区域 | 等级 | 环境与怪物 |

| 晴叶营地 | 1–3 | 绿叶阔叶林、花草、芽团 |

## 子弹动能、滚地与连锁撞击

弹道和怪物冲量用不超过 1/120 秒的物理子步计算。实弹拥有初速度、空气阻力、高度、重力和运动尾迹；命中冲量随剩余速度减弱。散弹较快减速，水弹有明显弧线，弹射弹触地最多回弹两次，每次损失速度与高度。射线扫掠避免高速穿过目标，激光保持瞬时穿透。

怪物受击按质量获得冲量，强冲击会打断前摇/扑击，短暂腾空、旋转滚地、落地产生烟尘，随后由地面摩擦减速回正。碰撞按照双方相对速度与质量传递冲量，可连续撞动第三只怪物，也可在滚动中再次受击；高速撞击会伤害被撞者。死亡后留下短暂滚动残骸及定向爆裂碎块，沿来弹方向飞散，不重复结算奖励。河岸和树干会阻挡滚动。

`src/rendering/monster-atlas.js` 参考同版 `game-slg/dog-animation.js` 的「帧清单、独立动画时钟、固定脚底锚点」技术，使用本地 Canvas 预绘制图集，提供待机、滚地、回正和爆裂序列，按 24 FPS 取帧。没有复制源项目角色素材。物理位移、腾空与滚转叠加到帧动画上，暂停冻结动作，减少动态模式保留实际位移和必要预警、降低视觉运动。

`tests/world-impact.test.mjs` 验证循环移动与河流接缝、跨边界命中和躲避、固定林团与等级成长、多体连续撞击、质量差异、帧率一致性、弹丸阻力/回弹、暂停与奖励去重。`tests/world-impact-browser.cjs` 验证 390/320 像素手机布局、区域地图暂停恢复、循环画面的像素一致性及四边无空白，并生成区域与滚地序列联系图。

`tests/weapon-progression.test.mjs` 验证领主门槛、两种资源不足时的事务原子性、刚好达标购买、战绩保存与旧枪兼容；`tests/weapon-progression-browser.cjs` 检查手机工坊提示、按钮状态、实际扣费及刷新保留装备。


## 森林音乐与音效

首次点击进入游戏后启用音频；主动关闭过声音时，在设置中重新开启。背景音乐与战斗/喵喵音量可以分别调节，设置页保留背景音乐试听，音效滑块调整完成后播放提示音。总开关和两条音量保存在独立键 `forest-patrol-audio-v1`，清空游戏进度不会删除声音偏好；刷新后等待首次点击或按键解锁浏览器音频设备，不自动播放。

- 背景为原创 88 BPM、十六小节、约 43.64 秒循环的森林主题，使用木琴、拨弦与柔和低音。夜晚降低明亮度，Boss 战稍微让出音乐音量。暂停时记录播放位置，继续后恢复。
- 15 种枪械各自使用机械瞬态、低频冲击、能量扫频、水泡、喷流或电锯音色。手持、独立炮塔与浮游炮挂载按实际枪型共用声音；榴弹爆炸和雷声保留独立低频音效。
- 换弹增加拔出弹夹与插入上膛两段提示，能量枪使用充能启动与完成音。由统一弹夹时钟触发，手持、载具、无人机和浮游炮均适用；浮游炮返航入坞后才播放开始声，弹药真实补满时播放完成声。暂停、切枪、下车不推进声音或重复提示；同时换弹合并同类声音，并在密集交火中优先保留装填提示。
- 松果轮式战车与主战坦克各有不同发动机循环，主战坦克保留履带声，直升机使用旋翼拍击。移动提高转速，上下车有启停声，装甲受击与角色受伤区分。
- 猫猫出发、受伤、胜利、倒下分别使用不同的合成猫叫；叫声有冷却，倒下声音可以替换尚未结束的受伤叫声。

`src/platform/audio-sounds.js` 提供可缓存的音色；`audio.js` 管理分轨、限流、压缩和生命周期；`audio-music.js` 提供音乐编曲与异步加载。音乐已预生成为 `assets/audio/forest-theme.wav`，手机仅异步解码；修改编曲后运行 `npm run build:audio`。首次使用时缓存短音效，循环至多两条，瞬态至多二十条，同枪型射击限频，节点结束后断开。后台、暂停与静音会停止战斗声和载具循环；设置页仅保留音乐试听，关闭设置后恢复原状态，销毁应用关闭设备。全部素材为项目内原创程序合成，不请求外部音频服务。

`tests/audio.test.mjs` 覆盖音色、限流、缓存、偏好隔离、异步完成时静音/销毁以及事件路由；`tests/reload-audio.test.mjs` 覆盖四类持有方式的换弹时机、切换冻结、返航入坞与分型提示；`tests/audio-browser.cjs` 在隔离端口 4174 验证真实 WebAudio、移动端设置、载具切换、暂停和刷新手势恢复。

## 无尽波次难度

`src/config/waves.js` 统一配置每波配额和强度。令 `n = 波次 - 1`：怪物总数 `12 + 4n`，基础生命倍率 `1 + 0.12n`，攻击倍率 `1 + 0.16n + 0.015n²`，移速倍率 `1 + min(1.4, 0.055n)`。第 1–3 波的生命再分别乘 0.55 / 0.70 / 0.85；普通怪和领主均使用该生命倍率。生命移除原先的平方增长，第 13 波倍率由 7.48 降为 2.44（约减少 67%），数量、攻击、移动、奖励与武器成长不变。以上乘在出生区域与阶级的基础属性上，跨区不会清空当前波次，已出生怪物也不会中途突然改属性。

| 波次 | 本波总数 | 生命倍率 | 攻击倍率 | 每批数量 |
| --- | --- | --- | --- | --- |
| 1 | 12 | 0.55 | 1.00 | 1 |
| 5 | 28 | 1.48 | 1.88 | 2 |
| 10 | 48 | 2.08 | 3.66 | 4 |
| 13 | 60 | 2.44 | 5.08 | 5 |

旧存档未完成的领主挑战由 `src/progression/boss-health-migration.js` 一次性更新血量。旧快照未保存挑战波次，因此使用未改动的攻击数值还原原始挑战波次，按新旧生命倍率换算最大生命，并保留当前剩余生命比例；迁移版本避免每次刷新再次削血。死亡重试继续保持迁移后的挑战强度，已有资源、装备和累计战绩不变。

第一波只出现基础怪，第二波开放高阶怪，第三波起开放精英并继续随波次提高概率。营地前三波的正常环形刷怪优先选择营地区域的落点，避免在邻接高等级区域刷出强怪压到出生点；主动进入高等级区域仍会遇到当地等级的怪物。营地第一波基础怪为 20–28 生命，初始手枪 18 伤害，两发非暴击即可击杀。这个开局减免按波次生效，不会因临时换枪改变已出生怪物属性。

刷新间隔从 1.8 秒起每波乘 0.88，最低 0.32 秒，每三波增加一个批量单位，最多每批 5 只；同屏最多 48 只，空出位置后继续补足本波配额。数量限制用于控制多体碰撞开销，后续波次的总数量、生命和攻击仍持续增加。怪物出现时距离玩家 320–430 世界像素，继续保留前摇、可躲避扑击和受击打断。

只有真实击杀本波怪物才能推进，砍树或远离目标不算完成。远处追击怪被回收时退还出生配额，再从玩家附近补刷，防止丢失最后一只而卡关。普通战斗全部清除后休整 3 秒。Boss 战中冻结刷怪计时、休整倒计时与波次推进，已在场小怪继续攻击，真实击杀仍记录配额；击败 Boss 后才恢复该波的休整或补刷。领主挑战保持每 12 次击杀解锁，首次召唤按当时波次与本局已击败领主数生成强度，领主战绩仍用于枪械购买。

暂停冻结波次和休整倒计时。倒下后停止战斗，显示本次抵达/完成波次；重新出发从第 1 波开始，永久资源与成长保留。使用设置中的清空进度会一并恢复初始成长。波次仅属于本次巡游，不写入永久存档。死亡重开的前三波普通怪生命与攻击额外乘 0.8 / 0.9 / 0.95，第 4 波恢复正常，数量配额不变。Boss 不受这项缓和影响。未完成挑战的最大生命、接触伤害、技能伤害与移速记录在永久字段 `bossChallenge` 中，死亡重试与刷新保持强度并重新满血；战胜该领主或清空进度时才清除记录。

`tests/waves.test.mjs` 覆盖逐波成长、真实清波、连续推进、出生配额、同屏上限、远处怪物补刷、暂停冻结、实际扑击致死和重开保留成长。

## 榴弹、火流与雷阵雨

- 松雷榴弹枪：3000 金币 + 1050 木材，累计击败 5 次领主解锁；普通点射基础伤害 17、间隔 0.32 秒。首次有效攻击后连续交火满 3 秒额外抛射一枚榴弹，锁定当时落点，落地半径 110，中心伤害为当前普通伤害的 4 倍，边缘递减到 55%，并向爆心外击退。怪物、领主与树木均受影响，玩家不受自己的爆炸伤害。
- 榴弹计时显示在角色状态区；失去范围内目标、切换装备或重新出发会清零，暂停冻结。普通射击与榴弹并行；换枪、升级不会改变已经飞出的榴弹。

### 雷雨画面

闪电采用与怪物相同的本地 Canvas 图集技术：24 FPS、18 帧，依次播放引导放电、主干与两级分叉扩散、余辉消退。三种固定形状按次轮换，最多缓存约 14 MiB 像素，不逐帧重建电弧。亮芯、蓝紫光晕、云层散射、湿地反光和实体背光投影一起变化；雷声沿用延迟播放与声音开关。闪电仅为环境表现，不造成伤害。

降雨分为远处细雨、世界坐标雨滴和近镜头风雨，具有不同的粗细、尾迹长度、下落速度和透明度。世界雨滴有固定落点，落地后播放八帧水花：河面扩散圆波、道路溅水与湿润反光、草地细溅、树冠滴水分别绘制，桥面不会出现河面圆波。雨场沿地图周期重复，只计算视口附近的网格，不影响战斗随机数；雷阵雨比小雨更密、更快。

系统开启减少动态时，停用闪电、雨丝、水花与相关动态光影，保留天气色调。昼夜周期、天气切换、战斗数值与存档格式不变。

## 苍隼狙击枪与高动能击杀

狙击枪以 1900 世界像素/秒发射实体穿甲弹，射程 700，约为手枪的 2.7 倍。弹丸保持原方向，最多命中 6 个不同目标，树木和领主同样消耗穿透次数；每次贯穿后伤害乘 0.86 并四舍五入，最低保留初始伤害的 50%。基础连续伤害为 92 / 79 / 68 / 58 / 50 / 46。每颗弹对同一目标仅结算一次，离开射程后回收；不会直接对整条射线瞬间扣血。自动瞄准继续优先怪物。

长枪管、瞄准镜、白蓝曳光、短促枪口气浪和独立的低沉枪声区分这把武器。后坐与枪口抬升使用较强、回正较慢的弹簧参数。命中产生局部亮芯和定向冲击波，致命命中进一步增加沿弹道喷散的木块、怪物碎片、尘团与腾空高度。怪物残骸先翻滚后逐帧爆裂，保留 1.05 秒参与连锁碰撞，仍受质量、河岸、树干、重力与摩擦约束；奖励不重复发放。

镜头不受战斗冲量影响；减少动态模式关闭气浪和高能闪光，保留真实弹丸与伤害反馈。粒子仍限制在 260 个，残骸最多 20 个。配置追加在武器目录末尾，已有八把武器的索引、价格和伤害不变，旧存档仅补齐锁定的狙击枪槽位。

`tests/sniper.test.mjs` 验证远射程、贴身和跨地图贯穿、伤害衰减、帧率一致性、购买与旧档、在途快照、击飞碰撞和清理。`tests/sniper-browser.cjs` 验证工坊购买升级与刷新保存，生成 `output/playwright/sniper-sequence.png` 实战序列图，并检查窄屏与减少动态模式。

狙击枪和重型脉冲枪优先选择能贯穿最多怪物的射线，选中后锁定该目标组，角色走位和目标移动时持续更新瞄准，前排死亡和侧面新怪不会抢走整组锁定；原组全部死亡或离开射程后立即选择下一组，不再等待 0.65 秒。脉冲枪镜头平滑注视角色与锁定射线最远怪物的中点，偏移受角色完整可见范围限制；为两名角色、长枪、后坐抬升和头顶换弹环保留至少 12 像素边距。目标位置与缓动过程都执行边界约束，窗口缩窄的首帧也不会出屏。采集树木时平滑回到角色跟随视角，不因远树拉长构图；瞄准线、射程、穿透和选敌不变，普通武器仍保持角色跟随。普通武器手机缩放固定为 0.85，宽屏固定为 1.05。狙击枪使用固定广角：手机 0.60、宽屏 0.75，可见宽高增加约四成。脉冲枪使用原始倍率除以 1.2（手机约 0.7083、宽屏 0.875），可见宽高增加两成。脉冲保持原有中点跟随、缓动和可见边界限制；狙击仅跟随角色，不向目标偏移，换弹、空场和换目标不改变倍率，从脉冲切入时立即清除原有偏移。不进行动态拉伸或战斗震屏。远距瞄准线和贯穿标记仍与真实弹道一致。

## 重型脉冲枪

雷霆重型脉冲枪在锁定目标后蓄能 1.2 秒，释放基础伤害 240 的实体脉冲，再冷却 1.1 秒。射程 820、初速 2300、碰撞半径 9，最多贯穿 12 个不同的树木、怪物或领主，每次伤害保留 95%，最低保留初始伤害的 50%。沿途目标依真实飞行先后受击，同一发不会重复造成伤害。丢失全部目标会散能，暂停冻结蓄能，换装与重生清空蓄能；在途脉冲保留发射时参数。

保留狙击瞄准线、距离提示和贯穿序号。蓄能时双层约束环收拢，20 条螺旋粒子流向枪口汇聚，枪身与双手的局部震动随蓄能增强，脚底和实际瞄准不受影响。发射时以粗壮亮芯、宽层辉光和侧翼电流组成能量通道；通道固定在发射原点，仅延伸到实际飞过的位置，停止后在 0.26 秒内衰减，不产生二次伤害。每隔 42 世界像素依次展开向两侧扩散的椭圆冲击波，同时保留短暂裂纹和物理碎屑；不会提前破坏前方地形。余辉保留原弹道，角色与瞄准线可立即跟踪下一目标，不等待余辉消失。致命冲击比狙击具有更大的碎裂气浪、更高的腾空与击飞速度；粒子仍上限 260 个，减少动态模式关闭枪身振动和汇聚粒子，保留进度弧与简化弹道。

开火向持有者施加与弹道相反的 360 速度冲量，按阻尼衰减，在开阔地静止时累计退步约 60 世界像素。反冲与摇杆速度分离，树干和河岸仍阻挡退步，不会被推穿地形。购买需累计击败 10 次领主，并消耗 7200 金币与 2600 木材；旧档新增锁定槽位，既有装备不变。

`tests/pulse.test.mjs` 覆盖蓄能、穿透、存档、后退碰撞和固定缩放；`tests/pulse-browser.cjs` 验证工坊、刷新保存、手机实战并生成 `pulse-sequence.png`。`tests/targeting.test.mjs` 验证密集射线选择、移动跟踪、击杀后立即选敌与中点镜头；`tests/target-lock-browser.cjs` 在真实渲染器中重放 180 帧前排死亡、侧面新怪和历史震屏冲量变化，确认锁定目标组与中点构图保持稳定。`tests/aim-tracking-browser.cjs` 额外验证走位蓄能、真实击杀后的同帧选敌和余辉期间的新瞄准线。

## 弹夹与自动装填

## 统一卡通森林与河流

环境美术以现有角色、怪物为基准：圆润轮廓、约 2.5 像素的清晰描边、低饱和色板和两级平涂。阔叶树使用云朵树冠与少量枝叶弧线；松树使用三层柔软垂枝；树干只保留一条高光。四个区域沿用各自配色，不再使用细叶、叶脉、树皮纹和体积渐变。

河水使用浅青色块与稀疏圆头波纹，河岸只有少量圆润卵石和草叶；瀑布使用宽水丝、云朵泡沫和圆水滴，两侧为平涂圆石。移除水下写实纹理、焦散、体积水雾和岩壁切面。

树木缓存最多 72 张昼夜及局部暖光图像，保留风摆、受击摆动和再生；河流按 24 FPS 更新局部画布，保留水流、雨天涟漪、昼夜过渡、桥面遮罩与减少动态模式。碰撞和仅能通过桥梁过河的规则不变。

## 枪械熟练度与互斥改装

每把枪独立积累永久熟练度：由该枪直接弹道或榴弹击碎树木 +1、击败怪物 +4、击败领主 +30；空射、重复攻击尸体和没有枪械来源的物理碰撞不增加熟练度。在途攻击记录发射武器，切枪后命中仍归属原枪。

熟练度等级 1–5 的累计门槛分别为 0 / 40 / 120 / 280 / 550，每升一级伤害 +2%，最多 +8%。它与花费资源升级枪械相互独立；倒下和刷新保留，设置中清空进度会一起重置。

熟练度 2 级解锁该枪的两个互斥分支。每次改装或换分支消耗 180 金币 + 60 木材，恢复原厂免费，重新装回仍要付费。十四把武器共 28 个分支，均有属性取舍，例如手枪快速射击/重弹、狙击轻型枪栓/钨芯穿甲、脉冲速充/过载、电弧分叉/聚能、冰晶深寒/霰射。改装不补弹，不叠加旧分支，也不改变在途弹丸；手持枪改装会清空尚未释放的蓄能。

`src/config/weapon-mods.js` 定义分支与统一有效参数，`src/progression/player/mastery.js` 负责奖励及扣费事务，`src/combat/elemental.js` 负责连锁判定。规则、工坊和 HUD 使用同一组有效属性。旧存档保留既有装备，补齐熟练度和改装字段，无需清空进度。

`tests/mastery-mods.test.mjs` 与 `tests/elemental-weapons.test.mjs` 覆盖存档、门槛、事务原子性、分支参数、在途归属、连锁、冰冻与暂停。使用独立 4174 端口运行 `tests/forest-mastery-browser.cjs` 可验证真实购买、改装及刷新保存，生成手机工坊、昼夜河流和元素弹道截图；不使用正式 4173 端口或正式进度。

## 夜晚萤火虫

黄昏到夜晚，萤火虫跟随光照权重渐入，白天渐出。整张循环地图保持 72 只：48 只分散于森林，24 只围绕两处湖畔花丛独立漂浮。每只拥有自己的漂移速度与发光相位，不追随其他个体；湖岸个体缩小漂移范围，停留在草沙交界附近，减少动态时保留静止光点。

`src/rendering/fireflies.js` 使用卡通柔光与亮芯绘制，不改变角色或 HUD。雨天亮度减弱，低动态模式停止漂浮与呼吸闪烁，保留静止光点。暂停战斗时仍沿用环境展示时钟，与河流、天气保持一致。

`tests/fireflies.test.mjs` 覆盖数量、随机源、帧率一致性、独立漂浮、跨边界、时钟恢复和光照；`tests/fireflies-browser.cjs` 在独立 4174 端口检查实际夜晚画面、独立散点数量、镜头稳定、昼夜及雨天亮度和 320 像素竖屏。

## 载具与武器工坊

开始巡游后，点击右下角 HP 血条下方的载具图标，即可召唤或下车；右侧「载具」入口打开收藏，预览四款载具、购买车体、选用及升级，并可查看各自耐久与炮塔。松果战车默认拥有，另外三款需要购买。收藏内有「载具养成 / 独立炮塔」两个页签，武器工坊也提供炮塔页入口。地面战车沿用树干碰撞、桥梁通行和循环地图规则；直升机可飞越树木和河流，低空仍受到怪物与领主伤害。主武器继续攻击，新增一个独立自动炮塔槽。十二种炮塔需要独立购买与安装，等级独立于手持枪；沿用同款枪械的领主门槛、价格、弹道、特殊技能、弹夹和装填时间，同型号共用熟练度与改装，不允许嵌套无人机或浮游炮。基础手枪炮塔售价为 120 金币、45 木材；其他炮塔价格与手持枪相同。购买不自动安装，已安装项置顶，可筛选已购买。

Boss 承受分级枪械击退：普通枪冲量系数 0.6、质量至少 6，合速度上限 55、阻尼 10，单次最大滑移约 5.5 世界单位。狙击与脉冲的冲量系数分别为 1.1／1.3，短时速度上限 125／180，增强窗口为 0.4 秒，之后恢复普通阻尼和限速。重击增加局部亮芯、定向冲击波与短促身体形变，额外特效每 0.09 秒最多一组；减少动态模式关闭形变与扩散环。以实际弹丸类型识别重击，浮游炮、载具挂载和切枪后的在途弹仍保持对应能力。所有枪械均不使 Boss 腾空、滚地或打断施法，撞树及河岸停止；被击飞的小怪不能间接撞退 Boss。野猪冲锋提示同步受击平移。参数在 `config/boss-combat.js`，绘制在 `rendering/boss-impact.js`。

Boss 援兵由 `core/boss-reinforcements.js` 独立调度：开战 10 秒后预警 2 秒，从镜头外每隔 0.7 秒加入一只；常规两只，Boss 半血后三只，批次结束后休息 14–18 秒。援兵最多 6 只，场上已有 12 只普通怪时延后增援；只生成基础阶级，生命为同条件普通怪的 65%、伤害为 70%。援兵给予正常击杀奖励，但 `wave=0`，不占主线出生配额、不推进主线波次；领主倒下后余兵撤离且不额外给奖励。暂停与死亡冻结调度，刷新恢复领主血量和主线进度后重新给予 10 秒准备时间。预警复用 Boss 血条，不新增常驻 HUD。

`src/combat/boss-terrain.js` 用空间索引处理五种领主技能毁树：野猪按实际冲锋路线、羽刃按移动线段、河龟按扩散环带、菇后与巨兽按生效区域摧毁树干。前摇、暂停及失效技能不毁树。碎屑和树桩再生沿用既有表现；Boss 毁树不奖励金币、木材、熟练度或采集计数。`tests/boss-terrain.test.mjs` 与 `tests/boss-combat-pressure.test.mjs` 覆盖受击、技能连续性、援兵归属、暂停恢复、地图接缝和奖励回归，`tests/boss-pressure-browser.cjs` 检查手机预警和重击画面。

## 手机卡顿诊断

手机宽度（≤600px）的战场顶部显示金币、木材与设置入口，下方紧贴波次卡，保留 Boss 头像挑战、怪物属性和击杀进度。进入 Boss 战后同位置替换为精简血条。区域说明、昼夜天气、暂停、音效及全屏控制放在设置页；打开设置临时暂停，普通关闭恢复战斗，选择「保持暂停并返回战场」则继续暂停。`src/ui/mobile-hud.js` 在屏幕宽度变化时仅搬移区域说明，波次卡始终留在主界面；`tests/mobile-hud-browser.cjs` 验证手机布局、资源与波次卡间距、嵌套环境设置、暂停归属、全屏与 Boss 召唤。

版本 `2026-10-20-render-pipeline-2` 默认在本机记录阶段耗时。访问 `/?perf=1` 可直接显示小型耗时面板，也可在「设置 → 性能诊断」开启。复现卡顿后点击「生成当前报告」，下载 JSON 或复制文本；局域网 HTTP 不支持自动复制时，会选中文本供长按复制。主循环停止后，独立面板会提示停滞。若整个浏览器主线程冻结，面板同样无法实时刷新，恢复后会记录长间隔。

记录最近 600 帧、最慢 30 帧、滚动 100 条事件和最多 40 条关键事件。初始化、首次怪物图集、预览中的怪物、进入战斗分别记录，避免混淆；战斗中怪物数量增加也有事件。每 15 秒、离开页面、首次画布上下文丢失及异常时自动留档。刷新后可点击「查看上次留档」。诊断存储键为 `forest-patrol-performance-report-v1`，清除诊断不会操作游戏进度，不向服务器上传日志。

计时口径：

- `logic`：游戏更新，细分寻敌、武器、弹道、刷怪、怪物物理与 AI 等。
- `render`：Canvas 绘制调用在主线程上的耗时，细分河流、实体、怪物、灯光、战斗特效和天气。
- `ui` / `storage`：界面刷新和同步存档耗时。存档可能嵌套在逻辑中，**子阶段不能再次与父阶段相加**。
- `interval`：真实回调到达间隔，未使用游戏限制为 50 ms 的 `dt`；后台切回重置基准，前台数秒冻结仍保留。
- `outside`：回调间隔减去上一帧回调耗时。这里只能提示浏览器调度、其他脚本、栅格化或合成的可能开销，不能当作 GPU 实测。支持的浏览器另记 Long Task / Long Animation Frame。
- 报告还包含尺寸与 DPR、resize、Canvas 上下文事件、已知缓存理论像素字节、初始化耗时及异常堆栈。理论字节不代表设备真实显存分配。合成的测试上下文事件标记 `trusted: false`。

### 本地排查结果（不能替代手机实测）

2026-10-20，在隔离端口使用 Chromium、390×844、DPR 2、CPU 4 倍降速，以新进度、手枪、晴天运行真实应用约 20 秒。未预热图集，也未替换正式 RAF；以下为第二轮记录末尾 120 个战斗帧的均值，包含波次休整：

| 项目 | 平均耗时 |
| --- | ---: |
| 游戏逻辑 | 2.84 ms |
| 怪物物理（包含在逻辑中） | 1.18 ms |
| 绘制提交 | 18.61 ms |
| 河流（包含在绘制中） | 9.89 ms |
| 怪物绘制（包含在绘制中） | 0.29 ms |

该轮平均约 36 FPS，帧间隔 P95 56.6 ms。第一次怪物图集生成 1.1 ms；世界初始化约 332 ms，渲染器初始化约 2822 ms。两轮本地记录均显示持续开销主要在绘制，尚未复现实机完全无法移动或真实 Canvas 丢失。

已确认的代码热点：出生点 390 宽镜头右边界约为世界 x=1129，河流缓存矩形从 x=1100 开始，因此只碰到透明边缘也会更新水纹。局部缓存虽已按纵向分块，但每块仍以 2 像素条带调用 `drawImage`，再重复绘制波光、遮罩。低帧率的真实时钟下，更多渲染帧会跨过 24 FPS 水纹更新时刻，固定 1/60 秒的预热测试可能低估开销。

另外，当前背景和河流已知缓存的 RGBA 理论下界为 98,000,000 字节（约 93.5 MiB），还未计前台画布及浏览器副本。库存列表签名包含整个进度，资源或巡游存档变化时，关闭的列表也会重建头像 Canvas。手机截图的空白静态图标使上下文与缓存压力值得继续验证，但不能仅凭截图断言内存不足；本次保留美术与战斗规则，先用报告区分具体原因。

`tests/performance-monitor.test.mjs` 验证计时口径、暂停、数秒冻结、有界记录和开关；`tests/performance-diagnostics-browser.cjs` 验证真实冷启动、刷怪、下载、刷新留档、异常停滞和诊断开销；`tests/performance-diagnostics-layout.cjs` 验证 320/390/580 布局、HTTP 复制回退及清日志不影响进度。浏览器脚本仅允许隔离端口 4174。

### 手机渲染管线优化（2026-10-20）

完整手机报告记录了 59 个战斗帧：平均约 3.24 FPS，逻辑 1.55 ms、绘制提交 99.35 ms，其中河流 75.38 ms、背景 17.95 ms。未记录真实上下文丢失。部分帧的 JS 已降至 17–24 ms，但 Long Animation Frame 仍超过 1 秒，提示浏览器绘制或合成也有压力，不能把这部分直接认定为 GPU 时间。

- `ground-art.js` 保留原种子、图元和地形布局；`ground-cache.js` 按视野生成 384 单位地块，最多保留 32 块，夜间纹理按需生成，淘汰时释放画布像素。`tile-blit.js` 对齐设备像素边界，防止固定缩放和循环地图出现细缝。区域地图直接缩绘原图元。
- `river.js` 按真实水域边界创建小块，透明边缘与离屏水域不更新；水纹仍按 24 FPS 流动，采样条带从 2 像素改为 8 像素，保留波光、瀑布、桥梁与岩壁遮挡。同帧及周期镜像复用结果。
- `scene-tone.js` 在现有画布内合成明暗和冷暖色，取消全屏 CSS filter 与混色 DOM 叠层，保留二十秒连续过渡。色调为视觉校准的近似合成，不承诺与旧 CSS 逐像素相同；白天、黄昏、夜晚已截图对照。菜单与暂停保留暗色遮罩，去除实时背景模糊。战斗美术、物理与连锁击退逻辑未改。
- 性能报告新增 `render.tone`、`groundCache`、`riverCache` 及实际缓存理论字节数，原有日志、导出、异常与留档功能保留。

本地第二轮对比：Chromium，388×748，设备 DPR 3.125、画布 DPR 2、CPU 四倍降速，基线为 `82ea756`。同样的固定种子场景分别运行 9 秒，以真实 RAF 更新，取末尾 120 帧均值；未混入 UI 列表刷新，不能当作真机完整应用帧率。

| 河边白天，12 怪 | 20.92 → 10.86 ms | 11.20 → 2.87 ms | 93.46 → 4.62 MiB |

该轮对应帧率为 44.0→51.8、32.4→50.6、14.3→22.2。第一轮夜雨为 22.0→21.9 FPS，说明复杂场景的总帧率存在较大波动；两轮河流提交耗时均明显下降，但没有真机优化后的 FPS 结论。缓存字节是已创建画布的 RGBA 理论大小，不包含浏览器副本、前台画布与其他实体缓存。

### 六类自然景观与自由组合

`src/world/landscape-variants.js` 保存四套独立目录，每类六种：

| 类别 | 形态 |
| --- | --- |
| 山体 | 草顶台山、错落双峰、石笋群峰、层叠台地、横卧山脊、环抱石冠 |
| 湖泊 | 豆荚湖、月牙湖、蜿蜒长湖、三湾湖、水滴湖、岩角湖 |
| 沙滩 | 弧湾、双湾、长岬、扇形沙洲、贝纹、起伏沙丘 |
| 树林 | 阔叶林、云杉林、白桦林、垂柳林、枫树林、柏树林 |

默认地图放置六组完整山湖沙岸，外围林团跟随组合选择树种；山脚与湖岸草坡相连，花石、漂木和木凳集中在边缘。全部湖泊沿用真实水界，气垫船仍可过水，山脚保留阻挡。湖畔萤火虫均分到各处花丛，总量仍为72只。

`generateNaturalTerrain({ seed })` 对四类目录分别洗牌；相同种子产生相同几何和搭配。`combinations` 可覆盖任意类别，支持6×6×6×6种目录搭配；位置不安全时省略地貌，不侵占道路。仍保留 `lakeZones`、`mountainZones`、`beachZones` 与 `reserved` 候选区接口，后续地图生成可替换选址。当前游戏使用固定种子，未添加运行时洗地图按钮。

```js
// 指定搭配可重复使用，其余形态由种子决定；不写入战斗或成长存档。
const terrain = generateNaturalTerrain({
  seed: 743,
  combinations: [{ mountain: 'twins', lake: 'crescent', beach: 'spit', forest: 'birch' }],
});
const landscape = generateLandscapeCompositions(terrain);
// landscape.groups 提供整组边界与成员；sites / props / habitats 分别供地面、排序物与环境光使用。
```

山体、树林共用现有昼夜图集和脚底排序。`visual-contract.json` 的 `landscape-group-0` 至 `landscape-group-5` 及 `-night` 案例复用实际绘制器。`tests/landscape-varieties.test.mjs` 覆盖目录组合、多个种子的六组完整性、岸线和林缘；浏览器脚本 `tests/landscape-varieties-browser.cjs` 在隔离端口4174检查昼夜手机同屏、整组图鉴及缓存接缝。
