# 团子PNG生成源记录

2026-11-10 使用内置 imagegen 逐种生成十五套透明部件图，没有使用 CLI。每个 `<id>-request.json` 记录实际提示词及生成来源，每个 `<id>.png` 为对应原始输出。统一参考上一阶段正式目录和首张雪帽团子部件图。

运行资源由 `scripts/build-dumpling-png.mjs` 使用 sharp 裁透明边、等比缩小和分区打包，不重绘生成内容。设置 SHARP_MODULE 可指定本地 sharp 模块位置。源图 SHA256 保存在上级 manifest.json 中；源文件不进入游戏分发包。

布局为左上身体、右上冠饰、左下左部件、右下右部件；不存在的部件保持透明。藤鞭没有顶部冠饰，左右独立藤蔓保留局部弯曲。脸、阴影、水纹与战斗特效由原运行时绘制。
